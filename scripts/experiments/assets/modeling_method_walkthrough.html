00 / THE WHOLE PICTURE

先用一句话抓住模型的工作

模型回答的是：给这条软臂施加这样的压力，考虑它此前经历过的动作，现在会形成什么形状？“当前压力”给出形变的主要趋势；两类记忆补充相同压力下的历史差别；几何生成把这些信息变成相互连接的节点位置。

四路压力历史做过哪些动作
→
当前参考 + 两类记忆现在在哪条响应路径上
→
局部角度与段长身体各处怎样变形
→
15个骨架节点全身占据哪些位置
论文式（1）zt = Fθ(zt−1, ut, Δt)
X̂t = G(Rθ(ut, zt))

第一行是更新记忆：用“上一步记忆 + 新动作 + 经过的时间”得到现在的记忆。第二行是生成形状：先把当前动作和记忆翻译成几何量，再把几何量拼成骨架。F、R、G分别是这三项工作的函数名，θ表示训练得到的一组参数。

训练时，相机提供答案

RGB图像 → SAM2掩码 → 有序中心线 → 15个节点。这些节点告诉模型“这段动作之后，软臂实际长成这样”。模型据此调整参数。

前向预测时，模型使用动作与记忆

给定动作和已有记忆，模型就能输出骨架。图像可以在下游反馈中修正内部状态；它并非这条动作到形状预测链每一步都要输入的特征。

一个有用的抽象：把模型看作“带记忆的身体计算器”。它保存的是一份可更新的历史摘要。输入新动作后，计算器先更新摘要，再算出身体形状。

本页的可调手算例子使用明确给出的教学系数；第12节另列当前正式模型的真实检查点与固定验证窗口。两者分别帮助理解计算和核对实现。

01 / READ THE SYMBOLS

符号看起来多，其实只有几类东西

下标 t 表示第几个时刻，c 表示第几个压力通道，i 表示沿软臂的第几个节点。粗体表示把多个数字排成一个向量或矩阵；帽子“ˆ”表示模型预测。求和符号“∑”就是“把指定的一串项加起来”。

u / a / e

u：物理压力命令；a=u/150：归一化压力；e=φ(a)：记忆算子使用的驱动坐标。论文常把归一化吸收到u的定义中。

p / q

p：play内部保留的位置；q=e−p：当前驱动与保留位置的差，也是送给几何读出的路径记忆量。

h / d

h：缓慢跟随驱动的时间记忆状态；d=h−e：跟随状态与当前驱动的差，是送给读出的时间特征。

r / τ / α

r：路径阈值；τ：时间常数，单位秒；α=exp(−Δt/τ)：经过一个采样间隔后保留旧状态的比例。

β / θ / λ / ℓ

β：局部转角；θ：相对固定坐标轴的累计方向角；λ：段长比例的自然对数；ℓ：实际离散区间长度。

ξ / X

ξ：角度与对数段长组成的几何坐标；X：节点笛卡尔坐标。前者描述“如何弯”，后者描述“点在哪”。

W / J

W：训练得到的记忆读出矩阵，把历史数字转换成几何变化；J：几何Jacobian，把微小几何变化转换成节点位移。

θ（参数） / z（状态）

参数θ在训练时学习，部署时通常固定。状态z=(p,h)随动作每步更新。参数集合θ与方向角θᵢ依语境区分。

向量、矩阵不是新的计算规则

向量只是有顺序的一串数。矩阵乘法就是多组“乘权重再相加”。例如两种记忆 q₁=0.2、q₂=−0.1，要预测两个角度的变化：

[ δβ₁ ]   [ 0.3   0.5 ] [  0.2 ]   [ 0.3×0.2 + 0.5×(−0.1) ]   [ 0.01 ]
[ δβ₂ ] = [−0.2   0.4 ] [ −0.1 ] = [−0.2×0.2 + 0.4×(−0.1) ] = [−0.08 ]

第一行说：两种记忆对第一个角度的影响部分抵消，最后增加0.01 rad。第二行说：它们对第二个角度的影响相加，最后减少0.08 rad。矩阵的每一行回答“这个输出受哪些输入影响”，每一列回答“这个记忆会影响身体哪些位置”。

02 / PRESSURE TO DRIVE

第一步：把压力换成模型更容易使用的坐标

输入：当前四路有效压力。输出：四个驱动坐标 e。真实采集保存六路命令，通过气腔联动提取四维有效输入。这里逐通道计算，所以先看一路。

例如压力为60 kPa，工作范围为0–150 kPa，归一化后 a=60/150=0.4。归一化只是在换刻度：0表示下限，1表示上限。随后用一个可学习、单调不减的折线函数φ，把a换成e。

a = u / 150，　e = φ(a)
φ(a) = ∑k wk max(a−κk, 0)，　wk ≥ 0

κ是折线开始增加斜率的位置；max(a−κ,0)在a没有到κ之前为0，超过κ后才增长。给这些“铰链”非负权重，加起来就是单调折线。当前实现还将权重整体缩放，使φ(1)=1，因此路径阈值r具有一致的驱动尺度。

把压力滑过一条非线性驱动曲线

教学折线：κ=(0,0.4,0.7)，原始权重=(1,0.8,0.4)，再除以上限处的值1.6。

意义：同样增加10 kPa，在不同压力区间对形变的影响可以不同。φ用少量参数调整压力轴上的敏感程度，让后面的历史算子在更适合这条软臂的坐标上工作。φ本身只看当前输入，历史信息从下一步的递推产生。
更深一层：非负、单调、可学习分别意味着什么？

代码用softplus(v)=log(1+exp(v))把任意实数参数v变成正权重。训练更新的是v，实际使用的是变换后的权重。当前5个铰链位于0、0.25、0.5、0.75、1。设正权重为sₖ，实际有效权重为wₖ=sₖ/[∑ⱼsⱼ(1−κⱼ)]，因此上限处的输出为1。

非负铰链保证每个单通道e随a不减，且斜率也不下降。这是一种受限的单调凸折线。最终节点坐标仍可以增大或减小，因为几何读出的系数可以带正负号，多个气腔也可以相互作用。

e是学习得到的无量纲驱动坐标。它的变化可用来组织历史，但其数值不直接等同于可测材料应变或腔内实测压力。

03 / CURRENT-INPUT REFERENCE

第二步：先给当前输入一个参考形态

输入：当前四维归一化压力a。输出：14个参考转角与2个参考对数长度，合成 ξref。这一步先回答：“只看现在的驱动，身体大致应该弯成什么样？”

ξref(a) = b + ∑c vc fc(ac) + ∑c<c′ vcc′ acac′

这里b是基准几何坐标，vc表示第c个通道对各个几何量的影响，fc是参考映射自己的单通道驱动函数。最后一项是两通道压力乘积，允许“两个气腔同时充气”的作用随组合而变。四通道共有6个不同的两两组合。

实现中有两套作用不同的驱动变换：参考项使用预拟合并固定的单通道函数 f；记忆分支使用前一节的可学习 φ。它们都由当前输入计算，但参数和用途各自独立。

先手算一个参考转角

假设一个局部转角满足 βref=0.1+0.3a₁−0.2a₂+0.1a₁a₂，当前a₁=0.4、a₂=0.6，则：

βref = 0.1 + 0.3×0.4 − 0.2×0.6 + 0.1×0.4×0.6
     = 0.1 + 0.12 − 0.12 + 0.024
     = 0.124 rad ≈ 7.10°

第一通道增加的弯曲与第二通道引起的反向弯曲在这里抵消，通道组合额外贡献0.024 rad。真实模型同时计算16个这样的几何坐标；参考函数的具体曲线和权重由训练数据拟合。

参考形态的地位：它是一条容易学习的主要趋势。加载与卸载到同一压力时，参考项相同，而历史修正可以不同。持续持压时，时间项逐渐消失，路径项仍可能保留，所以参考项并不必然等于所有加载历史共有的最终形态。
04 / PATH MEMORY

第三步：路径记忆怎样记住“从哪边走过来”

想象有一个以当前驱动e为中心、左右各宽r的滑动小盒子，里面放着一个标记p。盒子移动时，只要p仍在盒内，它就留在原处；当盒子边界越过p时，边界会把p推着走。这个简单规则就是play算子。

论文式（2）pt = clip(pt−1, et−r, et+r)
qt = et−pt

clip(x,L,U)的意思：小于L就取L，大于U就取U，在两者之间就保留x。p负责储存“上次被边界推到哪里”；q表示“盒子中心离这个保留位置还有多远”。q被限制在[−r,r]内，送给后面的几何读出。

把每次移动写出来：r=0.2

当前e上一p盒子范围[e−r,e+r]新的pq=e−p发生了什么
00[−0.2,0.2]00初始化
0.40[0.2,0.6]0.20.2下边界把p推到0.2
0.80.2[0.6,1.0]0.60.2继续加载，q到达正边界
0.60.6[0.4,0.8]0.60开始反转，p还在盒内
0.40.6[0.2,0.6]0.6−0.2反向行程累计0.4，到达负边界
0.40.6[0.2,0.6]0.6−0.2保持输入，路径记忆保留

关键就在两次e=0.4：第一次由低值加载上来，q=+0.2；第二次由高值卸载下来，q=−0.2。同样当前驱动，现在有了两个不同的历史标签，模型可以给出两个不同形态。

论文式（6）的第一行qt = clip(qt−1 + Δet, −r, r)，　Δet=et−et−1

这也是同一个规则，读作“把这次驱动变化加入已有记忆，再截到允许范围”。从+r走到−r需要累计反向变化2r，因此它不只是识别“正在充气还是放气”，还表达反转之后已经走了多远。

为什么两个公式完全等价？展开代数看看

由qt−1=et−1−pt−1可知，若p仍留在盒内，则qt=et−pt−1=qt−1+Δet。当这个数超过+r或低于−r，p恰好被相应边界推动，q截成+r或−r。于是三种情况正好合成clip公式。

保持e时Δe=0，q保持原值。在相同初始状态和相同驱动路径下，仅改变停留时间不会改变这一支的q。采样需要捕获路径的反转点，遗漏反转仍会改变计算结果。

多个阈值的意义：小r对较小的反转行程就会到达另一边界；大r可保留更长的反向行程信息。当前每个通道使用r=0.02和0.5两个固定阈值，读出学习如何组合它们。本页手算采用r=0.2，方便看清过程。
05 / TIME MEMORY

第四步：时间记忆怎样记住“变化发生多久了”

路径记忆在持压时保持不变，但软臂的形状仍可能继续变化。时间记忆为此引入一个缓慢追赶当前驱动的跟随量h。新目标突然升高，h一时跟不上；保持一段时间后，它才逐渐靠近新目标。

论文式（3）α = exp(−Δt/τ)
ht = αht−1 + (1−α)et
dt = ht−et

α位于0和1之间，是“旧跟随量占多少”；1−α是“当前目标占多少”。τ越大，α越接近1，旧状态保留越多，追赶越慢。输入增长时常见d<0，输入下降时可能d>0。这个差值的符号与持续时间都携带信息。

算一次从0跳到0.4的响应

设Δt=0.2 s、τ=1 s，起始h=0。α=exp(−0.2)=0.81873。

第1次更新：h₁ = 0.81873×0 + 0.18127×0.4 = 0.072508
           d₁ = 0.072508 − 0.4 = −0.327492
保持0.4，再更新：h₂ = 0.81873×0.072508 + 0.18127×0.4 = 0.131872
                d₂ = 0.131872 − 0.4 = −0.268128

当前输入没变，但d的绝对值变小了。读出可以把这段衰减转换成随时间继续发展的角度或长度变化。d<0本身不能直接说明向哪边弯：空间方向由Wh的系数决定。

调整时间常数，看追赶速度

为什么是exp？τ到底意味着什么？

若驱动在一个时间间隔内保持不变，一阶跟随方程 dh/dt=(e−h)/τ 的精确解就是指数追赶。经过τ秒后，初始差值还剩exp(−1)≈36.8%；经过3τ后还剩约5%。它描述一段时间尺度，不代表一个“到点就完成”的硬截止时间。

论文式（6）的第二行dt = α(dt−1−Δet)
dt = αtd0 − ∑a=1…t αt−a+1Δea

后一行把递推展开：每次过去的驱动变化都留下一个贡献，越久以前的变化，乘上的衰减越多。路径分支是有边界的行程累积，时间分支是会逐渐衰减的历史变化累积。

从h公式推到d公式；以及5 Hz和10 Hz怎么对应

因为ht−1=dt−1+et−1，代入得到dt=α(dt−1+et−1)+(1−α)et−et=α(dt−1−Δet)。再不断代入上一步，就得到带求和的展开式。

同一个τ下，5 Hz的α₅=exp(−0.2/τ)，10 Hz的α₁₀=exp(−0.1/τ)，因此α₁₀²=α₅。在相同恒定输入、相同初始状态下，两个0.1 s更新与一个0.2 s更新一致。若两次0.1 s之间动作已经改变，10 Hz捕获了更多输入细节，两种预测就可能不同。原生10 Hz建模还要保持时间常数和实际时间定义一致。

当前模型学到什么：使用6个固定时间常数，覆盖0.6–2.0 s；训练主要学习这些快慢成分分别如何影响身体各处。其τ和路径阈值r在当前配置中是固定网格，学习的是组合与几何作用。

从这个小例子扩展到真实模型

真实模型有8个q和24个d。有效Wp为16×8，Wh为16×24。它们各自输出16个修正量，再与16维参考相加。因此真实模型的矩阵乘法只是把上面的“一个q乘一列系数”扩成“很多个q各乘一列，再相加”。

实际代码的“增益 × 方向 × 尺度”如何对应W？

代码为每个记忆单元保存一个非负增益g、一个16维单位方向v以及统一的几何尺度s。该单元的有效列权重就是w=s⊙(gv)，其中⊙表示对应元素相乘。几何方向v带有正负号，因此非负g仍允许任意方向的身体修正。

弯曲部分还通过固定基矩阵B转换到14个局部转角。当前使用完整14维弯曲表示；可以把B并入有效W。教程第12节显示的是已经完成这些变换的实际角度、长度修正，所以能与论文的相加公式直接对应。

07 / FROM ANGLES TO POINTS

第六步：把转角和长度真正拼成一条臂

模型目前得到的是“怎样弯曲”，还没有得到坐标。下面沿着软臂从基座向末端走：先确定每一小段朝哪，再确定走多远，最后把位移逐段累加。

论文式（5）θi = ∑a=1…i βa
ℓi = ℓi0 exp(λs(i))
xi = xi−1 + ℓi[cos θi, sin θi]T
① 累加转角

β₁是首区间相对+x轴的方向；β₂起是相邻区间的方向变化。若β=(30°,20°,−10°)，则累计方向θ=(30°,50°,40°)。

② 把对数变回长度

若λ=ln(1.1)≈0.09531，exp(λ)=1.1。参考长度50 mm就变成55 mm。指数保证区间长度始终为正。

③ 分解并累加位移

长度ℓ沿方向θ走出去，横向位移是ℓcosθ，纵向位移是ℓsinθ。加到上一个节点上，就得到下一个节点。

第一段的具体计算

θ₁=30°，ℓ₁=55 mm，x₀=(0,0)
Δx₁=55×cos30°=47.631 mm
Δy₁=55×sin30°=27.500 mm
x₁=(47.631,27.500) mm

第二段：θ₂=50°，Δx₂=35.353，Δy₂=42.132
x₂=x₁+(35.353,42.132)=(82.985,69.632) mm

改变中间转角，看看哪些节点会跟着动

固定β₁=30°，β₃=−10°。三个区间参考长度均50 mm。

为什么上游转角能影响下游多个点？因为β₂进入θ₂和θ₃，第二、第三段都转了。第一节点不受β₂影响，第二节点和末端都会移动。这种几何累积正是“局部记忆修正形成全身位移”的关键。

对应当前15节点实现的几个约定

15个节点产生14个相邻区间。代码按7+7把区间分成两段，每段共用一个长度比例；标签节点按弧长构造，分组连接节点的位置需要与实际本体连接位置分别理解。每个区间拥有自己的转角，所以一整段不必都是常曲率圆弧。

β₁包含第一段相对固定x轴的方向；之后的β是相邻切向变化。计算使用弧度：1 rad≈57.30°。代码将λ限制在[−0.25,0.25]内，对应长度比例约0.779–1.284，再执行指数。第三空间坐标固定，训练接口仍保存xyz。

连接性与正长度由几何生成保证。避障、自交约束和接触力学需要额外任务或物理条件，不能单凭相邻点连接就推出。

第七步：模型究竟怎样从数据中学会这些系数

前面已经假设我们有参考映射和W。训练的任务就是确定这些数，让预测骨架靠近图像提取的监督骨架。公式规定了身体计算器的结构，数据决定这条具体软臂的参数。

骨架标签怎样反过来告诉模型“角度和长度应该是多少”？

先算相邻节点位移vᵢ=xᵢ−xᵢ₋₁；区间长度是‖vᵢ‖，方向是θᵢ=atan2((vᵢ)ᵧ,(vᵢ)ₓ)。atan2先接收纵分量，再接收横分量，算出向量朝向并区分象限。第一个转角β₁=θ₁，后续转角βᵢ=θᵢ−θᵢ₋₁，并把跨越±π的等价角度处理到一致区间。

例如相邻位移为(3,4) mm，则长度√(3²+4²)=5 mm，方向atan2(4,3)=53.13°。若前一段朝30°，这次局部转角就是23.13°。某一分段的总长若从参考100 mm变为110 mm，则λ=ln(110/100)=0.09531。

参考区间长度从训练窗末骨架的相邻距离统计得到。参考预拟合同时利用这些几何量与重建骨架误差，建立主要压力响应；随后几何坐标残差可用于初始化记忆读出。

初始W怎样拟合？先看最小二乘的意义

每个训练窗口计算一行历史特征v=[q;d]，同时计算该窗口的几何残差y=ξobs−ξref。把所有v排成设计矩阵V，把所有y排成Y，就要求V A接近Y，其中A相当于读出W的转置。

A* = arg minA [ ‖VA−Y‖²/N + ρ‖A‖² ]
A* = (VTV/N+ρI)−1VTY/N

第一项让历史特征解释几何残差；第二项惩罚过大的系数，使拟合更稳定。I是单位矩阵，转置T交换行列。实际求解使用线性方程，并先对特征和几何坐标缩放。上式表达其核心含义，避免把不同单位和数量级混在一起。

只有一个特征时尤其直观：q=(0.1,0.2)，希望修正的角度y=(0.02,0.04) rad，不加正则时w=(0.1×0.02+0.2×0.04)/(0.1²+0.2²)=0.2。于是每个q乘0.2正好得到两个角度修正。真实初始化一次拟合多个特征、多个几何量，之后仍允许联合训练继续调整。

MSE就是“对应坐标相减 → 平方 → 求平均”。平方让偏差大的点受到更大惩罚；末端项进一步提高远端在训练中的权重。训练MSE与报告用的骨架欧氏距离是相关但不同的量，前者便于优化，后者直接用mm解释误差。

用一个有15节点的简化误差例子算损失

假设只有末端预测错了(1,2,0) mm，其余14个节点都准确，坐标尺度s=10 mm。归一化后末端误差为(0.1,0.2,0)，平方和为0.05。整体MSE=0.05/(15×3)=0.001111；末端MSE=0.05/3=0.016667。因此总损失=0.001111+0.25×0.016667=0.005278。

末端已在整体项中出现，又获得附加权重。按单坐标贡献看，末端的系数是普通节点的1+15×0.25=4.75倍。坐标中心做减法、尺度做除法，使优化使用一致数量级；最终误差换回物理坐标后以mm报告。

760个参数具体分布在哪里？

当前参考角度、长度和通道耦合共有176个可训练系数；记忆驱动φ有20个原始权重；路径读出有8个增益和8×16=128个方向系数；时间读出有24个增益和24×16=384个方向系数。合计176+20+8+128+24+384=740。

再计入已经预拟合并冻结的20个参考驱动权重，模型记录的参数或拟合系数为760。归一化参数化会带来冗余，因此这个数不等于独立自由度。32个p/h是每个运行实例的动态状态，不计为全局学习参数。

“反向传播”也可以先只看一个数

把网络缩小成 ŷ=1+wq，给定q=0.2，目标y=1.5，开始w=1。预测1.2，误差−0.3，损失0.09。梯度 ∂L/∂w=2(ŷ−y)q=−0.12，说明增大w会让损失下降。

手动做一次参数学习

wnew = w − η · 2(1+0.2w−1.5) · 0.2，　η=0.5

这是标量梯度下降教学例子。真实训练由自动微分穿过矩阵、指数、三角函数和递推计算梯度，再用Adam更新参数。

怎样理解早期精度较好：结构先把任务限制为“参考 + 历史几何修正”，预拟合与读出初始化又提供了较好的起点。第一个联合优化epoch之后误差较小，可以支持早期精度的描述；样本效率需要减少训练数据量的对照，在线学习能力需要实际在线参数更新实验。
窗口初始化与连续部署为什么要分别理解？

当前窗口初始化取p₀=h₀=e₀，所以q₀=d₀=0。这是一种明确的有限历史边界条件，并不说明任意真实首帧都没有迟滞。20点窗口内首点负责初始化，随后进行19次更新。假如设定初态与未知真实初态之间存在差异，最大时间常数2 s对应的这部分初态误差，经过3.8 s后仍可能保留exp(−3.8/2)≈15%；路径项也可能保留更久以前的影响。

离线窗口误差评价的是给定历史预算与初始化方式的预测能力。连续部署保存p、h并接着更新，因此能持续承接历史，但需要连续预测与任务数据验证。每次新动作只推进一次；读取已经更新好的状态时不应再次推进时间。

09 / WHY MEMORY MOVES THE WHOLE ARM

再往深一层：记忆怎样经几何累积形成全身位移

这里把你关心的“节点空间增益规律”讲清楚。前面的W只告诉我们记忆怎样改变角度或长度；节点移动多远，还取决于当前身体姿态以及这个角度位于臂的什么位置。

论文式（7）m = Wpq + Whd
ΔX = G(ξref+m)−G(ξref)
ΔX ≈ J Wpq + J Whd，　J=∂G/∂ξ

Jacobian J就是一张局部敏感度表：“某个转角增加一点，第几个节点的x、y会分别变化多少？”近似号表示在当前参考形态附近采用线性近似。完整模型依然使用三角函数与指数进行非线性生成。

一个直接看出空间规律的例子

让三段臂笔直沿+x，每段50 mm。第一个角度增加0.01 rad时，三段方向都变化，末端法向位移近似(50+50+50)×0.01=1.5 mm。若只让第二角度增加0.01 rad，末端约移动1.0 mm；只改变第三角度，约移动0.5 mm。上游变化影响更长的下游臂段，几何累积自然产生不同的空间增益。

把“上游角度影响后续节点”写成导数
∂xi/∂βa = ∑j=a…i ℓj[−sinθj, cosθj]T，a≤i
∂xi/∂βa = 0，a>i

βa出现在所有j≥a的累计方向θj中，所以要把这些区间的方向导数相加。方向导数与原区间垂直，形成法向位移。分段λ的导数则把该段已累计的区间向量相加，形成切向伸缩；长度裁剪边界处要按代码的分段导数处理。

时间卷积核到底是什么

把d的历史展开式代入J Whd。先固定参考姿态，把初始项单独拿出来，那么每次驱动变化Δe对节点的后续位移贡献，就由一个随时间衰减的系数K决定：

Ki,c(ℓ) = −∑k (J Wh)i,c,k αkℓ+1
ΔXi,ttime ≈ 初始状态项 + ∑ℓ≥0,c Ki,c(ℓ) Δec,t−ℓ

ℓ=0表示这次刚发生的输入增量，已经经过当前一次更新，所以指数是1。K的单位是“每单位驱动增量产生多少mm位移”。它是时间记忆递推、学到的几何读出和当前姿态的几何敏感度合成的结果。

看同一组时间尺度怎样形成不同节点波形

教学参考臂沿+x，图示法向y位移核。单尺度τ=1 s；双尺度τ=(0.6,2.0) s。系数明确由示例给定，展示的是结构如何工作。

“共同时间波形 × 节点增益 + 节点差异”如何理解

Ki(t) ≈ gi φ(t) + εi(t)

φ表示多个节点共享的主要时间变化形状，gi表示第i个节点被放大或缩小的程度，ε表示这个节点与共同波形不同的部分。一个时间常数、固定参考姿态时，这种分解本来就能精确成立；多个时间常数和不同局部读出会引入波形差别。

因此，发现节点波形相似，首先说明时间基与几何传播共同组织了响应。要进一步说明“模型学到了这条软臂特有的规律”，还要看学到的增益与真实形态变化是否对应、跨参考姿态是否稳定，以及相同结构的未训练读出是否也出现类似模式。

怎样用真实数值检查这段解释？

记观测相对于参考预测的残差r=vec(Xobs−Xref)，记一阶两分支位移c=JWpq+JWhd。计算η=1−∑‖r−c‖²/∑‖r‖²。如果η=0.5，意思是几何修正解释掉原残差平方能量的一半；若η<0则使误差增加。

还可以比较一阶预测与完整非线性预测的差，检验局部线性化是否适合当前修正幅度。r中也含参考模型误差、分割误差等，因此η直接评价预测残差的减少，不能自动解释为“辨识出了多少真实材料迟滞”。

10 / REUSING THE MEMORY

记忆模块怎样接到线性模型或MLP上

两种记忆从动作历史计算出来，并不要求后面一定接骨架几何生成器。最直接的复用方式是把当前压力和记忆拼接，交给新的预测模型。

论文式（8）ηt=[at; qt; dt] ∈ ℝ36
X̂t = gψ(ηt)

分号表示按顺序接在后面：4维当前输入 + 8维路径 + 24维时间 = 36维。线性模型对这36个数加权；MLP再学习非线性组合。这样，同样当前压力的两个样本能因q、d不同而获得不同预测。

当前几何模型

动作与记忆 → 16维几何坐标 → 连通骨架。读出的每个量有角度或长度意义。

插件接入坐标MLP

动作与记忆 → MLP → 45维节点坐标。历史编码可以复用，但节点连接关系没有由显式几何构造直接规定。

当前插件实验使用新建算子的固定初始参数生成记忆特征，再训练各基础映射；它考察的是历史特征结构的复用，与迁移已经训练好的HOV驱动函数和几何读出是不同的实验。基础模型需要用自己的监督重新拟合读出，才能使用新增的历史信息。

为什么要有静态扩展和窗口MLP两种对照？

静态扩展也提供36维输入，帮助判断收益是否仅来自更多当前输入特征。窗口MLP直接获得20×4=80维历史，帮助判断紧凑记忆摘要与直接访问历史的差别。状态更紧凑是表示上的特点，是否同时更准确、更快，需要分别测量。

11 / USING THE MODEL TO CHOOSE ACTIONS

形状模型怎样变成规划和视觉反馈

建模完成后，参数固定，我们可以把候选动作交给模型，在执行前算出它们可能造成的形状。控制因此多了一层“在模型里试动作”的过程。

① 规划：选择预测误差较小的动作

论文式（10）U* = arg minU 平均未来时刻k、目标节点i ‖x̂i,t+k(zt,U)−xi,t+ktarget‖²
约束：压力在允许范围内，相邻动作变化不超过驱动速率限制。

arg min的意思是“找出让后面的代价最小的那个输入”。U是一串待执行动作；每个候选U都必须从同一份当前状态z开始递推，才能公平比较。

教学一步例子：目标某节点x=11 mm
候选A预测x=10 mm → 平方误差1
候选B预测x=13 mm → 平方误差4
候选C预测x=11.5 mm → 平方误差0.25
只看该目标与这三个合法候选时，选择C。

实际任务把多个节点与未来时刻的误差一起累加。如果只选末端，得到末端目标；如果选择全身节点，就把身体路径也纳入目标。50 kPa/s的变化率限制与0.2 s控制周期对应每步最多变化10 kPa。

② 观测：相机只提供能看见的那部分证据

论文式（11）yt = HΩ(Xt) + εt

HΩ表示将完整骨架映射到相机中，并只取可见区域Ω的观测。ε表示测量误差。当前反馈实现使用可见臂身侧边缘，与预测中心线生成的轮廓建立对应；隐藏区域主要由历史模型补全。

③ 校正：让历史先验与可见证据共同确定状态

论文式（12）z+ = arg minz∈Z [ 可见轮廓的预测误差 + (z−z−)TΛ(z−z−) ]

z−是动作递推得到的先验，z+是加入观测后的校正状态。第二项表示“改变历史状态要付出多少代价”，Λ控制约束强度。Z是状态允许范围，例如p要与当前驱动和路径阈值相容。完整实现还使用可靠性权重与鲁棒误差，降低异常边缘匹配的作用。

用一个标量，手算“信观测还是信预测”

假设一个简化模型的可见位置为x=10+2z，先验z⁻=0，相机测得x=11。取代价(10+2z−11)²+4(z−0)²=(2z−1)²+4z²。令导数为0：4(2z−1)+8z=0，所以z⁺=0.25，校正后x=10.5。

若没有先验项，会选z=0.5完全贴合观测；加入先验后只修正一部分，以平衡测量与历史。真实系统可能有多个状态都符合局部观测，所以局部可见信息通常不足以唯一确定所有历史变量。

闭环的完整顺序：动作推进记忆 → 预测完整形状 → 相机提供局部证据 → 校正内部状态 → 用校正状态重新评估候选动作 → 执行下一步。这里更新的是状态；部署期间的模型参数通常保持固定。

你可以先看“参考 + 两类修正”的第一行β₁，再看完整骨架如何改变。即使某个角度修正很小，累积到较长臂段后仍可能产生可观察的位移；角度和节点距离需要通过几何关系联系起来。

13 / PUTTING THE IDEAS TOGETHER

理解模型时，几个最关键的区分

我们要拟合的是“迟滞”，还是“形状”？

直接监督目标是全身形状。迟滞和时间相关响应是这个输入—形状关系的重要历史特性。模型通过有结构的记忆表达这些特性，让同一当前动作在不同历史下得到不同形状。它学到的是特定驱动装置与软臂组成系统的前向映射。

p和h是身体里真的存在的两种物理量吗？

它们是模型内部的历史摘要，具有明确的递推规则。p保留路径，h表达时间跟随。可解释性来自更新规则和几何作用可分析；将它们进一步认定为某一种真实材料内变量，需要独立测量与辨识证据。

有p、h，为什么还要算q、d？

p、h适合保存和递推；q=e−p和d=h−e表达相对于当前驱动的历史偏移，适合叠加到当前输入参考上。已知e时可以相互转换：p=e−q，h=e+d。它们是不同角色的坐标表达，并没有额外增加一倍记忆维数。

时间项消失，是否意味着迟滞完全消失？

持压时d逐渐趋于0，q仍可能保留路径偏置，因此最终预测可为ξref+Wp q。模型允许时间相关暂态消退后，加载路径造成的差别继续存在。

两类分支是否一定能把两种物理机制唯一分开？

分支的数学性质不同，但有限数据中的输入变化、保持时间和形变可能相关，两类读出可能部分补偿彼此。要支持更强的机制区分，需要同路径变速、同压不同历史、持压等专门数据；也可以检查修正方向与残差的关系。

为什么递推可以很快？

每来一个新动作，只更新8个p、24个h，再生成16个几何量和15个节点，状态规模不会随运行时间增长。若每次重新计算20点窗口，会额外重复历史更新。单次前向耗时支持的是模型求值吞吐，完整控制频率还包含图像、通信、状态校正与规划。

模型更小，为什么训练不一定更快？

训练耗时还取决于计算的组织方式。MLP的密集矩阵乘法容易批量并行；递推模型要沿时间顺序处理状态，几何、初始化和自动微分也有成本。因此参数量、训练速度和在线单步预测速度应分别测量。

如何判断我已经理解了？

可以尝试解释四件事：①为什么同一e能得到两个q；②为什么e保持时q不变而d衰减；③为什么某个β变化能移动多个下游节点；④为什么训练更新W、部署通常只更新p和h。能用第6节的数字说明这四点，就已经抓住模型的主体。
