# Hereditary / Analytic B 实验操作指南

2026-09-11：当前四页流程已包含自动 SAM 提示、折叠修正工具、末端余量及复用配准预热。打开 [带红圈编号的 HTML 操作手册](../workspace/runs/analysis/hereditary_deployment/release_20260911_002/guide/guide.html)。独立 ZIP 内为 `HEREDITARY_GUIDE.html`，截图内嵌，无需网络。

## 启动

```bash
python -m real_validation.main
```

Windows 也可用 `run_gui.bat`。建议 Python 3.10（64 位）；在包含 `real_validation/` 的目录安装 `real_validation/requirements.txt`。SAM 初始化另装 `requirements-sam2.txt`，真实 USB/串口按设备添加依赖或安装 `requirements-hardware.txt`；完整发行 ZIP 带所选权重和 SAM 源码，不依赖 `src/` 或 `real_capture/`。安装矩阵见 [README](README.md)。旧 OpenLoop 在 `--legacy-openloop` 兼容入口保留。YOLO 目前只在离线训练，依赖和发行内容见 [后续部署方案](YOLO_DEPLOYMENT_PLAN.md)。

## 1 设备模型

全平台 300 epoch 新模型位于 [`checkpoints/candidates/`](checkpoints/candidates/README.md)，分别选择 `hereditary_full_5hz_300ep_20260910_001.npz` 或 `hereditary_full_10hz_300ep_20260910_001.npz`；均配有同名 JSON，旧权重保留。文件名的300表示训练轮数，导出采用验证集最优权重（5 Hz第150轮、10 Hz第300轮）。

加载自动从同名 JSON 读取 `dt`：5 Hz为0.2 s，10 Hz为0.1 s。加载成功消息及第3页规划预览显示周期。当前不提供独立修改周期的控件，因为冻结模型的记忆衰减、限速与执行节奏都依赖该时基；换频率请换对应权重，不要只编辑 JSON。相机采样与界面刷新频率独立，实际执行周期仍受设备及计算时延影响。

加载同名 `hereditary.npz + hereditary.json`，检查紧凑两行六腔映射，默认 `[0,1,1,2,2,3]`。六腔必须覆盖四个输入，共享输入同压。模型加载只检查模型和配置，不发压力，不创建准备动作历史。

选择全 Mock 或真机验证，分别连接组1、组2与相机；连接内部校验配置，无需额外应用 profile。真实端口示例 COM3、COM46，按设备电脑实际设置。高级栏放 backend、波特率、从站、相机数量/serial 与保存位置。动作驱动 Mock 相机要求先加载模型；两组阀与真机使用同一连接入口。未连接的腔显示未知。

相机驱动可选 **自动 / RealSense SDK / 普通摄像头 UVC/OpenCV**。自动模式优先枚举 SDK 支持的 RealSense；未发现时使用 UVC 设备索引（默认 0，多台可在高级栏写 0,1）。RealSense 需要 `pyrealsense2`，其他兼容型号需支持配置的彩色流；同品牌不代表所有型号兼容。指定 RealSense 或 serial 后失败就报错，不换到其他设备。UVC 使用操作系统视频驱动，不需要 RealSense SDK。采集中途不会自动切换相机。两条路径目前都只保存彩色图像，不保存深度图。

第一页恢复 **NDI 可选连接**：backend、串口、探头数、连接/断开。未连接、选择 Disabled 或 NDI 报错都不阻止部署/执行；已连接的数据只作为独立评价流，不输入模型。

## 全局六腔控制

点击相机上方常驻 **六腔控制** 打开非模态窗口，主界面仍可操作。

- 表格给出每腔输入、目标、ACK 确认下发值、min/max、rise/fall。ACK 下发值不是实测腔压。
- 共享输入目标联动；每腔限制独立，与同输入其他腔及模型包取交集。速率 0 表示不额外收紧，模型包限速仍生效。
- **下发目标（按限速）**：输入目标后直接点击，校验目标与限制并连续调压，不需要先点其他按钮，不依赖录制、相机或部署预热（须已加载模型及连接所需阀组）。运行中按钮变为 **更新并下发目标**，编辑后再次点击即可更新，不重启发送线程。窗口显示调压进度、目标指令 ACK 或具体通信失败原因。
- **仅应用设置（不启动）**：只应用目标与限制，空闲时不发送压力；正在手动调压时下一拍采用。若范围排除当前下发压力，先调入新范围再收紧。未连组及缺少所需阀组的共享输入不能操作。
- **结束调压（保持）**、关闭窗口或 Escape 均停止手动发送，保持末压；**全部归零**独立。
- 自动执行中接管先停止旧发送器、处理在途 ACK，再开始手动。旧计划不能恢复。已部署的手动动作仍更新同一个模型状态；连续历史与相机不变时不重做几何对齐。

六腔窗口显示生效的升/降速率与模型部署上限。目前候选权重上限为 50 kPa/s，即 10 Hz 每周期最多约 5 kPa、5 Hz 约 10 kPa；共享腔与 GUI 更低的设置还会收紧。增加 GUI 数值超过模型上限不会进一步加速。ACK 是实际下发指令，不是传感器测得的腔压。

连接不会恢复上次的非零输出。映射/限制与设备配置保存；重新加载模型后的映射仍需核对实际接管。更换映射或模型驱动虚拟相机的模型前先断开相机。

六腔窗口顶部显示实际阀控制器的 REAL/MOCK、串口及协议；相机和阀的 backend 独立。表格区分“编辑目标”“生效目标”和“ACK 下发”。遇到 ACK 已达目标但机器人不动作，立即点击 **保存调压诊断**，路径显示在窗口及主日志中，文件位于本次模型目录的 `manual_diagnostics/`。其中包括最近 1000 条命令/应答事件及真实串口 TX/RX 字节，不作为模型准备历史输入。排查方法见 [手动调压诊断](MANUAL_PRESSURE_DIAGNOSTICS.md)。

## 2 初始化、尺度拟合与部署预热

初始化允许使用较慢的 SAM2；不要求 100 ms 完成。SAM2 不参与第四页的实时控制循环。先用六腔工具调到希望的初压，再结束调压并保持。

### 推荐：自动提取 → 检查 → 确认

1. 新独立包带 SAM2.1 Tiny 权重和上游源码。首次使用安装 `requirements-sam2.txt`（Windows 可运行 `install_sam2_windows.bat`）。默认选择 SAM2，设置在 **修正形状 / 高级设置** 中。
2. 点击 **自动提取当前完整形状**。根据图像亮暗、中心位置和区域几何生成候选提示，无需正常流程先框选；此候选不是训练过的语义检测器。场景有歧义时图像冻结，在臂身中间点一下即可重新分割。
3. 绿色为冻结 SAM 掩膜，黄色为待确认中心线。检查完整臂身与 BASE/TIP，必要时拖动黄点；错误时展开修正工具，使用框选、负提示、手绘及图像微调。
4. 点击 **确认形状并部署预热**。后台拟合相机统一尺度、旋转、base 与有界记忆状态，再进行连续新图像预热。

SAM 模型缓存和同一冻结图像的编码复用；所有入口使用一致的 CPU 线程限制。日志分开记录加载、编码、解码及总耗时。首次加载仍可能耗时数秒；场景含支架、同色背景时自动候选可能失败，需要人工修正。D415 近景不采用固定训练像素坐标。

第一次框选、自动提取或手绘都会先确认当前保持压力并建立必要历史；不会把压力改成固定初值。所有图像处理与参数拟合使用保存的同一冻结帧。压力或相机配置在此期间改变，则需要重新获取形状。

### 手绘与图像微调

**可以直接点击手动重画，不必先让自动提取成功。** 从实际 BASE 端面中心画到 TIP 端面中心，松开后可拖动黄点。手绘草稿可以直接确认；也可以先点 **结合图像微调草稿**。

- SAM2 模式：手绘内部点作为正提示分割，再沿草稿局部横截面居中。
- 传统模式：草稿附近自适应阈值、GrabCut 颜色分割和横截面居中，避免选到与臂身相连的整块支架。
- 默认勾选 **微调时保留我标定的 BASE/TIP**，保留人工端点，不再强制要求算法识别短边。取消该选项时尝试自动端面修正；不可靠则保留端点并要求复核。
- 搜索范围默认按草稿长度自动调整，可手动设 4–240 px。微调不跨较长的缺证据区间补全；很短的未支持区间保留手绘并记录，失败不清除原草稿。
- 选择传统分割可以不安装 SAM2。全图阈值仍可能混入背景，此时用框选或直接手绘，不将其误报为必然“机器人出画”。

### 预热与结果边界

保持当前压力，按时间推进状态，并由连续新图像校正。默认最短 2 s、最多 20 s、连续 8 帧；覆盖 ≥75%、边缘残差 ≤3 px、帧间估计变化 ≤1 px 才就绪，可在高级选项调整。SAM 的耗时不计入预热超时；预热开始后使用轻量边缘观察器。

单张图像不能唯一确定相机参数和全部物理记忆，因此状态拟合保留先验与物理边界。SAM 分数和较小拟合误差均不能证明分割正确、臂身完整或真实控制已到位。初始化需要人工检查可见的完整臂身；真实裁切、严重遮挡、透视变化或错误端点不能靠预热保证消除。相机距离变化可重新估计统一尺度；明显透视畸变不属于当前相似变换模型。

每次初始化保存原图、掩膜、草稿、SAM 权重哈希/提示点/分数/设备/耗时及标定参数；手绘端点在日志中标记为人工来源。完成后保存部署快照，包括控制模型、映射/限制、坐标变换、状态和预热质量。已有有效状态优先延续；否则以训练一致的当前输入平衡先验起步，不把该先验视为真实历史。

### 重复实验不重复配准

正常完成，无论模型估计是否达到目标，均保持最后压力；有有效反馈时可直接规划下一个目标。清零、手动调压或反馈失效后，保留有效配准和已确认动作历史，第二页同一个确认按钮变为 **保持当前压力，重新预热（复用配准）**。保持并恢复无遮挡视野后点击，只运行图像预热，不重新分割、拟合或发送气压。

相机改变、配准错误或动作历史未知时不能这样恢复；根据提示重新确认历史和形状。复用配准不代表跳过图像质量检查。

### 叠加图像代表什么

- **绿色掩膜**：某一冻结帧的 SAM 图像分割，确认后清除，不是持续 SAM 跟踪。
- **青色形状**：模型估计。保持时有局部边缘反馈，徒手小范围扰动可能跟随；手动调压时仅按 ACK 动作历史前向预测，结束保持后恢复图像修正。
- **白色边缘点**：当前可信的可见图像证据。看不见的部分不补成白点；过期证据清除。青色覆盖隐藏区域仍然只是模型估计。
- **红色目标 / 紫色预览 / 黄色草稿**：分别为期望形状、计划预测和待确认初始化中心线。

## 3 目标规划

先选择互斥的 **完整形状** 或 **局部目标（末端 / 一段）**。切换模式、局部类型或节点区间会清除旧目标和计划，不会同时保留两个目标。

- **完整形状**：从已对齐 base 按住左键连续画到 tip；起点偏差超过 5 mm 拒绝。全部活动节点参与拟合。
- **局部 → 末端点**：按“单击设置末端目标”，在相机画面单击目标位置，只约束 TIP。
- **局部 → 指定节点的一段**：选择对应臂身的起止节点（默认 11→14，即末端一段）；青色编号显示当前区段。按按钮，只画需要的一段，方向为靠近 base 的一端→靠近 tip 的一端，不必连接到 base。可改为中部区段。节点 0 是固定 base，不参与局部目标。

- **局部 → 任意臂段自动匹配**：只画需要到达的一段，无需选择节点，绘制方向不限。规划搜索不同连续臂段与正反对应；预览显示自动选中的节点范围，并在青色预测上标注。默认模型下可搜索182种节点区间/方向组合，受总预算限制；先按当前几何与长度排序进行粗搜索，再用剩余预算细化最优候选。较早达标可直接返回，不保证全局最优或穷尽全部候选。整条目标曲线重采样为32点，与候选臂段的插值曲线拟合，不能只对齐两端而忽略中间形状。匹配范围按模型连续节点区间离散选择（不包含固定base），尚不搜索节点间任意起止位置。

指定节点模式按所选节点等弧长对应；自动模式由规划器选择对应区段。两者都要求一段臂身在终态贴合目标曲线，不是要求末端依次走过这条曲线。自动选定的区段在预览与本次执行中固定，图像观察器仍利用全臂可信边缘估计状态。未选中的节点由模型预测、规划，只显示完整预测；不计入初始规划、在线 B、终态达标和执行前目标误差。完整/局部均受压力与变化率约束；减少目标约束有助于避免人为过度指定，但不能保证任意曲线可达。

默认受约束节点平均容限 **2 mm**、最大节点 **4 mm**，均可调整。无需知道应走几步：外层尝试 10、20、40、60、80 等长度，受模型最大时域与 15 s 初始搜索预算约束；复用候选，必要时补充限速终态压力搜索。返回首个预测达标候选，不能保证全局最短。未达标显示“当前搜索未达标”，保留当前最优合法计划用于预览，可按下述方式确认试运行；这不等于证明目标不可达。

点击 **初始规划参数…** 打开非模态弹窗：平均/最大节点容限、长度上限、总预算（默认 15 s）、每个长度 B 迭代上限（24）、终态优化评估上限（30）和搜索步长（20）。修改立即生效并使旧计划失效；计算/执行期间锁定。初始规划的总耗时及每个尝试长度耗时显示在预览并保存。预算在迭代间检查，单次调用可能略超预算；终态求解器评估上限不含数值差分的额外调用。

**播放模型预测 / 时间轴**显示每一步紫色预测和六腔压力曲线、数值。青色为当前估计，红色为目标，黄色为形状草稿。整体管身是中心线按模型半径扩展，可调透明度，不是隐藏区域的图像测量。

规划不发动作。执行前校验版本、映射、限制、相机和当前持压状态；原预览若因状态变化而明显失效，需重新规划预览，不静默换轨迹。达标计划也会重新核对目标容限；试运行仅豁免未达标的目标容限。当前不包含避障。

### 末端调整余量

在已有 **初始规划参数…** 中设置“末端调整余量”，默认 10 步，0 表示额外 0 步（不是 0 kPa，不会清零）：10 Hz 对应约 1 s，5 Hz 对应约 2 s。预览列出“主规划 + 余量 = 总步数”，主规划与余量合计最多 200 步。初始余量采用保持末压力，参考指向用户目标；在线 B 可以继续在压力与速率限制内修订。余量影响最终预览残差，因此也参与计划达标检查。

开环对照执行相同总长度。用尽全部步数后保持末压并报告模型估计残差与图像证据状态；不在实时周期启动全局重规划、不无限尝试。若仍未到位，可以根据当前状态再次规划；余量不能保证不可达目标可达。

### 未达标计划的探索性试运行

搜索结束后，即使没有满足目标容限，仍可查看紫色完整预测与六腔动作。在第4页查看平均/最大预测误差，勾选 **允许试运行未达标计划（已检查预览，仅探索）**，再确认当前计划并开始执行。试运行确认仅适用于本计划，重画目标、修改设置、重新规划或执行结束都会清除。未勾选时只提醒，不丢弃已有计划。

试运行沿用当前目标的图像反馈，观察这条合法计划实际能走到哪里；不会把 `qualified=false` 改为成功。`metadata.json`、`events.jsonl` 和 `initial_plan.npz` 记录 `unqualified_trial`、原目标达标标记和误差，结束显示“计划指令完成”不等于真实到位。该选项不允许绕过部署预热、相机/映射/动作历史一致性、压力和限速、过期预览、非有限数值或连续反馈失败停止条件。必须先生成有效的动作序列；计算异常而无计划时不能执行，也不在求解线程仍修改计划时直接发令。

### 不矫正的执行对照

第4页新增 **不使用矫正，仅执行规划（对照实验）**，默认不勾选，使用Analytic B。勾选后，开始按钮明确显示“不矫正”；切换会撤销执行/试运行确认但保留当前规划，执行中不能切换。

正式运动时不调用图像状态校正、不优化剩余动作，仅沿初始规划发令；图像照常采集保存，软件遮挡版本另存，NDI、命令/ACK和逐步时延继续记录。模型按ACK历史自然推进，不以本次图像改变状态。`control_mode=open_loop`、`correction_enabled=false`、`revision_status=disabled`明确区分对照模式，不产生反馈候选任务，未运行的计算时延留空。

两种模式都保留压力及变化率限制、ACK后的合法压力接续、设备异常、停止/归零与采集不到新图像的停止门限；ACK压力与计划不同而引起的接续修正会单独记录。无矫正时有效的全遮挡图像只记录，不因为没有边缘而中止。预热与正式运动前后的保持观测仍可估计状态，开关只控制正式执行阶段的矫正。

对比时尽量复现同一初始形状和压力历史、目标、规划与遮挡/扰动条件。连续做两次实验并不意味着初始记忆相同；不能仅凭两条不同起点的运动把差异归因于矫正。

## 4 执行记录

确认预览后勾选允许执行，再开始实验运动。真实或虚拟相机均可开启 **软件遮挡测试**。表格每行一个矩形，设置 x/y/宽/高（原图百分比）和灰度 0–255，可添加最多 16 个区域；点击应用后生效，执行期间锁定参数。整图遮挡为 0/0/100/100。它只修改图像副本，算法不接收矩形位置；真实物理遮挡无需手画区域。初始化前关闭此项。

每步为：压力 → 两组 ACK → 从实际 applied6 修复合法后缀 → 命令后的新图像 → 可信侧边校正 p/h → 重放图像后的已确认命令 → Analytic B 修订剩余动作。每次运动有独立 ID，与部署快照关联，保存动作、状态、后缀、计算时间及原图。

连续无新帧/可信边缘的停止门限默认 3 次，可在第四页设为 1–10 次。缺失期间仅按模型与合法后缀运行，不进行图像状态修正/后缀优化；达到门限停止归零，使部署就绪失效。不会无限搜索、自动试探压力或自动恢复旧计划。即使短计划在门限前结束，只要结束时仍缺失反馈，也会撤销就绪并标记未确认，不能直接继续规划。全遮挡下不能保证稳定跟踪，也不能确认到位；有纹理的遮挡物仍可能产生误匹配。指令失败同样停止归零。反馈采用独立状态快照，截止时间为本次发令时间 + 模型 dt − 3 ms 预留。按时完成才一起提交 p/h、历史和后缀；超时整次丢弃，保留实际 ACK 后修复的合法后缀。后台最多一个反馈任务，未结束时跳过新任务，不积压，也不能在迟到后修改实时模型。默认连续 10 次不能及时提交反馈停止归零，第四页可调为 1–100。

始终选用 ACK 后接收的新帧。第四页 **发令后额外等图** 默认 0 ms，可按设备需要调大，但会挤占当前周期的反馈预算；不再固定多等 50 ms。图片写盘使用有容量上限的后台队列，积压或保存失败会报告失败。至少间隔模型 dt 发令，不突发补发。此为 Python 软期限调度；相机、阀通信、GIL 和操作系统调度仍可能使实际间隔超过 dt，不能宣称硬实时 100 ms。最后一步仍超时/缺反馈则撤销就绪。

**停止运动（保持当前压力）**与手动接管正常停止旧轨迹。**中止并全部归零**为另一入口。正常结束保持末压，继续观测和显示漂移，不自动启用额外的目标保持控制器。`metadata.json` 的 `completion_assessment` 记录最终模型估计均值/最大误差、证据覆盖与时效；`physical_arrival_verified=false` 明确表示未用独立实测认证到位。`steps.jsonl` 的 `plan_phase` 区分主规划与余量。

分别看指令是否完成、模型受约束节点目标差、可信可见边缘到目标管身的差。局部目标下，后者只统计两端都属于目标区段的可见边缘；单独末端点没有侧边管身实测误差。后者只覆盖已有边缘，遮挡部分不宣称实测到位。“局部证据缺失”也可能来自光照、预测或对齐误差，覆盖率不是遮挡概率。

目前真实接口只支持正压，当前部署包 0–150 kPa；**实际负压不支持**。服务器没有连接设备，虚拟测试不证明实机通信或控制精度。

## 执行结果文件

每次运动在 `runs/hereditary/<run>/executions/<id>/` 独立保存，正常结束、普通停止、无图像/无边缘失败均有记录：

| 文件 | 内容 |
|---|---|
| `initial_plan.npz` | 初始完整动作（模型单位和六腔 kPa）、参考形状 mm、状态与版本 |
| `timings.csv` | 每步发令间隔/偏差、ACK、等图、预处理、反馈预算/等待/完整计算时间、边缘/观察器/B 耗时、写盘入队、循环耗时、提交状态 |
| `steps.jsonl` | 每步修订前、实际 ACK 后合法后缀、最终采用后缀（模型单位与 kPa）、状态/版本及采纳或跳过原因；故障步也记录 |
| `feedback_jobs/*.json` | 独立候选与真正计算完成时间，包括迟到结果；只是提案，是否采用以 steps.jsonl 为准 |
| `commands.csv` | 请求六腔 kPa、实际下发六腔 kPa、命令 ID、发送/ACK 时间与状态；故障归零也记录 |
| `raw/camN/*.png` | 每个控制步保存各相机最新原图；反馈主相机为此次真正选用的原帧，辅助相机是否在命令后有新帧明确标记 |
| `frames/*.png` | 真正送入观察器的主相机图像，包括人工软件遮挡；最后的失败帧也保留 |
| `samples.csv` | 步号、相机、图像时间、对应命令、命令后时间差、新鲜标记、图像路径、遮挡参数、后台实际写图耗时 |
| `ndi.csv` | 执行期间全部 NDI 样本，逐探头保存位置/姿态/quality/valid；失锁保留 NaN，未连接时仅表头 |
| `frame_ndi.csv` | 每张图像对应的最近且不晚于图像的 NDI 时间、年龄，以及是否在 200 ms 内；无数据留空 |
| `metadata.json` | 设备模式与驱动、部署 ID、执行状态、遮挡配置、NDI 连接/样本信息 |

`feedback_wait_ms` 是控制线程等待时间，超时任务的完整耗时在随后写出的提案文件中；未完成不填 0。`metadata.json` 记录关闭时尚未写完的反馈提案，进程提前结束可能无法得到这些任务的完整耗时。`cycle_ms` 到本步审计写入前为止；真实的命令间隔还包含调度和日志开销。

上级 `events.jsonl` 继续记录模型状态、每步反馈与剩余动作修订。压力是命令及 ACK，不是实测腔压；NDI 是独立测量。时间采用主机 monotonic 接收时间，多相机并非曝光同步，NDI 的时间接近也不代表设备硬件同步。NDI 缓冲最多保存 60000 条，元数据给出最早保留时间，便于检查记录范围。

## A 与 B 的实测比较

原高变化 80 帧窗口（182519，2198–2277，56×56 固定方块），以校正后模型预测和录制参考形状比较，排除固定 base：

| 指标 | Cached A | Analytic B |
|---|---:|---:|
| 整段平均节点距离 mm | 0.7474 | 0.7064 |
| 最后一帧平均节点距离 mm | 0.5723 | 0.3668 |
| 最后一帧 tip 距离 mm | 1.0696 | 0.1712 |
| 后缀接受次数 | 16/79 | 78/79 |
| 反馈计算 P50 / P95 / max ms | 22.1 / 27.7 / 33.8 | 39.8 / 48.1 / 54.6 |

B 在此窗口的差异更小，但原图不会响应修订后的动作，因此不是实机控制精度对照。

A 的拒绝中，7 次为缓存与非线性 rollout RMS 失配 > 0.5 mm，56 次为投影及回溯后，坐标 MSE 没有下降至少 `1e-8 mm²`；回溯比例 1、1/2、1/4、1/8，修正信赖范围 0.08 模型单位。拒绝保留上次合法后缀，图像状态观察器仍会更新，故接受率不等于控制成功率。

B 另一次独立进程计算 P95/最大为 58.5/139.2 ms，不能保证所有周期 < 100 ms；以上不含相机曝光、等新帧、阀通信和写图。完整来源见 [回放验证记录](../docs/experiments/partial_observation_replay_validation.md)。
