# 软体机器人实机验证：Windows 操作指南

## 安装与启动

1. 设备电脑安装 **Python 3.10（64 位）**，以及相机、USB/串口设备所需的系统驱动。
2. 完整解压 ZIP 到可写目录。首次安装保持联网，双击包根目录的 **install.bat**；脚本创建 `.venv` 并安装全部运行依赖，等待成功提示。
3. 双击同目录的 **run.bat** 打开四页 App。后续启动直接运行此文件；首次加载分割模型可能需要数秒。

包根目录包含本指南、`install.bat`、`run.bat`、`real_validation/` 和运行后生成的 `results/`。代码、控制与分割模型、依赖清单和许可证均在 `real_validation/` 内。移动到另一台电脑时复制原始 ZIP 并重新安装；`.venv` 是当前电脑的环境。

## 1 设备模型

- 加载 `real_validation/checkpoints/hereditary_current/hereditary.npz`，同目录须保留同名 JSON。本包默认是 10 Hz；`checkpoints/candidates/` 提供 5 Hz 模型。
- JSON 的 `dt` 决定控制周期：5 Hz 为 0.2 s，10 Hz 为 0.1 s；换频率请选择对应模型。实际节奏还受通信与计算耗时影响。
- 核对六腔到四输入映射，默认 `[0,1,1,2,2,3]`，共享输入的腔同压。分别设置并连接组 1、组 2 的阀串口和相机；真实 COM 口、波特率等按本机设备填写。阀和相机分别选择真实或 Mock 模式。
- 相机可选自动、RealSense SDK 或普通 UVC/OpenCV；自动模式优先 RealSense，否则使用视频设备索引（通常为 0）。保持完整臂身及 BASE/TIP 可见。
- NDI Aurora 为可选评价设备：填写串口、探头数后连接；其数据用于独立评价。未连接也可完成四页流程。

## 六腔手动调压

点击相机上方 **六腔控制**，设置目标 kPa、每腔范围及升/降速率，点击 **下发目标（按限速）**。修改运行中的目标后再次点击更新。

**结束调压（保持）**停止发送并保持末压；**全部归零**用于清零。当前候选支持 0–150 kPa 正压，模型速率上限为 50 kPa/s，实际限制取模型与各腔设置的交集。界面的 ACK 值表示确认下发的指令值，实测腔压需由压力传感器取得。

## 2 部署预热

1. 手动调到初始压力，结束调压并保持。
2. 点击 **自动提取当前完整形状**，检查完整臂身、黄色中心线和 BASE/TIP。
3. 需要修正时展开 **修正形状 / 高级设置**：可拖动黄点、手绘，或进入 **分割设置…** 切换 YOLO n/s、CPU/CUDA。默认 YOLO n，包内也提供 SAM2 提示分割。
4. 点击 **确认形状并部署预热**，保持压力和相机位置，等待就绪。清零或手动调压后，若配准和历史仍有效，可使用同一按钮 **复用配准重新预热**。

## 3 目标规划

选择完整形状、末端点或局部臂段，在画面绘制目标，点击 **规划当前目标 / 预览**，播放模型预测并检查紫色形状及六腔压力。

**初始规划参数…** 可调整容限、搜索预算、规划速度比例及末端余量。规划默认使用有效升/降速率的 **80%**，在线矫正可使用 100%。末端余量默认 10 步，含在预览总时长内；设为 0 表示额外 0 步。预览失效时重新规划。

## 4 执行记录

检查计划后勾选执行确认，再开始运动。默认启用矫正，每 **2 步**后台计算一次：10 Hz 模型对应约 5 Hz 矫正，5 Hz 模型对应约 2.5 Hz；间隔设为 1 可逐步反馈。对照实验可勾选 **不使用矫正，仅执行规划**。

**停止运动（保持当前压力）**停止当前轨迹；**中止并全部归零**停止并清零。正常完成后保持末压。完成状态与模型估计残差请结合原图及独立测量判断。

## 到哪里找结果

结果默认保存在包根 **`results/hereditary/<会话>/`**。第一页高级设置中的“保存根目录”可选择其它磁盘，在加载模型前设置。每次执行结束，第四页日志也会显示具体目录。建议分析或备份时复制整个会话文件夹。

```text
results/hereditary/<会话>/
  events.jsonl                 # 部署、预热、动作与状态事件
  initial_*.png / *_mask.png    # 初始化原图与分割
  plan_*.npz                   # 规划预览
  manual_diagnostics/          # 点击“保存调压诊断”后生成
  executions/<执行标识>/       # 每次运动独立保存
    metadata.json              # 状态、控制模式、参数与最终估计
    initial_plan.npz           # 初始动作、目标、状态与模型周期
    commands.csv               # 压力指令、ACK 与时间
    timings.csv / steps.jsonl  # 逐步耗时、状态及实际采用的动作修订
    feedback_jobs/             # 后台矫正候选及完整计算耗时
    raw/camN/ / frames/         # 相机原图 / 实际反馈图像
    samples.csv                # 图像路径、时间与命令对应关系
    ndi.csv / frame_ndi.csv     # NDI 测量及图像时间关联
```

分析先读 `metadata.json`，再用 `commands.csv`、`timings.csv`、`steps.jsonl` 对照动作与耗时；图像对应关系看 `samples.csv`。矫正候选是否采用以 `steps.jsonl` 为准。NDI 未连接时没有有效测量；时间关联使用主机接收时间。
