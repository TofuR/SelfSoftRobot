# 软体机器人自建模 — 项目进展汇报

> 2026.04.29 — 综合文献分析与实验结果更新

---

## 一、项目目标

**让软体机器人仅通过观察自身的外部图像（2D 相机拍摄），学会预测自身在不同驱动输入下的三维形态。**

原始构想源自 NeRF 思路：
```
输入: (3D空间点坐标, 模型参数/驱动信号)
输出: (该点的可见度, 该点的密度)
训练信号: 2D 相机图像
```
即用体渲染 (Volume Rendering) 把 3D 场景投影到 2D，用 2D 图像做监督。

## 二、相关文献分析与借鉴

### 2.1 三篇核心文献概览

本项目的研究路线受到三篇核心文献的直接影响：

| 文献 | 年份 | 建模对象 | 3D 表示 | 相机设置 | 条件输入 | 与本项目关系 |
|------|------|---------|---------|---------|---------|------------|
| **Hu et al. (FBV-SM)** | 2025 | 4-DOF 刚性臂 | 隐式密度场 | 单视角 RGB | 关节角度 | **直接代码基础**，复用体渲染管线 |
| **Chen et al.** | 2022 | 4-DOF 刚性臂 | SDF | 5× RGB-D | 关节角度 | **多视角方案验证**，SDF 表示启发 |
| **Shan et al. (SoftNeRF)** | 2024 | 硅胶软体机器人 | SDF + NeRF | 多视角 RGB（仿真65视角/真实环绕） | 驱动状态(4缆绳) | **最直接相关工作**，软体 NeRF 先驱 |

### 2.2 Hu et al. 2025 — FBV-SM（我们的代码基础）

**核心方法**：将 NeRF 的"视角 → 图像"变为"关节角度 → 机器人外观"。

```
关节角度 → CmdEncoder → 与 3D 坐标编码拼接 → MLP → [visibility, density]
                                                     ↓
                                               OM_rendering → 2D 图像
```

**关键设计——几何先验与网络学习的分工**：
- 前 2 个关节（θ, φ）控制整体偏航/俯仰 → 旋转矩阵 `Rot_Z(θ) × Rot_Y(φ)` 确定性处理
- 剩余关节控制局部构型 → 交给网络学习
- 效果：确定性变换不需要学，网络只需学局部变形

**我们直接复用的组件**：
- OM_rendering（不透明度调制渲染）
- sample_stratified（均匀射线采样）
- get_rays（射线生成）
- 位置编码 PositionalEncoder

**FBV-SM 的局限与我们的改进**：

| 局限 | 原因 | 我们的改进 |
|------|------|-----------|
| 隐式密度场难以提取精确 3D 形状 | density > 0.4 阈值过滤，精度有限 | 显式骨架输出 SkeletonHead |
| 无时序建模 | 刚性臂响应瞬时，不需要历史 | MultiScaleEMA 时序编码器 |
| 单色输出（灰度 visibility） | 刚性臂外观简单 | 同样适用于软体臂 |
| 10000 张图像训练 | 信息量需求大 | 利用仿真器 3D GT，~5000 数据点 |

### 2.3 Chen et al. 2022 — 多视角 SDF 自建模

**核心方法**：5 个 RGB-D 相机环绕机器人，多视角点云融合 → 条件化 SDF 学习。

```
双编码器架构:
  3D 坐标 X → Coordinate Network (SIREN) → C(X) ─┐
                                                     ├─→ SDF Head → d (符号距离)
  关节角度 A → Kinematic Network (SIREN) → K(A) ──┘
```

**关键技术亮点**：

1. **SIREN 激活函数**：`sin(ω₀ · Wx + b)`，ω₀ = 30
   - 梯度始终非零，天然适合连续几何表示
   - 对比 ReLU 在零点不可导，不利于 SDF 梯度优化
   - **我们可借鉴**：尝试在 SkeletonConditionedDensity 中引入 SIREN

2. **SDF 表示**：输出符号距离值，天然支持：
   - 内外判断（d 正负）
   - 碰撞检测（d < 0 表示穿透）
   - 梯度优化（∇d 指向表面法线）
   - **我们可借鉴**：将密度场输出替换为 SDF，解锁运动规划和碰撞检测

3. **5× RGB-D 深度监督**：
   - 直接 3D 点云训练，用 Chamfer-L1 损失
   - 避免了 2D→3D 的歧义
   - 模型仅 1.1MB，单 2080 Ti 训练数小时
   - **对我们的启示**：多视角是消除深度歧义的根本方案

4. **损伤检测与恢复**：
   - 检测：比较 SDF 预测与实际点云距离
   - 恢复：50 个样本 + 100 epochs（8.13 分钟）微调
   - **对我们的启示**：软体机器人容易变形，快速适应能力很重要

**Chen 2022 与我们的关键差异**：

| 特性 | Chen 2022 | 本项目 |
|------|-----------|--------|
| 机器人 | 刚性（4-DOF WidowX 200） | 软体连续体 |
| 运动学 | 已知 DH 参数 | 未知，需同时学习 |
| 3D 表示 | SDF | 骨架 + 条件密度场 |
| 深度监督 | 5× RGB-D 点云 | 无（仅 2D 渲染） |
| 条件化 | 关节角度 → Kinematic Net | 动作时序 → EMA → SkeletonHead |
| 训练损失 | Chamfer-L1 (3D) | MSE 渲染 + 骨架 3D loss |

**Chen 2022 给我们的核心启示**：
- 多视角 RGB-D 是 3D 精度的根本保障 → 验证了我们的多相机方案（方向 C）
- SIREN + SDF 比我们当前的 ReLU + 密度场更适合几何建模 → 可作为改进方向
- 双编码器设计（空间 + 运动学）与我们的骨架条件密度场思路一致

### 2.4 Shan et al. 2024 — SoftNeRF（最直接相关）

**核心方法**：首个将条件化 NeRF 应用于软体机器人的工作。

```
3D 坐标 X → 多尺度哈希编码 (Instant-NGP) → F_g(X) ─┐
                                                       ├─→ SDF 解码器 → s
驱动状态 A → MLP 编码 → F_k(A) ─────────────────────┘
                                                       ├─→ 颜色解码器 → c
                                                      ↓
                                                体渲染 → 2D 图像
```

**关键技术亮点**：

1. **多尺度哈希编码**：16 个分辨率级别（16 → 4096），比频率编码更高效
   - 自适应分配容量到需要的空间区域
   - 对大变形场景（软体机器人）比固定频率编码更好
   - **我们可借鉴**：MultiScaleEMA 的空间编码可以引入哈希编码

2. **误差引导自适应采样**：
   - 粗采样 → 误差估计 → 高误差区间密集重采样 → 合并渲染
   - 对软体机器人大变形区域分配更多采样点
   - **我们可借鉴**：当前体渲染管线是均匀采样，可引入误差引导策略

3. **SDF 体渲染**：`α_i = max(0, (Φ_s(s_i) - Φ_s(s_{i+1})) / Φ_s(s_i))`
   - 用 SDF 值直接计算不透明度，物理意义更明确
   - 配合 Eikonal 正则化（||∇s|| = 1）

4. **软体机器人平台**：硅胶 + 4 根缆绳驱动 + 多视角 RGB 相机
   - 与我们的区别：SoftNeRF 使用多视角（仿真 65 视角 / 真实环绕视频），我们目前单视角
   - SoftNeRF 的多视角 2D 监督通过体渲染隐式恢复 3D，但精度仍不如直接 3D 监督
   - **我们面临更严重的深度歧义**：单视角限制更严格

**SoftNeRF 的局限（正是我们的创新空间）**：

| SoftNeRF 局限 | 我们的优势 |
|--------------|-----------|
| 多视角但仅 2D 渲染监督，精度有限；无时序建模 | 我们已量化分析深度歧义（exp3），提出双视角方案；MultiScaleEMA 时序编码 |
| 无时序建模，忽略迟滞 | MultiScaleEMA / HA-EMA 时序编码器 |
| 缺乏定量 3D 评估 | 仿真器提供精确 3D GT，MNE 等指标 |
| 隐式密度场，难以直接使用 | 显式骨架输出，可直接用于控制 |
| 无公开代码 | — |

## 三、模型演进路线

### 3.1 第一代: MSTNF — 直接 NeRF 思路

```
驱动信号序列 → MultiScaleEMA → 物理状态向量 (128维)
空间查询点 (x,y,z) → 位置编码 → 与物理状态拼接 → 5层MLP → [可见度, 密度]
体渲染 → 2D图像 → 与GT图像对比 → 反向传播
```

**问题**: 模型需要同时学习"软体机器人在哪"和"它长什么样"，搜索空间太大。变形场 MLP 产生高频振荡，骨架不光滑。

### 3.2 第二代: C-MSTNF 系列 — 典范场 + 变形场

引入"典范场"思路（借鉴 D-NeRF）：
```
静态典范场: 学习静止状态下机器人的外观
变形场: 学习驱动信号引起的三维位移
组合: 典范场(变形(空间点, 驱动信号)) → [可见度, 密度]
```

三个变体:
| 模型 | 时序编码 | 变形场 | 结果 |
|------|---------|--------|------|
| C-MSTNF | MultiScaleEMA | 5层MLP + 位置编码(n=6) | 高频跳变 |
| ODE-CMSTNF | Neural ODE | 同上 | ODE改进时序，空间问题不变 |
| Smooth-CMSTNF | MultiScaleEMA | Spectral Norm MLP | 尖端发散(SN限制大变形) |

**根本问题**: 变形场用 MLP + 高频位置编码映射到 3D 位移，ReLU 的分段线性 + 高频振荡 → 骨架不光滑。

### 3.3 当前模型: MS-SCNF — 骨架先验 + 骨架条件密度场

**核心转变**: 不再让网络隐式学习变形，而是**直接输出三维骨架坐标**，再基于骨架计算密度。

```
                        ┌─── SkeletonHead ──→ coarse骨架(4节点)  ─┐
                        │                                      ├── 多尺度3D loss
驱动序列(20帧) → EMA → ┼─── SkeletonHead ──→ medium骨架(10节点) ─┤
                        │                                      ├── 3D MSE loss
                        └─── SkeletonHead ──→ fine骨架(31节点)  ─┘
                                              │
                                              ↓
                            SkeletonConditionedDensity:
                            空间点 → 计算到骨架距离 → 距离编码 + 位置编码 → MLP → [可见度, 密度]
                                              │
                                              ↓
                            体渲染 → 2D图像 → 与GT图像对比 → 渲染loss
```

**为什么这样设计**:
1. **骨架是连续的**: 输出 (31, 3) 坐标序列，天然光滑，不需要正则化
2. **密度由距离决定**: 离骨架近 → 密度高，远处 → 密度趋零。`exp(-dist²/2σ²)` 天然无穷阶可导
3. **3D GT 直接监督**: 仿真器提供 31 个节点的精确坐标，比间接的 2D 渲染 loss 更有效
4. **多尺度训练**: 先学粗骨架(4节点)，再逐步精细到 31 节点

### 3.4 架构演进与文献对应

```
文献启发链:

NeRF (位置编码+体渲染)
  └→ FBV-SM (关节角度替代视角, 隐式密度场)
       └→ C-MSTNF (典范场+变形场, 动作时序替代关节角度)
            └→ 问题: 变形场不光滑
                 └→ BANMo启发: 骨架驱动变形
                      └→ MS-SCNF (显式骨架 + 条件密度场)
                           │
                           ├─ Chen 2022 启发: SDF/SIREN → 待引入
                           ├─ SoftNeRF 启发: 哈希编码/误差采样 → 待引入
                           └─ 多视角启发: 双相机消除深度歧义 → 方向 C
```

## 四、MS-SCNF 各组件详解

### 4.1 MultiScaleEMA — 时序编码器

```python
输入: 动作窗口 action_window (B, 20, 2)  — 过去20帧的2个驱动扭矩
输出: 物理状态 physics_state (B, 128)

原理: 4个不同衰减率的指数移动平均(EMA)
  α₁, α₂, α₃, α₄ — 可学习的衰减率(sigmoid约束到(0,1))

  对每个尺度 s:
    state_s = 0
    for t in [0, 1, ..., 19]:
      state_s = α_s * state_s + (1 - α_s) * action[t]
  → state_s 捕捉不同时间尺度的历史信息

  快衰减(α小): 捕捉最近几帧的变化
  慢衰减(α大): 保留长期趋势

  4个状态拼接 + 当前动作 + 速度 → MLP → 128维物理状态
```

**与文献对比**：
- FBV-SM：无时序编码，直接用当前关节角度
- Chen 2022：无时序编码，直接用当前关节角度
- SoftNeRF：无时序编码，直接用当前驱动状态
- **我们的创新**：EMA 编码器捕捉时间尺度信息，是本项目与所有现有工作的核心差异

**局限**: EMA 是线性算子，无法捕捉非线性迟滞（加载/卸载不对称）。HA-EMA 是改进方向（exp5）。

### 4.2 SkeletonHead — 骨架回归头

```python
输入: physics_state (B, 128)
输出: {coarse: (B, 4, 3), medium: (B, 10, 3), fine: (B, 31, 3)}

结构:
  共享 trunk: Linear(128→256) → ReLU → Linear(256→256) → ReLU
  ├── coarse_head: Linear(256 → 4×3=12)
  ├── medium_head: Linear(256 → 10×3=30)
  └── fine_head:   Linear(256 → 31×3=93)
```

**与文献对比**：
- SoftNeRF 的多尺度哈希编码 → 我们用多尺度骨架输出
- BANMo 的骨架驱动变形 → 我们用骨架条件密度场
- Chen 2022 的 Kinematic Network → 我们的 SkeletonHead 更直接（输出坐标而非特征）

31 个节点沿杆体均匀分布，从 base (z≈0) 到 tip (z≈0.5m)。输出直接是三维坐标 (x, y, z)，单位米。

### 4.3 SkeletonConditionedDensity — 骨架条件密度场

```python
输入:
  - query_points (N_rays, n_samples, 3) — 沿射线采样的3D点
  - skeleton (B, 31, 3) — 预测的骨架节点

处理流程:
  1. 计算 query_point 到每段骨架线段的距离 d
     → point_to_segment_distance (可微)
  2. 对距离做正弦位置编码: PE(d) → 13维
  3. 对查询点做位置编码: PE(x,y,z) → 28维
  4. 拼接 → 41维 → 5层MLP → [visibility, density] (2维)

直觉:
  - 离骨架近 → d小 → 编码值特殊 → 密度高
  - 远离骨架 → d大 → 密度趋零
  - 位置编码提供额外的空间位置信息
```

**与文献对比**：
- FBV-SM：`PosEncoder(xyz) + CmdEncoder(joints) → MLP → [vis, dens]`，无距离约束
- Chen 2022：`C(xyz) + K(joints) → SDF`，纯隐式
- SoftNeRF：`F_g(xyz) + F_k(A) → SDF`，纯隐式
- **我们的优势**：骨架距离显式约束密度分布，物理直觉清晰，训练更稳定

### 4.4 体渲染 — 从 3D 密度到 2D 图像

```python
1. 从相机发射射线 (100×100 = 10000 条)
2. 沿每条射线采样 48~64 个 3D 点
3. 每个点查询 density → (visibility, density)
4. OM_rendering (来自 FBV-SM):
   α = 1 - exp(-softplus(density))
   pixel = Σ(α × visibility)  # 沿射线累积
5. 得到 100×100 的渲染图像
6. 与真实图像比 MSE → 反向传播
```

### 4.5 两阶段训练

```
Phase 1 (骨架学习, ~50 epochs):
  loss = MSE(pred_skeleton, GT_3D_positions) + smoothness_reg
  只训练 temporal + skeleton_head, density 冻结

  这里用了仿真器的 3D GT！这是模型精度高的关键，也是
  "真正自建模"需要去掉的依赖。

Phase 2 (联合训练, ~200 epochs):
  loss = 3D_skeleton_loss + 0.5 × rendering_loss
  同时训练全部组件
```

| 纯2D渲染loss (exp1) | 0.3129 | 0.5884 | 0.041 | 0.014 | 0.302 | **85%** |

### 5.3 Exp1 — 纯 2D 渲染学习骨架（基线）

直接用 MS-SCNF 架构，不用 3D GT，纯 2D 渲染 loss 端到端训练。

```

正则化: λ_smooth=0.1, λ_length=0.05, λ_gravity=0.02
```

| 指标 | 结果 |

**分析**：Z 轴误差（0.264m）占总误差的 85%，证实单视角深度歧义是纯 2D 训练的根本障碍。

### 5.4 Exp1b — 渐进式 2D 骨架学习（改进）

采用三阶段渐进训练（垂直线先验 → 渲染 loss 渐进接管 → 纯图像监督），是物理先验辅助纯 2D 训练的首次验证。

| 对比 | MNE (m) | 改善倍数 |
|------|---------|---------|
| Exp1b vs Exp1 原始 | 0.154 vs 0.313 | **2.0x 改善** |
| Exp1b vs MS-SCNF (3D GT) | 0.154 vs 0.059 | 2.6x 差距 |

**逐轴分析**：
- X/Y 轴误差（0.060/0.037 m）相对合理，接近有 3D GT 的水平
- **Z 轴误差仍占主导**（0.110 m，占比 72%），但比 exp1 原始（85%）有明显改善
- 物理先验（垂直线 + 长度守恒 + 光滑）部分缓解了深度歧义，但**无法根本消除**

**结论**：物理先验 + 渐进训练将纯 2D 训练的骨架精度提升了 2 倍，Z 轴误差从 85% 降至 72%。但 Z 轴（深度方向）仍然是主要误差来源，单视角的深度歧义是**固有的几何限制**。

### 5.6 Exp3 — 多视角深度歧义分析

对已训练的 MS-SCNF（有 3D GT）模型，从正面/侧面/顶部三个视角分别渲染，分析骨架误差的轴向分布。

**骨架 GT 各轴变形量**：
- X range: mean=0.099m, max=0.288m（正面相机的深度方向）
- Y range: mean=0.115m, max=0.296m（侧面相机的深度方向）
- Z range: mean=0.446m, max=0.500m（垂直方向，变形量最大）

**模型预测各轴误差**：

| 方向 | 误差均值 (m) | 误差标准差 (m) | 误差最大值 (m) | 占比 | 该方向的相机可见性 |
|------|-------------|---------------|---------------|------|-----------------|
| X (正面深度) | 0.0373 | 0.0546 | **0.334** | **41.1%** | 正面相机看不到 |
| Y (侧面深度) | 0.0292 | 0.0446 | 0.266 | 32.2% | 侧面相机看不到 |
| Z (垂直) | 0.0242 | 0.0394 | 0.259 | 26.7% | 两个相机都能看到 |

**关键发现**：
1. **深度方向误差是固有且最大的**：即使在有 3D GT 训练的模型中，正面深度方向（X）误差也占 41.1%，最大单点误差达 0.334m
2. **误差排序与可见性完全对应**：看不到的方向误差最大 → 单视角深度歧义是不可回避的几何事实
3. **最大变形方向恰好是深度方向**：GT 骨架 Z 轴变形（0.446m）远大于 X/Y（0.099/0.115m），但 Z 不是深度方向所以误差反而最小
4. **推理：增加一个正交视角可以互补消除深度歧义**

### 5.7 Exp4 / Exp4b — 域随机化

**Exp4 原始结果**（存在评估 bug）：

| Baseline (无DR) | 1.221 m |
| DR 训练 | 1.108 m |

**Exp4b 修复后结果**（评估渲染 PSNR）：

| 配置 | Clean PSNR (dB) | PSNR@σ=0.1 | Drop | MNE (m) |
|------|----------------|------------|------|---------|
| no_dr | 21.84 | 17.56 | 4.28 | 1.533 |
| dr_light | **23.49** | **18.86** | 4.63 | 0.918 |
| dr_heavy | 17.16 | 17.97 | **-0.81** | 0.872 |

**分析**：
1. **dr_light 效果最好**：Clean PSNR 最高（23.49dB），噪声下也最好（18.86dB）
2. **dr_heavy 的反常表现**：Clean PSNR 反而低（17.16dB），但噪声下几乎不掉（Drop=-0.81）→ 过度随机化牺牲了干净条件下的精度，换来了极端鲁棒性

4. **MNE 仍然偏高**（~0.9-1.5m），说明 DR 实验的整体训练可能存在问题，需要进一步调试

### 5.8 Exp5 — 迟滞分析 (Standard EMA vs HA-EMA)

|--------|---------|---------------|------------|
| StandardEMA | **0.0226** | **0.0568** | 0.00513 |
| HA-EMA | 0.0234 | 0.0581 | **0.00439** |

**分析**：
1. **HA-EMA 的 MNE 略高于 StandardEMA**（0.0234 vs 0.0226，差 3.3%）→ HA-EMA 在骨架精度上**未表现出优势**
2. **HA-EMA 的 Smoothness 更好**（0.00439 vs 0.00513）→ 方向感知衰减率确实产生了更光滑的骨架
3. **可能原因**：

4. **结论**：HA-EMA 的方向感知设计在当前仿真设置下优势不明显。后续可尝试：
   - 增大仿真器阻尼系数，制造更强的迟滞效应
   - 在加载/卸载不对称的数据集上专门评估
   - 考虑更复杂的时序模型（如 GRU/LSTM 替代 EMA）

## 六、当前模型与原始设想的差距

### 6.1 保留了什么

| 原始设想 | MS-SCNF |
|---------|---------|
| 空间点坐标 + 驱动信号 → 可见度/密度 | ✅ 有这个路径 (forward) |
| 2D图像作为学习信号 | ✅ Phase 2 用渲染 loss |
| 体渲染框架 | ✅ OM_rendering (来自 FBV-SM) |

### 6.2 改变了什么

| 原始设想 | MS-SCNF | 原因 |
|---------|---------|------|
| 隐式学习3D形态 | 显式输出骨架坐标 | 隐式学习搜索空间太大，不收敛 |
| 只用2D图像训练 | Phase 1 用3D GT坐标 | 2D渲染loss梯度太弱，无法训练骨架 |
| 网络自由发现结构 | 假设31节点链式骨架 | 软体机器人是细长杆，骨架先验合理 |
| 单阶段端到端 | 两阶段训练 | 先学骨架再学外观，更稳定 |

### 6.3 本质差异

**原始设想**: 模型是一个纯粹的隐式场 (implicit field)，网络自己决定"机器人长什么样"

**当前 MS-SCNF**: 模型是一个**半显式**表示：
- 骨架是**显式**的（直接输出 3D 坐标）
- 外观（密度/可见度）是**隐式**的（基于骨架距离的神经网络）
- 训练依赖仿真器的 **3D GT 监督**

这不是完全的"自建模"——机器人被告知了骨架在哪里。但密度场部分确实是从 2D 图像学到的。

### 6.4 自建模假设深度分析

> 本节讨论自建模的定义边界、骨架先验的合理性、以及与现有工作的假设对比。

#### 6.4.1 假设的本质区别：输入先验 vs 输出先验

经过深入讨论，认识到我们的假设与三篇文献有**本质区别**——不在同一个层面：

| 文献 | 它的"假设" | 假设层面 | 对模型自由度的影响 |
|------|-----------|---------|------------------|
| FBV-SM | 前2关节用旋转矩阵 | 输入预处理 | 4 DOF→2 DOF，模型仍自由学习这2个DOF的影响，**输出形态完全自由** |
| Chen 2022 | 已知DH参数 | 输入空间定义 | 网络里根本没用DH参数，只是知道有几个关节，**输出形态完全自由** |
| SoftNeRF | 已知缆绳位移 | 驱动信号 | 这本来就是输入量，不是假设，**输出形态完全自由** |
| **本项目** | **31节点1D链骨架 + 距离条件密度** | **输出形态约束** | **输出形态被约束为细长杆** |

**关键区别**：前三篇论文的假设都在**输入侧**（知道驱动参数是什么、如何预处理），模型对输出形态完全不做假设——网络可以学出任何形状。而我们的假设在**输出侧**，直接约束了机器人的几何结构。

因此，前三篇是**通用的自建模方法**（理论上适用于任何形状的机器人），我们是**针对特定形态的自建模方法**。

#### 6.4.2 骨架距离约束的数学本质

SkeletonConditionedDensity 的密度约束是**软偏置**，不是硬公式：

```
硬约束（我们没有用）：
  density = σ_max × exp(-d² / (2σ²))    ← 固定高斯核，无法学习

软偏置（我们实际使用的）：
  d = point_to_segment_distance(xyz, skeleton)    ← 计算到骨架距离
  input = concat(PE(d), PE(xyz))                   ← 距离编码 + 空间编码
  [vis, dens] = MLP(input)                          ← MLP 自由决定输出
```

- MLP 接收距离编码作为主要输入特征（13/41 维）
- 但理论上可以输出任意密度模式（没有硬编码的衰减公式）
- **密度场是软偏置，但骨架本身是硬约束**——SkeletonHead 输出的31个节点必须是真实骨架位置

#### 6.4.3 异形机器人的骨架定义问题

当前方案对机器人形态的依赖：

```
圆柱形软体臂 → 骨架 = 中心线 → 清晰定义 ✅

异形机器人？
  - 平面软体机器人（片状游动器） → 1D骨架不够，需要2D骨架面
  - 分支软体结构（软体抓手） → 需要树状骨架
  - 膨胀/收缩型（气囊） → 骨架概念完全不适用
```

**改进方向——从2D图片提取骨架信息替代3D GT**：

| 方案 | 骨架来源 | 优势 | 局限 |
|------|---------|------|------|
| 当前 Phase 1 | 仿真器 3D GT | 精确 | 真实部署无法获取 |
| **改进方案** | **2D图片提取骨架/中心线** | 不需要3D GT，可用于真实部署 | 单视角缺深度信息 |
| 改进+多视角 | 多视角2D骨架三角化→3D | 结合方向C，获取3D骨架 | 需要多相机 |

改进方案的可行性分析：
1. 2D骨架/中心线提取是成熟技术（细化算法、关键点检测等）
2. 对于高对比度的软体臂目标，2D中心线提取尤其简单
3. 单视角2D骨架提供 X,Y 约束（缺 Z），结合物理先验可部分推断 Z
4. 多视角2D骨架三角化与方向C（多相机）天然结合
5. 骨架先验来源从"预设"变为"观测"——更接近真正的自建模

#### 6.4.4 "已知是圆柱体，为什么不直接建模？"

**我们知道"类型"，不知道"变形"**：
- 已知：机器人是细长杆（形态先验）
- 未知：给定驱动输入后，杆弯曲成什么形状（这正是要学习的映射）

**但这个先验确实限制了通用性**。核心矛盾是：

```
骨架先验的优势：降低学习难度，少量数据，直接3D输出
骨架先验的代价：只适用于可定义"骨架"的机器人形态

权衡：我们选择在特定形态上做到高精度，而非在所有形态上都做不好
```

#### 6.4.5 我们的定位

```
自建模方法的谱系（按输出自由度排序）：

完全自由输出（FBV-SM / SoftNeRF）
  ├─ 输入：3D坐标 + 驱动参数 → 输出：密度/颜色（隐式场）
  ├─ 对输出形态零假设，理论上适用于任何形状
  ├─ 代价：需要大量数据，深度歧义严重
  └─ 本质：通用自建模

结构化输出（Chen 2022）
  ├─ 输入：3D坐标 + 关节角度 → 输出：SDF值（隐式场）
  ├─ 不假设几何形态，但假设已知运动学结构
  ├─ 代价：需要DH参数 + RGB-D相机
  └─ 本质：运动学已知条件下的几何学习

形态约束输出（本项目）
  ├─ 输入：动作时序 → 输出：骨架坐标 + 条件密度场
  ├─ 假设输出为细长杆骨架，密度由骨架距离决定
  ├─ 代价：只适用于可定义骨架的形态
  └─ 本质：特定形态的高精度自建模
```

**论文定位建议**：

1. **诚实承认**：我们的方法引入了形态先验，不适用于所有类型的机器人
2. **强调优势**：形态先验带来的好处——少量数据、高精度、直接3D输出、可用于控制
3. **指出改进路径**：
   - 短期：2D图片提取骨架替代3D GT（Section 6.4.3），去除对仿真器的依赖
   - 长期：探索更通用的形态表示（如从数据中自动发现骨架结构）
4. **合理应用场景**：软体连续体机器人（气动/缆绳驱动的杆/臂）是最常见的软体机器人形态之一

## 七、后续发展方向

### 7.1 方向 A: 纯 2D 自建模 — 去除 3D GT 依赖

**要回答的问题**：去掉仿真器的 3D GT 坐标监督，仅用 2D 图像，MS-SCNF 能学到什么程度的 3D 骨架？

**已完成实验**：
- exp1: 纯 2D → MNE=0.313m（深度歧义严重，Z占85%）
- exp1b: 渐进式+物理先验 → MNE=0.154m（改善2x，Z降至72%）
- exp2: 3D GT vs 2D 对比 → 4.96x 差距

**结论**：单视角纯 2D 的精度上限约 0.15m（MNE），深度歧义无法完全消除。

**后续路径**：需要引入多视角约束（方向 C）才能进一步提升。

### 7.2 方向 B: 时序迟滞建模

**要回答的问题**：软体机器人的粘弹性迟滞能否被时序编码器捕捉？

**已完成实验**：
- exp5 Part 1: 仿真器迟滞验证 → 确认 PyElastica 有迟滞环
- exp5 Part 2: StandardEMA vs HA-EMA → HA-EMA 未显著优于 StandardEMA

**分析**：HA-EMA 的方向感知设计未带来显著精度提升。可能原因包括仿真器迟滞较弱、EMA 的 4 个 scale 已隐式捕捉历史信息等。

**后续路径**：
1. 增大仿真器阻尼制造更强迟滞
2. 在加载/卸载不对称数据上专门评估
3. 考虑更强的时序模型（GRU/LSTM）

### 7.3 方向 C: 多相机系统 — 消除深度歧义（推荐优先）

**要回答的问题**：额外增加一个正交相机视角，能把纯 2D 训练的骨架精度提升多少？

**已有证据**：
- exp3: 深度方向误差占 41.1%（最大单点 0.334m）
- exp1b: 物理先验将 Z 误差从 85% 降至 72%，但仍不够
- Chen 2022 验证：5× RGB-D 可实现精确 3D 自建模

**方案对比**：

| 方案 | 相机数量 | 是否需要 RGB-D | 深度歧义 | 实现复杂度 |
|------|---------|--------------|---------|-----------|
| Chen 2022 方案 | 5 台 RealSense D435i | 是 | 无 | 高 |
| 双视角 NeRF（推荐） | 2 台普通 RGB | 否 | 基本消除 | 中 |
| 单视角 + 物理先验 | 1 台 RGB | 否 | 部分缓解 | 低 |

**推荐方案**：双视角 RGB 相机 + 体渲染

理由：
1. 体渲染天然支持多视角训练，每个视角独立渲染、loss 累加
2. 双视角渲染 loss：`loss = MSE(render_front, GT_front) + MSE(render_side, GT_side)`
3. 不需要 RGB-D（Chen 2022 需要），体渲染从多视角 2D 图像隐式恢复 3D
4. 软体机器人是细长杆体，两个正交视角足以覆盖主要变形方向

**预期效果**：MNE 从 0.154m 降至 ~0.08-0.10m，接近有 3D GT 的 0.065m。

### 7.4 方向 D: 仿真到真实迁移

**要回答的问题**：域随机化能否提升模型在真实世界图像上的鲁棒性？

**已完成实验**：
- exp4: 评估 bug（MNE 与噪声无关）
- exp4b: 修复后 → dr_light 在 PSNR 上最优（23.49dB clean, 18.86dB noisy）

**结论**：轻量域随机化对渲染鲁棒性有帮助，但需要控制强度。

### 7.5 方向之间的执行优先级

```
推荐执行顺序:

1. 方向 C (多相机) — 最高优先级
   理由: exp1b 已确认单视角上限, 多视角是突破关键
   文献支撑: Chen 2022 的 5 相机方案验证了可行性
   预期: MNE 从 0.15m 降至 0.08m

2. 方向 A+B 结合 (纯2D + 多视角)
   理由: 多视角 + 物理先验组合可能接近 3D GT 水平
   预期: 纯视觉方案达到实用精度

3. 方向 D (sim-to-real)
   理由: 在仿真精度满足后, 需要验证真实世界可行性
   文献支撑: Chen 2022 已展示 sim→real 迁移
```

## 八、可能的论文定位

### 8.1 与三篇核心文献的差异化

| 论文定位 | 与 FBV-SM 的区别 | 与 Chen 2022 的区别 | 与 SoftNeRF 的区别 |
|---------|----------------|-------------------|-------------------|
| 软体机器人自建模 | 软体连续体 vs 刚性臂 | 未知运动学 vs 已知 | 显式骨架 vs 隐式场 |
| 骨架条件化密度场 | 隐式场 vs 显式骨架 | SDF vs 距离编码密度 | 隐式 vs 显式 |
| 时序历史建模 | 无时序 vs EMA | 无时序 vs EMA | 无时序 vs EMA |
| 纯视觉+双相机 | 单相机 | 5×RGB-D | 多视角RGB |

### 8.2 建议定位

**A+B+C 组合：骨架条件化软体机器人自建模 + 双视角消除深度歧义**

核心故事线：
1. 软体机器人需要从 2D 图像学习 3D 形状 → 借鉴 NeRF 范式
2. 纯隐式方法（FBV-SM/SoftNeRF）不收敛 → 提出显式骨架 + 条件密度场
3. 单视角存在深度歧义（exp3 量化） → 提出双视角体渲染方案
4. 时序编码器（EMA）捕捉软体特有的动态响应 → 区别于所有刚性机器人工作
5. 物理先验 + 渐进训练进一步缩小纯 2D 与 3D GT 的差距（exp1b 验证）
