# 实时分割与离线 SAM2 标签比较

## 1. 结论

在 `seq_20260819_182519` 的 3073 帧、9.17 Hz 实物序列上，当前单帧分割与15节点
骨架的平均计算时间为 **16.59 ms/帧**。SAM2.1 Hiera Tiny 因果前向传播加同一骨架
算法为 **134.04 ms/帧**；计入官方 video state 的图像预处理摊销后，估计在线感知时间为
**155.14 ms/帧**。

因此，在当前 RTX 3090、SAM2内部1024像素输入和现有实现下：

- SAM2在线感知比当前单帧方法平均增加 **138.55 ms/帧**，总计算时间约为 **9.35倍**；
- 持续处理能力约 **6.45 Hz**，低于该序列的9.17 Hz采集频率；
- 因果 SAM2 相对离线双向 SAM2 伪GT的平均 mask IoU 从0.910提高到0.960；
- 15节点平均误差从1.016 mm降至0.581 mm，超过5 mm的中心线异常从3.22%降至0；
- 每200帧因果重新锚定时，误差与锚点距离没有形成持续增长，主要差异来自运动片段和
  当前锚帧质量。

当前10 Hz控制链路适合继续使用单帧方法并执行质量门控。SAM2因果前向适合5 Hz级感知，
或在完成增量视频state、输入尺度和推理优化后重新评估10 Hz运行。

本实验比较感知计算，不包含相机曝光/传输、Planner、阀通信和控制等待时间。

## 3. 三种方法

### 3.1 单帧方法

该方法对应当前 `real_validation` 的白色机器人/蓝背景在线路径：

1. HSV低饱和高亮度得到白色外观区域；
2. 当前帧与固定背景的灰度差得到运动区域；
3. 两者取交集；
4. 开闭运算、孔洞填充和主体连通域选择；
5. 基座宽附件修剪；
6. 闭合细线遮挡窄缝并提取15节点骨架。

每一帧独立处理，输入为当前图像和部署时保存的背景。

### 3.2 SAM2因果在线方法

每个200帧块的第一帧使用当时单帧方法产生的主体mask作为当前提示，SAM2只向之后帧
传播。frame `t` 的结果仅使用 `0...t` 的图像和当前块首提示。这个定义用于量化在线
前向跟踪质量。

官方 SAM2 video predictor 接收完整JPEG目录建立state。本实验分别测量：

- PNG转JPEG暂存；
- state图像加载与归一化；
- mask prompt；
- 逐帧GPU前向、mask回传和CPU骨架。

其中在线时间估计排除了PNG转JPEG暂存，计入state图像预处理的逐帧摊销。部署到
`real_validation` 还需要实现相机帧逐张加入state的增量适配器。

### 3.3 SAM2分块双向伪GT

每个200帧块从全块候选中选择质量最高的锚帧，并从锚帧向块尾正向传播、向块首反向传播。
该结果是当前训练前处理采用的二维视觉监督标签，也是本实验的统一比较参考。

双向结果不是独立物理真值。它用于度量在线方法相对当前训练标签的数据分布差异。

## 4. 延迟结果

| 方法/阶段 | mean | p50 | p95 | 最大值 |
|---|---:|---:|---:|---:|
| 单帧分割 | 6.05 ms | 6.35 ms | 7.72 ms | 20.79 ms |
| 单帧骨架 | 10.54 ms | 10.99 ms | 12.40 ms | 72.60 ms |
| **单帧分割+骨架** | **16.59 ms** | **17.59 ms** | **19.73 ms** | **93.39 ms** |
| SAM2 GPU前向与mask回传 | 125.59 ms | 127.37 ms | 128.28 ms | 129.83 ms |
| SAM2结果骨架 | 8.44 ms | 7.76 ms | 10.75 ms | 24.65 ms |
| **SAM2前向+骨架** | **134.04 ms** | **135.29 ms** | **138.46 ms** | **151.58 ms** |
| state图像预处理摊销 | 21.02 ms | 20.99 ms | 24.72 ms | 24.80 ms |
| **SAM2估计在线感知总时间** | **155.14 ms** | **156.40 ms** | **159.56 ms** | **172.68 ms** |

模型首次加载需要0.943 s，一次运行只发生一次。当前SAM2估计在线感知比109 ms的输入
帧间隔多46.14 ms，持续输入时每秒会新增约423 ms积压。

本机SAM2可选CUDA后处理扩展未加载，当前运行跳过其小孔填充步骤。离线与在线比较均使用
当前环境的模型实现；部署版本应固定同一依赖合同后重新测量。

## 5. 相对离线双向伪GT的精度

### 5.1 汇总指标

| 方法 | mask IoU mean / p50 | 15节点误差 mean / p50 / p95 | tip误差 mean / p95 |
|---|---:|---:|---:|
| 单帧方法 | 0.910 / 0.928 | 1.016 / 0.470 / 1.444 mm | 1.583 / 2.182 mm |
| 因果 SAM2 | **0.960 / 0.965** | **0.581 / 0.360** / 1.790 mm | **0.319 / 0.845 mm** |

因果SAM2的平均值、中位数和极端尾部更稳定；单帧方法的p95全节点误差略小，但它在更高
尾部出现细线粘连引起的中心线长分支：p99达到14.99 mm，最大47.82 mm。因果SAM2的
p99为2.01 mm，最大2.47 mm。

### 5.2 异常比例

| 条件 | 单帧方法 | 因果 SAM2 |
|---|---:|---:|
| mask IoU < 0.9 | 33.88% | 1.63% |
| 全节点平均误差 > 2 mm | 3.48% | 1.11% |
| 全节点平均误差 > 5 mm | 3.22% | 0% |
| tip误差 > 2 mm | 5.60% | 0.33% |
| tip误差 > 5 mm | 3.42% | 0% |

真实照片叠图显示，单帧候选偶尔把末端细线连接到主体，最长主路径随后沿细线继续延伸。
因果SAM2在这些帧保持了主体对象的时间一致性。

### 5.3 锚点后步距

将每个200帧因果块按距离当前锚点的步数分为25帧一组，mask IoU均值保持在
0.956–0.961，15节点均值保持在0.543–0.617 mm。步距与指标的相关系数为：

- `corr(k, mask IoU) = 0.0178`
- `corr(k, node error) = 0.0362`

这批数据中没有观察到200帧范围内随步距单调增加的漂移。各块15节点平均误差范围为
0.184–1.532 mm，说明当前提示和运动片段是更主要的变化来源。

## 6. 双向传播的等待时间

离线流程在每块中选择质量最高的锚帧。该序列16个锚帧相对块首的偏移为：

- mean：99.6帧，10.85 s；
- p50：112.5帧，12.26 s；
- p95：180.3帧，19.65 s；
- max：193帧，21.04 s。

因此，即使在锚帧到达后立即反向处理，块首附近标签也需要等待约0.4–21.0 s的未来图像。
双向流程适合采集后的监督标签生成和离线评价。

## 7. 对 real_validation 的建议

### 当前10 Hz实验

使用单帧方法作为每帧主感知，并利用已有面积、路径长度、端点和时间连续性质量门控。
质量异常帧保持最近一次合格Anchor并请求下一帧，避免细线粘连进入Planner状态。

### SAM2部署实验

SAM2因果前向可作为独立5 Hz配置开展真实控制测试。部署工作包括：

1. 实现增量相机帧state，保持当前帧与历史记忆的因果关系；
2. 固定锚点确认和周期重锚策略；
3. 将SAM2输入尺度从1024开始做512/768消融；
4. 启用并验证CUDA后处理扩展；
5. 同时记录相机时间戳、分割完成时间和控制动作时间；
6. 用本脚本重新检查延迟、mask IoU、15节点误差和按锚点步距漂移。

10 Hz版本的准入条件是感知p95低于109 ms，并为Planner和阀通信保留单独预算。
