## 1. NeRF (Mildenhall et al., 2020) — Neural Radiance Fields

**一句话**：用 MLP 将 5D 坐标（3D 位置 + 2D 视角）映射为颜色+密度，通过体渲染合成新视角图像。

**核心创新**：
- **隐式神经表示**：不用显式网格/点云，用一个 MLP 表示整个 3D 场景
- **位置编码（Positional Encoding）**：将低维坐标映射到高频正弦-余弦空间，使 MLP 能拟合高频细节。公式：`PE(x) = [x, sin(2^0 x), cos(2^0 x), ..., sin(2^L x), cos(2^L x)]`，L=10
- **体渲染（Volume Rendering）**：沿射线采样点，用密度加权求和得到像素颜色。可微，支持端到端训练
- **分层采样（Coarse + Fine）**：先均匀采样训练 coarse 网络，再用 coarse 的密度分布指导 fine 网络的重点采样

**关键技术细节**：
- 渲染公式：`C(r) = Σ T_i * α_i * c_i`，其中 `T_i = Π(1-α_j)` 是累积透射率
- 输入：`(x, y, z, θ, φ)` → 输出：`(RGB, σ)`
- 训练数据：仅需多视角 2D 照片 + 相机位姿

**与我们项目的关联**：
- 整个项目基于 NeRF 范式——FBV-SM 将视角替换为关节角度，我们进一步替换为动作时序
- 位置编码、体渲染、射线采样等核心组件直接复用

## 2. FBV-SM (Hu et al., 2025) — Teaching Robots to Build Simulations of Themselves

**一句话**：让机器人通过单相机自我观察学会一个"自仿真模型"——输入关节指令就能预测自己的外观。

**核心创新**：
- **NeRF 范式的创造性迁移**：将 NeRF 的"从视角合成图像"变为"从关节角度合成机器人外观"
  - NeRF 输入 `(x,y,z, θ,φ)` → FBV-SM 输入 `(x,y,z, joint_angles)`
  - 输出从 RGB 颜色简化为 `(visibility, density)`，因为机器人是单色的
- **几何先验与网络学习的分工**：
  - 前 2 个关节（θ, φ）控制整体偏航/俯仰 → 用旋转矩阵 `Rot_Z(θ) × Rot_Y(φ)` 确定性处理
  - 剩余关节控制局部构型 → 交给网络学习
  - 意义：确定性变换不需要学，网络只需学局部变形，大幅降低难度
- **自仿真应用**：学到的模型不止用于可视化，还能做运动规划：
  - 梯度优化：优化关节角度使端点到达目标位置
  - A*/RRT 路径规划：用自模型的 3D 占据点云做碰撞检测
  - 无碰撞轨迹规划：联合优化距离损失 + 碰撞损失 + 平滑损失

**关键技术细节**：
- 4-DOF 刚性臂（PyBullet 仿真），固定单相机视角
- 网络架构：`PosEncoder(3D) + CmdEncoder(joints) → FeedForward → [vis, dens]`
- 约 10000 张不同关节配置下的图像即可训练
- 可提取 3D 占据点云：在空间均匀采样查询点，过滤 `visibility > 0.08` 的点

**与我们项目的关联**：
- 我们直接复用了 FBV-SM 的体渲染管线（OM_rendering、sample_stratified、get_rays）
- 我们将"关节角度"扩展为"动作时序窗口"（因为软体机器人有惯性/迟滞）
- 几何先验分工思想 → MS-SCNF 中骨架回归（确定性几何）与密度场（学习部分）的分离

## 3. Chen et al., 2022 — Full Body Visual Self-Modeling of Robot Morphologies

**一句话**：机器人的全身视觉自建模——从不完美的自我感知中学习完整的身体模型。

**核心创新**：
- **全身建模**：不只是端点或局部，而是学习机器人完整身体的 3D 模型
- **不完美自我感知**：机器人只能看到自己的部分身体（遮挡、视角限制），但仍需推断完整形态
- **形态发现**：在没有 CAD 模型的情况下，通过自观察发现自身的几何结构

**与我们项目的关联**：
- 与 FBV-SM 的工作一脉相承，FBV-SM 可视为该工作的 NeRF 化升级
- 强调了自建模中"从不完整观测推断完整形态"的挑战，这在我们单视角设置中同样存在

## 4. D-NeRF (Park et al., 2021) — Deformable Neural Radiance Fields

**一句话**：将动态场景分解为静态 canonical 场 + 动态变形场，实现单视频的动态 NeRF 重建。

**核心创新**：
- **Canonical + Deformation 范式**：
  - Canonical field：一个静态的 3D 场景表示（所有时刻共享）
  - Deformation field：对每个时刻 t，将观测空间的点映射回 canonical 空间
  - 查询流程：`观测点 x_t → Deformation(x_t, t) → canonical 坐标 x_c → Canonical(x_c) → (color, density)`
- **解耦形状与运动**：形状信息集中 canonical，运动信息集中在 deformation
- **时间编码**：将时间 t 作为 deformation MLP 的输入条件

**关键技术细节**：
- Deformation MLP 输入：`(x, y, z, t)` → 输出：3D 位移 `(Δx, Δy, Δz)`
- Canonical MLP 输入：变形后的坐标 → 输出：`(color, density)`
- 训练只需要单摄像机视频（不同时刻的图像）

**与我们项目的关联**：
- **C-MSTNF 直接采用此范式**：
  - CanonicalField = 零动作下机器人的静止形态
  - DeformationField = 动作引起的 3D 变形
  - 但用 MultiScaleEMA 替代时间 t 作为变形条件
- **问题也来源于此**：D-NeRF 的 deformation MLP 是无约束的，在刚性场景效果好，但对软体机器人的大幅变形容易出现高频跳变

## 5. Nerfies (Park et al., 2021) — Deformable Neural Radiance Fields for Casual Videos

**一句话**：用可变形 NeRF 从随手拍的视频中创建可动画化的 3D 场景（如人脸表情变化）。

**核心创新**：
- **变形基函数（Deformation Basis）**：不是让网络自由输出变形，而是学习一组基函数，变形 = 基函数的加权组合
  - 好处：基函数本身光滑 → 变形天然光滑，不产生高频伪影
- **可变形基函数约束**：通过约束基函数的性质来保证变形的物理合理性
- **用于人脸/宠物等非刚性场景**：处理表情变化、身体运动等

**关键技术细节**：
- 每帧有一个低维 appearance embedding 作为变形条件
- 变形场用 MLP 但增加了弹性正则化（as-rigid-as-possible）
- 使用 coarse-to-fine 的位置编码策略避免局部最优

**与我们项目的关联**：
- 变形基函数思想直接启发了我们的 improvement_proposals 方案 A（RBF 基函数变形）
- "约束基函数保证光滑"的思路 → MS-SCNF 中"约束骨架结构保证光滑"
- coarse-to-fine 位置编码 → 我们的课程式频率学习方案 E

## 6. HyperNeRF (Park et al., 2022) — A Hyperdimensional View of Deformable NeRF

**一句话**：Nerfies 的升级版，能够处理拓扑变化的动态场景（如杯子被遮挡/露出）。

**核心创新**：
- **超维切片（Hyperdimensional Slicing）**：
  - 不在一个固定的 3D canonical 空间中变形
  - 而是在一个更高维的 canonical 空间（如 4D/5D）中，每个时刻取一个"切片"
  - 不同时刻的切片可以对应不同的拓扑结构
- **拓扑变化建模**：能处理物体的出现/消失、折叠、展开等
- **可变形基函数的扩展**：基函数不再是一组固定的函数，而是可以变化的

**关键技术细节**：
- Canonical 空间是 (x,y,z,w) 的超维空间，每个时刻 t 对应一个 3D 切片
- 用环境图（ambient map）将观测点映射到高维空间
- 训练需要视频 + 相机位姿估计

**与我们项目的关联**：
- 超维切片概念可以理解为我们 MultiScaleEMA 的物理类比——将高维动作历史压缩为低维"切片"
- 我们不需要拓扑变化（软体臂始终是连续杆），所以 D-NeRF 的标准范式已够用

## 7. SoftNeRF (Shan et al., 2024) — A Self-Modeling Soft Robot Plugin for Various Tasks

**一句话**：首个将条件化 NeRF 应用于软体机器人的自建模方法，使用多尺度哈希编码 + SDF 体渲染，通过多视角 RGB 图像训练。

**核心创新**：
- **Kinematic-Aware SDF Hash Grids**：
  - 灵感：软体机器人的粗大结构（整体弯曲）需要低分辨率编码，精细结构（局部皱褶）需要高分辨率编码
  - 实现：Instant-NGP 风格的多分辨率哈希编码（16 级，2⁵~2¹¹），自适应分配容量
  - 效果：比统一频率编码更好地平衡全局形状与局部细节
- **条件 NeRF for 软体**：
  - 以机器人驱动状态（4 根缆绳位移）为条件，而非固定形态
  - 不同驱动状态 → 不同 SDF 场 → 不同 3D 形状
- **多视角 2D 监督**：
  - 仿真：每个驱动状态 65 张多视角 RGB 图像
  - 真实：手机环绕拍摄多视角视频
  - 通过体渲染的多视角一致性隐式恢复 3D 结构
- **误差引导自适应采样**：
  - 粗训练（10K 迭代全像素）→ 精训练（误差引导像素采样）
  - 在图像平面上根据渲染误差重采样像素，聚焦高误差区域

**关键技术细节**：
- 输入：3D 坐标 + 软体驱动参数 → 输出：SDF 值 + 颜色
- 架构：Kinematic Encoder (4层MLP, 128ch) + SDF Decoder (4层MLP, 128ch) + Color Decoder (2层MLP, 64ch)
- 哈希编码：16 级，分辨率 2⁵~2¹¹，每级 8 通道，总输出 128 维
- 训练：100,000 迭代，RTX 6000，λ_color=1, λ_reg=0.1, λ_mask=0.1

**与我们项目的关联**：
- **最直接的相关工作**——也是软体机器人 + NeRF 自建模
- 大小精度编码启发了我们的多尺度骨架设计：SkeletonHead 在 coarse(4) / medium(10) / fine(31) 三个尺度回归
- Phase 1→Phase 2 的 coarse-to-fine 训练策略也借鉴了"先粗后细"的思想
- 关键区别：SoftNeRF 仍用隐式密度场，我们用显式骨架 + 骨架条件密度场

## 8. BARF (Wang et al., 2021) — Bundle-Adjusting Neural Radiance Fields

**一句话**：不需要精确相机位姿，联合优化 NeRF 和相机位姿——核心是课程式位置编码。

**核心创新**：
- **课程式位置编码（Coarse-to-Fine Positional Encoding）**：
  - 不一次性使用全部频率的位置编码
  - 训练初期只用低频（1-2 个频率）：让网络先学全局结构
  - 训练后期逐步增加高频：让网络再学局部细节
  - 好处：避免高频分量在初期干扰全局优化，防止陷入局部最优
- **联合优化（Bundle Adjustment）**：同时优化 NeRF 参数和相机位姿参数
  - 传统 NeRF 需要精确的相机位姿（COLMAP 等 SfM 预处理）
  - BARF 从粗糙位姿出发，在训练中逐步精化

**关键技术细节**：
- 频率 mask：`mask(f) = sigmoid(α * (f - β))`，β 随训练进度线性增加
- 低频时只能看到模糊的全局形状 → 相机位姿优化更稳定
- 高频时才引入细节 → 此时位姿已基本正确

**与我们项目的关联**：
- 直接启发了方案 E（课程式频率学习），并在 notebook 07 中验证
- 我们在变形场中使用 `deform_n_freqs=6`，BARF 的策略建议从 2 开始逐步增加到 6
- 核心洞察：**频率控制 = 优化难度的控制**，对变形场同样适用

## 9. BANMo (Yang et al., 2022) — Building Animatable 3D Neural Models from Casual Videos

**一句话**：从随意拍的视频中构建可动画化的 3D 动物模型，核心是骨架驱动的变形。

**核心创新**：
- **骨架驱动变形（Skeleton-Driven Deformation）**：
  - 先预测 3D 骨架（关节位置），再用骨架驱动表面变形
  - 骨架是低维的（几十个关节点），表面是高维的（数万顶点）
  - 骨架变化 → 蒙皮权重（LBS）→ 表面变形
- **从视频到可动画模型**：
  - 输入：随意拍摄的视频（多视角、非同步）
  - 输出：一个可以驱动关节来动画化的 3D 模型
  - 无需 3D 扫描或动作捕捉
- **形状、姿态、外观的解耦**：
  - Shape：个体特有的体型（胖/瘦）
  - Pose：关节角度驱动的姿态
  - Appearance：纹理/颜色

**关键技术细节**：
- 使用模板网格 + Linear Blend Skinning (LBS)
- 从视频中提取 2D 关键点，通过多视角约束反推 3D 骨架
- 可学习的蒙皮权重将骨架运动传播到表面

**与我们项目的关联**：
- **骨架驱动思想直接启发了 MS-SCNF**：
  - BANMo：骨架 → 表面变形
  - MS-SCNF：骨架 → 密度场（距离到骨架的距离）
- 我们的任务更简单：软体臂只有一个"关节"（固定端），骨架就是中心线
- 区别：BANMo 需要学习蒙皮权重，我们用距离函数隐式处理

## 11. 文献启示与我们的创新点

### 从文献中得到的启示

| 启示来源 | 核心思想 | 我们的运用 |
|---------|---------|-----------|
| NeRF | 位置编码 + 体渲染 + 隐式表示 | 整个管线的基础 |
| FBV-SM | 几何先验与网络学习分工 | 骨架回归（确定性） vs 密度场（学习） |
| D-NeRF | Canonical + Deformation 解耦 | C-MSTNF 的架构基础 |
| Nerfies | 变形基函数保证光滑 | 骨架结构天然光滑 |
| SoftNeRF | 多尺度精度编码 | 多尺度骨架 (coarse→medium→fine) |
| BARF | 课程式频率学习 | 频率 schedule + coarse-to-fine 训练 |
| BANMo | 骨架驱动表面变形 | 骨架条件密度场 |

### MS-SCNF 的核心创新

1. **显式骨架回归替代隐式变形场**：SkeletonHead 直接预测 3D 节点坐标，物理约束自然保证平滑性和端点精度

2. **多尺度骨架监督**：coarse(4) → medium(10) → fine(31)，粗尺度先学整体趋势，细尺度再修局部

3. **骨架条件密度场**：密度取决于查询点到骨架曲线的距离，物理合理且自动稀疏

4. **仿真器 3D GT 监督**：利用 PyElastica 的 position_collection 做定量 3D 评估

5. **部署直接输出 3D 形状**：一次前向推理输出完整 3D 骨架，无需体渲染
