## 1. Neural ODE 时序编码（ODE-CMSTNF）

**日期**: 2026-04
**状态**: 已实现，归档

**灵感来源**: 软体臂的弯曲响应物理上近似为阻尼谐振子，EMA 是一阶系统只能指数衰减，无法捕捉振荡。

**核心想法**:
用 Neural ODE 替代 MultiScaleEMA 做时序编码。状态分为 [position, velocity]，动力学为阻尼弹簧模型：
```
ds_pos/dt = s_vel
ds_vel/dt = -k * s_pos - c * s_vel + B * action
```
k（刚度）、c（阻尼）、B（力矩阵）可学习。

**优势**:
- ODE 积分保证状态轨迹连续——微小输入变化不会导致输出跳变
- 二阶动力学可捕捉阻尼振荡
- 可嵌入物理先验

**归档原因**: 训练不稳定（RK4 积分梯度爆炸），效果不如 EMA。思路本身有价值，后续可用 adjoint method 或更稳定的 ODE solver 重新尝试。

**归档文件**: `docs/archived/ode_cmstnf/`

## 2. 光谱正则化变形场（Smooth-CMSTNF）

**日期**: 2026-04
**状态**: 已实现，归档

**灵感来源**: C-MSTNF 的变形 MLP 可能产生高频跳变——微小动作变化导致巨大形状变化。

**核心想法**:
在 C-MSTNF 变形场上施加三种正则化：
1. **Spectral Normalization**: 限制变形 MLP 每层权重矩阵的谱范数，控制 Lipschitz 常数
2. **Jacobian Penalty**: `mean((∂displacement/∂x)²)` — 惩罚变形场对空间坐标的剧烈梯度
3. **Temporal Gradient Penalty**: `||D(x,a_t) - D(x,a_{t+1})||² / ||a_t - a_{t+1||²` — 变形随时间的变化率应正比于动作变化率

**归档原因**: 正则化权重调节困难，过于保守则变形能力不足，过于宽松则无效果。当前骨架+SDF 方案（方案 B）从架构层面保证了连续性，不需要额外正则化。

**归档文件**: `docs/archived/smooth_cmstnf/`

## 4. Flow Matching 条件点云生成（方案 A）

**日期**: 2026-05
**状态**: 调研中，未实现

**灵感来源**: Action-Conditioned Flow Matching（arXiv 2605.09216, 2025）

**核心想法**:
放弃隐式场+体渲染，改用 action-conditioned flow matching 直接生成点云。学习条件速度场 `u_theta(X_t, t | c)`，从高斯噪声积分到目标点云。

**预期优势**: 点云天然连续不存在断裂；Flow 的平滑性保证时间连续性；无需体渲染。

## 5. 顶层思考：从"更好的预测"到"真正的科学问题"

**日期**: 2026-06
**状态**: 深度思考中

### 背景反思

Tang 2026 (ICRA) 和 Yu 2026 (arXiv) 的成功模式：

| 特征 | Tang 2026 | Yu 2026 |
|------|-----------|---------|
| 方法复杂度 | CNN + 在线优化（简单） | Bézier + Neural ODE（简单） |
| 科学贡献 | "全身形状控制"（新问题） | "可解释形状"（新视角） |
| 实验验证 | 真实硅胶臂 | 真实线驱动臂 |
| 创新核心 | 问题重新定义 | 表示方法创新 |

**共同规律**：创新不在算法复杂度，而在**问题定义**。他们不是在别人的基础上换模型，而是重新定义了"什么值得解决"。

**我们目前的困境**：
- 一直在优化"从驱动参数预测3D骨架"这个预测精度问题
- 这是一个工程问题（"预测得更准"），不是科学问题（"为什么是这样"）
- 预测精度再提升，也只是边际改进，不会让审稿人兴奋

### 我们的独特优势（别人没有的）

经过几个月的探索，我们积累了两个独特优势：

1. **迟滞建模能力**：GammaLaguerre / FractionalMemory 时序编码器，可以建模加载历史对当前形状的影响。这是目前所有软体机器人自建模工作都忽略的维度。

2. **仿真平台的物理真实度**：PyElastica 是经过验证的 Cosserat 杆仿真器，它的粘弹性、迟滞响应是物理真实的。我们可以在仿真中创造现有方法必然失败的场景。

### 核心洞察

**迟滞不是需要"克服"的工程问题——它是软体机器人区别于刚性机器人的本质物理特征。**

刚性机器人：当前状态 = f(当前动作) → 无记忆，马尔可夫
软体机器人：当前状态 = f(动作历史) → 有记忆，非马尔可夫

所有现有方法（Tang, Yu, SoftNeRF, 3DGS）都隐式假设了马尔可夫性。
一旦这个假设被打破（循环加载、变速加载、残余变形），这些方法都会失败。

**我们不是在做一个"更好的预测模型"，而是在揭示一个被整个领域忽略的基本物理现象。**

### 判断标准

什么样的方向值得投入？用三个标准过滤：

1. **物理必然性**：不是"也许能改进"，而是"物理上必然如此"
2. **现有方法的根本盲区**：不是现有方法做得不够好，而是它们在概念上就不可能做到
3. **简单到令人信服**：实验设计简单，结果直观，审稿人一看就懂

## 6. 方向一：粘弹性体的历史依赖逆运动学

**日期**: 2026-06
**状态**: 新方向
**科学问题**: 软体机器人的逆运动学是"函数"还是"泛函"？
**目标会议/期刊**: RSS / ICRA / T-RO

### 问题重新定义

传统逆运动学（IK）假设：

```
target_shape → find action a* s.t. shape(a*) = target
```

这是"函数"思维：给定目标，找一个最优动作。对于刚性机器人，这是正确的——相同动作永远产生相同构型。

但对于粘弹性软体机器人：

```
target_shape + current_state → find action SEQUENCE s.t. shape(sequence) = target
```

这是"泛函"思维：相同目标形状，从不同初始状态出发，需要**完全不同的驱动轨迹**才能到达。而且，到达同一个目标形状的路径不止一条——加载速度、路径曲率都会影响最终形状。

**这不是工程细节，而是根本性的区别。** 现有的软体机器人 IK 方法（Yu 2026 的 Jacobian 伪逆、DVIK 的隐式 latent IK）都在概念上假设了函数映射。如果我们在循环加载或变速加载下测试这些方法，它们会系统性地失败。

### 为什么别人没想到？

因为现有论文的数据采集都是在"准静态"条件下进行的：
- Tang 2026: 每个形状保持足够长时间才拍照 → 排除了瞬态
- Yu 2026: 每次驱动后等待稳定才采集 → 排除了历史效应
- SoftNeRF: 多视角拍照是静态场景 → 没有动态

他们的"成功"建立在排除粘弹性效应的实验设计上。一旦实验条件包含动态加载，这些方法就会暴露出根本性缺陷。

### 方法（非常简单）

不需要新的神经网络架构。只需要：

1. **正向模型**：我们已经有的 SpatialSequence + GammaLaguerre
2. **逆向求解**：给定 target_shape 和 current_state，通过梯度优化找 action_sequence
3. **基线对比**：无记忆模型（直接用当前 action）vs 有记忆模型（用 action history）

```python
# 伪代码
def hysteresis_aware_ik(target_shape, current_state, model, n_steps=10):
    """历史依赖逆运动学"""
    action_seq = torch.randn(n_steps, action_dim, requires_grad=True)

    for iteration in range(max_iter):
        # 用有记忆的正向模型预测形状
        pred_shape = model.forward(action_seq, initial_state=current_state)
        loss = MSE(pred_shape[-1], target_shape)
        loss.backward()
        action_seq.data -= lr * action_seq.grad
        action_seq.grad.zero_()

    return action_seq
```

### 关键实验

**实验 1：循环加载下的 IK 失败**
- 从状态 A 驱动到形状 B，再回到 A，再驱动到 B
- 无记忆模型：第二次到达 B 的预测与第一次相同 → 错误（粘弹性累积效应）
- 有记忆模型：正确预测第二次的形状不同于第一次

**实验 2：速率依赖 IK**
- 同一目标形状，分别用 0.1s、1s、5s 的驱动时间到达
- 无记忆模型：预测相同的最终形状 → 错误（粘弹性速率依赖）
- 有记忆模型：预测不同的最终形状，且给出到达目标的最优速率

**实验 3：残余变形下的 IK**
- 从已变形状态（卸载后未完全恢复）出发，驱动到目标形状
- 无记忆模型：假设从零状态出发 → 错误
- 有记忆模型：正确补偿残余变形

### 科学贡献

1. **首次形式化**软体机器人 IK 的历史依赖特性
2. **揭示**现有方法在动态加载条件下的根本性失败
3. **提出**简单有效的历史依赖 IK 框架
4. **实验验证**粘弹性效应在真实软臂控制中的影响

### 发表策略

- **短版本**（6 页）→ ICRA 2027：聚焦"循环加载下 IK 失败"的发现 + 简单解法
- **长版本**（15 页）→ T-RO：全面的理论分析 + 实验验证 + 与 Yu/Tang 的对比
- **前提**：需要至少仿真层面的完整实验（PyElastica 足够），真实机器人更佳

## 7. 方向二：迟滞不是 Bug，是 Feature——粘弹性体的信息容量

**日期**: 2026-06
**状态**: 新方向（高风险高回报）
**科学问题**: 软体机器人的当前形状编码了多少关于加载历史的信息？
**目标期刊**: Science Robotics / Physical Review / Nature Communications

### 核心洞察

粘弹性迟滞通常被视为需要克服的麻烦。但如果换一个视角：

**软体机器人的身体就是一个物理记忆装置。**

加载历史被"写入"材料的微观结构中，表现为当前的宏观形状。这就像一个模拟存储器——不是数字的 0/1，而是连续的空间变形场。

生物学类比：
- 人类的皮肤在受到持续压力后留下压痕（可逆的物理记忆）
- 植物的向光性生长记录了光照方向的历史
- 肌肉的张力状态编码了最近的运动历史

软体机器人也有这种"身体记忆"。问题是：**这个记忆的容量有多大？能否被读取？**

### I(S; H) 的物理含义——直白解释

I(S; H) 是互信息（Mutual Information），其中：
- **H** = 加载历史 = 过去的动作序列 {a₁, a₂, ..., aₜ}
- **S** = 当前形状

**物理含义**：如果你只看机器人当前的形状，你能推断出多少关于它过去被怎么驱动的信息？

两种极端情况让你直观理解：
- **无迟滞（理想弹性体）**：形状只由当前动作决定 → I(S; H) ≈ 0，看形状猜不出历史
- **完美记忆（迟滞无穷大）**：形状完全编码了整个加载路径 → I(S; H) 很大，看形状就能反推出历史

**所以 I(S; H) 本质上是在量化"这个材料有多少迟滞"。**

### 与两种假设的关系

这个方向和自回归文档中讨论的两种假设有层次上的区别：

| 层次 | 问题 | 性质 |
|------|------|------|
| 假设一（稳态） vs 假设二（状态转移） | 迟滞**怎么建模**？ | 工程问题：选哪个模型 |
| 信息容量方向 | 迟滞**有多少**？ | 科学问题：量化一个物理性质 |

信息容量方向为假设选择提供**定量依据**：
- 如果 I(S; a_{t-k}) 在 k>3 时就接近零 → 记忆窗口只有 3 步，假设一够用
- 如果 I(S; a_{t-k}) 衰减很慢 → 假设二必须用，而且需要长历史窗口

**简单说：先用量化实验测迟滞有多强，再决定用什么模型。**

### 信息论形式化

设加载历史为随机变量 H = {a₁, a₂, ..., aₜ}，当前形状为 S。

**核心问题**：I(S; H) = ? 即当前形状包含多少关于加载历史的信息？

具体而言：
- **短期记忆**：I(S; aₜ₋₁) vs I(S; aₜ₋₅) vs I(S; aₜ₋₂₀) → 衰减曲线
- **顺序记忆**：给定形状，能否区分 [左→右] vs [右→左] 的加载序列？
- **速率记忆**：给定形状，能否区分快速弯曲 vs 慢速弯曲？
- **极限容量**：加载序列空间中，有多少个可区分的形状状态？

### 方法（极简）

不需要复杂的神经网络。只需要：

1. **编码实验**：生成大量不同的加载历史 H_i → 仿真得到形状 S_i
2. **解码实验**：训练简单分类器/回归器从 S_i 预测 H_i 的某些属性
3. **容量估计**：用互信息估计器（MINE 或 binning 方法）计算 I(S; H)

```python
# 伪代码：信息容量估计
# 1. 采样不同加载历史
histories = sample_diverse_loading_sequences(n=10000)
# 2. 仿真得到形状
shapes = [simulate(h) for h in histories]
# 3. 训练解码器
classifier = train_classifier(shapes, labels_from(histories))
# 4. 测量解码精度 → 估计互信息
accuracy = evaluate(classifier, test_shapes, test_labels)
I_S_H = estimate_mutual_information(accuracy, n_classes)
```

### 关键实验

**实验 1：时间窗口的互信息衰减**
- 测量 I(形状; k 步前的动作) 随 k 的变化
- 预期：幂律衰减（分数阶记忆的物理对应）
- 对比：EMA 模型预测的指数衰减 vs 实际的幂律衰减

**实验 2：顺序可辨识性**
- 生成加载序列 A=[+1, -1, +1] 和 C=[-1, +1, -1]（相反顺序，最终驱动值相同）
- 问题：最终形状能区分 A 和 C 吗？→ 回答"迟滞是否可观测"

**实验 3：速率编码**
- 同一最终目标，不同加载速率
- 问题：形状能解码加载速率吗？→ 回答"速率依赖性是否可观测"

**实验 4：物理记忆的写入-读取**
- "写入"：施加特定加载序列
- "存储"：等待一段时间
- "读取"：从当前形状推断加载序列的类别
- 问题：存储时间如何影响读取精度？

### 科学贡献

1. **首次量化**粘弹性软体机器人形状的信息编码能力
2. **建立**迟滞的信息论框架——从"工程麻烦"升格为"物理通道"
3. **连接**软体机器人学与信息论、非平衡态统计力学
4. **启发**新型传感器设计——利用身体本身作为分布式传感器

### 为什么这可能发 Science Robotics？

因为它重新定义了"软体机器人"的本质特征：
- 不是"用软材料做刚性机器人能做的事"
- 而是"利用软材料的独特物理性质（迟滞=记忆）实现刚性机器人做不到的事"

这种范式转换是 Science Robotics 级别的贡献。

### 风险

- 如果互信息太小（形状几乎不编码历史），结论是负面但仍有价值："粘弹性记忆在当前材料参数下不可观测"
- 需要真实材料参数的验证——纯仿真可能被认为不够
- 信息论估计方法需要选择合适的技术路线

## 8. 方向三：因果结构自发现——未校准软体机器人的自建模

**日期**: 2026-06
**状态**: 新方向
**科学问题**: 一个"出厂"的软体机器人，能否仅通过观察自身的运动，自动发现其驱动结构的因果图？
**目标会议**: CoRL / RSS

### 问题重新定义

现有自建模方法的隐含假设：

| 假设 | 含义 | 问题 |
|------|------|------|
| 已知驱动维度 | 知道有几个电机 | 新设计可能不确定 |
| 已知驱动映射 | 知道哪个电机控制哪段 | 线驱/气动的映射很复杂 |
| 已知响应特性 | 知道响应延迟和幅度 | 材料/温度会改变 |

**问题**：如果把一个全新的软体机器人放在那里，让它随机驱动自己、用相机观察自己的形状变化，它能自动搞清楚：
1. 有几个独立的自由度？
2. 每个自由度影响身体的哪个部位？
3. 每个自由度的响应延迟是多少？
4. 自由度之间是否存在耦合？

这就像婴儿学习自己的身体：通过随机运动（motor babbling），逐渐建立"我的手可以这样动"的身体模型。

### 为什么这比现有工作重要？

- Yu 2026 和 Tang 2026 都假设了已知的驱动结构
- 所有 NeRF/3DGS 自建模方法都假设已知哪些参数是驱动输入
- **没有人问过：如果不知道驱动结构呢？**

这连接了两个领域：
- **因果发现**（Causal Discovery）：从观测数据发现变量间的因果关系
- **软体机器人标定**（Calibration）：确定驱动器与身体部位的对应关系

### 方法

**Step 1: 随机驱动 + 视觉观测**
```python
# 随机动作序列
for t in range(T):
    a_t = random_action()  # 每个维度独立随机
    robot.actuate(a_t)
    shape_t = camera.observe()  # 提取 2D 骨架
    record(a_t, shape_t)
```

**Step 2: 因果图发现**
- 对每个身体部位（骨架节点），测试哪个驱动维度对其有因果影响
- 使用 Granger 因果检验或条件互信息
- 延迟估计：最大化互信息 I(shape_node_t; action_dim_{t-τ}) 关于 τ

**Step 3: 验证发现的结构**
- 用发现的因果图构建驱动模型
- 对比"已知结构"vs"发现结构"的预测精度
- 如果精度接近，说明自发现有效

### 关键实验

**实验 1：DOF 数量发现**
- 训练数据来自 N 个驱动器
- 方法能否自动发现"驱动空间的有效维度是 N"？
- 使用 PCA 或 Granger 秩估计

**实验 2：空间影响区域**
- 每个驱动器主要影响骨架的哪些节点？
- 发现的"影响区域"是否与物理直觉一致（近端驱动器影响根部，远端驱动器影响尖端）？

**实验 3：响应延迟估计**
- 从数据中自动估计每个驱动器-部位对的响应延迟
- 与 PyElastica 的已知动力学对比

**实验 4：跨结构迁移**
- 在 2-DOF 机器人上发现的框架，能否直接用于 3-DOF 或 4-DOF？

### 科学贡献

2. **实现零先验知识的驱动结构自动发现**

## 9. 方向四：速率依赖的形状控制——加载速度作为新的控制维度

**日期**: 2026-06
**状态**: 新方向
**科学问题**: 软体机器人的形状不仅取决于"驱动多少"，还取决于"驱动多快"。加载速率能否成为形状控制的额外自由度？
**目标会议**: ICRA / CoRL

### 核心洞察

传统软体机器人控制只规划"驱动量"（what to actuate），不关心"驱动速度"（how fast to actuate）。但粘弹性材料对加载速率的响应根本不同：

```
慢速弯曲 → 更多时间让材料松弛 → 接近平衡态弯曲
快速弯曲 → 材料来不及松弛 → 偏离平衡态 → 更大的回弹
```

这意味着：**相同的驱动量，以不同速率执行，产生不同的最终形状。**

反之：**不同的目标形状，可能需要不同的执行速率。**

### 这不是工程参数调优

这不是"调一下速度让效果更好"。这是一个新的控制维度：

- 刚性机器人：控制空间 = {位置, 速度, 力矩}，控制目标 = 位置/速度
- 软体机器人（现有方法）：控制空间 = {驱动量}，控制目标 = 形状
- **软体机器人（新范式）**：控制空间 = {驱动量, 驱动速率}，控制目标 = 形状

增加速率维度后，可达的形状空间可能变大了（某些形状只能通过特定速率到达）。

### 方法

**极简实验设计**：

1. 在 PyElastica 中，对同一目标驱动值，以不同速率（0.5s, 1s, 2s, 5s）执行
2. 记录最终稳态形状
3. 量化"速率-形状"关系：同一驱动值，不同速率，形状差多少？
4. 反问题：给定目标形状，是否可以通过选择合适的速率来更精确地到达？

### 关键实验

**实验 1：速率-形状关系的量化**
- x 轴：加载时间（0.1s ~ 10s）
- y 轴：与平衡态形状的偏差
- 预期：幂律关系（粘弹性标度律）

**实验 2：速率增强的形状可达性**
- 不用速率：可达形状集合 A
- 使用速率：可达形状集合 B
- B ⊃ A？即速率是否扩展了可达形状空间？

**实验 3：速率-形状映射的可学习性**
- 训练模型预测"驱动量 + 速率 → 形状"
- 对比"驱动量 → 形状"（忽略速率）
- 在变速率数据上的精度差异

### 科学贡献

1. **首次将加载速率显式建模为软体机器人形状控制的自由度**
2. **量化速率对可达形状空间的影响**
3. **提出速率感知的形状控制框架**

### 发表策略

- 这个方向的实验非常容易在 PyElastica 中完成
- 如果速率确实显著影响形状，这是一个强而简单的发现
- 可以作为短论文（ICRA 4 页 + 补充材料）或 RA-L

## 10. 方向五：热力学一致的自建模——能量视角下的软体机器人

**日期**: 2026-06
**状态**: 新方向（理论基础强）
**科学问题**: 学习到的软体机器人自模型是否满足热力学定律？如果不满足，我们能得到什么物理保证？
**目标期刊**: T-RO / Physical Review / ICRA

### 核心洞察

当前的学习模型是"黑盒"：输入动作序列，输出形状，中间没有任何物理约束。

但软体机器人的变形过程服从热力学：
1. **能量守恒**：输入功 = 储存应变能 + 耗散能
2. **Clausius-Duhem 不等式**：耗散能 ≥ 0（能量不能从热自动转化为功）
3. **迟滞环面积 = 耗散能**：循环加载下，应力-应变曲线围成的面积等于每个循环耗散的能量

如果学习模型违反这些约束，它可能在物理上不一致的区域产生错误预测。

### 反问题：学习模型的能量审计

不要求模型在训练时满足热力学约束，而是**事后审计**：

1. 用 PyElastica 仿真一条循环加载路径
2. 用学习模型预测每个时间步的形状
3. 从预测形状反推"等效应力-应变曲线"
4. 检查：迟滞环面积是否非负？能量是否守恒？

如果学习模型违反了热力学约束，这就是一个科学发现：
**"端到端学习的软体机器人自模型在物理上是不一致的。"**

### 正问题：热力学约束的学习

更激进的做法：在模型架构中**硬编码**热力学约束。

设计一个 Neural ODE，状态为 [形状, 速度]，动力学满足：
```
dshape/dt = velocity
dvelocity/dt = f(action, shape, velocity)  — 满足能量守恒
```

其中 f 的参数化保证能量守恒：E = KE + PE + dissipated ≥ 0

### 关键实验

**实验 1：现有模型的热力学审计**
- 对 MSTNF / SpatialSequence / PCSpatial 做循环加载预测
- 计算等效耗散能，检查是否为负（违反第二定律）

**实验 2：热力学约束的影响**
- 训练有约束 vs 无约束的模型
- 在训练分布内的精度差异
- 在训练分布外（新加载速率、新材料参数）的泛化差异

**实验 3：可解释的耗散图**
- 画出模型预测的"沿臂各段的能量耗散率"热图
- 与 PyElastica 的真实耗散对比
- 如果匹配良好 → 学习模型捕获了真实的物理耗散

### 科学贡献

1. **首次审计**学习模型的热力学一致性
2. **证明**（或否定）热力学约束能提升泛化
3. **提供**可解释的能量耗散图（连接学习与物理）
4. **建立**软体机器人自建模的热力学基础

### 为什么这可能很重要？

如果热力学约束确实提升了泛化，这意味着：
- 物理约束不仅仅是"正则化技巧"
- 它们是模型泛化到新场景的**结构性保证**
- 这连接了机器学习理论和非平衡态统计力学

这在方法论上是一个重要贡献，适用于所有学习物理系统的场景。

## 11. 方向六：内部应力场的视觉推断——从外部形状到内部状态

**日期**: 2026-06
**状态**: 新方向（高创新性）
**科学问题**: 能否从软体机器人的外部视觉观测推断其内部应力分布？
**目标期刊**: Science Robotics / T-RO

### 核心洞察

所有现有方法（Tang, Yu, SoftNeRF, 我们）都只关注"形状预测"——预测机器人的外部几何形状。

但**形状只是表面现象，应力才是根本原因**。

如果我们能从视觉观测推断内部应力分布：
1. **安全操作**：预测哪里即将发生材料失效（应力集中点）
2. **接触力估计**：从应力推断外部接触力（不需要力传感器）
3. **疲劳预测**：累积应力 → 材料疲劳寿命估计

### 为什么这可能有答案？

在 PyElastica 仿真中，每个节点的内部应力（弯矩、剪力、轴向力）都是已知的。这意味着我们有完美的 ground truth。

问题简化为：给定外部形状（31 个节点的 xyz 坐标），能否推断内部应力？

从力学的角度：给定一条 Cosserat 杆的构型（位置 + 方向），其内部力分布由平衡方程决定。这在理论上是有解的——平衡方程就是约束条件。

但如果我们**不知道**材料参数和外力，仅从形状推断应力就是欠约束的。

**关键转折**：如果我们同时利用**形状的历史变化**（而不只是当前形状），信息量就大大增加了。因为：
- 应力变化率 = 动力学方程的约束
- 形状变化的历史 = 对动力学方程的多次观测
- 从多次观测中可以反推材料参数和应力状态

这又回到了我们的独特优势：**时序建模**。

### 方法

```python
# 伪代码：应力场推断
class StressInferenceModel(nn.Module):
    def __init__(self):
        self.shape_encoder = SpatialSequenceModel(...)  # 已有
        self.stress_decoder = nn.Sequential(...)         # 新增

    def forward(self, action_window):
        # 1. 从动作历史预测形状序列
        shapes = self.shape_encoder(action_window)  # (B, T, 31, 3)

        # 2. 从形状序列推断应力场
        # 物理先验：应力是形状+形状变化的函数
        strain = compute_strain(shapes)       # (B, T, 31, 6) - 应变张量
        stress = self.stress_decoder(strain)  # (B, T, 31, 6) - 应力张量

        return shapes, stress
```

### 关键实验

**实验 1：静态应力推断**
- 给定单一形状，能否推断各节点的弯矩？
- 精度上限在哪里？（理论上：没有历史信息时，应力是欠约束的）

**实验 2：动态应力推断**
- 给定形状历史序列，能否推断应力场？
- 随着历史窗口增大，精度如何提升？

**实验 3：接触力检测**
- 在仿真中施加外部接触力
- 模型能否从形状变化检测到接触位置和力的大小？

### 科学贡献

1. **首次提出**从视觉观测推断软体机器人内部应力场
2. **建立**形状历史 → 内部状态的映射关系
3. **连接**机器人视觉与连续介质力学
4. **应用价值**：材料失效预测、接触力检测、安全操作

### 风险

- 如果仅从形状无法推断应力（即使有历史信息），结论也是重要的负面结果
- 需要谨慎区分"形状约束的应力"和"实际应力"
- 真实机器人的应力验证困难（需要嵌入 FBG 或其他传感器）

## 13. 对当前项目定位的反思

### 我们应该停止做什么

1. **停止优化 3D 骨架预测精度**：从 0.0014 到 0.0012 的 CD 改善不会改变任何事情。没有人会因为 CD 改善 15% 而引用我们。

2. **停止尝试新的编码器架构**：EMA、FractionalMemory、GammaLaguerre 的比较已经足够。如果核心科学问题是"迟滞可建模/可利用"，编码器的选择是工程细节。

3. **停止追求完整 3D 表面重建**：Tang 和 Yu 的成功表明，2D + 简单方法 > 3D + 复杂方法。3D 重建是一个很难的技术问题，但不是一个好的科学问题。

### 我们应该开始做什么

1. **设计让现有方法失败的实验**：不是证明我们的方法好，而是证明现有方法在物理上是错的。这比"我们的 CD 更低"有说服力得多。

2. **用最简单的方法验证概念**：如果"速率影响形状"是真的，那用最简单的回归就能验证。不需要 Neural ODE，不需要 Flow Matching，一个线性模型就够了。

3. **从"预测"转向"控制"**：形状预测的终点是形状控制。如果我们能展示"考虑迟滞的控制比不考虑的好 X%"，这就是一个完整的故事。

### 底线

**如果我们的贡献是"考虑了迟滞的软体机器人自建模"，那必须回答三个问题：**
1. 迟滞真的存在且可观测吗？（物理验证）
2. 不考虑迟滞的方法在什么条件下失败？（对比实验）
3. 考虑迟滞的方法能做什么不考虑就不能做的？（能力边界）

如果三个问题的答案都是肯定的，不管方法多简单，这就是一篇顶刊。
