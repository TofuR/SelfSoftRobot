## 1. 上次汇报回顾（简述）

上次汇报中，我们介绍了软体机器人自建模的背景——从刚性机械臂（Chen 2022、Hu 2025）到软体机器人（Shan 2024）的迁移，以及我们的 MS-SCNF 模型：用**骨架条件化密度场 + 体渲染**的方案，通过两阶段训练（3D 骨架监督 → 2D 图像渲染联合训练）实现形态预测。

当时发现的核心问题是：
1. **单视角深度歧义**：纯 2D 训练 Z 轴误差占总误差 85%，MNE 达 0.313m
2. **密度场不具备 3D 几何意义**：体渲染的积分特性导致密度通道"偷懒"，不提供真实的 3D 占据信息
3. **对 3D GT 监督的依赖**：模型精度高是因为用了仿真器的 3D ground truth，不是真正的"自建模"

> **汇报语言：**
> 上次汇报我们已经讲到，MS-SCNF 骨架条件密度场方案在有 3D GT 监督时效果不错（MNE 6.5cm），但有两个根本性的问题：一是单视角深度歧义严重，纯 2D 训练误差近 5 倍；二是发现密度场并没有真正学到 3D 几何，只是服务于 2D 渲染的辅助模块。所以接下来我们进行了方法上的重新思考。

## 2. 方法范式的转换：从体渲染到直接骨架预测

### 2.1 核心观察

经过对 MS-SCNF 的深入分析，我们发现了一个关键事实：**模型的 3D 形态信息实际上完全集中在骨架预测头上**——因为它直接受 3D GT 监督。密度场和体渲染管线虽然复杂，但对 3D 形态恢复没有实质贡献。

这带来了一个重要的思路转换：

| | 旧方案（MS-SCNF） | 新方案（SpatialSequence） |
|---|---|---|
| **核心思想** | 骨架条件密度场 + 体渲染 | 直接预测中心线节点坐标 |
| **输出** | 3D 密度场（+ 骨架） | 31 个 3D 中心线节点 |
| **训练信号** | 2D 图像 + 3D 骨架 GT | 仅 3D 骨架 GT |
| **训练方式** | 体渲染积分 → 图像 MSE | 坐标直接 MSE + 平滑正则 |
| **参数量** | ~600K | ~184K |
| **优势** | 理论上可恢复完整 3D 形状 | 简单、直接、收敛快 |

> **汇报语言：**
> 既然 3D 形态信息实际上全部集中在骨架上，我们做了一个"回归本质"的转换：**去掉体渲染管线，直接预测机器人的 31 个中心线节点坐标**。这大幅简化了模型架构——参数量从约 60 万降到 18 万，训练信号从复杂的体渲染积分变成了直接的坐标 MSE，收敛更快也更稳定。

### 2.2 SpatialSequenceModel — GRU 沿 Z 轴空间传播

新模型的核心设计是用 **GRU 沿机器人的纵轴（Z 轴）顺序传播空间状态**：

```
驱动序列(40帧) → 时序编码器 → 物理状态向量(128维)
                                ↓
              GRUCell 初始化: h₀ = MLP(physics_state)
                                ↓
              Z 轴逐步传播:
                h₁ = GRUCell(z₁, h₀) → 坐标₁
                h₂ = GRUCell(z₂, h₁) → 坐标₂
                ...
                h₃₁ = GRUCell(z₃₁, h₃₀) → 坐标₃₁
```

这个设计的物理直觉是：软体臂是一个**悬臂梁**，从固定端（底部）到自由端（顶部）依次变形。每个节点的位置不仅取决于驱动输入，还受到前一个节点位置的约束——这正是 GRU 的顺序传播所建模的。

**为什么不用 Transformer 做空间传播？** 因为悬臂梁的变形是因果的（从根到尖），不像时间序列可以全局关联。GRU 的因果结构恰好匹配这个物理约束。

> **汇报语言：**
> 这个模型的关键设计是用 GRU 沿 Z 轴——也就是从固定端到自由端——逐步传播空间状态。物理直觉是软体臂是一个悬臂梁，每个节点的位置受到前一个节点的约束。GRU 的因果顺序恰好匹配这个物理结构。初始化时把时序编码器的输出投影为 GRU 的初始隐状态，然后从底部到顶部逐节点预测坐标。

### 2.3 PCSpatialSequenceModel — 预测-修正框架

在 SpatialSequence 的基础上，我们进一步设计了**预测-修正（Predictive-Corrective）两阶段模型**，灵感来自卡尔曼滤波：

```
Phase 1 (Predictive): 驱动历史 → 时序编码器 → GRU → 中心线预测
Phase 2 (Corrective): 预测中心线 + CNN(图像) → 残差修正 → 最终中心线
```

**设计动机**：仿真环境中我们有精确的 3D GT，但真实部署时只有 2D 图像。预测-修正框架的思路是：

- **预测分支**（Phase 1）在仿真中训练，提供强大的物理先验——仅靠驱动历史就能预测大致形态
- **修正分支**（Phase 2）学习从图像中提取残差信息，弥补预测与真实之间的差距
- 部署时，如果只有驱动信号就用预测分支；如果有图像就加修正分支

这为**从仿真到真实的迁移**提供了一条清晰的路径。

> **汇报语言：**
> 在直接骨架预测的基础上，我们还设计了预测-修正框架。灵感来自卡尔曼滤波——先用驱动历史做预测，再用图像观测做修正。这样做的好处是：预测分支可以在仿真中充分训练，提供很强的物理先验；修正分支学习从图像中提取残差信息。部署的时候如果只有驱动信号就用预测，有图像就加修正。这为后续从仿真到真实的迁移提供了一条清晰的路径。

## 3. 时序编码器的演进

上次汇报提到，我们最初使用的时序编码器是 MultiScaleEMA——4 个不同衰减率的指数移动平均。在这段时间里，我们围绕"如何更好地编码驱动历史"这个问题，做了系统性的编码器探索。

### 3.1 编码器分类

现在项目中有 6 种时序编码器，可以分为两类：

**加权求和类（顺序不敏感）**——本质是线性操作，丢失序列顺序：

| 编码器 | 核心机制 | 物理类比 |
|--------|---------|---------|
| MultiScaleEMA | 多尺度指数衰减 | 多松弛时间常数 |
| FractionalMemory | 分数阶 Grünwald-Letnikov 权重 | 幂律衰减记忆核 |
| GammaLaguerre | Gamma 分布核（有延迟峰值） | 粘弹性延迟响应 |

**顺序敏感类**——能区分 `[0.1→0.2→0.3→0.4]` 和 `[0.4→0.3→0.2→0.1]`：

| 编码器 | 核心机制 | 复杂度 |
|--------|---------|--------|
| TemporalGRU | GRU 沿时间轴扫描 | O(K) |
| TemporalTransformer | 自注意力 + CLS 聚合 | O(K²) |
| TemporalTCN | 因果膨胀 1D 卷积 | O(K) |

### 3.2 从 EMA 到 FractionalMemory：物理先验的引入

EMA 的衰减核是指数函数 $e^{-\lambda t}$，这隐含了一个假设：历史信息的影响力随时间**指数衰减**。但粘弹性材料的记忆核通常是**幂律衰减**的（$t^{-\alpha}$），即历史影响衰减得比指数函数慢。

FractionalMemory 基于分数阶微积分的 Grünwald-Letnikov 离散化，引入可学习的阶次参数 $\alpha$：
- $\alpha = 1$ 时退化为标准一阶差分（类似 EMA）
- $\alpha < 1$ 时产生幂律衰减的长记忆核
- $\alpha > 1$ 时加强对远期历史的衰减

这提供了一种物理先验更强的时序编码方式。

### 3.3 GammaLaguerre：延迟峰值响应

EMA 和 FractionalMemory 的权重都是从当前帧开始单调衰减的——意味着"越近的动作影响越大"。但粘弹性材料可能存在**延迟响应**：施加一个动作后，形态不是立刻变化，而是在一段时间后才产生最大响应。

GammaLaguerre 用 Gamma 分布作为权重核，峰值位置由参数 $k$（阶次）和 $\lambda$（衰减率）共同决定：
- 峰值时间 $t_{\text{peak}} = (k-1) / (-\ln\lambda)$
- $k > 1$ 时权重有延迟峰值（先升后降）
- $k \leq 1$ 时退化为单调衰减（类似 EMA）

我们在实验中观察到，训练初期部分核的 $k$ 值接近 0，peak 为负——即模型认为"最远的帧最重要"，这不太合理。随着训练推进，$k$ 值逐渐增长，peak 向合理范围收敛。

### 3.4 顺序敏感编码器：为什么需要

所有加权求和编码器都有一个根本局限：**丢失了序列的顺序信息**。`[0.1→0.2→0.3→0.4]`（加速充气）和 `[0.4→0.3→0.2→0.1]`（减速放气）的加权和可能相同，但物理含义完全相反。

对于有明显迟滞效应的软体机器人，加载和卸载路径的不同正是核心挑战。因此我们新增了 GRU、Transformer、TCN 三种顺序敏感编码器：

- **TemporalGRU**：最简洁的顺序编码方式，单向 GRU 沿时间轴扫描，取最终隐状态
- **TemporalTransformer**：自注意力机制，全局关联整个历史窗口中的每一帧，理论上限最高
- **TemporalTCN**：因果膨胀 1D 卷积，多尺度感受野，支持并行计算

> **汇报语言：**
> 时序编码器方面，我们从最初的 EMA 扩展到了 6 种编码器。有两个维度的改进：
>
> 第一个维度是物理先验的增强。EMA 假设指数衰减，但粘弹性材料的记忆核通常更接近幂律衰减。所以 FractionalMemory 引入了分数阶微积分的权重核，让衰减形态可以学习。而 GammaLaguerre 更进一步，允许权重有延迟峰值——对应粘弹性材料"施加力后延迟一段时间才产生最大响应"的物理现象。
>
> 第二个维度是顺序敏感性。之前所有的加权求和编码器都有一个根本问题：丢失了序列的顺序信息。加速充气和减速放气的加权和可能相同，但物理上完全不同。所以新增了 GRU、Transformer、TCN 三种能保留顺序的编码器。目前所有编码器都通过 `--encoder` 参数选择，可以直接对比不同编码器的效果。

## 5. 新发现的问题

### 5.1 预测超前问题

在 SpatialSequence 和 PC-Spatial 模型的训练和可视化中，我们发现了一个新问题：**模型预测的中心线系统性超前于真实值**。即预测的弯曲程度比实际更大，仿佛模型"反应过快"。

**可能的原因**：
1. **Current action 短路**：模型输入中除了时序编码器的输出，还拼接了当前帧的 action 和速度。如果当前 action 的信息直接"短路"到输出，模型可能倾向于立刻响应最新动作，而忽略了迟滞效应
2. **权重形态不匹配**：编码器的衰减核形态可能不适合当前数据的响应特性
3. **缺少物理状态反馈**：模型只有 action 输入，没有前一步的物理状态，所以无法区分"正在加载"和"正在卸载"

**对应的三个研究方向**：

```
问题：预测超前于真实响应
    │
    ├─ 原因1：输入冗余 → Action 窗口降采样（10x 重复值）
    ├─ 原因2：current_action 短路 → Action 偏置消融实验
    └─ 原因3：缺少物理状态反馈 → 自回归状态动力学
```

> **汇报语言：**
> 训练过程中还发现了一个新的问题：模型预测的中心线系统性超前于真实值，预测的弯曲程度比实际更大。这可能有三个原因——一是输入窗口中 75% 的 action 是重复值，有效信息量很低；二是当前帧的 action 直接拼接在输入中，可能"短路"绕过了迟滞建模；三是模型没有物理状态反馈，无法区分正在加载还是正在卸载。这三个原因分别对应了三个研究方向。

### 5.2 Action 窗口冗余问题

通过分析数据采集参数，我们发现 action 输入窗口中存在严重的**信息冗余**：

```
采集参数:
  steps_per_action = 500（每个动作保持 500 步 = 50ms）
  record_interval = 50（每 50 步记录一帧 = 5ms）
  → 每个动作值产生 10 帧记录

模型输入:
  window_size = 40 帧
  包含 ~4 个不同动作值，每个重复 ~10 次
  → 有效序列长度仅为 4，75% 是冗余
```

这意味着虽然模型看到 40 帧的输入窗口，实际上只有约 4 个不同的动作值。对于 EMA/Fractional/Gamma 等加权求和编码器，重复值的权重被合并，实际效果等同于对 4 个值做加权平均——编码器的大部分计算量是浪费的。

**解决方案**是在数据加载时对 action window 做降采样（stride=10），保留唯一值。这样 window_size=40 变成有效的 4 个不同值，编码器可以更高效地处理。

> **汇报语言：**
> 还发现了一个数据层面的问题。当前采集参数下，每个动作值会重复记录 10 帧。所以 40 帧的输入窗口里只有约 4 个不同的动作值，75% 都是重复的。这对加权求和类编码器影响尤其大——重复值的权重被合并了，实际效果等价于只处理了 4 个值。解决方案是对 action window 降采样，去掉重复值。

## 6. 研究方向体系

围绕上述发现，我们将当前的研究方向整理为一个分层体系：

```
出发点: 带迟滞的 3D 全身状态估计
    │
    ├──── 核心技术层（解决超前预测）
    │     ├─ 自回归状态动力学：前一步物理状态作为输入
    │     ├─ 迟滞信息容量分析：编码器能编码多少迟滞信息
    │     ├─ Action 窗口降采样：消除 10x 冗余
    │     └─ Action 偏置分析：消融 current_action 拼接
    │
    ├──── 形状表达层（骨架→完整形状）
    │     ├─ 骨架→形状转换：可变半径 / 学习截面
    │     ├─ 拓扑引导残差流：物理粗变形 + FM 残差
    │     └─ 从轮廓恢复形状：Visual Hull + 骨架条件
    │
    └──── 感知与部署层
          ├─ 多视角 2D→3D 骨架：双视角三角化
          ├─ 视觉辅助部署：在线适应 + 残差修正
          └─ Sim-to-Real 迁移：域随机化
```

已归档的方向（已完成实现）：
- 分数阶记忆核 → `src/encoders/fractional_memory.py`
- Gamma/Laguerre 延迟编码 → `src/encoders/gamma_laguerre.py`
- 顺序敏感编码器 (GRU/Transformer/TCN) → `src/encoders/temporal_*.py`
- 空间序列生成 → `src/models/model_spatial_sequence.py`
- 预测-修正框架 → `src/models/model_pc_spatial.py`

> **汇报语言：**
> 基于目前的发现，我们将研究方向整理成了三个层次。核心技术层围绕预测超前问题，有四个方向——自回归状态动力学、迟滞信息容量分析、action 窗口降采样、和 action 偏置消融。形状表达层关注如何从骨架扩展到完整 3D 形状。感知与部署层则是从仿真走向实际应用的路径。

> **汇报语言：**

|------|---------|---------|
| **方法** | MS-SCNF（骨架条件密度场 + 体渲染） | SpatialSequence（直接骨架预测）、PC-Spatial（预测-修正） |
| **时序编码** | MultiScaleEMA | 6 种编码器（EMA、Fractional、Gamma、GRU、Transformer、TCN） |
| **核心发现** | 单视角深度歧义 | 预测超前、action 窗口冗余 |
| **研究方向** | 多视角方案 | 三层体系：核心技术 → 形状表达 → 感知部署 |

**核心思路的变化**：从"让隐式场通过体渲染学习 3D 形状"转向"直接预测显式骨架 + 用物理先验增强时序编码"。这条路线更简单、更可控，也为后续的形状扩展和真实部署提供了更好的基础。

> **汇报语言：**
> 总结一下，从上次汇报到现在，最大的变化是方法范式的转换——从骨架条件密度场加体渲染的方案，转向了直接预测骨架中心线的方案。时序编码器从单一的 EMA 扩展到了 6 种，涵盖了物理先验增强和顺序敏感性两个维度。发现了预测超前和 action 窗口冗余两个新问题，对应地整理出了完整的研究方向体系。下一步重点是完成编码器对比实验，并尝试 action 窗口降采样和自回归状态动力学。
