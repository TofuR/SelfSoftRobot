## 〇、动因:迟滞信息现在存在哪里(诊断)

当前主线 `StateTransitionSpatialModel`([`src/models/model_state_transition.py`](../../src/models/model_state_transition.py))中,"迟滞"有三个藏身之处,**全部是隐式的**:

| # | 位置 | 问题 |
|---|------|------|
| 1 | **FractionalMemory 的特征**([`src/encoders/fractional_memory.py`](../../src/encoders/fractional_memory.py)):4 个可学习 α 的 GL 幂律权重加权动作历史 → MLP 任意混合 | 先验在**特征**上不在**结构**上。"30 秒前那次加载留下的残余应变"在模型内部没有对应物;能读出 α=0.4,但无法回答"它对形状贡献了什么、多少" |
| 2 | **自由潜变量 z**:无 GT、无语义、端到端学;冷启动 `z_init` 是动作窗口的函数 | 不可辨识;lazy-z 风险(定位文档 §6 警告过)本质是没有任何东西强制 z 承载迟滞 |
| 3 | **窗口截断**:GL 核在 K=20(10 Hz 下 ~2 s)硬截断 | 与论文自己宣称的"弛豫秒-分钟量级、幂律衰减"**自相矛盾**——幂律核支撑集无限,当前架构原理上就表示不了论文声称存在的记忆。蓝图 §1¶3 自己写出的矛盾 |

**结论:迟滞目前是模型的"输入特征",不是模型的"状态"。** 特征级先验(换编码器、换权重形状)只能回答"拟合得好不好",回答不了"表示了什么"。

### 什么才算"定量表示"——四条判据

类比系统辨识的 Bode 图:每台对象数值不同,但**测量方法普适、产物是对象属性而非网络属性**。据此:

| 判据 | 含义 | 当前模型 |
|---|---|---|
| 可辨识 | 少量参数、从数据稳定估出、不随初始化漂移 | ❌ 藏在 MLP 权重 |
| 有语义 | 参数有名字有单位(α 无量纲、τ 秒、密度函数) | 半✅(仅 α) |
| 可独立对照 | 模型内部量能与**不经模型**的机器人测量对上 | ❌ |
| 可迁移预测 | 一种加载协议辨识的参数预测另一种协议的行为 | ❌ |

"强先验"的正确位置:**不是"特征怎么算"(编码器),而是"状态怎么演化 + 记忆怎么进入输出方程"(结构)。**

## 一、对抗审稿裁决:什么死了、什么活了

> 原始草案(v1)经三路独立审稿。裁决记录在此,防止迭代中重蹈。

### 死掉的三处(v1 的错误,已修正进 v2)

1. **[CRITICAL·数学 bug] 输出方程把水平量当增量用**。v1 写 `s_t = s_{t-1} + F_static + Σp·B + Σh·C`,但 p(h)是持续水平量(hold 时收敛到非零常数),当增量累加则动作恒定时 s 线性无界漂移;且 PI 迟滞的核心现象(同一压力下加载/卸载分支的**持久偏移**)在增量形式下无法表示。**修正:水平量读出或进平衡方程(§2)。**
2. **[CRITICAL·物理错位] 记忆放骨架空间 + 常值全局模态形状 B_i**。大弯曲(90°+)下形状空间是弯曲流形;物理上记忆活在**矩/曲率层**(Simo 1987 有限应变粘弹性:内变量在应力空间加性、应变经当前刚度/几何调解,F=F_eF_v 乘性拆分)。**修正:版本 A 放矩空间逐节点(§2.1);版本 B 模态形状经局部标架旋转(§2.2)。**
3. **[CRITICAL·定位陷阱] "算子嵌入"不是创新点**。事实核查确认(经 Crossref 逐句核对):Krikelis et al. 2021(IFAC)/2023(Measurement)已把 play/stop 算子写成 ReLU 循环 ANN、BPTT 梯度训练、与线性动力学联合辨识——与 v1"可微算子嵌入学习模型"方法级几乎逐条重合;PAM 上 PI+NN 有 2015→2026 连绵文献带(Zhang 2019 D-EUPI、Ma 2024 FN-QUPI、Zhang 2024 GPI+fuzzyNN 等)。**修正:主卖点=对象+闭环,不是嵌入技术(§5)。另外"非马尔可夫"措辞是红线——有限 Maxwell 组在增广状态上就是有限维马尔可夫,Krauss 方可反咬;正确楔子见 §3。**

### 活下来的核心(三位审稿人一致)

- 迟滞从编码器特征变成显式算子状态——**方向正确**
- PI play 组 + 广义 Maxwell 恰是填充弹性体流变学标准模型类(LVE + 率无关摩擦;力学文献多称 Iwan/Masing/Coulomb,结构同构)
- **加性线性模态读出是整个定量主张的地基**——但注意:它保证的是**干预的良定义性**(消融/置零分量良定义),**不保证参数可辨识性**;后者是 (结构约束 × 激励协议 × 初始化协议) 的联合性质(§4)
- 一个意外收获:**硅胶迟滞的速率相关性文献双向**(SMS 2024:低损耗硅胶亚 Hz 迟滞近率无关 vs MMT 2023/Ecoflex 2023:率相关)——"这台臂 PI/Maxwell 份额几何"本身是开放科学问题,测出无论哪边都是新知识(退路 §5.2)

## 二、修正后的模型(v2)

### 2.1 版本 A(论文主模型):平面 Cosserat 内变量模型

物理最干净,且与 planar-constrained 分支天然契合——平面 15 节点骨架可用切线角 θ(s)∈R^M 参数化(弧长积分重建,天然不可伸长,消掉 3N 冗余)。

```
状态:  θ_t ∈ R^M (切线角),  κ_t = Dθ_t (曲率)
输入:  a_t = 实测腔压 (Arduino I2C 气压计, 非指令!)

驱动(逐段, 学习):        u_{i,t} = W_i · a_t

弹性矩(捕捉几何刚化/软化): m^e_{i,t} = f_i(κ_{i,t}) = K₁κ + K₃κ³

广义 Maxwell(矩空间, 精确ZOH): m^v_{i,k,t} = e^(−Δt/τ_k)·m^v_{i,k,t−1}
                                       + (1−e^(−Δt/τ_k))·G_k·f_i(κ_{i,t})

Iwan/PI play(曲率上, 率无关): p_{i,j,t} = clip(p_{i,j,t−1}, κ_{i,t}−r_j, κ_{i,t}+r_j)
                              m^f_{i,t} = Σ_j b_j·(κ_{i,t} − p_{i,j,t}),  b_j ≥ 0

平衡(逐节点标量可微不动点, 2-3 次迭代):
                          u_{i,t} = m^e + Σ_k m^v + m^f  → 解出 κ_t → 积分得 s_t

残差:  小有界网络 r_t, 输入仅限 (a_t, 算子状态) —— 结构性禁止其私藏长记忆
```

数值要点:
- **Maxwell 必须精确 ZOH 离散**(`e^{−Δt/τ}` 形式,无条件稳定;显式 Euler 在 Δt/τ≥2 发散,10 Hz 采样 + τ_min=20ms 即爆炸),τ_min ≥ 3Δt
- **谱参数化用低维平滑形式**:log G(τ) = 3-4 节点样条,而非逐模态自由权重(有限指数和逼近幂律是 Laplace 反演型不适定问题,对数网格相邻模态窗口内近共线,自由权重高方差)
- **自检性质全部内置**:慢加载→环面积率无关分量恒定;速率升→Maxwell 份额增长;幅值依赖刚度→Iwan 阈值结构;全部历史依赖**构造性只走算子通道**;几何非线性在 f 与运动学积分里

### 2.2 版本 B(最小手术,先做):水平量读出 + 局部标架模态

保留现有骨架空间管线(`StateTransitionDataset`、episode BPTT、shooting planner 全部原样),只动四处:

```
s_t = S(a_t; θ) + Σ_i p_{i,t}·B_i(s̃_t) + Σ_k h_{k,t}·C_k(s̃_t) + r_t
      ↑历史无关    s̃_t = S(a_t) 参考形状; B_i/C_k 经局部标架旋转 R(s̃)
```

- S:每通道单调样条(≤5 节点),**禁止跨通道 MLP**
- Maxwell 精确 ZOH,τ_min ≥ 3Δt
- 算子输入 = 每段伪应变(对抗腔压差),**非原始 4 维动作**(阈值 r 落指令单位与 PI 文献 μ(r) 应变单位不可比;压力→弯矩非线性会混叠进 μ(r))
- z 砍到 4-8 维残差,输入限 (a_t, 算子状态),方差份额单列报告

### 2.3 四条公理(违反任何一条,分解退化为随机数)

| # | 公理 | 防的是什么 |
|---|------|-----------|
| 1 | **静态通道历史无关**:S 只见 a_t | F_static 自回归结构偷携带记忆,方差分解失去意义 |
| 2 | **严格加性**:p, h 永不喂进 F_static 或 GRU | 干预消融失去良定义性 |
| 3 | **非负谱**:μ(r)≥0, Maxwell 顺度 ≥0(耗散先验) | 相邻模态正负抵消→谱变噪声(无符号约束的过完备字典在有限数据下必然抵消) |
| 4 | **实测压驱动**:指令→压力单独建执行器块 | 阀限流/充气 RC 滞后冒充"材料指纹";部署时同样在线用实测压 |

### 2.4 与现有管线的兼容(anchor 红利的准确版本)

- Play/Maxwell 递推全链可微(分段线性,ReLU 族),episode BPTT 与 shooting planner **原样兼容**;O(1)/步、无窗口截断
- **anchor 红利(准确版本)**:"from-rest 初始化无歧义、消解 lazy-z 与 init_z_from_action 启发式"——成立且值得写。**前置条件**:协议规定 episode 前静置 ≥3τ_max + 零包络(否则 play 状态依赖此前全部历史,lazy-z 变 lazy-p);训练/部署输入一致(实测压)
- 长时未观测的重锚定为 **open problem**(算子状态无 innovation 校正机制,衔接方向 D3 主动再锚定)——不可宣称"无需视觉重锚定",那会与 K_max 滚动重观测故事自相矛盾
- `real_validation/runtime/model.py` 部署精简版反而更简单(状态小、确定性)

## 三、对 Krauss 2026 的正确楔子(替换"非马尔可夫")

> 红线:**绝不能**在论文里写"我们非马尔可夫他们马尔可夫"——有限 Maxwell 组在增广状态上就是有限维马尔可夫,会被一枪打死。

**正确楔子:"所需状态数与状态坐标的结构,本身就是被测量的对象。"**

- Krauss 类 = 2 态(ξ=[z,ż])通用潜空间;实测所需 = 铺满数十年时标的算子坐标 + 率无关非光滑动力学
- 配套理论图(数学已核实):**log-uniform Maxwell bank 逼近幂律 t^{−α} 的误差随模态数指数下降**(Beylkin-Monzón 2005;数值验证:3 十进位窗口 α=0.5 下,3 模态/十进位→误差<0.01%),固定阶 ODE 只线性下降。这是理论上最干净的定量差异
- 诚实窗口声明:幂律只在 [τ_min, τ_max] 内被有界逼近——对 Krauss 的指数记忆同样成立,差别是**逼近窗口宽度和误差衰减率**。正确表述:"用结构化截断替换任意窗口截断(K=20)",不宣称"无限记忆"
- FractionalMemory(GL 核)保留为同管线可互换的对比模型类,E4 消融里同台,"谱宽到底需不需要分数阶"由 AIC 裁决

## 四、可辨识性协议(与模型同等重要)

> 核心教训(可辨识性审稿人):可辨识性 = (结构约束 × 激励协议 × 初始化协议) 的**联合性质**。没有协议配合,X%/Y%/Z% 是随机数。

### 4.1 三大可辨识性陷阱与对策

| 陷阱 | 对策 |
|------|------|
| **分解不唯一**:F_static 是无约束网络时原则上可复现任何快 Maxwell 模态(τ≲2-3Δt 在 10 Hz 下与"静态增益+一帧滞后"观测等价),存在等价分解流形,梯度下降选择由初始化决定 | 削减 F_static 容量(单调样条);非负谱约束;**交付"分解 vs F_static 容量"扫描图**(若 X% 随容量 60%→20% 摆动,主张是容量伪影——单一最强鲁棒性证据) |
| **单速率数据定义性不可分**:PI 与 Maxwell 环面积区分度完全来自耗散-速率标度律(Maxwell 低频 ∝ω,PI 率无关),10 Hz 随机游走速率内容不受控 | 训练集必须含**时间缩放的重复路径**(同一三角波多速率,见 E3);辨识精度先算 CRLB 按 D-最优性选协议再采集 |
| **F_static 定义不良**:PI 状态死区内连续统平衡,实物无 virgin state | 操作化定义:饱和条件化后的初始加载分支(循环至环闭合,闭合判据=连续 3 环差异<噪声底) |

### 4.2 可辨识窗口(诚实声明,写进论文)

- **τ ∈ [3Δt, T_contig/2] ≈ [0.3s, ~2min]**(10 Hz;仅当算子状态沿 246 s 连续序列 TBPTT 携带)
- 当前 4 s episode 重置会掐死 τ≳2s 的模态——**算子状态跨截断携带(TBPTT)+ burn-in 前缀无梯度前向初始化,是全部分意义所在,不能省**
- r ∈ [0, 最大幅程/2] 之外 μ(r) 不可辨识;子秒动力学统一折入"static+快模态"并声明 τ_min≈0.3s
- 谱只报可辨识带 + bootstrap 置信带;网格边缘质量堆积 = 窗外内容诊断信号,显式检查并标注
- 网格鲁棒性:τ, r 可学习(log 参数化、网格初始化)或密度连续参数化;必做半格偏移网格重训检验;逐点谱无意义时降级为低阶矩(总权重、log-均值、log-展宽)

### 4.3 方差归属协议(预注册)

- 归属对象 = 一步预测 Var(Δs) + rollout 干预消融两个统计量
- 3 分量用**精确 Shapley**(6 个子集重拟合,便宜且免顺序依赖)
- ≥10 随机种子 × 2 网格偏移 × 3 F_static 容量;episode 级 block bootstrap 置信区间
- 必报"相关份额"=(ΣVar_i − Var_total)/Var_total 与分量时间序列相关矩阵
- **预注册接受判据**:种子 IQR < 8 个百分点、相关份额 < 15%、对容量单调稳定。任一不满足,主张撤回
- 分解是 (模型, 激励协议) 的函数——逐速率档报告 + 措辞限定"在 PI+Maxwell 算子基内的分解",不宣称基中立

### 4.4 混杂变量控制(物理审稿人:"材料指纹"实为整厂指纹)

| 混杂源 | 对策 |
|--------|------|
| 阀限流 + 腔室充气 RC(10-100ms,气动非材料) | 算子输入用实测腔压;指令→压力单独建块(§2.3 公理 4) |
| 绝热膨胀冷却→模量漂移(分钟级热时标) | 温度/时段分块随机化;长 hold 与气压-时间曲线对照 |
| 接触摩擦(率无关,会被 PI 份额吸收) | 若臂触约束面,PI 份额注明含接触摩擦 |
| Mullins/scragging(μ(r) 非平稳) | 每次记录前最大幅值预条件化 3-5 循环(橡胶测试通行惯例,勿归于 ASTM D412 条款);环面积 vs 循环指数平稳性图 |
| 措辞 | "whole-body kinematic memory fingerprint"(整机运动学记忆指纹),**不写**"材料粘弹指纹"——那是 DMA 的地盘 |

## 五、实验协议(~3h 采集,全部模型无关)与论文定位

### 5.1 实验 E0-E4

| 实验 | 内容(~时长) | 裁决什么 |
|------|------------|---------|
| **E0 条件化** | 全幅循环加载至环闭合(~10min) | 定义可复现初始迟滞态;无此则一切初值未知 |
| **E1 速率标度环** | 同一三角轨迹 × 3 速率(铺一个十进位,如 0.005/0.02/0.05 Hz)× 4 幅值(25/50/75/100%)(~40min) | **全案枢纽**:环面积 vs 速率平坦→PI 主导,∝ω→Maxwell 主导;幅值系列给 μ(r) 模型无关包络。不做等于没做 |
| **E2 同压异程 + step-release** | 上/下方到达同压保持至收敛;阶跃后保持 {5s, 30s, 2min, 5min} log 间隔(~60min) | 速率无关记忆幅度(mm);模型无关弛豫谱(2-3 指数和 vs 幂律 AIC);要主张"分钟级"必须有 5min 保持 |
| **E3 辨识训练集** | 保持时长 log-uniform [0.1s, 30s] 多速率激励,功率铺 4 个十进位,含稳态驻留+快速反转(~40min, ~24k 帧≈现有 7 倍) | 训练数据;先用 E1/E2 结果算候选协议 CRLB,D-最优选设计再采集 |
| **E4 协议切分** | 训练 E3,测试 (a) 新频率多正弦 (b) E1 慢环(低于训练最慢内容) (c) E2 长保持 (d) 长程开环 rollout | **"测机器人不测模型"的兑现**:E1/E2 不进训练集,模型内谱必须预测它没见过的实验类型;误差 vs (测试时标/训练最大时标) 曲线是主图 |

### 5.2 主图设计(三张定生死)

1. **环面积-频率曲线**(E1 实测)叠加各类模型预测——二阶马尔可夫/指数记忆在低 ω 处环面积必然 ∝ω 趋零或线性,实测若平坦则 PI 结构必要(模型类楔子)
2. **谱对齐三方对照**:模型内 H(τ)/μ(r) ↔ E2 实测 step-release 谱 ↔ Krauss 类模型线性化提取的有效记忆核——"机器人核是幂律/长尾;A 类结构性无法表示,B 类可以"
3. **误差 vs 距 anchor 时间**(双模型对照)——K_max 首次获得谱机理解释;漂移比曲线 ρ(k) 应可由辨识谱预测,重观测间隔首次由记忆结构给出(全领域没人给过的部署参数物理依据)

### 5.3 论文定位

**主卖点 = 对象 + 闭环,不是嵌入技术**:

> 首次把一台真实软体机器人的全身形态记忆做成显式、可读、可定量的对象:其内部谱与机器人自身的模型无关测量**互相裁决**,且谱结构直接参数化部署。

四条贡献(按序):
1. **现象**:真实气动软臂全身形态记忆的首个模型无关定量刻画(帧对分歧分布、阶跃松弛谱、回线-速率标度律)
2. **表示**:遗传算子状态形态模型(PI 组+广义 Maxwell 组+静力网络,O(1)/步、无窗口截断),其辨识出的 μ(r) 与 H(τ) **预测了训练中未见类型的机器人谱学实验**——表示的裁决者是机器人的可观测量,不是拟合误差(明确声明:算子嵌入技术不新,引 Krikelis 2021/2023、PI-NN 文献带)
3. **后果**:无记忆规划循环/变速加载失效演示 + 历史条件规划恢复;K_max 谱机理解释
4. **数据**:循环/变速加载协议 + NDI 真值的真实软臂数据集

Related work 定位段(可直接用):"我们不主张 PI 算子嵌入学习模型的新颖性——该技术已在标量迟滞系统上成熟(Krikelis et al.; PAM 文献带)。既有工作的目的是**假设**一个迟滞结构以求逆补偿;本工作的目的是**测量**一台软体机器人的全身形态需要哪类记忆、各占多少份额、对部署意味着什么——因此我们保留两族算子的可分性而不是融合它们,并以模型无关谱学作为外部裁决。"

三幕结构(蓝图骨架不动,§5 仪器替换):第一幕·现象(模型无关)→ 第二幕·表示(算子模型+谱学闭环)→ 第三幕·后果(失效演示+K_max 机理+控制展示)。免标定管线定位为使能者,不进主张清单头条。**不拆两篇**(测量篇的仪器有 lazy-z/K=20 两个已知伤疤;算子篇离开测量篇协议就没有裁决标准;Krauss future work 窗口敞开但不会一直敞开)。

### 5.4 退路阶梯(每级仍有可发表物)

1. 点谱噪声大 → 报区间谱+可辨识带 [τ_min, τ*];"τ* 之外存在不可分辨的长记忆"与 K_max 下界互锁
2. 分解不稳定(换基/换种子漂移大) → 降级聚合量(参考速率回线面积、α_eff、主导 τ 频段);重心移第一/三幕
3. **μ(r)≈0(速率无关份额可忽略)→ 负结果叙事**:"整体浇注硅胶连续臂与 PAM 相反,形态记忆以速率相关粘弹为主"(对比 Zhang 2019 PAM 结论,指导领域补偿模型选型);模型优雅退化为 Maxwell+静力网络
4. 算子模型精度输给黑盒 → 黑盒当主模型,算子模型作可解释分析副线如实报告;论文退回蓝图原案(现象+仪器+后果,本来就不依赖模型精度成篇)
5. 谱学对照失败(模型内谱≠模型无关谱) → 最伤一级;只保留第一幕+第三幕,算子模型作为"一次诚实的尝试"进讨论节。**这一条必须在写作前用零成本先决实验裁决**(先 E1/E2 再决定第二幕写不写)

### 5.5 Baseline 对比设计(证明模型类差异而非参数量差异)

- 臂:(a) Krauss 类二阶马尔可夫 (s,ṡ)+MLP(忠实复现,含振荡器变体),参数量 ≥2× 本模型;(b) 现 StateTransition GRU 窗口模型,K=20 与 **K=160**(公平的"只是记忆更长?"对照);(c) 本模型消融:PI-only / Maxwell-only / 全 / 无算子
- 裁决逻辑:本模型以**更少参数**在 E4 外推协议上胜出 → 容量解释被排除;参数量+训练算力表随表交付
- 若算子模型开环 drift/K_max 输给黑盒:如实报(主张从未建立在"算子模型精度最高"上)
