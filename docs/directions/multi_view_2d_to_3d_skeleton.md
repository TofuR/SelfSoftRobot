# 方向：多视角 2D→3D 骨架重建

> 状态：待探索
> 优先级：中高
> 关联：Yu 2026 (T-RO) 的 Bézier 双视角方法、导管双平面透视

---

## 问题

当前模型**只从驱动参数（action）预测 3D 骨架**，不使用任何视觉输入。但在实际部署中：
1. 模型预测不可避免有误差
2. 环境因素（外力、温度、老化）会改变 actuation→shape 映射
3. 只用 action 历史（无物理状态反馈）无法完全捕获迟滞

**如果部署时有相机，能否从 2D 图像辅助修正 3D 骨架？**

这正是 PCSpatial（预测-修正框架）的修正分支的设计初衷——但目前的修正分支**仅用于训练时的精细化**，且效果有限。

---

## 方案

### A. 2D 骨架提取 + 3D 三角化

Yu 2026 的方法：
1. 从两个正交视角的图像中提取 2D 骨架曲线
2. 用 Bézier 曲线参数化 2D 骨架
3. 双视角三角化得到 3D 控制点

适配到我们：
- 仿真中已有渲染图像（PyVista 生成）
- 可以提取 2D 骨架（`src/utils/skeleton_2d.py` 已实现）
- 双视角 → 3D 骨架重建

优点：几何方法，可解释，不需要额外训练
缺点：依赖 2D 骨架提取质量；正交视角假设

### B. 可微渲染反传骨架参数

Li et al. (ICRA 2023) 的可微渲染方法：
1. 用当前骨架参数渲染图像
2. 与真实图像比较，计算 loss
3. 反传梯度更新骨架参数

适配到我们：
- 我们的渲染管线已经是可微的（体渲染 / NeRF）
- 可以把骨架节点坐标作为可优化参数
- 渲染 loss → 骨架梯度

优点：端到端可微，不依赖 2D 骨架提取
缺点：需要好的初始化（否则陷入局部最优）；慢

### C. 学习 2D→3D 映射网络

训练一个网络直接从 2D 图像特征预测 3D 骨架修正：
1. 预测分支给出初始 3D 骨架（当前模型）
2. 修正分支从 2D 图像特征预测残差（PC-Spatial 的 CNN 分支）
3. 初始 + 残差 = 精化 3D 骨架

**这就是 PC-Spatial 的设计**。目前问题：
- CNN 修正分支效果不明显（可能因为训练数据中图像信息量不足）
- 训练时 GT 骨架已知，修正分支的梯度信号可能被预测分支"短路"

改进：
- 两阶段严格训练：先冻结预测分支，再训练修正分支
- 增加图像信息量（多视角、深度图）
- 数据增强（模拟光照变化、背景噪声）

### D. Visual Hull 约束骨架 ★

结合方向 6（Shape from Silhouette）：
1. 从多视角轮廓构建 Visual Hull（体素空间）
2. 在 Visual Hull 内搜索最优骨架（最大化骨架与 Visual Hull 的拟合度）
3. 骨架的先验由预测模型提供

优点：结合了几何约束（Visual Hull）和学习先验（预测模型）
缺点：Visual Hull 分辨率受限；需要多视角
