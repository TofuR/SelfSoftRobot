# 方向：仿真到真实迁移（Sim-to-Real Transfer）

> 状态：规划中（迁移策略 + **实物数据采集平台已细化**）
> 优先级：中（取决于是否有真实机器人）
> 核心参考：ETH Zurich RA-L 2024 Best Paper Award
>
> **结构**：上半部分「问题/方案/数据需求」= 迁移**策略**（假设真实数据已存在）；
> 下半部分「实物数据采集平台」= **如何实际获取这些真实数据**（平台、采集协议、GT、评估）。

---

## 问题

当前所有训练和评估都在 PyElastica 仿真中完成。真实软体机器人与仿真的差异（sim-to-real gap）：
1. **材料特性**：硅胶/TPU 的超弹性、粘弹性、各向异性
2. **驱动模型**：气动/线驱的非线性响应与仿真的理想化假设不同
3. **传感器噪声**：相机噪声、标定误差、遮挡
4. **环境因素**：温度、湿度、老化
5. **几何差异**：制造公差、非均匀壁厚

---

## 方案

### A. 零样本迁移（最乐观）

假设：仿真足够精确，直接迁移即可。

Yoo et al. (arXiv:2303.04307) 尝试了这种方法：
- 仿真中采集高保真点云
- 训练形状预测模型
- 零样本迁移到真实 3D 感知

适用条件：仿真器精度高，任务容错大
我们的情况：PyElastica 对 Cosserat 杆的仿真精度较好，但气动驱动模型可能不够精确

### B. 残差物理学习（最推荐） ★★

ETH Zurich (RA-L 2024) 的方法：
1. **解析仿真器**：提供粗略但快速的物理预测
2. **残差网络**：学习仿真器与真实之间的系统性偏差
3. **少量真实数据**：只需 N ≈ 100-1000 个真实样本

```
真实形状 = 仿真形状 + 残差网络(action, 仿真形状)
```

适配到我们：
- PyElastica 仿真器（已有）
- 神经场模型 = 学习 action→shape 的完整映射
- 真实数据 = 用相机采集少量真实形状数据
- 残差 = 真实形状 - 模型预测形状

优点：
- 利用物理仿真的先验知识
- 少量真实数据即可
- 可解释（残差反映了 sim-to-real gap）

### C. 域随机化（Domain Randomization）

在仿真中引入随机变化：
- 材料参数随机化（杨氏模量 ±20%）
- 驱动延迟随机化
- 传感器噪声注入
- 几何尺寸随机化

训练出的模型对参数变化更鲁棒，迁移时泛化能力更强。

优点：不需要真实数据
缺点：模型精度可能降低（为了鲁棒性牺牲精度）

### D. 渐进式微调（Progressive Fine-tuning）

1. 在仿真数据上充分训练
2. 收集少量真实数据
3. 冻结大部分参数，只微调最后几层
4. 逐步增加真实数据比例

类似迁移学习的标准流程。

## 实物数据采集平台（Physical Data-Collection Platform）

> 本节是 sim-to-real 的"如何实际获取真实数据"操作层。上面的残差物理 / 渐进微调等方法都假设真实数据已存在——本节定义平台、采集协议、GT 获取方式与评估方法。
>
> **硬件前提**（2026-06 确认）：
> - 软臂：3 腔道气压驱动 + 中心工作腔道；实物 ~10 cm，腔道内径 ~1–2 mm（仿真 `base_length=0.5 m`，约 5× 尺度差）。
> - 驱动：当前仅做好**单腔道驱动器**（实现单平面弯曲，类似"半个自由度"），后续扩展三腔道。
> - 可用传感：手机/普通相机 + 1–3 台工业/USB 相机 + **NDI Aurora 电磁追踪**；无深度相机。
> - **即时目标**：在单平面弯曲上把"采集→分割→2D 骨架→3D 三角化→评估"整链跑通。
> - **终态目标**：相机→3D 骨架的感知模型，供**闭环控制部署**（部署时**只有相机**，NDI/多视角仅离线 GT/训练）。

### 平台核心决策（GT 策略）

回答"NDI 还是图像好"的问题——**二者分工，不是二选一**：

| 角色 | 设备 | 用途 |
|------|------|------|
| **主动态 GT** | 2–3 相机三角化 | 逐帧、稠密 31 节点 3D 中心线；运动中可跑；与部署同源（相机） |
| **GT 地板 / 稳态表征** | NDI 单传感器静态 pullback 扫描 | 量相机 GT 不确定度下限 + 测 settling time τ / 稳态流形 |
| **动态独立锚点（可选）** | NDI 单传感器固定嵌于末端 | 1 个独立 3D 点逐帧验证三角化时序保真度，打破"GT 与部署同源"循环 |

**关键认识**：中心工作腔道正好是模型预测的**骨架中心线**所在，所以 NDI 是天然的"真值"；但**不需要多点**——静态扫描给高精度标定，单个末端锚点给动态验证即可，完美规避"腔道里放很多定位点很难"。动态稠密 GT 由相机承担，这也是部署输入，与"面向控制"目标一致。
**方案 B 的边界**（重要）：静态 pullback 量的是**平衡态形状**，而我们研究的论点是**动态/历史依赖形状 ≠ 平衡态**。所以方案 B **不能当动态 GT**，只作"标定 + 稳态表征实验"。

### 0. 目标与边界

- 本节=物理采集平台；sim→real 迁移**策略**仍用上文 A/B/C/D。
- 部署路径 = 相机 only；NDI/多视角 = 离线 GT/训练。
- 真实数据的 .npz **对齐仿真 schema**，使现有 `SoftSequenceDataset` / `UnifiedTrainer` 直接消费（零侵入复用）。

### 1. 仿真↔实物映射（鸿沟分析）

| 仿真量 | 实物对应 | 鸿沟 | 缓解 |
|--------|----------|------|------|
| 30 单元 / 31 节点，0.5 m，r=0.015 m | ~10 cm，腔道 1–2 mm | 尺度 5× | 归一化（`pc_center`/`pc_scale`）；真实骨架重采样到 31 节点 |
| 2D 扭矩 ±5 mN·m，random walk | 腔道气压（kPa），当前 1 腔 | 动作语义不同 | 存**实测气压** `(N,2)=[p,0]`；同时记指令气压 |
| PyVista 干净二值图 | 真实剪影 | 分割 / 半透光 / 高光 | 背光剪影 or 消光涂层 or 颜色阈值分割 |
| 精确 3D `positions` | 相机三角化 + NDI 标定 | 无精确 GT | 三角化为主，NDI 量地板 |
| z-buffer `depth_maps` | 无深度相机 | — | 三角化 / visual hull 代替（深度监督可选） |
| dt=1e-4，record≈200 Hz | 相机 30–60 Hz，τ≈0.5–3 s | 时间尺度 | 重定义 `dt`/`window_size`；**连续录制全瞬态** |
| 同步仿真循环 | 异步多传感器 | 同步 | 时间戳 + LED 标记（+ 硬件触发可选） |
| `camera_params(V,10)` | 标定外参 | 标定 | 每视角 `[eye(3),center(3),up(3),focal(1)]`，格式同仿真 |
| `norm_factor=max\|actions\|` | 实测气压 | 量纲 | 加载时按实测气压重算 |

### 2. 硬件 rig

- **相机**：2–3 台工业/USB 相机固定于刚性框架；手机补拍多角度静态图（做 visual hull 稠密形状）。
- **距离**：~10 cm 臂 → 相机距 **~30–50 cm**，让臂充满画面、像素/mm 足够（小臂分辨率是关键约束，优先高分辨率/手机 4K）。
- **布局（单平面弯曲初阶）**：1 台在弯曲平面内（看清弯）、1 台垂直平面外（看透视深度，利于三角化 z）；3 视角则在臂周 ~120° 分布。
- **背景与光照**：统一纯色背景（与臂色互补）+ 漫射光；硅胶半透明易高光→**背光剪影法**最稳（臂成黑色剪影），或消光涂层/偏振。
- **驱动与传感**：单腔道驱动器 + **气压传感器**（高频记实测气压，kPa）；后续三腔道岐管 + 3 传感器。
- **NDI Aurora**：场发生器固定于 rig/world；传感器穿中心腔道。
- **同步标识**：LED 入所有相机视场 + 时间戳入同一主机钟（软件同步），或硬件触发（最佳）。

### 3. 坐标系与标定（精度命脉）—— `camera_params` 怎么得到？

> **核心澄清**：`camera_params(V,10)=[eye,center,up,focal]` **不是用尺子量的**，是从标定算出来的。
> - `focal` 是**像素焦距 fx**（不是镜头物理焦距），由棋盘格内参标定精确求出；
> - **世界系**由标定靶自身定义（把靶贴在机器人基座 → 靶系 = robot-base 系）；
> - `eye/center/up` 由外参 `solvePnP` 解出 R,t 后**换算**得到。
>
> 相机-机器人的距离/高度是标定的**输出**（仅 sanity check），不是输入。
> **唯一要用尺子量的**：棋盘格方格边长（一次）。

四系：world(=基座靶系) / robot-base(=world) / camera_i / NDI-field。标定步骤（已实现 `src/calibration/`）：

| 步骤 | 方法 | 产出 | 代码 |
|------|------|------|------|
| 内参 | 每相机拍多张棋盘格 → `cv2.calibrateCamera` | K, dist, fx | `calibrate_intrinsics` |
| 外参 | 每相机拍一张【基座处(世界原点)棋盘格】→ `solvePnP` | R, t (world→camera) | `solve_extrinsics` |
| 换算 | R, t, fx → eye, center, up, focal | `camera_params(V,10)` | `extrinsics_to_camera_params` |
| 一致性校验 | 三角化已知点 / 投影往返 | mm 级精度 | `scripts/real/_smoke_triangulation.py` |

**换算公式**（OpenCV `[R|t]` ↔ 项目 `[eye,center,up,focal]`，精确可逆，自检误差 `<1e-12`）：
`eye = -Rᵀt`，`center = eye + Rᵀ[0,0,1]`，`up = Rᵀ[0,-1,0]`，`focal = fx`。
反方向由 eye/center/up/focal 重建 `K[R|t]`，与 `skeleton_2d.project_3d_to_2d` 投影一致 → 三角化可直接复用（`camera_params_to_K_Rt`）。

- **去畸变**：图像先 `cv2.undistort`（用 K, dist），使"主点≈图像中心、单一 focal"假设成立（`io_video.make_undistorter`）。
- **NDI-field ↔ world**：NDI 探针触已知 world 点配准（pivot/registration）。
- **GT 地板**：静态 NDI pullback 扫描与三角化比对，量出相机 GT 的不确定度下限。

> **入口**：`scripts/real/calibrate_cameras.py`（棋盘格图 → `config/real_camera_params.npz`）。
> **标定误差直接进 GT**，这一步决定整体精度上限，必须先做且做扎实。

### 4. 每帧采集字段（对齐仿真 .npz schema）

| 字段 | 形状 | 说明 |
|------|------|------|
| `images` | (N, V, H, W) | 多视角原始/处理图（V=2/3，统一存多视角） |
| `actions` | (N, 2) | **实测气压**；单腔道存 `[p, 0]` 以兼容 sim 动作维 |
| `positions` | (N, 3, 31) | **三角化 3D 骨架**（替代 sim 的精确 GT），世界系米 |
| `radii` | (N, 31) | 真实壁厚（常数即可） |
| `camera_params` | (V, 10) | 每视角 `[eye, center, up, focal]` |
| `focal`/`H`/`W`/`dt`/`view_names` | — | 同 sim |
| `masks`（建议） | (N, V, H, W) | 分割二值掩码（可复现/版本化分割） |
| `commanded_actions`（建议） | (N, 2) | 指令气压（迟滞分析用） |
| `ndi_tip_anchor`（可选） | (N, 3) | 末端 NDI 锚点（独立动态验证） |

### 5. 实物→仿真格式处理管线（✅ 已实现）

入口 `scripts/real/capture_to_npz.py` 串联 `src/data/real/` 子包
（`io_video` / `segmentation` / `triangulation` / `assemble_npz`），2D 骨架复用 `src/utils/skeleton_2d`：

1. 视频/图 → 逐帧多视角图（多相机去交错 + 去畸变，`io_video`）。
2. **分割出二值剪影**（替代 PyVista 干净二值）→ `masks(N,V,H,W)`；处理硅胶透光（背光/消光涂层/颜色）。
3. **复用 `skeleton_2d.extract_skeleton_2d`** 提 2D 骨架 `(N,V,31,2)`。
4. **多视角三角化**（DLT，由 `camera_params` 构 P 矩阵）→ `(N,31,3)` 世界系骨架。
5. **NDI 标定**：静态 pullback 得参考中心线，求尺度/配准对齐三角化↔NDI，存变换。
6. **动作同步**：气压日志时间戳对齐相机帧（插值）→ `actions(N,2)`。
7. **组装 .npz**（仿真 schema）。

> 步骤 3 直接复用现有代码，是 sim→real 复用的关键点。

### 6. 采集协议（显式抓迟滞）★

> 这是研究的核心：软臂状态依赖**动作施加时间/历史**（迟滞）。协议必须捕获**瞬态**，而非只取稳态。

1. **前置实验：settling-time 表征**。施加阶跃气压，记录指令→过冲→稳定的完整曲线，测 `τ_rise`/`τ_settle`（代表气压档各测一次）。**据此设定真实 `dt`/`window_size`**——仿真 `window_size=40≈0.2 s` 须按真实 τ 重定义（如真实时间窗 ~2–5 s × fps = N 帧）。
2. **动作协议 = 气压空间随机游走**（对应仿真 `ActionSchedule` random）。**下一个动作在完全稳定前就施加**——让连续帧含瞬态 + 历史依赖，这正是仿真 `steps_per_action` 的行为，也是迟滞数据的来源。
3. **连续录制，不在稳定处分帧**：完整捕获上升/过冲/稳定。
4. **多工况**：zero（canonical）/ random（sequence）/ hold（batch）/ **step（settling 表征）**，对应仿真 `--action-x/y` 模式 + 新增 step。
5. **可复现性**：多序列；记温度（迟滞温敏）。
6. **样本量**：≥ 方向 11 残差法所需 100–1000 样本；动态数据越多越好。

### 7. 同步与时序

- 以**相机 fps 为帧节拍**；所有传感器时间戳入同一主机钟（同机最佳，否则 NTP/PTP）。
- **LED 闪烁模式**入所有视场，离线对齐 camera↔NDI↔pressure；有硬件触发更佳。
- 气压/NDI 插值到相机帧时刻。
- `dt = 1/fps`；真实 `window_size`（帧）= 真实时间窗 × fps。

### 8. 实物评估指标（两档）

| 档 | 指标 | 实现 |
|----|------|------|
| **3D 骨架** | mean/endpoint/max/chamfer (mm)、per-node base/mid/tip、%arm | **直接复用 `metrics_3d.evaluate_skeleton`**，`arm_length=0.1`、`rod_radius=真实壁厚`，GT=三角化骨架 |
| **2D 投影** | 投影预测骨架到各视角 vs 图像 2D 骨架，像素误差 | 复用 `skeleton_2d.project_3d_to_2d`；**无需 3D GT**，贴近部署 |
| **NDI 独立验证** | 静态扫描残差 = GT 地板；末端锚点 = 动态时序验证 | 打破 GT/部署同源循环 |
| **稳态误差** | 模型收敛预测 vs NDI 平衡态 | 分离"动态误差"与"稳态误差" |
| **GT 不确定度预算** | 报告三角化 GT 误差地板 | 模型误差不能低于 GT 误差 |

> 训练中评估可直接复用已实现的 `evaluate_transition_during_training`（rollout 指标 + CSV/JSON）与 `evaluate_skeleton_during_training`，只需把 `arm_length`/`rod_radius` 改成实物值。

### 9. 分阶段路线（可验收里程碑）

- **P0 表征臂**：测 τ、气压范围、可分割性（背光/涂层对比）。
- **P1 单相机 + 单腔道**：单平面弯曲，2D 骨架链路打通（分割→`extract_skeleton_2d`→评估）。
- **P2 2–3 相机 + 标定 + 三角化**：出首份真实 3D GT；NDI 静态标定；训练 image→3D 骨架，用 NDI 验证。
- **P3 动态/迟滞数据集**：随机游走 + 瞬态，训练状态转移模型，对比仿真模型。
- **P4 三腔道 2-DOF + 闭环控制部署**（纯相机）。

### 10. 风险与未知（诚实）

- **硅胶透光** → 分割难：背光剪影 / 消光涂层 / 颜色。
- **10 cm 小臂** → 分辨率：近距离 + 高分辨率/手机 4K。
- **三角化 GT 精度**受标定 + 分割 + 2D 骨架质量限制 → NDI 量地板，公开报告。
- **1–2 mm 腔道** → 多锚点难：用单末端锚点（0.5–0.8 mm 传感器可入）。
- **气压迟滞大** → 利于研究，但需仔细记指令 vs 实测。
- **无硬件触发** → 时间戳抖动 → LED 标记缓解。
