# 06 · 多视角自标定设计 —— 3D 多驱动升级(免标定的 3D 形态)

> **日期**:2026-08-10 · 分支 `feat/real-data-transition`
> **状态**:设计定稿(方案层);落地映射到现有代码;实验补充见 `04_experiments.md` Exp H。
> **动机**:多驱动(6 通道、两段三腔、真正 3D 运动)的**控制需要度量 3D 形态**(单目深度歧义 + 避障/冗余在 3D 才成立)。用户确认优先 **L2(身体自我标定)+ L3(学习式免标定几何)**,反对传统标定作主线。
> **一句话**:免标定不是二元开关——把它拆成"内参/外参/尺度/手眼"四层,**选择性放弃**;让**臂自己的身体 + 静态场景**(而非标定板)出借几何与尺度。

---

## 一、为什么多驱动必然要 3D,以及"免标定"到底免什么

### 1.1 为什么不能单目 2D 直控多驱动
1. **深度歧义**:同一 2D 观测对应无数 3D 形状,单目无法唯一确定 6 通道下的 3D 形态 → 控制目标不唯一。
2. **避障/冗余**:1-DOF 平面"到达+避障"没有零空间(命题本身不成立);3D 冗余下全身避障才可解。这正是 2026-07-28 决策("免标定已反转,进入 3D")的原因。

### 1.2 免标定四层拆解(核心框架)

| 层 | 含义 | 传统做法 | 2D 基线(现状) | L2 身体自标定 | L3 学习式免标定 |
|---|---|---|---|---|---|
| **内参 K** | 焦距/主点/畸变 | 标定板 | 不需要(纯像素) | **近似 K**(相机规格书标称焦距,非标定流程) | 不需要(学习) |
| **外参 R,t** | 相机间相对位姿 | 标定板双视角 | 不需要(单目) | **自标定**:静态场景 + 固定底座刚性对应;或**模型在环**(见 §3.3) | 学习预测 |
| **尺度 mm** | 像素→毫米 | 标定板已知间距 | 不需要(像素) | **臂物理总长 / 支架上两已知间距标记**(量具,非相机标定) | 学习 / 或同左 |
| **手眼** | 相机-机器人基座 | 手眼标定 | 不需要(相机固定) | 不需要(相机固定) | 不需要 |

**结论**:3D 升级引入的最小几何信息 = **近似 K(规格书)+ 外参(身体/场景自标定)+ 尺度(量具)**。没有标定板、没有标定流程、没有手眼。这就是"免标定的 3D 形态"的可辩护表述。

---

## 二、L1(传统标定)—— 只作对照,不作主线

- 标定板求 K + R,t → 三角化毫米 3D。流程重、相机动要重标、与"自建模取代显式几何"故事相悖。
- **定位**:作精度/鲁棒对照基线(证明 L2/L3 达到可比精度),不写进主贡献。

## 三、L2 身体自我标定(推荐主线)

### 3.1 核心思想
**相机外参 + 尺度不预先测量,而是从"臂自己的身体 + 静态场景"的观测中估计。** 相机不是需要标定的传感器,而是被身体模型"驯服"的观测通道。

### 3.2 流程(两阶段:一次性自标定 → 每帧三角化)

```
阶段一(一次性,采集任意一段含 3D 激励覆盖的数据):
  多相机同时拍:静态场景(支架/桌面/底座) + 臂运动(覆盖 3D 弯曲)
    ├─ 静态场景:提取刚性特征(现有 background/registration 的参考帧)
    ├─ 用近似 K(规格书)+ 基础/本质矩阵 → 相机相对位姿(up to scale)
    ├─ 尺度:臂物理总长 或 支架上两已知间距标记 → 固定 mm
    └─ Bundle Adjustment:在臂骨架集上精修外参(重投影误差最小)
阶段二(每帧部署):
  各相机逐帧 2D 骨架 → 三角化 → 毫米 3D 骨架 state → 喂状态转移模型
```

### 3.3 关键:两个几何来源(分开处理,别混)

| 来源 | 刚性? | 作用 | 风险与对策 |
|---|---|---|---|
| **静态场景**(支架/桌面/底座) | ✅ 刚性 | **外参**(两视图本质矩阵 / SfM) | ⚠️ 若背景近平面(蓝墙)→ 本质矩阵退化。**对策**:用非平面结构(支架 3D 棱角/桌面纹理),或在刚性支架上贴 **2–3 个已知间距标记**(量具,非标定板)——给静态场景足够的非平面结构 |
| **臂骨架** | ❌ 形变 | **尺度**(已知总长)+ 三角化目标 | 软体伸展 → 尺度漂移。**对策**:尺度用"动作/模型约束"(状态转移模型本身是弧长一致性约束源)代替"固定总长" |
| **底座节点**(node 最远端/根部) | ✅ 固定 | 刚性锚点,给外参一个稳定的世界原点 | 每帧都有 → 也是质量门控的一项 |

### 3.4 模型在环自标定(优雅升级,与核心故事同构)
若状态转移自模型已足够好,部署时把**相机位姿 + 隐藏记忆状态**作为可优化变量,联合满足:
1. 模型先验:`ŝ_t = F(s_{t-1}, a_t, z_{t-1})` 给出形状预测;
2. 多视角投影:预测 3D 骨架 → 各视角 2D 投影 vs 观测骨架 重投影误差。

⇒ **模型本身成为标定约束**:自模型学得"驱动历史→3D 形状",就同时锚定了"相机该放在哪才能看到这个形状"。这比"静态场景自标定"更优雅,且是论文级卖点("the self-model calibrates the cameras")。**建议作为 L2 的进阶实现 / 论文讨论。**

### 3.5 可计算细节
- 初始化:两视图 DLT/八点法(本质矩阵,配近似 K)→ `cv2.recoverPose`;多视图:`cv2.sfm` 或最小化重投影(Levenberg-Marquardt,`scipy.optimize`)。
- 三角化:`cv2.triangulatePoints`(多视图最小二乘)。
- 质控:每帧三角化后的深度合理性、重投影误差阈值、可见视角数(≥2);被拒帧跳过(复用 `perception/quality.py` 的门控框架)。
- 退化检测:激励覆盖需让每段往多个方向弯(三腔协同),否则外参不可观测 —— 写进采集协议。

## 四、L3 学习式免标定几何(DUSt3R / MUSt3R 类)

### 4.1 是什么
现成模型从多视角图直接回归稠密 3D pointmap + 相对位姿,无显式标定流程。项目笔记已收录 MUSt3R("扩展到多视角,transformer 预测点图,无需相机标定",arXiv:2503.01661)。

### 4.2 优点 / 缺点
- ✅ 省事、对非平面场景鲁棒、可与 L2 交叉验证(两个独立通道得同一 3D → 互证)。
- ❌ 黑盒;要 GPU 实时性;软体半透明/高光的**分割鲁棒性存疑**(项目 raw mask 教训:分割最易错);输出尺度语义需确认。
- **定位**:作**辅助/基线**,不作唯一几何来源;若实时性达标,可作 L2 的 fallback。

## 八、诚实边界

1. **"免标定"的严格边界**:L2 仍需**近似 K(规格书)+ 一个量具(臂长/标记间距)**。这不是"零几何信息",而是"无相机标定流程"。审稿人若问,诚实说清即可——它比单目 2D 更硬(能控 3D),比传统标定更省(无标定板/流程/手眼)。
2. **平面背景退化**:两视图自标定在近平面背景下失效 → 必须给静态场景非平面结构或量具标记。
3. **软体伸展导致尺度漂移**:固定总长不可靠 → 用模型/动作约束,或分段尺度。
4. **模型在环(L2 进阶)依赖自模型够好**:若模型精度不够,模型先验反而污染外参 → 先做静态场景自标定(独立于模型),模型在环只作精化/讨论。
5. **L3 黑盒风险**:分割敏感 + 实时性未知 → 先离线验证再上部署。
