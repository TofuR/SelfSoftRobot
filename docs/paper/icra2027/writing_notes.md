# 初稿论证与证据说明

这份说明服务于后续修改，不进入论文正文。正文采用中文工作稿形式，把相关工作融入引言；保留可执行的实验细节，暂不按会议页数删减。文献采用现有21篇核心卡片中与论点直接有关的14篇，不以扩大引用数为目标，也不声称进行了新的系统性穷尽检索。

## 1. 核心判断

本稿以“控制相关状态能否从局部视觉中得到有用修正”为主问题，自模型是贯穿预测、状态校正与动作评估的基础。全身形状、自建模、历史建模和部分视觉都已有直接工作，不能将这些名词分别写成首创。方法贡献需要由以下因果链支持：真实动作历史 → 状态先验 → 可信可见证据 → 后续预测改变 → 未执行压力改变 → 真实任务误差改变。

32维状态与16维几何之间的欠定关系是方法设计理由：单帧不应覆盖全部历史，先验和局部更新是合理约束；它不是动态可观测性证明。控制收益也不能从局部优化下降推出，所以正文把未来同动作预测与真实闭环分开。

## 2. 引言每段如何承接

| 段落 | 正文中心句 | 承接与推进 | 原文借鉴及本稿处理 |
|---|---|---|---|
| P1 | 软臂的形状任务要求控制整条臂身，而不仅是末端的位置。 | 用同末端不同中段说明任务变量，再引出所需区域被遮挡的困难 | Yu I第3段、Almanzor引言；承认已有全身控制，场景限定为无接触遮挡形状调节 |
| P2 | 要在观测缺失时评估动作结果，机器人需要能够预测自身响应的模型。 | 从任务转到自建模，解释模型为何有用，再指出预测仍需新观测纠偏 | Chen 2022动作结果评估、SoftNeRF表示到任务、Yu几何读出；不把当前模型写成NeRF |
| P3 | 视觉反馈能够提供这种修正，但遮挡改变了图像实际包含的信息。 | 从“需要反馈”转到“得到何种反馈”，讨论完整恢复的优势与依赖 | AFT I第6–8段先分析标记替代、再引入自然纹理；本稿提出局部边缘直接校正，不贬低重建路线 |
| P4 | 这一问题还受到历史依赖的影响，因为当前形状并不必然包含预测后续响应所需的全部信息。 | 从形状缺失推进到动态状态歧义，区分方向、窗口和递归历史 | Chen 2025 I第4段、Park历史长度、Schäfke状态处理、Krauss递推；不称RNN无长期记忆 |
| P5 | 将历史与新观测结合，因而应当被视为状态估计问题。 | 给出承接历史与局部信息的共同视角，继而说明欠定性和先验 | Wang融合；Zheng物理边界观察器；Herrmann状态估计；不移植物理观察器定理 |
| P6 | 即使状态估计得到改善，这种改善也只有及时进入后续动作才具有控制价值。 | 从估计到动作再到时间期限，形成方法必须同时处理的两个问题 | Krauss预测指标与控制的区别、Schäfke隐藏状态和NMPC条件 |
| P7 | 为此，本文提出以可在线校正的历史自模型连接部分视觉证据与全身形状控制。 | 对前述困难逐项给出机制职责，形成整体方法 | 自行组织当前代码，不复制任何一篇的贡献主张 |
| P8 | 本文的研究内容由三个可检验的命题组织。 | 把机制转换为可验证主张，接入方法和分层实验 | 参考AFT分层验证、Chen先证问题、Zheng分离不确定因素；不预写性能结论 |

只读这八句，应能得到“全身任务 → 自模型预测 → 遮挡使反馈局部化 → 历史状态歧义 → 先验约束的估计 → 及时改变动作 → 方法 → 证据”的连续逻辑。段落中的文献按这一问题组织，未另设Related Work章节。

## 3. 引用使用范围

本轮重新打开了AFT、Yu、Krauss、Chen 2025、Zheng、Schäfke、Park和Wang的本地HTML，核对相关引言和作者题名；读取了Almanzor、Chen 2022、SoftNeRF、Tang与Xu的PDF提取文本开头，并读取Herrmann的题名/作者。实验细节沿用已整理核心卡片指定的原文章节范围，未将“已有摘要”当作全文精读。来源清单的哈希另行核验。

| 正文引用 | 采用的论点 | 必须保留的限制 |
|---|---|---|
| [1] Almanzor | 视觉全身静态控制、手绘目标 | 不将采集1 Hz当控制频率，不据此断言动态历史能力 |
| [2] Yu | 曲线表示连接自建模与几何控制 | 原方法多视角，不描述为单视角任意三维 |
| [3] Chen 2022 | 自模型评估动作与身体几何 | 原文出版题名确为“Fully body…”；不改成自行猜测的题名 |
| [4] SoftNeRF | 软体视觉隐式自模型服务下游任务 | 当前论文采用中心线，不继承隐式体积模型实现 |
| [5] AFT | 自然外观、数字遮挡重建、另行闭环实验 | RGB-D条件；重建与控制分节，不扩大为所有因素联合实机验证 |
| [6] Chen 2025 | 气压方向特征与迟滞感知全身模型 | 不误写为无历史或仅仿真监督；更长历史需更强配对证明 |
| [7] Park | TCN与历史窗口补偿 | RGB-D及物理标记；长缆迟滞不同于气动本体 |

| [9] Krauss | 视觉潜动力学与真实开环控制 | 有历史；预测代理与实机控制分开；50 Hz不是优化频率 |
| [10] Wang | 动作历史与RGB融合估计 | 受载估计并不自动给出遮挡闭环证据 |

## 5. 实验链与结果解释

| 层次 | 新增加的证据 | 对前一层的补充 | 不能跳过的对照 |
|---|---|---|---|
| E1 历史配对 | 同输入同方向、不同历史导致未来差异 | 确认模型要解决的问题确实存在 | 同历史重复波动；同输入与近完整形状分开 |
| E2 独立预测 | 学得模型捕捉上述差异并跨采集预测 | 从现象进入模型有效性 | 方向模型、充分调优GRU、重训练消融 |
| E3 局部校正 | 部分观测改善相同未来动作预测 | 从模型进入观察器有效性 | 当前几何校正、状态重启、同信息GRU、已知遮挡特权对照 |
| E4 真闭环 | 修订动作改变真实响应并改善任务 | 从估计进入实际控制 | 2×2状态/动作消融；真实分别执行 |
| E5 有效边界 | 可见位置、时长、外观和物理遮挡下的退化 | 从代表成功任务进入可用条件 | 软件与物理分开；全遮挡停止纳入分母 |
| E6 时间条件 | 反馈在完整执行时序中仍有用 | 从算法结果进入可部署性 | 计算/图像/ACK延迟分别注入；误差与频率一起报 |

三个容易误解的设计已经在正文展开：

1. **仅状态校正通常不应改变真实运动。** 若相同压力和时序下也出现“控制提升”，优先检查实际压力、终止门控、调度和统计波动。它是验证动作环节的负对照。
2. **几何偏差与历史状态是可比较的替代路线。** B1保持短时几何偏差，B3传播校正后的历史，二者在反转/持压之后可能不同；不能只设一个故意很弱的静态模型。
3. **停止不能降低误差积分分母。** 使用统一评价时长，停止后继续测量实际形状；全遮挡超过三次无证据门限时评价终止行为，不预期持续控制。
