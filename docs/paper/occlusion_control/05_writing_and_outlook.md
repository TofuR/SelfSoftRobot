# 成稿、图表、结论与展望

## 1. 推荐成稿次序

先写实验协议与证据表，再写方法，最后写引言和摘要。当前先交付“可以执行的论文准备包”，不强行重写整篇论文并用占位结果支撑强结论。

| 顺序 | 写什么 | 通过条件 |
|---|---|---|
| 1 | 问题定义与信息预算 | 谁看原图、谁看遮挡图、谁看 NDI、何时初始化均无歧义 |
| 2 | 实验表的空模板 | 每列指标有真值、分母、单位、失败定义和对应假设 |
| 3 | 方法与算法图 | 每个公式对应实现；拟议扩展清楚标明；所有状态时间一致 |
| 4 | 原论文引言/实验借鉴 | 引用可回到具体段落；不引用旧笔记中的夸大差异 |
| 5 | 运行 E1–E6 的必要子集 | 得到独立真实控制结果，不用回放代替 |
| 6 | 引言与相关工作 | 六段中心句能独立成链，最接近工作被正面讨论 |
| 7 | 摘要、结论、题名 | 所有定量主张可回到冻结 run/表格；关键词不超出实验范围 |

若篇幅按机器人会议组织：引言约1页，相关工作0.5–1页，方法2页，实验2–3页，讨论/结论0.5页；这是布局建议，投稿目标确定后再按实际模板调整。

## 3. 结论怎么写

按“回答的问题→证据支持的机制→有效范围→限制”四步写。现阶段可用的研究总结是：

> 当前实现将动作历史、部分图像证据与剩余序列优化接入同一控制流程，并通过有期限的快照提交明确处理迟到反馈。回放和虚拟设备验证了实现与记录链路；其能否在真实遮挡条件下改善全身形状控制，仍需同信息预算的模型/观察器对照和实机试验。

实机结果完成后再改为定量结论：“在×平台、×遮挡范围、×独立episodes中，相对×基线，×指标变化×，代价为×；在×条件下退化/停止。”不在结论新提出正文未检验的安全性、三维能力或材料解释。

## 4. 有针对性的展望

| 当前限制 | 下一步 | 需要的新增证据 |
|---|---|---|
| 单帧状态欠定 | 依据多时刻敏感度选择校正子空间/自适应正则 | 时窗可观测性与未来预测、控制对照；不能只展示奇异值 |
| 全遮挡失去视觉约束 | 经验证的短时预测+不确定性门控；必要时主动恢复可见性 | 超时长遮挡风险、主动动作是否受约束，实机验证；当前未实现主动探测 |
| 纯色/局部边缘误匹配 | 纹理跟踪/语义前端与几何一致性融合 | 同预算与多外观测试；AFT作为重要参照 |
| 真实压力与下发压力不同 | 同步实测腔压、低层执行器响应建模 | 延迟/速率试验，区分执行器和本体记忆贡献 |
| 平面与相似变换假设 | 多视角/深度、出平面读出与配准 | 新数据、新几何模型和独立3D真值，不承诺单目自动解决 |
| 无接触与安全证明 | 显式负载/接触状态、约束控制或安全滤波 | 参考Tang/Xu/Wong的假设及证明；不能以目前归零策略替代 |
| 开发证据与设备单一 | 跨实验日、机器人实例、材料老化/温度 | 分组测试和重训练/适应成本，不以一条曲线声称泛化 |

优先做“实测气压与时间同步、同信息状态基线、真实闭环”三项，不要同时扩展为三维重建、接触力控制和自动探索而稀释主问题。

## 5. 以后如何查看与维护

- 从本目录 [README](README.md) 开始；查关键词用 HTML 工作台或文献 `catalog.csv/json`。
- 读论文先看其 `verification` 和原文定位，再看本文档写作建议；旧笔记只作线索。
- 新结果先进入正式 experiment/run，再更新 `01` 的证据表；不能只改摘要中的数字。
- 新论文先合并 DOI/arXiv 重复条目，再补主分类、交叉标签、最接近关系、原文实验和引言段落；不靠“标题看起来相关”判定空白。
- 按 [训练/评价标准](../../standards/training_and_evaluation.md) 与 [证据语言标准](../../standards/evidence_language.md) 冻结最终 claim。正文不引用本准备材料当作外部学术证据，引用原论文。

离线工作台把本套文档与文献数据内嵌到单个HTML，复制到个人电脑也可搜索和阅读；外部论文需联网，源码/原始运行链接需保留仓库。公式保留可复制的LaTeX。更新Markdown/JSON后，可生成到一个新报告目录：

```bash
python scripts/maintenance/build_paper_workbench.py \
  --out workspace/reports/paper_preparation_<日期_序号>/index.html
```

生成器拒绝覆盖已有HTML。文档为源，HTML为可重新生成的阅读副本；本次已检查71条记录、61个原引言定位、文档链接以及浏览器搜索/分类/核对等级筛选和段落跳转。
