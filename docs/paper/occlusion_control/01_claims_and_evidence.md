# 工作关键点、贡献候选与证据边界

## 1. 一句话定义工作

研究对象是**受控平面内运动的气动软臂**。学习动作历史到全身中心线的预测模型，在单个 RGB 视角只提供局部可见边缘时，校正模型的历史状态并更新剩余动作；对计算迟到和观测失效进行显式处理。

英文问题描述可用：*Whole-body shape control of a soft arm from partially occluded monocular feedback using an online-correctable history-dependent self-model.* 这是问题描述，不是已经验证的性能声明。

## 2. 关键词与论文角色

| 关键词 | 当前具体含义 | 论文角色 | 不能扩大的含义 |
|---|---|---|---|
| 全身形态控制 | 15 节点中心线；目标/预测误差覆盖除 base 外全部节点，非仅 tip | 任务定义与主要指标 | 不代表任意三维表面、接触力或体积控制 |
| 自建模 | 用机器人自身动作—视觉形状数据学习可前向预测的模型 | 学习方式；模型可用于候选动作评估 | 不是当前重新训练 NeRF；不是零数据、无结构先验或损伤后自动重学 |
| 单视角 | 当前控制只读取指定一个相机的 RGB 图像 | 传感预算与部署条件 | 不解决任意单目三维歧义；RealSense 品牌不意味着控制用了深度 |
| 部分观测 | 每次只使用通过可靠性检查的可见侧边缘 | 核心问题 | 不是先补齐隐藏骨架再当真值；不假定已知遮挡掩码 |
| 遮挡 | 模型附近的可信边缘减少；纯色方块为一种可重复扰动 | 主要评价轴 | 不等于识别了遮挡物；缺边缘也可能来自对齐/颜色/光照失败 |
| 历史依赖 | play 与 Maxwell 状态由实际已下发动作和时间演化 | 预测与补偿的模型机制 | 有限状态递推不是“非马尔可夫定理”；不是材料谱辨识 |
| 状态补偿 | 图像误差用于修正 p/h，网络权重固定 | 方法核心之一 | 不是在线参数重训；不能宣称恢复了唯一真实物理记忆 |
| 动作补偿 | 用修正状态重新预测，对剩余序列做约束局部更新 | 方法核心之一 | 不是补偿未知接触力；也不保证全局最优 |
| 闭环 | 已确认动作 → 新图像 → 状态/动作更新，影响下一条命令 | 控制结构 | 录制图像不会响应新动作，不能用回放证明实机闭环精度 |
| 实时性 | dt≈100 ms 的名义周期；带期限的快照提交、迟到丢弃和任务数量上限 | 控制实现约束与性能指标 | 计算 P95<100 ms 不等于端到端硬实时 10 Hz |
| 初始化/对齐 | 当前完整形状约束相似变换，再估计状态并保持预热 | 实验成立的前提 | 不是无校准、自动识别任意透视，或一帧消除全部记忆不确定性 |
| 安全停止 | 断流/无边缘、反复迟到、ACK 失败触发终止；正常结束持压 | 故障策略 | 不是闭环稳定性、碰撞安全或医疗安全证明 |

NDI 是可选评价流，不进入控制。每条压力记录是请求/ACK 确认下发值，当前没有独立实测腔压闭环。6 腔映射为 4 个有效输入，默认 `c0→u0,c1/c2→u1,c3/c4→u2,c5→u3`，可在 GUI 更换映射，但这不会改变模型的实际训练域。

## 3. 候选贡献如何收敛

建议论文只组织三个相互支撑的贡献，而非堆列八个关键词：

| 候选贡献 | 要回答的问题 | 可提交论文前必须补的证据 |
|---|---|---|
| C1：可在线修正的历史形状自模型 | 部分观测时，保留历史并局部校正是否优于无历史/重置/一般递归状态估计？ | 跨序列预测、相同当前输入及末次方向但不同历史的配对任务、同观测 GRU 基线；E1–E3 |
| C2：可见证据驱动的状态—动作联合更新 | 不恢复完整骨架，能否通过可见边缘改善后续全身控制？ | 同一模型下 open-loop / state-only / action-only / both；真实机器人软件遮挡和物理遮挡；E3–E5 |
| C3：有期限约束的闭环实现及性能评估 | 在实际采集/通信开销下，补偿是否仍来得及且有效？ | 控制机端到端分布、迟到比例、有效反馈频率、同预算对照、故障实验；E6 |

C3 通常是 C1/C2 能落地的支撑，而非单独声称“发明实时 MPC”。如果一般 GRU 观察器同样好，应将 C1 改写为结构紧凑与计算/数据效率优势，而不是坚持“只有显式算子才能处理历史”。若动作修订未改善真实控制，应保留状态估计结果并收缩论文范围。

## 5. 最需要补的科学证据

1. **真实闭环反事实**：相同初始条件下执行不同方法的动作，观察机器人实际响应。
2. **隐藏区域评价**：先在实机在线图像上软件遮挡，原图仅供评价；物理遮挡另用独立评价视角/测量系统。NDI 末端不能证明全身误差。
3. **强状态基线**：不仅比较静态 MLP，还比较递归传播且能接收同样局部观测的 GRU/TCN 或误差状态观察器。
4. **同预算与可观测性**：收益来自更好状态、更多计算，还是只选容易的遮挡位置？需要分离。
5. **停止与性能一起报**：全遮挡时停止次数、归零过程、误差和超时不能从成功率分母删除。
