# 引言、相关工作与论文叙事

## 1. 用可检验问题统领全文

推荐核心问题：**在连续完整视觉反馈不可保证时，怎样用部分图像证据与动作历史，让软臂继续完成全身形状任务，并限制失效估计和迟到优化对控制的影响？**

不是“别人没有把六个模块放在一起”。有竞争力的回答应解释两个困难之间的联系：遮挡使当前状态约束不足；历史依赖使简单的当前输入/当前图像映射不足；而优化必须赶上下一个动作周期。解决方式是保留可传播的历史估计，让图像只修正有证据支持的方向，再把修正传递到后续动作。

## 2. 建议的六段引言骨架

下面是新写的中心句与段落功能，不是完整引言成稿，不继承旧稿。

| 段落 | 本段中心句（草拟） | 展开内容与引文 | 如何接下一段 |
|---|---|---|---|
| P1 任务价值 | 软臂执行形状任务时，仅将末端送到目标不足以确定整条臂身应呈现的形态。 | 用一个无接触的中心线目标例子；引用 Almanzor、Yu、Chen，承认已有全身控制；不要开篇罗列所有软机器人应用 | 全身控制需要持续掌握全身形状 |
| P2 观测条件 | 视觉提供了低侵入的全身信息，但环境遮挡会使控制所需的形状证据变得局部且间歇。 | 引 AFT 的实际遮挡工作、视觉方法条件；区分单 RGB、RGB-D、多视角与嵌入式传感；承认已有可靠重建方法 | 有形状重建进展，仍需考虑历史和动态控制状态 |
| P3 历史与状态 | 当软臂响应依赖加载路径和保持时间时，可见的当前形状与当前命令未必足以确定后续演化。 | 引 Chen 的方向特征、Park 的 TCN、Schäfke 的 RNN/NMPC、Krauss 的潜动力学；提出“相同当前输入/形状近似、未来响应不同”的具体检验 | 部分观测时不能把每次重建当作完整状态重启 |
| P4 剩余问题 | 需要研究的是如何把不完整视觉证据转化为对历史状态和未来动作的有效修正，同时满足控制时限。 | 按信息条件对比：AFT 重建反馈、Zheng 稀疏物理传感观察器、Krauss 开环预测；不用“所有工作均忽略遮挡” | 从缺口过渡到设计原则 |
| P5 方法思想 | 我们以可递推的历史形状模型连接动作与全身几何，用可信可见边缘约束状态，并通过受限局部优化调整未执行动作。 | 只说 p/h 机制、部分残差、动作更新、期限；不在引言塞全部公式和 GUI 按钮。明确平面 RGB 与固定几何对齐 | 方法需要怎样的证据 |
| P6 贡献与验证 | 通过历史配对、可见性变化、状态/动作分离消融及真实闭环比较，检验这种设计在何种条件下有效。 | 与 C1–C3/E1–E6 一一对应。真实结果完成后填数字；当前只写研究计划，不用虚拟数字冒充实机结果 | 指向方法与实验章节 |

写完后只连读六句中心句，应该能读到“全身任务→观测不足→历史歧义→待解控制问题→机制→证据”。如果去掉某段仍不影响逻辑，该段需要删除或并入相关工作。

### 可以使用的短动机示例

让软臂在两种加载历史后保持相近初始形状，再要求相同目标；运动中挡住中段。只看末端不能评价中段，完整骨架提取可能失效，纯模型又会积累失配。我们关心的不是隐藏轮廓画得是否顺滑，而是**可见部分能否帮助修正足够的控制相关状态，使下一段真实动作更接近目标**。这里“更接近”是待验证假设。

| 写作分组 | 应讲的进展 | 核心引用 | 我们接续的具体问题 |

| RW1 全身形状表示与视觉自建模 | 从形态/占据预测走向直接形状控制；明确几何表达可被规划使用 | Chen 2022、Hu 2025、SoftNeRF、Almanzor、Yu | 部分图像下更新控制状态，而非再证明能够预测/描画形状 |

## 4. 标题、摘要与贡献措辞

建议题名按证据强度选：

- 实机验证完成后：**History-Conditioned Whole-Body Shape Control of a Soft Arm under Partial Visual Occlusion**。
- 侧重估计机制：**Correcting History-Dependent Soft-Robot Shape Models from Partial Visual Evidence**。
- 只有回放/虚拟验证时：以 *framework / prototype / feasibility study* 明确范围，不用实机闭环性能导向题名。

摘要顺序：任务及观测约束 → 现有困难 → 两重更新机制 → 实验平台和比较对象 → 真实定量结果 → 适用范围。不要用“单目、免标定、首次、物理可解释、实时、鲁棒”连续堆砌。

贡献最终应是结果支持的命题，例如“在固定观测预算下，历史状态校正减少了……”，而非“我们实现了 GUI/NDI”。界面和记录系统放实验可复现性或补充材料。

## 5. 不应照搬的论证

- RNN 的递归状态可携带更早历史，不能按输入窗口或状态阶数断言“对方没有长期记忆”。
- 全身 + 单视角 + 遮挡 + 控制已存在，AFT 尤其直接；其遮挡估计试验与闭环试验分开报告，也不能替它扩大为“全部组合条件已验证”。
- Zheng 的 boundary 是杆的基座/末端物理边界，不是图像轮廓边缘。
- 学习式模型同样有训练域、几何/观测先验；不能说物理模型一损伤必然失效而学习模型天然不受影响。
- 一次局部预测误差下降不等于真实任务误差下降，更不等于稳定性证明。
- 全遮挡只剩传播与故障策略；写清能维持多久、何时停止，不以“鲁棒”略过。
