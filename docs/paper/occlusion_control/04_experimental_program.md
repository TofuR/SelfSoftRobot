# 实验如何逐层建立证据

本文件是**拟议实验协议**，不将尚未运行的对比写为结果。先确定论文要证明的命题，再选择足以区分机制的实验；不以完成所有模型排列组合为目标。

## 1. 六个实验问题

| 实验 | 可证伪假设 | 协议与对照 | 主指标 | 支持或否定后的写法 |
|---|---|---|---|---|
| E1 历史是否影响控制相关预测 | 相同当前输入及末次变化方向不足以决定未来全身响应 | 加载/卸载、嵌套小回线、不同保持时长后到同一输入；加相同后续探测动作；静态、方向特征、GRU、Hereditary 对照 | 未来窗口全身误差、tip误差；同输入响应分离度 | 若只在方向不同才有差异，不能证明复杂历史状态必要 |
| E2 自模型是否跨采集泛化 | 结构模型能在独立序列维持多步预测，且计算代价合理 | 同数据与选择协议；持续 rollout、固定周期观测、冷启动分开；独立速率/保持/反转序列 | 全身/最大节点误差随 horizon、推理时间、参数/数据效率 | GRU更优时报告权衡，不写算子优越性；不把 within-sequence 当跨域 |
| E3 部分证据如何修正状态 | 历史先验+可见边缘优于重启和未经筛选的视觉校正 | 真实录制轨迹上只用原动作；输入图像加遮挡，原图可评价；见 2×2 消融 | 校正前后可见/隐藏段误差、后续同动作预测误差、错误接受率 | 只拟合当前帧而恶化未来则否定有效状态补偿 |
| E4 真正的遮挡闭环 | 状态+动作更新能减少真实任务误差，而非仅降低模型 residual | 真机器人实时图像的软件遮挡；各方法分别实际执行；原图只作评价 | 全身任务误差积分、终态误差、成功率、到达时间、压力变化 | 这是当前核心缺口；没有此实验不能把回放称为控制提升 |
| E5 外推与失效边界 | 方法在不同位置/持续时间的遮挡下有可重复的有效区间 | 冻结参数后变遮挡位置、覆盖、连续时长；另做真实物体遮挡、相似颜色/纹理、视角轻微失配 | 成功率与恢复时间曲线、误关联、提前停止、隐藏段误差 | 若只对纯色块有效，明确限定场景，不能泛化到任意遮挡 |
| E6 截止期与精度是否同时成立 | 有期限事务避免迟到结果污染，且计算跳过不会抵消控制收益 | 同观测/任务，故意注入计算、图像、ACK 延迟分别测试；限时/同步阻塞比较 | P50/P95/P99/max、超期比例、有效更新率、真实控制误差 | 不只报平均计算；报性能随延迟退化和停止比例 |

E1–E3 可以先用现有数据做机制筛选，E4–E6 要在实机执行。当前服务器只具备虚拟设备验证，需在硬件电脑采集正式证据。

## 2. 对比模型不是越多越好

### 2.1 前向模型（固定几何/数据输出口径）

| 编号 | 基线 | 为什么需要 | 公平实现条件 |
|---|---|---|---|
| M0 | 当前输入 → 形状的静态 MLP | 最小无历史基线 | 相同 15 节点与单位，充分调参；不是故意弱化模型 |
| M1 | 输入 + 各通道末次变化方向 → 形状 | Chen 2025 的主要思想，检验“只有方向”是否足够 | 零变化时方向定义固定；按本平台四输入重新训练，不冒充原论文复现 |
| M2 | GRU 历史状态 + 同一几何读出 | 最关键的一般递归状态竞争者 | 同 train/val/test、训练预算、multi-step 目标；隐状态合理初始化和持续携带 |
| M3 | TCN/NARX 历史窗口 + 同一读出（次优先） | Park 等的有限历史路线 | 因果窗口；窗口长度参与验证集调参，不用双向未来帧 |
| M4 | 当前 Hereditary 无残差模型 | 完整模型 | 同数据，正确记录训练与部署 dt、归一化和初始历史 |

训练开销、模型尺寸与误差一起报告。只把训练好的分支权重置零是“模型依赖诊断”，**不是重训练消融**；最终应重训去 play、去 Maxwell、去全部记忆。若改用自由点坐标读出，另做相同历史机制下几何读出消融，避免同时更改时序与空间结构。

### 2.2 控制与观察器（主比较）

| 编号 | 方法 | 与完整方法隔离什么 |
|---|---|---|
| B0 | 相同自模型和初始计划，后续仅由已执行动作传播 | 图像闭环的总价值；同一动作约束、观测记录与停止政策 |
| B1 | 完整视觉形状估计 → 误差反馈/约束 Jacobian 控制 | 与传统视觉伺服/重建反馈相比；从 Almanzor、Yu/AFT 借鉴，区分 RGB 与 RGB-D预算 |
| B2 | GRU 动力学 + 可处理局部观测的状态更新 + 相同动作优化器 | 判断收益来自结构化状态还是一般学习观察器；必须让 GRU 接收同样的信息，而非拿开环 GRU 充当强闭环基线 |
| B3 | Hereditary + 可见边缘状态校正 + Analytic B | 完整方法 |
| O1 | 未遮挡完整视觉反馈 | 特权参考/上界条件，不列作同观测竞争者 |
| O2 | 已知真实遮挡掩码/对应关系的观察器 | 只诊断前端误关联损失；必须标 oracle，不能给完整方法使用 |

B2 可先采用带掩码/可靠度输入的 GRU 状态编码器，或对隐藏状态做同一几何残差局部校正；两者择一实现并充分验证，不能默认随意覆盖隐藏状态就是公平比较。信息预算：所有控制方法只看当时可获得的图像与动作；评价原图、未来帧、NDI若未向完整方法开放，就不能给普通基线暗用。

AFT 若无法在当前纯色、无深度条件忠实复现，可比较其“先重建形状再反馈”的同预算适配版，并明确名称/改动；不得把删去其深度/纹理条件后的失败直接归为原算法失败。另有条件的 RGB-D 原方法可单列，不与单 RGB 数字混排名。Krauss VON/Koopman 适合作进阶竞争者，但需独立训练与同协议状态更新；优先做正确的 GRU，而非堆凑未经调优的多种模型。

## 3. 核心 2×2 因果消融

固定同一个模型、初始计划、视觉前端和动作约束：

| 状态校正 S | 动作修订 A | 实际做什么 |
|---|---|---|
| 0 | 0 | 原计划执行，模型只传播 |
| 1 | 0 | 用图像修正状态，但继续原合法动作，检验估计收益能否转化为控制（通常缺少动作环节） |
| 0 | 1 | 不使用图像状态修正，从原传播状态同预算优化剩余动作，隔离“多算一次”收益 |
| 1 | 1 | 完整两重更新 |

四个条件都记录真实已下发压力，ACK 后的合法接续修复不是算法优势，所有条件一致。比较 S=1 时还应保留：原历史先验、每帧从当前形状重置、只估计几何偏差的轻量观察器。重置基线要采用合理的完整/部分拟合与相同预算，不能故意给零初值制造失败。

次级消融按主结果选择：可信边缘过滤/无过滤；稳健损失/普通平方；状态先验/弱先验；解析导数/自动导数；8块/更少或更多块；Cached A/B。导数实现比较应先验证同目标/同分支的数值一致性，再比较耗时，不把浮点分支差异当作算法优越性。

## 4. 实机分两级验证遮挡

**L1 真机器人 + 在线软件遮挡。** 相机得到完整原图，控制输入副本被遮挡；执行后的机器人会真实响应各方法的动作，因此是真闭环实验。原图保存且只用于评价，可统计被人工遮挡区的真实中心线误差。这与“把旧录像注入新动作”的离线回放有本质区别。

**L2 真机器人 + 物理遮挡。** 遮挡物不接触臂身，先避免把接触扰动与视觉遮挡混在一起。隐藏区域真值需独立评价视角、经配准的后视相机或足够的外部形状测量。单个 NDI tip 只支持末端真值；没有隐藏全身真值时只报告可见部分与 tip，不能用模型补出的形状评价自己。

“单视角”指控制的信息预算，论文可以有一个不进入控制的评价相机，但必须在系统图中清楚分离并说明标定。实机物理遮挡与软件遮挡结果分表。

## 5. 任务与因素

| 因素 | 建议层级 | 目的 |
|---|---|---|
| 目标 | 独立实拍可达目标为主；均匀覆盖 workspace；直臂、单弯、双段不同弯曲、同 tip 不同中段；模型生成目标单列 | 避免仅测试自身模型生成的容易目标；证明全身任务必要 |
| 初始历史 | 加载/卸载、嵌套循环、不同持压时间 | 分离同输入与同形状条件，不能把二者混称完全同状态 |
| 遮挡位置 | 基段附近、中段、远端；保持像素/弧长定义一致 | 同覆盖比例的信息量可能不同 |
| 覆盖强度 | 以真值中心线被遮弧长比例报告，如 0/20/40/60%；另记像素方块大小 | 不用框宽比例等同身体可见比例 |
| 时间模式 | 固定遮挡、运动中出现、间歇遮挡；100/300/600 ms 和更长失明段先做仿真 | 区分空间缺失与传感 dropout；停止策略应一致 |
| 外观 | 纯色、接近臂色、纹理；背景与光照变化 | 检验误关联，而非仅缺少边缘 |
| 运动 | 多速率、保持、反转、大变化；先无接触 | 研究历史与时延，避免混入尚未建模的力学机制 |
| 系统负载 | 正常、独立计算拖慢、图像拖慢、ACK拖慢 | 各种延迟分开注入，不用一个 sleep 代替所有时序机制 |

固定目标容限和最大动作数/时长，记录未达标规划和被拒执行。任意手绘曲线未必可达，不可在得到不同方法结果后删除“难目标”；可达性筛选使用独立校验数据或预先规定标准。

## 6. 指标与统计

- 全身误差：\(e_{body}(t)=\frac1{N-1}\sum_{i=1}^{N-1}\|x_i^{gt}(t)-x_i^*\|\)；终态、最大节点、时间积分均报；tip另列。按臂长归一化便于不同尺度理解，但不跨论文混做排名。
- 估计误差：\(\|\hat X-X^{gt}\|\)，分可见/遮挡区域；当前 residual 与真实误差分开。再报告**校正后使用相同未来动作**的多步预测误差。
- 到位：真实平均及最大节点阈值同时满足并持续预定驻留时间；规划预测达标不是到位。阈值按仪器精度和任务在 pilot 后冻结；不能因结果不好调阈值。
- 控制代价：动作总变差、峰值/速率约束违反、有效动作步数、规划失败和停止比例。
- 时序：全阶段墙钟、图像年龄、命令间隔、deadline miss、state commit、actual suffix change分别统计；分母包含超时、无边缘和停止前的全部机会。报告执行频率及**新鲜有效反馈更新频率**，二者不同。
- 统计单位：独立实验 episode/采集序列，不把视频帧当独立重复。配对目标和历史、随机化方法执行顺序、阻断实验日与机器人批次；给每个 episode 散点、置信区间与效应量。
- 可从 pilot 的 episode 方差决定正式样本数。最低可操作示例：3目标×2遮挡×3方法×2重复=36次 pilot；正式核心6目标×3遮挡×4方法×3重复=216次，再决定是否扩大，不将该数量当作统计功效证明。

## 7. 数据与防泄漏

遵守 [数据划分标准](../../standards/dataset_split.md)：先按独立 sequence/实验日划分，再构窗；标准化/几何基只由训练集获得，val用于调参/模型选择，test冻结后仅正式报告。所有模型使用同一数据内容，历史长度可调但须声明。训练、当前模型选择和最后实机验证的目标不能默默重用。

软件遮挡的原图可作测试真值，但测试时不得流入观察器或形状初始化之外的控制状态。遮挡前初始化允许完整视野，这一假设所有方法一致。自动选择高变化片段可以用于开发，正式测试不能只挑模型表现好的段落。

## 8. 从现有资产到正式实验的顺序

1. 冻结数据划分、单位、目标、评价流隔离和初始化流程；核对真实腔道下发及相机时间。
2. E1/E2：训练 M0/M1/M2/M4，筛查历史效应和泛化；判断是否值得保留结构机制主张。
3. E3：只用原动作，做部分观测状态校正及未来预测；修掉前端误关联主导的问题。
4. E4 pilot：实机软件遮挡，至少 B0/B2/B3；完成2×2小子集后再扩大。
5. E5物理遮挡与E6压力测试，固定主参数；记录退化曲线而非只放成功视频。
6. 最后写性能主张和摘要，负结果也进入讨论，图表中的占位数不先编。
