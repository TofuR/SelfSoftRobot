# 02 · 科学问题重构与五支柱判定

> **结论先行**:原始科学问题("不同参数/不同外力下控制难")在**控制侧**已被 2026 Nature Comms + Sci Adv 解决,必须重构。重构后的科学问题把注意力从"输入的多样性"转向"**系统自身的非马尔可夫结构**"——这是现有文献(包括已解决原问题的那些)都没有触碰的。

## 一、为什么旧问题死了(诚实)

| 原问题的子问题 | 被谁解决 | 解决方式 |
|---|---|---|
| "不同**参数**(构型/材料/几何)下控制难" | Zhang et al., Nat Comms 2026 | 共享 Koopman 线性动力学嵌入 + 单基础 RL 策略在线更新,33 构型 |
| "不同**外力**(负载/扰动/未知情境)下控制难" | Tang et al., Sci Adv 2026; Tang IJRR 2026; Lu 2024; Fang 2026 等 | 在线突触/元学习/FBG 在线/在线模型 RL —— 全是闭环适应 |
| "骨架点→曲线参数降低预测难度" | Yu 2026; Rao 2022; Mbakop 2024; Valadas 2024 等 | 低维连续曲线表示(已多组占据) |

**结论**:如果论文声称"解决不同构型/外力的控制",审稿人会立刻指到 Nat Comms / Sci Adv —— 必被拒。**不能再往这里站。**

## 二、重构后的科学问题

> **软体机器人的整体形态自建模是"非马尔可夫系统辨识"问题:粘弹性使"指令 → 全身形态"不是函数,而是加载历史的泛函。**

### 2.1 形式化

正向映射在物理上是一个**泛函**:
```
S_t = F[{a_0, a_1, ..., a_t}]     ← 依赖整段历史,不是 F(a_t)
```
- 相同指令 `a_t`、不同历史 → 不同形态(路径依赖)
- 相同路径、不同速率 → 不同形态(速率依赖)
- 迟滞使逆映射 `a_t = F⁻¹(S_t)` **不适定**:同一目标形态可能由多条历史分支到达(歧义集 > 1)

### 2.2 为什么这是科学问题而非工程问题

1. **结论由物理决定,不依赖模型选择**:记忆视界 h / 临界记忆长度 T* 由材料弛豫谱决定,换 EMA/GRU/Transformer 都不改变极限(项目 `docs/directions/12` §七 已有论证)。
2. **可证伪**:可从弛豫谱解析预测 h ≈ τ_max/Δt、T*,再用实验验证(项目 `docs/directions/12` 已给出)。
3. **现有工作系统性回避**:几乎所有视觉自建模都在准静态下采数据(等稳定再拍),从而在实验设计上**排除**了迟滞与速率 —— 这与"控制侧"的解决无关,是**建模侧**的空缺。

### 2.3 与方向 12/17 的衔接(项目已有思考的落点)

- **方向 12 问题 A(形状即记忆)**:从当前形状解码加载历史 → 记忆视界 h。
- **方向 12 问题 B(IK 可逆性)**:消除 IK 歧义所需的最小历史 → 临界记忆长度 T*,并给出"泛函 vs 函数"的形式化。
- **方向 17(路径依赖 IK)**:已用实物数据测出迟滞回线(load/unload 位移差 1.53mm 准静态 → 2.06mm 动态),是"非马尔可夫性"的**首个实物锚点**。

> ⚠️ 注意:方向 17 里被压测毙掉的 contraction/K_self 路线(超参 confound)不要复活;方向 17 已诚实记录 z 懒惰的风险(见本文件 §四)。

## 三、五支柱判定(对抗复核结果)

> 两个 workflow 的独立批判 agent 对五支柱逐条做了"找茬"。判定等级:STILL-OPEN / PARTIALLY-CLAIMED(注明空缺残余)/ CLAIMED。

| 支柱 | 判定 | 空缺残余 | 能否做头条 |
|---|---|---|---|
| **P3** GL 分数阶幂律核作神经形状模型**时序编码器** | **STILL-OPEN** | 无任何已核实工作把 GL 离散核放作"动作历史→形状模型"的时序层;分数阶+软体+NN 组合全部把分数阶放控制器/物理权重/优化器/图导航 | ✅ 能(但必须与四类近邻显式区分) |
| **P4** 迟滞感知 + 开环逆动作序列规划 + **可信视野认证** | PARTIALLY-CLAIMED | 每件单独已发表;组合"显式迟滞 + 开环多步序列 + 认证视野"无人占;Thuruthel 2017 明确回避可达性验证 | ✅ 能(与 P3 组脊柱) |
| **P1** 经验非马尔可夫性(全身,NDI,速率+路径) | PARTIALLY-CLAIMED | 前向路径依赖已量化(Chen 3.4%、Cho 9±6.5%);空缺 = 全身 + 速率 + NDI 统计严谨 + **IK 歧义集量化** | ⚠️ 只作动机/证据 |
| **P2** 无记忆模型反转处失效 | **CLAIMED** | 无(Wang 2024、导管 2024、Ma 2022 已量化) | ❌ 不能 |
| **P5** 全身避障 + 冗余 3D 臂 | **CLAIMED** | 头条级被 Yu/Kasaei/Hachen/Wong/Gandhi 占据;残余只有"免标定 2D 骨架 + 显式全身形状轨迹规划 + 自碰撞"这种配置级空缺 | ❌ 降为 demo |

### 两个批判 agent 的一致建议(写进策略)

> **论文脊柱 = P3 + P4(P3 分数阶记忆编码器是核心方法贡献;P4 可信开环历史感知规划是被解锁的新能力),P1/P2 作动机与证据(引 Wang 2024、Chen 2025、Cho 2024 为"我们证实的现象",不宣称首创),P5 作硬件 demo。三个"首次"级实证(全身速率/循环加载定量评估、NDI mm 真值自模型、免标定 2D 骨架 state)叠加成护城河。**

## 四、诚实边界(写论文/做实验前必须面对)

1. **z 懒惰是硬伤**:方向 17 已测 z 范数≈0.0016、per-window 重置 → z 是 cond 的函数,不是真记忆。**不要**把"可学习迟滞潜变量 z"当卖点;记忆机制应挂在 **动作历史窗口 + 分数阶 GL 核**(确实携带历史)上。要么修 z(序列级训练,方向 17 §5 风险 1),要么弱化 z 声称。
2. **单构型**:1-DOF 两段硅胶、单序列、10214 帧。**不声称泛化**(那是 Koopman/NJF 的)。声称的是"在动态/循环加载下,记忆自模型比无记忆自模型在该臂上更忠实"。
3. **未上真机闭环**:所有控制结论是模型内验证;规划动作未在真机执行过。P2 重采重训 + 真机执行是论文的验收里程碑。
4. **P3 的物理接地需要实证**:GL 幂律核是否真比调好的整数阶 GRU/TCN 更好,必须头对头测(含速率泛化);否则"物理接地"被当 story-telling。
5. **"首次"类声称要谨慎**:搜索有覆盖率限制;"全身速率定量评估首次"应在投稿前再核一遍近期 RA-L/IROS/CoRL 归档。
