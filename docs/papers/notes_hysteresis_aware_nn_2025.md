# 阅读笔记：Hysteresis-Aware Neural Network for Soft Robot Proprioception

> arXiv: 2504.13582, 2025

## 一句话概括

针对软体机器人中**方向依赖的迟滞效应**（相同压力在充气/放气过程中产生不同的末端执行器位置），提出专门设计的神经网络架构来建模迟滞行为，偏差可达机器人总长度的 3.4%。

---

## 核心问题

软体机器人的本体感知 (proprioception) 面临一个根本性挑战：**迟滞 (hysteresis)**。

同一驱动输入（如气压），通过充气（pressurization）或放气（depressurization）到达时，末端执行器位置不同。这种方向依赖性源于：

1. **粘弹性 (viscoelasticity)**：材料的应力-应变关系与加载历史有关
2. **缆绳摩擦 (cable friction)**：驱动传输链路的库仑摩擦
3. **肌腱伸长 (tendon elongation)**：驱动肌腱在反复加载后的永久变形
4. **材料非线性 (material nonlinearity)**：硅胶/聚合物的超弹性行为

前馈网络 (feedforward network) 本质上无法捕捉这些效应——因为它们将输入映射为单一输出，而迟滞的本质是**同一输入对应多个输出**（取决于历史路径）。

## 方法架构

### 迟滞建模的网络设计

核心思路：网络不仅要接收当前驱动输入，还需要某种形式的**历史状态编码**：

- **LSTM / GRU**：通过隐藏状态 (hidden state) 携带时序信息，天然适合建模路径依赖
- **TCN (Temporal Convolutional Network)**：因果膨胀卷积，用固定长度的历史窗口编码上下文
- 关键挑战：在**闭环控制**中，隐藏状态的初始化和维护需要特别处理——不能简单复用开环训练的状态

### 方法特点

- 明确区分**前馈方法**与**时序方法**在迟滞建模上的能力差异
- 量化迟滞程度：偏差达到机器人总长度的 3.4%（这是一个显著的工程问题）
- 探讨了在闭环控制场景下如何处理 RNN 隐藏状态的策略

## 关键创新

1. **问题定量化**：将迟滞从定性现象量化为具体的误差指标（3.4% 总长度），为后续研究建立了基准
2. **架构针对性**：不是通用网络设计，而是针对迟滞这一物理现象的专用架构
3. **时序模型的闭环考量**：指出 LSTM/GRU 在闭环控制中的隐藏状态管理问题，这是从实验室到实际部署的关键gap

### 关键启发

1. **互补的研究视角**：
   - 本文问的是"如何用网络拟合迟滞"——工程问题
   - 我们的方向 02（[粘弹性迟滞的信息容量](../directions/02_hysteresis_information_capacity.md)）问的是"迟滞编码了多少信息"——科学问题
   - 两者互补：先知道有多少信息（我们的先验实验），再决定用多复杂的网络去建模

2. **迟滞的物理来源验证**：
   - 本文列出的四个来源（粘弹性、摩擦、肌腱伸长、材料非线性）与我们的 PyElastica Cosserat 杆模型高度相关
   - PyElastica 的阻尼模型部分捕捉了粘弹性效应
   - 3.4% 总长度的偏差量级为我们设计实验提供了参考

3. **时序编码器选择的验证**：
   - 本文确认 TCN 和 GRU 对迟滞建模有效
   - 我们的 TemporalTCN 和 TemporalGRU 编码器（`src/encoders/`）设计方向正确
   - 但我们的 MultiScaleEMA 可能更有优势：多尺度结构天然对应迟滞的多时间常数

4. **闭环控制的隐藏状态问题**：
   - 本文指出 RNN 在闭环控制中的隐藏状态管理是个未解决问题
   - 这与我们的方向 01（[自回归状态动力学](../directions/01_autoregressive_state_dynamics.md)）中的假设二（状态转移）直接相关
   - 如果能从形状推断隐状态（自回归），就能绕过 RNN 隐藏状态的初始化问题

## 局限

1. **数据需求大**：依赖大量训练数据来拟合迟滞行为，数据效率低
2. **时序建模深度有限**：未探讨长程依赖（如蠕变效应持续数分钟到数小时）
3. **仅关注末端执行器**：不涉及 3D 全身形状，无法捕捉中间段的迟滞差异
4. **仿真-实物差距**：在真实机器人上验证，但未讨论不同材料/几何参数的泛化性
5. **缺乏理论分析**：没有从动力学系统角度分析迟滞的可建模性上限
