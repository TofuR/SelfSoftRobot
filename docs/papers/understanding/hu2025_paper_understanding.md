# Teaching Robots to Build Simulations of Themselves — 论文与代码理解

> 论文：Hu et al., "Teaching robots to build simulations of themselves," 2025
> 核心思想：让机器人通过自我观察（相机图像）学习一个**隐式神经仿真器**，无需 CAD 模型或物理先验。
> 原始代码仓库：https://github.com/H-Y-H-Y-H/SelfSimRobot

---

## 1. 问题定义

给定一个未知形态的机器人，仅通过一个固定（或少量）视角的相机观察其运动：

- **输入**：关节控制指令（归一化角度）
- **输出**：机器人运动后从相机视角看到的**灰度图像**
- **目标**：学习一个从"控制指令 → 外观图像"的映射，即机器人自身的**自仿真模型**

该方法不依赖机器人的 CAD 模型、运动学参数或物理属性，完全数据驱动。

---

## 2. 方法概述：Forward-Body-View Self-Model (FBV-SM)

### 2.1 核心类比：NeRF → 机器人自仿真

论文将问题重新构造为一个类似 NeRF（Neural Radiance Fields）的问题：

| NeRF | FBV-SM |
|------|--------|
| 输入：3D 坐标 + 视角方向 | 输入：3D 坐标 + **关节控制指令** |
| 输出：颜色 + 密度 | 输出：**可见性 (visibility)** + **密度 (density)** |
| 渲染：体渲染 → 2D 图像 | 渲染：体渲染 → 2D 图像 |
| 训练信号：多视角真实照片 | 训练信号：不同关节角度下的相机照片 |

### 2.2 网络架构

代码中对应模型为 `FBV_SM`（[model.py](src/models/model.py)）：

```
输入: (xyz: 3D坐标, cmd: 关节角度) → 拼接后总维度 = (DOF-2) + 3

        ┌─────────────┐     ┌─────────────┐
xyz ──→ │ PosEncoder  │ ──→ │             │
        │ (位置编码)   │     │             │     ┌──────────┐
        └─────────────┘     │ FeedForward │ ──→ │ Output   │ → [visibility, density]
        ┌─────────────┐     │ (融合层)     │     │ (线性层) │
cmd ──→ │ CmdEncoder  │ ──→ │             │     └──────────┘
        │ (指令编码)   │     │             │
        └─────────────┘     └─────────────┘
```

**关键设计**：
1. **位置编码 (PositionalEncoder)**：将低维 3D 坐标和关节角度映射到高维频率空间，采用正弦-余弦编码（类似 NeRF 的做法），`n_freqs=10`，`log_space=True`
2. **分离编码器**：3D 坐标和关节指令使用独立的 MLP 编码器，再通过融合层拼接
3. **输出**：2 维向量 `[visibility, density]`，其中 density 的 bias 初始化为 -5.0（初始稀疏）
4. **隐层维度**：`d_filter=128`
5. **重要：前两个关节角度的几何处理**：`d_input = (DOF-2) + 3`，即对于一个 4-DOF 机械臂，只有后 2 个角度作为网络输入（cmd），前 2 个角度（θ, φ）通过旋转矩阵 `pts_trans_matrix()` 在几何层面处理坐标变换

### 2.3 坐标变换：几何先验与网络学习的分工

这是论文中一个关键而容易被忽略的设计：

- **前 2 个关节（θ, φ）**：控制机器人整体的偏航（yaw）和俯仰（pitch），通过 `pts_trans_matrix(θ, φ)` 构建一个 **Z-Y 旋转矩阵**，将相机坐标系中的 3D 点变换到世界坐标系
- **剩余关节**：控制机械臂的局部构型变化，作为网络的条件输入（cmd），由网络学习其对形状的影响
- **意义**：全局旋转是确定性的几何操作，不需要网络学习；网络只需学习局部变形，降低了学习难度

`pts_trans_matrix()` 定义在 `func.py` 中，本质是一个 4×4 齐次变换矩阵：

```
R = Rot_Z(θ) × Rot_Y(φ)
T = [[R, 0],
     [0, 1]]   (4×4)
```

### 2.4 体渲染管线

代码中对应 `func.py` 的 `model_forward()` 函数：

```
完整流程:
1. get_rays()          — 根据相机参数生成每个像素的射线 (ray origin + direction)
2. sample_stratified() — 沿每条射线均匀采样 n_samples=64 个 3D 点
3. 拼接剩余关节角度 → 送入 FBV_SM 网络查询每个点的 (visibility, density)
4. OM_rendering()      — 不透明度调制渲染:
   alpha = 1 - exp(-relu(density))
   pixel = Σ (alpha × visibility)
5. MSE Loss vs 真实图像 → 反向传播
```

**OM_rendering（不透明度调制渲染）**是论文的核心渲染方式：
- 密度 σ 经 ReLU + exp 变换得到不透明度 α
- 最终像素值 = 各采样点的 α × visibility 之和
- 这与标准 NeRF 的区别：不需要 RGB 颜色通道，只预测灰度可见性

## 3. 数据采集流程

### 3.1 仿真环境

代码中对应 `env.py`（`FBVSM_Env`）：

- 使用 **PyBullet** 物理引擎模拟机器人臂
- 支持 3 种不同的 4-DOF 机器人 URDF 模型（robot_ID = 1, 2, 3）
- 相机固定在世界坐标系中，距离机器人 `cam_dist=1.0`，FOV=42°
- 关节控制使用位置控制模式（`POSITION_CONTROL`）
- 包含自碰撞检测（`getContactPoints`）
- 相机沿 X 轴方向，通过 `forward_matrix()` 方法进行坐标系对齐

### 3.2 数据采集

代码中对应 `data_collection.py`：

1. 加载预定义的动作列表（`data/action/action_robot{id}.csv`）
2. 对每个关节配置执行仿真，等待收敛
3. 采集相机图像，经 `green_black()` 预处理（绿色背景 → 白色）
4. 图像反转（`1 - img/255`），保存为 `.npz` 文件
5. 数据内容：`images`, `angles`, `focal`

### 3.3 预处理

- 绿色背景检测并替换为白色（`predefined.py: green_black()`）
- 图像归一化并取反（机器人部分为暗色 → 高值）
- 相机射线按针孔模型生成，相机沿 X 轴方向

### 3.4 自碰撞过滤

`predefined.py` 中的 `self_collision_check()` 函数：
- 遍历所有可能的关节角度组合
- 使用 PyBullet 的碰撞检测排除自碰撞的构型
- 确保采集的训练数据都是物理可行的构型

## 4. 训练流程

代码中对应 `train.py`：

### 4.1 超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| DOF | 4 | 关节自由度 |
| d_input | (DOF-2)+3 = 5 | 网络输入维度（3D坐标 + 剩余2个角度） |
| select_data_amount | 10000 | 训练数据量（不同关节角度的图像） |
| n_samples | 64 | 每条射线采样点数 |
| d_filter | 128 | 网络隐层维度 |
| lr | 5e-4 | 学习率 |
| n_iters | 400000 | 最大迭代次数 |
| center_crop | True | 前 200 迭代裁剪图像中心 50% |
| training ratio | 0.8 | 训练/验证划分 |

### 4.2 训练循环

```
for each iteration:
    1. 随机选择一张训练图像及其对应关节角度
    2. (可选) 中心裁剪（前 200 次迭代）
    3. 生成射线 → 采样点 → 查询网络 → 体渲染 → 预测图像
    4. MSE Loss 反向传播更新参数
    5. 每 1000 步验证，保存最佳模型
    6. ReduceLROnPlateau 调度 + 早停 (patience=100)
    7. 支持训练重启（loss 停滞时自动重启）
```

### 4.3 训练策略

- **中心裁剪热身**：前 200 次迭代只使用图像中心 50%，降低初始学习难度
- **单图像随机采样**：每次迭代随机选一张图训练，类似 NeRF 的策略
- **分块推理**（`prepare_chunks`）：将大量射线查询分块避免显存溢出

## 5. 3D 占据点云提取

代码中对应原始仓库的 `test_model.py`。

### 5.1 query_models()

给定关节角度，提取机器人的 3D 占据点云：

```
流程:
1. 在 3D 空间中均匀采样查询点
2. 拼接剩余关节角度 → 送入 FBV_SM 得到 (visibility, density)
3. 通过阈值过滤：visibility > 0.08 的点被视为占据
4. 通过 pts_trans_matrix(θ, φ) 将相机空间坐标变换到世界坐标
```

### 5.2 query_models_separated_outputs()

返回分离的密度和可见性点云：
- 密度阈值：`density > 0.4`
- 可见性阈值：`visibility > 0.25`

### 5.3 端点位置估计

当 `mean_ee=True` 时，函数返回可见性加权的质心坐标，作为端点（end-effector）的位置估计：

```
ee_pos = Σ (visibility_i × xyz_i) / Σ (visibility_i)
```

## 6. 运动规划

代码中对应原始仓库的 `visualize_bullet.py`。论文利用学到的自仿真模型进行多种运动规划任务。

### 6.1 梯度优化到达目标位置

`go_to_target_pos()` 函数：

```
目标：给定 3D 目标位置，找到使端点到达该位置的关节角度

方法：
1. 初始化关节角度
2. 循环：
   a. 用 query_models() 查询当前角度下的端点位置
   b. 计算端点位置与目标的距离损失
   c. 使用 Adam 优化器对关节角度求梯度并更新
3. 收敛后返回最优关节角度
```

### 6.2 无碰撞轨迹规划

`collision_free_planning()` 函数：

```
目标：从起始构型到目标构型的无碰撞轨迹

损失函数 = 距离损失 + 碰撞损失 + 效率损失 + 平滑损失
- 距离损失：端点与目标距离
- 碰撞损失：检测占据点云是否与障碍物重叠（AABB 包围盒检测）
- 效率损失：鼓励更短的轨迹
- 平滑损失：相邻关节角度变化量的惩罚

使用 Adam 优化整个轨迹的关节角度序列
```

### 6.3 A* 搜索

`A_star_search()` 函数：

```
在关节角度空间中使用 A* 搜索：
- 节点：离散化的关节角度构型
- 边：相邻构型之间的转移
- 启发函数：使用自仿真模型预测的端点位置到目标的距离
- 碰撞检测：使用自仿真模型的占据点云检测与障碍物的碰撞
```

### 6.4 RRT 路径规划

`rrt()` 函数：

```
快速随机树搜索：
1. 从起始构型开始，随机采样关节空间
2. 向最近的树节点扩展
3. 碰撞检测使用自仿真模型
4. 到达目标区域后连接路径

配合 shortcut_path() 进行路径平滑，去除不必要的绕行
```

### 6.5 双模型策略

运动规划中同时使用两个模型：
- **全身模型（arm model）**：用于碰撞检测，预测完整机器人的占据点云
- **端点模型（ee model）**：用于端点定位，只关注端点区域

## 8. 关键洞察总结

1. **NeRF 范式的创造性迁移**：将 NeRF 的"从视角合成图像"转化为"从关节角度合成机器人外观"，视角被关节控制指令替代
2. **几何先验与网络学习的分工**：前两个关节角度通过旋转矩阵进行确定性坐标变换，其余角度由网络学习，降低了学习难度
3. **极少的训练数据**：仅需约 10000 张不同关节配置下的图像即可训练，因为 3D 结构先验（体渲染）提供了强约束
4. **隐式 3D 表示**：网络实际上学习了机器人的隐式 3D 形状表示，不同关节角度对应不同的变形
5. **物理可行性过滤**：通过 PyBullet 碰撞检测确保采集的数据都是物理可行的构型
6. **从自仿真到运动规划**：学到的自仿真模型可以直接用于梯度优化、A*、RRT 等运动规划方法，展示了自模型的实用价值
7. **坐标系约定**：PyBullet 中相机沿 X 轴，通过旋转矩阵与标准 NeRF 坐标系对齐；机械臂基座位于 `[0, 0, -0.108]`

## 9. 深入讨论笔记

> 以下为阅读论文过程中的深入分析与讨论记录。

### 9.1 NeRF 范式的创造性迁移

FBV-SM 的核心创新在于发现 NeRF 与机器人自建模之间的**数学同构**：

| NeRF | FBV-SM (自建模) |
|------|----------------|
| 输入：3D 坐标 (x,y,z) + 视角方向 (θ,φ) | 输入：3D 坐标 (x,y,z) + **关节角度** |
| 输出：颜色 (RGB) + 密度 (σ) | 输出：**可见性 (vis)** + **密度 (dens)** |
| 训练：多视角照片 | 训练：不同关节角度下的照片 |
| 推理：新视角图像 | 推理：新关节配置下的外观 |

**为什么这个迁移能运作**：
- NeRF 中，视角方向决定了"从哪个角度观察 3D 场景"
- 自建模中，关节角度决定了"机器人以什么姿态出现"
- 两者都是**条件化输入**，控制 3D 场景/机器人以不同状态呈现
- 体渲染的可微性使得从 2D 图像监督反传到 3D 表示成为可能
- 多视角/多姿态的一致性约束迫使网络学习正确的 3D 结构

### 9.2 位置编码（Positional Encoding）的作用

**问题**：为什么 3D 坐标和关节角度都需要位置编码？直接用原始值不行吗？

**MLP 的频谱偏差（Spectral Bias）**：
- 标准 MLP（ReLU 激活）天然偏向学习低频函数（平滑变化）
- 但机器人的表面是高频信号——在边界处密度从 0 突变到高值
- 没有位置编码，MLP 只能学到模糊的、过平滑的形状

**位置编码的解决方式**：
```
PE(x) = [x, sin(2⁰x), cos(2⁰x), sin(2¹x), cos(2¹x), ..., sin(2¹⁰x), cos(2¹⁰x)]
```
- 将低维输入映射到多个频率的正弦-余弦空间
- 低频分量（2⁰, 2¹）捕捉全局结构
- 高频分量（2⁹, 2¹⁰）捕捉精细边界
- MLP 在这个高维空间中更容易拟合高频变化

**FBV-SM 中的具体设置**：
- 3D 坐标编码：n_freqs=10，log_space=True → 63 维
- 关节角度编码：n_freqs=10，log_space=True → (DOF-2)×21 维
- log_space 意味着频率指数增长，覆盖从极粗到极细的尺度

### 9.3 点云提取的两种阈值策略

FBV-SM 提供了两种 3D 点云提取方法，用途不同：

**方法 1 — `query_models()`（简单提取）**：
- 阈值：`visibility > 0.08`
- 返回一个统一的占据点云
- 用途：快速获取机器人 3D 形状，用于端点位置估计

**方法 2 — `query_models_separated_outputs()`（分离提取）**：
- 密度阈值：`density > 0.4`
- 可见性阈值：`visibility > 0.25`
- 分别返回密度点云和可见性点云
- 用途：分析密度分布和可见性分布的差异

**两个阈值是"或"还是"并"的关系**：
- 在方法 2 中，`density > 0.4` 和 `visibility > 0.25` 是**两组独立的过滤条件**
- 它们产生**两个独立的点云**，分别用于不同的分析目的
- 不是并集或交集，而是**两种不同的视角**看同一个输出
- 理想情况下，高密度区域和高可见性区域应该高度重叠（都是机器人所在位置）

**端点位置估计**：
- 当 `mean_ee=True` 时，使用可见性加权质心：
  ```
  ee_pos = Σ (visibility_i × xyz_i) / Σ (visibility_i)
  ```
- 可见性越高的点权重越大，质心偏向机器人最可见的部分（通常是端点）
