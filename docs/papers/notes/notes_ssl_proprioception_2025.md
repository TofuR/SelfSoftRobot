# 阅读笔记：Self-Supervised Learning for Soft Robot Proprioception

> Hu, Dong, Giorgio-Serchi, Yang — IEEE TNNLS, 2025
> University of Edinburgh / Zhejiang University

## 一句话概括

提出 **Capacitance Masked Autoencoder (CMAE)** 自监督预训练方法，利用大量无标注电容传感数据做预训练，仅需 **100 个标注样本**（全监督需要 2000 个）即可实现高分辨率 3D 形态重建，大幅降低软体机器人本体感知的数据标注负担。

---

## 核心问题

软体机器人本体感知 (proprioception) 的学习方法依赖大量标注数据（3D 形状 ground truth），但获取精确 3D 标注成本极高：

- 传统全监督方法需要 ~2000 个带 3D GT 标注的样本
- 软体机器人的 3D 形状测量需要运动捕捉系统或 RGB-D 传感器阵列
- 数据采集和标注成为方法落地的瓶颈

**核心问题**：如何减少对标注数据的依赖，同时保持高精度的 3D 形态重建能力？

## 方法架构

### Capacitance Masked Autoencoder (CMAE)

基于 MAE (Masked Autoencoder) 范式，适配电容传感器阵列数据：

```
原始电容传感矩阵 → 随机 Mask 部分传感单元 → Encoder 编码可见部分 → Decoder 重建完整矩阵

预训练阶段：仅使用无标注的电容传感数据，自监督重建任务
微调阶段：少量标注数据（100 samples）微调下游 3D 形态重建头
```

### 两阶段训练

1. **自监督预训练 (SSL Pretraining)**：
   - 输入：电容传感器阵列的空间分布矩阵
   - 任务：Masked reconstruction（随机遮蔽部分传感单元，重建完整矩阵）
   - 数据：大量无标注的传感数据（采集成本低）
   - 目的：学习电容信号的空间相关性和形态先验

2. **有监督微调 (Supervised Fine-tuning)**：
   - 在预训练编码器基础上添加 3D 形态重建头
   - 仅需 100 个带 3D GT 的标注样本
   - 标注效率：100/2000 = 1/20 的标注量

## 关键创新

1. **CMAE 自监督预训练**：首次将 MAE 范式引入软体机器人传感领域，利用传感数据的空间结构做自监督学习
2. **20x 标注效率提升**：从 2000 个标注样本降至 100 个，性能与全监督方法可比
3. **高分辨率 3D 形态重建**：从电容传感信号实现密集的 3D 形状恢复，而非稀疏的关节角度估计
4. **传感器-形态映射的隐式学习**：通过预训练捕获电容信号与机器人形态之间的复杂映射关系

## 与本项目的关联

| 维度 | Hu 2025 (CMAE) | SelfSoftRobot (本项目) |
|------|-----------------|----------------------|
| **传感模态** | 电容传感器阵列（本体嵌入） | 视觉（外部相机观察） |
| **监督信号** | 自监督（传感重建）+ 少量 3D GT | 体渲染自监督（2D 图像重建） |
| **数据效率策略** | SSL 预训练减少标注需求 | 体渲染隐式监督避免 3D GT |
| **输出** | 3D 形态重建 | 3D 密度场 / SDF / 点云 |
| **迟滞处理** | 未涉及 | MultiScaleEMA 时序编码 |
| **机器人类型** | 真实软体机器人 | PyElastica 仿真 Cosserat 杆 |

### 关键启发

1. **数据效率的两种路径**：
   - CMAE 路径：大量无标注数据预训练 + 少量标注微调
   - 本项目路径：体渲染提供自监督训练信号，推理时不需要 3D GT
   - 两种路径正交互补——理论上可以组合使用

2. **传感模态的互补性**：
   - 电容传感提供本体感知（触觉/形变），视觉提供外部感知（全局形状）
   - 多模态融合（电容 + 视觉）是潜在的提升方向

3. **自监督范式的参考价值**：
   - MAE 的 mask-reconstruct 范式可以迁移到本项目
   - 例如：在体渲染训练中随机 mask 部分射线/像素，迫使模型学习更鲁棒的 3D 表示
   - 或者对动作历史做 mask，增强时序编码器的泛化能力

## 局限

1. **依赖特定传感器硬件**：需要电容传感器阵列嵌入软体机器人，硬件实现成本和复杂度高
2. **泛化性未验证**：未测试跨机器人形态（不同尺寸、材料）的泛化能力
3. **无时序建模**：不考虑粘弹性迟滞、蠕变等时间相关的软体行为
4. **静态形状重建**：仅重建瞬时形状，未涉及动态运动过程中的连续形状预测
5. **与视觉方法的对比缺失**：未与基于视觉的本体感知方法进行系统对比
