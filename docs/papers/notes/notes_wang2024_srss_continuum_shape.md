# 阅读笔记：Shape Reconstruction of Extensible Continuum Manipulator Based on Soft Sensors

> Pengyuan Wang, Yaqing Feng, Zheng Zheng, Zhiguang Xing, Jianwen Zhao — Soft Robotics (Mary Ann Liebert), 2024
> 链接: https://doi.org/10.1089/soro.2023.0094
> arXiv: 无

## 一句话概括
用沿可伸缩连续体臂分布的硅胶橡胶应变传感器(SRSS)在少量离散点测应变，再通过显式本体感觉模型积分重建整臂形状，实现端点平均位置误差仅臂长 1.61%。

## 核心问题 / 动机
- 可伸缩连续体臂在受限环境中有空间适应性与操作灵活性优势，但要量化其形状才能强化避障能力与端点位置精度。
- 已有形状感知手段(FBG光纤、电磁/永磁传感、缆绳长度电感编码等)大多给出离散点信息或依赖外部追踪，难以低成本、本体式地获得整臂连续形状。
- 需要一种能与软体本体共形集成、且能处理扭转(压缩引起的扭转变形)的本体感觉重建方法。

## 方法
- **传感模态**: 硅胶橡胶应变传感器(SRSS)，通过卷绕工艺把平面硅胶传感器做成细长圆柱结构，可共形贴附在可形变本体上。
- **布置**: 物理样机为三根驱动腱驱动的可伸缩连续体臂，沿臂体布置 **9 个 SRSS** 在特定位置测应变。
- **重建模型**: 建立 SRSS 应变 ↔ 臂体形变之间的本体感觉(proprioceptive)模型，显式考虑压缩引起的扭转现象，再"积分所有传感器信息"重建整臂形状(显式模型，非数据驱动端到端)。
- **评测**: 多种运动轨迹下评估，并特别考察端点带载(end-effector loads)工况。

## 主要结果
- 多轨迹实验表明该方法能较准确地重建臂形，**端点带载下尤其有效**。
- 端点平均(最大)绝对位置误差为臂长的 **1.61% (3.45%)**(据摘要)。

## 与本项目的关系
- **关联主题**: soft-strain-sensor 形态感知、连续体臂形状重建、本体感觉模型、离散点 → 形状积分
- **可借鉴 / 差异**:
  - 可借鉴: 该工作把"为何需要整臂形状"(避障 A2、带载端点精度 A3)讲得很清楚，与我们动机高度一致;9 点离散应变 + 显式模型积分的范式，是典型的"显式两阶段(传感→模型)"路线，正好反衬我们端到端数据驱动自建模的价值。
  - 差异/我们更优: 他们依赖显式本体感觉模型与精确物理(扭转)建模，且形状只在 9 个离散传感点处可靠——这正是 A4 的离散点局限;一旦臂体损伤或材料参数变化，显式模型失效(A6)，而我们的神经场 + 免标定 2D 管线不依赖先验 CAD/物理参数。此外他们未触及粘弹性迟滞(A7/A8)，仅做准静态多轨迹重建。
- **支撑哪句论述**: 主要支撑 **A4**(现有方法只能得离散点、不能完整连续形态建模——9 个 SRSS 点 + 显式积分正是离散点方法的典型代表);同时支撑 **A2/A3**(论文自述目标是避障与带载端点精度，论证仅尖端不够、需整臂形状);并侧面支撑 **A6**(显式物理模型依赖先验参数，损伤/变形后失效)。
