# 阅读笔记：On Prandtl–Ishlinskii Hysteresis Modeling of a Loaded Pneumatic Artificial Muscle

> Mohammad Al Saaideh, Mohammad Al Janaideh — ASME Letters in Dynamic Systems and Control, 2022
> 链接: https://doi.org/10.1115/1.4054779
> arXiv: 无

## 一句话概括
提出一个"负载依赖"的 Prandtl–Ishlinskii(LDPI)算子模型,用负载依赖的权函数刻画气动人工肌肉(PAM)在 不同负载力 下测得的不对称迟滞回线;验证该模型能同时表征迟滞的 不对称性 与 负载效应。

## 核心问题 / 动机
- PAM 在高精度机电应用中作驱动时,其迟滞非线性是影响精度的核心瓶颈。
- 现象学迟滞建模(经典 PI 算子)只能刻画对称回线,无法同时描述 PAM 实测回线的 **不对称性** 与 **随外负载力漂移** 这一耦合行为。
- 本文目标:用一个统一的负载依赖算子,把"负载力 → 回线形状/位移漂移"这一关系显式建出来。

## 方法
据摘要:
- **LDPI(Load-Dependent Prandtl–Ishlinskii)模型**:在经典 PI 玩具算子(play operator)叠加结构上,把权函数(weight function)设为负载力的函数,使回线形状随负载变化。
- 实验获取不同负载力下 PAM 的迟滞回线,据此标定 LDPI 的负载依赖权函数。
- 将模型估计回线与实测回线逐负载对比,评估对 不对称性 + 负载漂移 的表征能力。

## 主要结果
据摘要:
- LDPI 能在多种负载力下重现实测迟滞回线,同时刻画 **不对称(asymmetric)** 与 **负载力效应(load force effects)**。

## 与本项目的关系
- **关联主题**: soft-actuator hysteresis; phenomenological operator modeling (P-I); load-dependent nonlinearity; 自建模 vs. 显式迟滞建模
- **可借鉴 / 差异**:
  - 这是"为单驱动器建一个专用的、显式的迟滞算子"的典型路线 —— 把迟滞作为 PAM 自身的材料/驱动特性,用现象学算子(PI/Preisach 类)显式参数化,且必须 **逐负载** 标定。
  - 与本项目(神经场 3D 自建模 + 免标定 2D 形态 + 迟滞状态转移)的差异:LDPI 只刻画 **单驱动器的力-位移迟滞**,不涉及全身连续体形态、不做形态自建模、也不与运动学/形状估计耦合;而本项目的迟滞是 **整臂加载-卸载形态迟滞回线**(exp5b 仿真对照、实物加载-卸载),由数据驱动状态转移网络隐式吸收,无需显式 PI 算子或逐负载标定。
  - 可作为"专用迟滞算子文献存在、但与全身形态自建模解耦"这一空白的佐证:迟滞被研究得很充分,但几乎都在 **驱动器层级**,而全身形态估计文献很少把这种负载依赖迟滞纳入。
- **支撑哪句论述**:
  - **A8** —— 经典自/运动学建模(含显式 PI 算子这类)把迟滞当作驱动器级现象独立处理,不与整臂形态自建模联合,高速/变载下形态估计难准确;本文正是"迟滞与形态解耦"现状的一个具体例子。
  - **A7**(辅助)—— 本项目端到端数据驱动可隐式捕获粘弹性迟滞,作为对这类显式负载依赖算子建模路线的对比/替代。
