# 阅读笔记：Learning Soft Robotic Dynamics with Active Exploration (SoftAE)

> Hehui Zheng, Bhavya Sukhija, Chenhao Li, Klemens Iten, Andreas Krause, Robert K. Katzschmann — arXiv preprint, 2025
> 链接: https://arxiv.org/abs/2510.27428
> arXiv: 2510.27428

## 一句话概括
提出 SoftAE —— 一个基于不确定性感知(概率集成模型)的主动探索框架,让软体机器人自主采集数据以学到任务无关、可泛化的前向动力学模型,并在三款仿真平台 + 一台真实气动连续体臂上验证其优于随机探索与任务专用 MBRL。

## 核心问题 / 动机
软体机器人柔顺、高维、非线性的动力学使其难以建模用于控制;现有数据驱动方法往往因数据采集方式受限(任务专用演示或低效随机探索)而泛化性差。作者要解决的是"如何用更少人为任务监督、更高效地采集覆盖多样行为的数据,从而得到可复用的动力学模型"这一数据效率与泛化问题。

## 方法
(据摘要)
- **概率集成模型 (probabilistic ensemble)**:估计状态-动作空间中的认知不确定性 (epistemic uncertainty)。
- **主动探索 (active exploration)**:以不确定性为驱动,主动引导机器人探索欠表征区域,无需任务特定监督即可高效覆盖多样行为。
- **任务无关 / 可泛化**:目标是学到一个 task-agnostic、可迁移到未见任务的动力学模型,而非针对单一任务拟合。
- 评测平台:三个仿真平台(连续体臂、流体中铰接鱼、混合驱动的肌骨腿)+ 一个真实气动连续体软臂。

## 主要结果
(据摘要)
- 相比随机探索与任务专用 MBRL,SoftAE 得到更准确的动力学模型,并在未见任务上实现更优的零样本控制。
- 在传感噪声、驱动延迟、非线性材料效应等扰动下保持鲁棒。
- 跨多种软体形态(连续体 / 游动 / 肌骨 / 气动)展示可扩展、可复用的动力学模型。

## 与本项目的关系
- **关联主题**: data-driven self-modeling, forward dynamics, soft continuum arm, real-world pneumatic arm, generalization
- **可借鉴 / 差异**: 该工作代表当前 (2025) 软体机器人数据驱动动力学建模的前沿:仍以**集总式前向动力学模型** (state-action → next-state) 为目标,通过**主动探索 + 不确定性量化**提升数据效率与泛化,但**未将迟滞显式分解为独立状态变量** —— 它把"非线性材料效应/驱动延迟"当作鲁棒性测试的扰动源,而非在模型内部显式建模一个迟滞隐状态 z。这与本项目"把迟滞作为显式隐状态转移"的路线形成鲜明对比:本项目针对免标定 2D 管线下的加卸载迟滞回线,用状态转移显式捕获历史依赖;SoftAE 的概率集成则把这种历史依赖吸收进不确定性估计里。可借鉴:其不确定性量化思路可用于本项目 open-loop rollout 的误差传播与漂移估计。
- **支撑哪句论述**: **A8**。SoftAE 形态建模(动力学)效果好、泛化强,但未显式建模迟滞与高速运动下的历史依赖,只是把非线性材料效应作为鲁棒性扰动处理 —— 这正印证 A8 "一些自建模工作形态好但没考虑迟滞与高速运动",为"本项目显式迟滞隐状态 z"的创新性提供对照。同时也间接呼应 **A7**(数据驱动端到端自建模趋势)。
