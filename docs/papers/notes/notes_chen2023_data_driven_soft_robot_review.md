# 阅读笔记：Data-driven Methods Applied to Soft Robot Modeling and Control: A Review

> Zixi Chen, Federico Renda, Alexia Le Gall, Lorenzo Mocellin, Matteo Bernabei, Théo Dangel, Gastone Ciuti, Matteo Cianchetti, Cesare Stefanini — IEEE Transactions on Automation Science and Engineering (T-ASE), 2025（arXiv 2023-05-20 预印）
> 链接: https://arxiv.org/abs/2305.12137
> arXiv: 2305.12137 (v3); DOI: 10.1109/TASE.2024.3377291

## 一句话概括
一篇系统综述：先把软体机器人建模/控制的数据驱动方法放在"**物理模型 vs. Jacobian 矩阵**"两类基础之上，再按"**统计方法 / 神经网络 / 强化学习**"三大类梳理各自的模型动力学、数据需求与目标任务，并讨论各自优劣与未来方向。

## 核心问题 / 动机
软体机器人本征柔顺、具无限自由度，可用于手术、康复、仿生、非结构环境探索与工业夹持；但材料的**非线性与迟滞效应**给建模带来沉重负担，且柔顺性使控制比刚体机器人更难。作者试图给"用数据驱动方法建模和控制软体机器人"这一散乱领域提供一个**统一的分类坐标系**：从两大基础（物理模型、Jacobian）出发，比较三大类数据驱动方法在建模与控制上的特征差异，并指出各自的局限与未来走向。配套网站 (sites.google.com/view/23zcb) 持续更新。

## 方法
（据摘要，未读全文）
- **两大基础 (foundations)**：
  1. **物理模型 (physical models)** —— 解析/Cosserat-rod/常曲率等先验物理模型，作为数据驱动方法的对照与先验来源。
  2. **Jacobian 矩阵** —— 把驱动输入到末端/形态的映射用雅可比表示，作为数据驱动校正的对象。
- **三大类数据驱动方法**：
  1. **统计方法 (statistical method)** —— 如高斯过程回归等。
  2. **神经网络 (neural network)** —— 含前馈/RNN 等。
  3. **强化学习 (reinforcement learning)** —— 端到端学习控制策略。
- **比较维度**：在各类内与各类间比较 *model dynamics / data requirement / target task*，最后汇总各方法特征并预测数据驱动方法在软体机器人中的未来。

## 主要结果
（据摘要，综述类无单一定量结果）
- 提出了一个被广泛引用的**二基础 × 三方法**分类框架，明确刻画了"物理先验"与"数据驱动"的分野。
- 指出软体机器人建模的核心障碍是**非线性 + 迟滞**，传统物理模型参数依赖强、损伤/变形后失效；数据驱动方法可绕过精确物理参数但需大量数据。
- 讨论了各方法在**模型动力学刻画、数据需求、目标任务**上的优劣，并给出未来方向（含 sim-to-real、样本效率、安全等开放挑战）。

## 与本项目的关系
- **关联主题**: data-driven soft robot modeling survey; physical-prior vs. data-driven dichotomy; hysteresis; Jacobian-based modeling; neural network / RL control
- **可借鉴 / 差异**:
  - **可借鉴**：(1) 本文是"**解析先验（物理模型）vs. 数据驱动**"二分法的标准出处，正是我们项目 (A6→A7) 立论的坐标系——可作综述级引用锚点；(2) 它把"非线性 + 迟滞"显式列为软体建模的一阶障碍，与我们神经场自建模 + 迟滞状态转移的主张一致；(3) 其"物理模型基础"一节可直接对照我们想回避的先验参数依赖问题。
  - **差异/我们如何不同**：(1) 本文是综述，提供分类与动机，不提出新模型；我们做的是具体的端到端神经场自建模 + 免标定 2D 管线。(2) 本文的三分法（统计/NN/RL）侧重**建模 vs. 控制**的任务划分，而我们的切入是**全身形态估计 + 隐式迟滞**这一更窄但更深的子问题。(3) 本文未专门讨论"视觉/图像 + 自建模做全身形态"的免标定路线（A10），我们在此补足。
- **支撑哪句论述**:
  - **A6**（传统建模需先验 CAD/精确物理参数，损伤后失效）——本文"物理模型基础"一节正是该论点的综述级来源。
  - **A7**（数据驱动端到端联合训练避免先验依赖 + 误差累积，隐式捕获粘弹性迟滞）——本文的二分法直接支撑"数据驱动是绕开先验参数依赖的路线"的定位，是 A7 立论的框架性引用。
  - **A5**（形态学与运动学两阶段串联误差累积）——本文对"建模"与"控制"分开讨论的传统范式，间接印证两阶段分离的常见做法，可作为我们要超越的范式背景。
