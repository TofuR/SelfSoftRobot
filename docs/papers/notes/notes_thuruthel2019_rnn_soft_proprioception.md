# 阅读笔记：Soft robot perception using embedded soft sensors and recurrent neural networks

> Thomas George Thuruthel, Benjamin Shih, Cecilia Laschi, Michael T. Tolley — Science Robotics, 2019 (Vol. 4, Issue 26, eaav1488)
> 链接: https://www.science.org/doi/10.1126/scirobotics.aav1488
> arXiv: 无

## 一句话概括
受人类感知系统启发,在软体气动致动器体内嵌入冗余、无结构排布的软电阻应变传感器(cPDMS),并用一个通用机器学习(循环神经网络)方法从这些非线性、时变、带漂移的传感器读数中实时学习软致动器的前向模型,从而同时实现自身运动学感知(全身形变)与外加作用力估计,无需解析模型。

## 核心问题 / 动机
- 传统刚性固态传感器无法捕捉软系统高维形变;嵌入式软应变传感器虽能贴体测量,但其本身及所包裹的动力学系统都呈现非线性、时变、迟滞与蠕变(creep),难以用解析方法建模。
- 此外,传感器的设计、布局、制造往往依赖大量人工与先验知识(类型/数量/位置的选择都需要已知模型)。
- 动机:摆脱对精确解析模型与精细传感器布局的依赖,用一个数据驱动的"合成感知系统"端到端地建模未知软致动器(据摘要 + 引言)。

## 方法
- 传感器:多层 PDMS 浸渍碳纳米管(cPDMS)制成的软电阻应变传感器,刻意采用"冗余且无结构(redundant and unstructured)"的拓扑,散布于软致动器体内——即放弃精确定位,转而用数量与机器学习弥补。
- 真值:用基于视觉的动作捕捉系统提供运动学真值。
- 模型:通用机器学习方法,用循环神经网络(标题中的 recurrent neural networks)从传感器历史读数(及动作)映射到致动器位形;利用循环结构的记忆能力建模传感器与软体系统的时变/迟滞行为。
- 验证维度:(i) 实时运动学建模(全身形变);(ii) 与外部物体交互时的作用力估计;(iii) "动作在感知中的作用"(据摘要与引言)。

## 主要结果
- 据摘要:所提方法能在实时对软连续体致动器的运动学建模,同时对传感器非线性与漂移具有鲁棒性。
- 据摘要:同一套系统在交互时还能估计外加作用力。
- 注:全文为付费,以上结果来自摘要;具体定量误差数值、baseline 对比、RNN 架构细节(LSTM/GRU 等)未在公开摘要/引言中给出。

## 与本项目的关系
- **关联主题**: data-driven-self-modeling, hysteresis-modeling, recurrent-state-transition, proprioception, embedded-sensing, continuum-arm
- **可借鉴 / 差异**:
  - 强力先例:直接印证"用 RNN/循环网络作为软体机器人状态转移前向模型"的范式——与我们用 GRU/MultiScaleEMA 等时序编码器做 action→state 转移学习的思路同源。
  - 数据驱动端到端:不依赖 CAD/先验物理参数,隐式捕获软传感器与软体本体的非线性、迟滞、蠕变——正面支撑 A7 的"隐式捕获粘弹性迟滞"论断。
  - 关键差异:该工作用**体内嵌入式软应变传感器**(非视觉),真值靠外部动作捕捉;且目标是"以动作+传感器→位形"的前向感知,而非"以图像→全身形态"的自建模。我们走免标定 2D 视觉 + 神经场全身形态建模路线,与它的"嵌入式传感 + RNN 位形回归"互补而非重叠。
  - 该工作聚焦传感迟滞(传感器本身的非线性/蠕变),而我们的迟滞主要来自气动软体本体的加载-卸载力学迟滞——但"循环网络能捕获历史依赖"这一结论对两者都成立。
- **支撑哪句论述**: A7(数据驱动端到端联合训练、不依赖先验 CAD,并隐式捕获粘弹性迟滞——本文以嵌入式软传感器 + RNN 建模软致动器即典型实证)、A6(不依赖先验物理参数/解析模型即可建模未知软系统,损伤/变形下数据驱动更具鲁棒性)、A8(循环结构显式建模时变/迟滞,是处理高速与迟滞动态的方法学先例)。
