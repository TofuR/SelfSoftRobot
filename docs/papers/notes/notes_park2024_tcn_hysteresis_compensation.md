# 阅读笔记：Hysteresis Compensation of Flexible Continuum Manipulator Using RGBD Sensing and Temporal Convolutional Network

> Junhyun Park, S. C. Jang, Hyojae Park, Seongjun Bae, Minho Hwang — IEEE Robotics and Automation Letters (RA-L), 2024 (arXiv 预印本 2024-05-08)
> 链接: https://arxiv.org/abs/2402.11319
> arXiv: 2402.11319

## 一句话概括
针对微创手术中缆绳驱动的柔性连续体机械臂因摩擦/伸长/耦合产生的迟滞,采用数据驱动方法:用 RGBD 相机 + 7 个基准标记采集"指令关节角→实际关节角"的迟滞数据,训练 TCN(时序卷积网络)学习这一前向迟滞映射,并基于 TCN 构建补偿控制器逆向输出校准后的指令角,显著降低位置与姿态跟踪误差。

## 核心问题 / 动机
- 缆绳驱动柔性连续体机械臂(>1.5m 长 Bowden 缆绳)存在摩擦、扭转、伸长、间隙、多段耦合等非线性迟滞,导致控制精度差。
- 传统解析建模难以捕捉这种"依赖历史状态"的非线性迟滞,尤其在长且多段耦合的机械臂上更难。
- 目标:用数据驱动方法显式建模迟滞,进而补偿以提升任务空间跟踪精度(面向内窥镜手术如 ESD、缝合)。

## 方法
- 数据采集:RGBD 相机 + 7 个 3D 打印基准标记(fiducial markers)贴在机械臂钳子上,估计各关节物理位姿;采集"指令关节角 → 实际关节角"配对数据。
- 模型:对比 4 种 DNN(2 类方法、4 种架构、不同输入序列长度);TCN 在序列长度 80 时预测能力最强,被选为迟滞前向模型。
- 补偿控制:用训练好的 TCN 构建控制算法,给定期望关节角,输出校准后的指令关节角以抵消迟滞(据摘要)。
- 注意:用基准标记做关节角(离散点)的位姿估计,而非全身形态(shape)建模。

## 主要结果
- TCN 在 4 种 DNN 中估计能力最高(据摘要对比)。
- 在未见过的任务空间轨迹上,补偿控制器将平均位置误差降低 61.39%(13.7mm → 5.29mm),平均姿态误差降低 64.04%(31.17° → 11.21°)。
- 结论:该校准控制器能通过估计迟滞有效到达期望位姿。

## 与本项目的关系
- **关联主题**: data-driven-self-modeling, hysteresis-modeling, temporal-network, continuum-arm
- **可借鉴 / 差异**:
  - 共同点:同为数据驱动建模迟滞、同为连续体机械臂、都用时序模型(TCN vs 我们的 GRU/MultiScaleEMA)捕获历史依赖——这正面支撑"数据驱动可隐式捕获粘弹性迟滞"的论点。
  - 关键差异:该方法只做关节角/末端位姿(离散点)的迟滞补偿,**不做全身形态(shape)估计**;依赖外部 RGBD + 基准标记做位姿真值,**非免标定、非纯 2D 图像**;机械臂是缆绳驱动手术臂,而非气动软体臂。
  - 对本项目:A7/A8 的有力旁证——TCN 这类时序网络确实能从输入历史中学习迟滞;同时反衬我们"全身形态 + 免标定 2D"的定位与之互补。
- **支撑哪句论述**: A7(数据驱动端到端可隐式捕获粘弹性迟滞——TCN 学习缆绳迟滞即实证)、A1(该工作只做关节角/位姿迟滞补偿,不做全身形态估计,印证"大多数工作仅关注末端/关节而非全身形态")。
