# 阅读笔记：Koopman Embedding for Cross-Configuration Control of Soft Robots

> Zhang et al. — Nature Communications, 2026

## 一句话概括

通过学习**线性 Koopman 嵌入空间**来实现软体机器人的跨构型控制迁移，在共享的线性动力学表示中训练强化学习策略，实现 75 倍的样本效率提升，覆盖 33 种不同构型，并处理高速运动、重载和多执行器故障场景。

---

## 核心问题

软体机器人的强化学习控制面临一个根本困难：**每种新构型（morphology/configuration）都需要重新训练**。

软体机器人的构型变化多样：
- 不同的长度、直径、段数
- 不同的材料硬度
- 执行器故障（部分失效）
- 负载变化

传统方法为每种构型单独训练策略，样本效率极低。核心挑战是：**能否找到一个共享的表示空间，使得策略可以在不同构型之间迁移？**

## 方法架构

### Koopman 理论基础

Koopman 算子理论的核心洞察：**非线性动力学可以被提升 (lift) 到一个无穷维空间中变为线性的**。

```
原始空间：x_{t+1} = f(x_t, u_t)     — 非线性
提升空间：z_{t+1} = K · z_t           — 线性（K 是 Koopman 算子）
```

实践中学习有限维近似：
- 学习提升函数 φ: x → z（将状态映射到嵌入空间）
- 学习 Koopman 矩阵 K（线性动力学）
- 在线性空间中设计控制策略

### 方法流程

1. **Koopman 嵌入学习**：
   - 从多种构型的运动数据中学习共享的嵌入空间
   - 不同构型的状态被映射到同一线性空间
   - Koopman 矩阵 K 在嵌入空间中是通用的

2. **强化学习策略训练**：
   - 在 Koopman 嵌入空间中训练 RL 策略
   - 由于空间是线性的，策略学习更容易
   - 策略与具体构型解耦

3. **跨构型迁移**：
   - 新构型只需要学习其提升函数 φ
   - 控制策略直接复用，无需重新训练
   - 实现 75 倍的样本减少

### 关键能力

- **高速运动**：线性嵌入保证稳定性
- **重载**：嵌入空间捕获负载-动力学关系
- **多执行器故障**：故障构型被视为新构型，自动适应
- **33 种构型**：覆盖参数化变化族

## 关键创新

1. **Koopman 嵌入用于跨构型迁移**：首次将 Koopman 理论系统性地应用于软体机器人的构型泛化问题
2. **解耦策略与构型**：控制策略在构型无关的线性空间中定义，新构型仅需学习提升函数
3. **稳定性保证**：线性嵌入空间天然提供稳定性分析工具
4. **75x 样本效率**：显著的工程实用性提升
5. **故障容错**：执行器故障被自然地纳入跨构型框架，无需特殊处理

### 关键启发

1. **Koopman 理论与迟滞记忆的联系**：
   - 如果软体机器人动力学可以被线性嵌入（Koopman），那么迟滞的"记忆"可以通过 Koopman 算子的**谱 (spectrum)** 来分析
   - Koopman 算子的特征值对应系统的固有频率和衰减率
   - 这为方向 02（[粘弹性迟滞的信息容量](../directions/02_hysteresis_information_capacity.md)）提供了理论工具：记忆容量 = Koopman 谱中非零特征值的"有效维度"

2. **线性嵌入与状态空间框架**：
   - Koopman 嵌入将非线性动力学线性化
   - 我们的时序编码器（MultiScaleEMA 等）隐式地在学习某种"嵌入"
   - 如果这个嵌入接近 Koopman 的，那么 EMA 的衰减系数可能与 Koopman 特征值对应
   - 这可以解释为什么多尺度 EMA 有效：不同尺度对应 Koopman 谱的不同频率分量

3. **跨构型迁移与自建模**：
   - Koopman 方法的核心是找到构型无关的动力学表示
   - 我们的自建模关注的是"机器人学习自己的形状"
   - 两者可以结合：先自建模（学习当前构型的嵌入），再跨构型迁移
   - 这为方向 11（[sim-to-real transfer](../directions/11_sim_to_real_transfer.md)）提供了新的迁移思路

4. **控制是建模的下游任务**：
   - 本文从控制角度出发，使用动力学嵌入
   - 我们从感知/建模角度出发，学习形状预测
   - 完整的系统需要两者：先建模（理解身体），再控制（使用身体）
   - Koopman 嵌入可以作为建模和控制的统一框架

5. **稳定性保证的价值**：
   - 线性 Koopman 空间提供稳定性证明
   - 我们的 Neural Field 方法缺乏这种理论保证
   - 如果能将 Neural Field 的形状空间映射到 Koopman 空间，可能为形状预测的稳定性提供保证

## 局限

1. **嵌入学习需求**：仍需为每种新构型学习提升函数 φ，虽然样本需求大幅减少但非零
2. **特定软体机器人族**：在特定设计的软体机器人族上验证，泛化到其他类型（如气动、磁驱动）未验证
3. **控制导向，非感知导向**：关注控制策略迁移，不涉及形状估计或自建模
4. **有限维近似的误差**：实际 Koopman 算子是无穷维的，有限维近似引入的误差未充分讨论
5. **无 3D 全身形状**：与大多数软体机器人工作一样，未涉及全身 3D 形状重建
6. **Koopman 假设的适用性**：强迟滞系统（如我们的粘弹性 Cosserat 杆）的 Koopman 嵌入维度可能非常高，实际效果存疑
