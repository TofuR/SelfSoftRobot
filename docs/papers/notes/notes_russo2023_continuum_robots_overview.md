# 阅读笔记：Continuum Robots: An Overview

> Matteo Russo, Seyed Mohammad Hadi Sadati, Xin Dong, Abdelkhalick Mohammad, Ian D. Walker, Christos Bergeles, Kai Xu, Dragos A. Axinte — Advanced Intelligent Systems (Wiley), 2023, vol. 5, issue 5, 2200367
> 链接: https://advanced.onlinelibrary.wiley.com/doi/10.1002/aisy.202200367
> arXiv: 无

## 一句话概括
一篇权威的连续体机器人综述(Open Access),系统梳理其设计、建模与控制的最新进展、当前局限与开放挑战,覆盖恒曲率(CC)与 Cosserat 杆等经典建模框架及其在载荷/摩擦/损伤下的失效,是讨论"解析先验在真实大变形下失效"与"端到端学习自建模为何兴起"的核心支撑文献。

## 核心问题 / 动机
连续体机器人靠柔性骨架连续弯曲,可在狭窄蜿蜒环境中实现长臂可达,在医疗/工业/服务领域有刚性臂无法完成的任务。但随着研究爆发,设计/建模/控制方法鱼龙混杂,需要一篇统一综述来对比已有方案、指出尚未解决的开放问题。该综述旨在:(1) 全面盘点现有连续体机器人与新兴技术;(2) 对比建模与控制方法;(3) 分析连续体机器人独有的导航策略(follow-the-leader、coiling、circumnutation);(4) 概述应用并指出未来研究方向。

## 方法
据摘要与综述性质(非提出新方法):
- **建模方法对比**:涵盖运动学级的恒曲率(Constant Curvature, CC)模型、几何精确的 Cosserat 杆理论、以及有限元等力学模型;指出 CC 假设(每段为常曲率圆弧)在受外载荷、摩擦、重力下垂或损伤时会失效,Cosserat 虽能处理变曲率/载荷/摩擦但仍需精确物理参数识别且计算昂贵、接触建模常被简化。
- **控制与导航**:讨论连续体机器人特有的 follow-the-leader(整段跟随首段轨迹)、coiling(缠绕)、circumnutation(旋转环绕)等导航策略。
- **设计分类**:按致动方式(气动/液压内致动 vs 腱/杆/柔管外致动)与骨干类型分类。

## 主要结果
综述类文献,无单一数值结果。据摘要与综述范围:
- 系统对比了各类连续体机器人在医疗(如手术导管)、工业(如航空发动机内腔检测)、服务(如狭小空间作业)三类应用的能力边界。
- 明确指出建模与控制是当前最大瓶颈:经典解析模型(CC/Cosserat)依赖精确先验(CAD/材料参数),在载荷、摩擦、磨损或损伤下预设模型失效,而实时、准确、无需精确先验的全身形态估计仍是开放问题。

## 与本项目的关系
- **关联主题**: continuum-robot-survey, constant-curvature-limitation, cosserat-vs-learning, prior-dependent-modeling, whole-body-shape
- **可借鉴 / 差异**: 本综述从"传统解析建模"侧论证了我们走"数据驱动端到端自建模"路线的必要性——它正面承认 CC/Cosserat 等先验模型在真实变形(载荷/摩擦/损伤)下失效,正是我们神经场自建模 + 迟滞状态转移 + 免标定 2D 管线要绕开的痛点。我们不同于该综述讨论的解析路线:用视觉观测 + 体渲染训练信号隐式学习形态(含粘弹性迟滞),不依赖 CAD/材料参数,因此对损伤与大变形更鲁棒。可与 `notes_webster2010_constant_curvature_review.md`(恒曲率经典)互补:Webster2010 是 CC 的奠基性综述,本篇是更全面、更近期(2023)的连续体机器人全景。
- **支撑哪句论述**:
  - **A6**(传统建模需先验 CAD/精确物理参数,损伤或变形后预设模型失效):本综述明确指出 CC/Cosserat 等解析模型在外载荷/摩擦/损伤下失效,是 A6 的权威直接引用。
  - **A7**(数据驱动自建模端到端联合训练,避免先验依赖+误差累积):该综述从反面印证解析路线的局限,支撑"转向端到端学习"的动机。
  - **A1/A2**(大多建模只关注尖端/狭窄环境需全身形态):综述强调连续体机器人的核心价值在"长臂可达狭窄蜿蜒环境",间接说明中段形态感知对避障/接触操作的必要性。
