# 阅读笔记：A Closed-Form CLF-CBF Controller for Whole-Body Continuum Soft Robot Collision Avoidance

> Kiwan Wong, Maximillian Stölzle, Wei Xiao, Daniela Rus — IEEE International Conference on Soft Robotics (RoboSoft 2026)
> 链接: https://arxiv.org/abs/2603.19424
> arXiv: 2603.19424

## 一句话概括
提出一个闭式（closed-form）的 CLF-CBF 控制器，把软体连续臂的全身 3D 避障约束解析地嵌入控制输入，无需在线求解 QP，比基于在线优化的 CLF-CBF 快约 10×、比采样式规划（RRT*）快约 100×，同时给出形式化的稳定性与安全性保证。

## 核心问题 / 动机
- 软体机械臂虽具被动柔顺性，但现代设计越来越刚/驱动更强，单靠被动安全不够，必须做主动碰撞避让。
- 现有 3D 连续软体臂避障工作多为路径/轨迹规划（RRT*、MPC），计算昂贵、缺形式化安全保证，且通常不直接给出驱动设定点，需级联一个高速内环控制器。
- 基于 CBF 的在线 QP 方法在高维软体（PCC/PCS 多段）+ 密集碰撞几何（球/凸包离散化）下约束数量爆炸，在线求解难、易数值不稳定、甚至不可行，削弱了形式化安全保证。
- 目标：在保证全身安全的前提下做到实时（高控制频率）、形式化、可扩展。

## 方法
- **运动学模型**：分段常应变（Piecewise Constant Strain, PCS）建模软体臂主干（腱驱动两段臂），是可微的运动学模型，而非完整连续体动力学。
- **闭式 CLF-CBF**：将 CLF-CBF 二次规划的解 `u*` 解析地求出（显式闭式表达式），把 CBF 安全约束直接嵌入控制输入，完全避免在线 QP。
- **全身安全约束**：把整条软体主干沿弧长用密集的空间离散化（密集球/几何基元）表示，对每个身体点的障碍距离都施加约束，从而对整条臂而非仅末端做避障。
- **对比基线**：与 RRT* 规划 + 无避障意识的运动学底层控制器的级联架构做设定点调节对比。
- 代码开源：https://github.com/KWWnoob/closed-form-clf-cbf-soft-robot

## 主要结果
- 比"在线 QP 求解 CLF-CBF"快约 **10×**，比传统采样式规划（RRT*）快约 **100×**。
- 仿真 + 硬件（腱驱动软体臂 + 反光标记动作捕捉）实验：在杂乱障碍环境中做到精确 3D 轨迹跟踪 + 稳健避障，并严格满足安全约束。
- 闭式控制器在设定点调节任务上比 RRT* 级联基线表现更好，且计算开销低约两个数量级；相比在线优化式 CLF-CBF，跟踪性能更好且严格不违安全约束。
- 消除了在线优化常见的可行性（infeasibility）与数值稳定性问题。

## 与本项目的关系
- **关联主题**: 全身避障控制、连续体软体机器人、CLF-CBF 安全控制、闭式控制律、腱驱动软臂、PCS 运动学
- **可借鉴 / 差异**:
  - 本文做的是**控制层**——给定一个全身 3D 形状模型，如何实时生成安全驱动指令；它依赖一个可微的 PCS 运动学模型来计算每个身体点位置以喂给 CBF 约束。
  - 我们的神经场自建模（route B 免标定 2D 管线）输出的是**全身形态估计**，恰恰可以作为这类全身避障控制器的形状输入；本文明确论证了"仅末端不够、中段每个点都要查障碍"这一动机，正是我们工作要支撑的下游需求。
  - 差异：本文用先验 PCS/CAD 运动学（A6 类先验依赖），而我们走数据驱动、免 CAD、含迟滞的路线；两者互补——本文是控制下游，我们是形态自建模上游。
- **支撑哪句论述**:
  - **A2**（仅尖端不够：狭窄环境避障需中段同样不碰障碍）：本文正是基于"整条臂每个点都要查障碍"才提出全身 CBF，是最直接的下游证据，证明 A2 的需求真实存在且被形式化建模。
  - **A6**（传统建模需先验 CAD/精确物理参数）：本文依赖 PCS 运动学这一先验模型，反面说明为何需要数据驱动自建模来摆脱先验；其可微 PCS 模型一旦损伤/变形就需重标定，正是我们想规避的。
