# 阅读笔记：A three-dimensional fractional visco-hyperelastic model for soft materials

> Yunfei Gao, Deshun Yin, Mao Tang, Bin Zhao — Journal of the Mechanical Behavior of Biomedical Materials (JMBBM), vol. 137, 105564, 2022
> 链接: https://doi.org/10.1016/j.jmbbm.2022.105564
> arXiv: 无 (期刊付费全文; 早期预印见 SSRN 4210189, 2022)

## 一句话概括
把分数阶(Caputo/Riemann-Liouville)粘弹性算子嵌入 Yeoh 型超弹本构, 给出可三维有限元实现、参数少且物理意义明确的"分数粘-超弹"本构模型, 用于刻画软组织/弹性体在大变形、率相关(不同应变速率)与循环加载下的应力-伸长响应。

## 核心问题 / 动机
软材料(生物软组织、VHB 类弹性体、水凝胶等)同时呈现**大变形超弹性 + 率相关粘弹性 + 历史相关迟滞**, 传统广义 Maxwell/Prony 级数需要非常多单元才能逼近宽频松弛谱, 参数多、物理意义不清。分数阶导数天然对应**幂律记忆核**, 用单一分数阶阶数 α∈(0,1) 即可等价"无穷多 Maxwell 单元", 参数精炼且能描述层级(分形)材料的宽谱松弛。本文要解决: 如何把 1D 分数粘-超弹关系推广到**三维有限变形**, 并保证可数值实现/可拟合实验。

## 方法
- 在超弹性部分采用 Yeoh/Gent 类应变能函数描述有限弹性骨架。
- 粘弹性部分把经典整数阶偏应力项替换为**分数阶导数** (Riemann-Liouville / Caputo 形式), 其核为非奇异幂律 (t−τ)^{−α}, 对应长尾、跨多时间尺度的记忆积分; 阶数 α 介于纯弹性(α=0)与纯粘性(α=1)之间。
- 给出三维张量形式 + 有限元离散方案, 强调分数阶核"谱松弛时间"特性: 单一 α 等价于无穷 Maxwell 单元链, 显著少于 Prony 展开。
- (据摘要/相关姊妹篇) 与"时变黏度"模型建立等效桥梁, 解释 α 的物理意义; 通过 VHB 4910 等软弹性体不同应变速率下的单轴拉/压实验拟合与预测验证率相关性。

## 主要结果
据摘要与同作者后续(Fractal Fract. 2022, 6:590; Meccanica 2022)交叉确认:
- 三维分数粘-超弹模型用**很少的参数**(超弹常数 + 一个分数阶 α + 一个松弛时间)即可同时刻画软弹性体/软组织在不同应变速率下的非线性应力-伸长响应。
- 分数阶核提供**连续松弛谱**(宽频记忆), 相比固定项数的 Prony 级数在宽载荷历史下拟合/外推更稳。
- 后续变阶(variable-order)工作进一步证明: 用线性变阶函数 α(λ) 可同时刻画初始弹性段与屈服后应变硬化段, 优于常数阶。

## 与本项目的关系
- **关联主题**: 分数阶记忆核、幂律松弛/迟滞、本构参数先验、数据驱动隐式记忆替代
- **可借鉴 / 差异**: 本文是本项目"用可学习 latent z 隐式吸收粘弹性记忆"这一论点的**物理根基与对比靶子**。经典连续体臂建模(含本项目 PyElastica 仿真底座)通常把粘弹性以**固定形式的 Prony 级数 / spring-pot**硬编码进本构; 本文恰恰证明软弹性体的记忆本质是**分数阶幂律长尾**, 而这种固定形式难以覆盖损伤、老化、个体差异下的真实记忆结构。我们的神经场自建模做法不预设核函数, 而用时间编码器(MultiScaleEMA / GRU)+ latent z 由 2D 图像骨架监督端到端学出"等价的记忆核", 可视为本文分数阶遗传积分的**数据驱动柔性代理**: 既能隐式复现幂律长尾, 又能在物理参数变化(损伤/变形)后自适应而无需重设 α/Prony 表。差异点: 本文是白盒三维本构辨识(参数少、可解释, 但需预设形式 + 已知材料常数); 我们是黑盒全身形态免标定 2D 学习(不假设核形式, 但牺牲可解释性, 依赖数据)。
- **支撑哪句论述**: **A7** —— 软体材料本征地携带分数阶(幂律)长尾粘弹性记忆, 这是把记忆"学进去"而非"预设进去"的物理动机; 数据驱动自建模用 latent z + 时间编码器隐式捕获这种记忆, 正是该物理事实的端到端学习化代理。同时支撑 **A8**: 若不显式/隐式建模这种率相关记忆(如本文所示高速下迟滞叠加应变硬化), 高速运动下形状估计误差必然放大, 凸显"考虑迟滞"的必要性。
