# 阅读笔记：Modeling of Viscoelastic Electromechanical Behavior in a Soft Dielectric Elastomer Actuator

> Guo-Ying Gu, Ujjaval Gupta, Jian Zhu, Li-Min Zhu, Xiangyang Zhu — IEEE Transactions on Robotics (TRO), vol. 33, no. 5, pp. 1263–1271, 2017
> 链接: https://doi.org/10.1109/TRO.2017.2706285
> arXiv: 无 (实验室全文 PDF: https://softrobotics.sjtu.edu.cn/pdf/38.pdf)

## 一句话概括
对承受循环电压加载的介电弹性体致动器(DEA)做系统的电-机耦合粘弹性实验刻画, 并基于非平衡热力学原理提出含多个耗散弹簧-阻波单元(内变量)的本构模型, 定量预测蠕变漂移、可重复迟滞回线以及位移峰相对电压峰的滞后偏移。

## 核心问题 / 动机
软体 DEA 具有"类肌肉"的大应变/快响应/高能量密度, 但其建模因**材料非线性 + 非线性机电耦合 + 时间相关粘弹性**而极困难。已有研究多偏力学/物理/材料层面, 对 DEA 的定量行为表征(尤其循环加载下的迟滞与蠕变)重视不足, 而这恰恰是模型预测控制、设计优化与实时操作的前提。本文要解决: 如何用一个统一的本构模型, 同时定量刻画循环电压下 DEA 的**蠕变漂移、可重复迟滞、位移峰滞后**这三类粘弹性现象。

## 方法
- 实验装置: 夹持平面 DEA, dSPACE 板卡采样 1 ms, MATLAB/Simulink 实现, 施加 4 种电压模式(VP1–VP4)进行循环加载, 记录电压-位移时间序列。
- 关键实验观察(据正文):
  1. **蠕变漂移 (creep drift)** —— 位移随时间整体漂移, 在前 3 个周期主导, 之后逐渐减弱;
  2. **迟滞 (hysteresis)** —— 全程显著存在, 经前几周期"训练"后加载/卸载路径变得可重复; 最大位移随周期数增加(蠕变效应);
  3. **位移峰滞后** —— 位移峰不与电压峰对齐, 出现在卸载段、落后于最大电压。
- 建模: 基于**非平衡热力学**, 引入若干耗散非平衡机制(并联 spring-dashpot 内变量单元)构成非线性粘弹性本构模型。
  - **Model I**: 单 spring-dashpot 单元, 能拟合首周期迟滞与可重复回线, 但无法预测蠕变漂移;
  - **Model II**: 双 spring-dashpot 单元(两个不同松弛时间 T1=0.5 s, T2=5 s), 同时刻画迟滞与蠕变, 预测显著改善。
- 结论: 增加并联耗散单元(更丰富的内变量/记忆尺度)可更准确预测粘弹性效应。

## 主要结果
- Model II(双松弛时间)在 4 种电压模式(VP1–VP4)下与实验定量吻合, 同时复现蠕变漂移、可重复迟滞回线、位移峰滞后三类现象; Model I(单松弛时间)能拟合迟滞但无法捕捉蠕变。
- 预测表明: 黏弹性效应需要**多个不同时间尺度的耗散机制并联**(对应不同的内变量/记忆时间常数), 单一时间尺度不足以同时刻画短期迟滞与长期蠕变漂移。
- 模型可作为 DEA 这种粘弹性致动器**控制**的基础, 为软体机器人的应用铺路。

## 与本项目的关系
- **关联主题**: 软体致动器粘弹性迟滞/蠕变、内变量状态空间建模、记忆/松弛时间常数、数据驱动自建模的物理先例
- **可借鉴 / 差异**: 这是本项目循环状态转移 `s_t = F(s_{t-1}, a_t, z_{t-1})` (含 latent z)**物理谱系上的根基之一**。本文用"多个并联耗散内变量 + 不同松弛时间常数"显式刻画粘弹性记忆; 我们的做法是把同样的"多时间尺度记忆"思想**学习化、视觉监督化**: 不手写 spring-dashpot 方程, 而用 GRU/多尺度 EMA 时间编码器 + latent z 隐式吸收这些耗散内变量, 由 2D 图像骨架监督端到端学出来。差异点: 本文是**单致动器、一维位移**的本构辨识(物理白盒); 我们是**全身形态、免标定 2D 骨架**的隐式黑盒状态转移; 但两者共享"软体行为必须用带记忆/内变量的状态空间描述"这一核心命题, 本文为该命题提供了被引 ~190 次的权威实验与理论支撑。
- **支撑哪句论述**: **A7** —— 软体致动器本质上呈现粘弹性(蠕变 + 迟滞 + 峰值滞后), 必须用带内变量/记忆的状态空间建模; 数据驱动自建模用时间编码器 + latent z 隐式捕获这些现象, 正是这条物理谱系的端到端学习化后裔, 避免先验依赖与误差累积。同时为 **A8** 提供背景: 高速/复杂载荷下迟滞与蠕变叠加(本文定量所示), 单一模型难以泛化, 凸显考虑迟滞的必要性。
