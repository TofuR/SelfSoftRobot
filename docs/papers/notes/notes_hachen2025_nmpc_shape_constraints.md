# 阅读笔记：A Non-Linear Model Predictive Task-Space Controller Satisfying Shape Constraints for Tendon-Driven Continuum Robots

> Maximillian Hachen, Chengnan Shentu, Sven Lilge, Jessica Burgner-Kahrs — IEEE Robotics and Automation Letters (RA-L), 2025 (arXiv 预印本 2024-09)
> 链接: https://arxiv.org/abs/2409.09970
> arXiv: 2409.09970

## 一句话概括
提出一种针对腱驱动连续体机器人(TDCR)的非线性模型预测控制(NMPC),在任务空间跟控制末端的同时,把"全身形状"作为硬约束纳入优化,实现整臂避障,可在 30Hz 实时运行,并优于传统 Jacobian 控制器。

## 核心问题 / 动机
- TDCR 用于微创手术、航空发动机检修等狭窄受限环境,既要插入小孔又必须避免与环境碰撞。
- 既有工作常假设机器人柔性结构本身"天然安全",故容忍接触;但当机器人刚度提高或环境脆弱(如血管附近),该假设失效,**碰撞必须被主动避免**。
- 关键缺口:任务空间控制器/路径规划器往往只跟踪末端(tip),忽略身体中段,导致中段在避障上失守。本文要"在引导末端的同时,让整段身体都遵守环境约束"。

## 方法
- **建模**:用分段常曲率(Piecewise Constant Curvature, PCC)名义模型来高效计算可行轨迹;PCC 作为快速可微的运动学近似。
- **NMPC 框架**:将末端任务空间跟踪目标与**全身形状约束(3D 有符号距离/安全区)**统一写成 MPC 的硬约束,显式利用 TDCR 的运动学冗余。
- **局部反馈控制器**:叠加一个局部反馈环节,补偿 PCC 名义模型的建模误差与外部扰动。
- **实时性**:NMPC 设计为 30Hz 输入处理能力,具备控制限(control limits)的纳入。
- **控制侧定位**:这是一个控制/规划方法(非感知/自建模),PCC 模型是先验解析模型,不涉及从图像学习形状。

## 主要结果
(据摘要;仿真与硬件实验)
- 仿真中,所提 NMPC 在位置跟踪上优于传统 Jacobian 控制器,尤其在**存在扰动与用户定义形状约束**时优势明显,并能纳入控制限。
- 在硬件样机上验证,展示了其在提升遥操作任务安全性方面的潜力。
- 实时性:具备 30Hz 处理能力。

## 与本项目的关系
- **关联主题**: continuum-robot control, whole-body shape constraint, MPC, task-space control, collision avoidance
- **可借鉴 / 差异**:
  - 与本项目"全身形态需被建模/控制"立场高度一致——它从**控制侧**论证了同一论点:身体而非仅末端必须被纳入约束(本项目则是从**感知/自建模侧**论证)。
  - 方法上是互补关系:它用先验 PCC 解析模型 + MPC;本项目走数据驱动神经场自建模,免先验 CAD、可应对损伤/变形与粘弹性迟滞。可作为"先验建模路线在控制端的代表"对照引用。
  - 不能替代本项目:它假设形状可由 PCC 解析获得,未处理迟滞、高速、免标定观测等本项目关注点。
- **支撑哪句论述**: **A2**(仅尖端不够——狭窄环境碰撞避让需中段同样安全)。该文正是把"整段身体的安全区"写成 MPC 硬约束,直接佐证"末端+全身形态必须联合控制/约束"的论点。
