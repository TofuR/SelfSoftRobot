# 阅读笔记：Machine Learning Best Practices for Soft Robot Proprioception

> Annan Zhang*, Tsun-Hsuan Wang*, Ryan L. Truby, Lillian Chin, Daniela Rus — IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS), 2023, pp. 2564–2571
> 链接: https://doi.org/10.1109/IROS55552.2023.10342379 (PDF: https://www.annanzhang.com/data/pdf/zhang2023machine.pdf)
> arXiv: 无

## 一句话概括
首个针对软体机器人本体感知(soft robot proprioception)的机器学习管线设计选择的系统性大规模实证研究:在两个差异巨大的软体机器人数据集(电气驱动平台 + 气动软躯干)上训练 363 个模型,从"输入信号选择 / 数据表示 / 时序处理 / 网络架构"四个维度提炼出可跨平台推广的最佳实践。

## 核心问题 / 动机
- 软体机器人材料连续变形大、具有粘弹性(应变率依赖、应力松弛、蠕变)及长期不可逆效应(聚合物老化、疲劳),解析建模(连续介质力学/有限元)极困难,因此学界越来越多地用机器学习绕过建模困难。
- 然而缺乏对"如何为软体机器人本体感知搭建一个 ML 管线"的系统性分析:该选什么传感器与驱动信号、如何处理输入输出、如何应对数据分布随时间漂移、该选什么网络架构——这些都是研究者反复面对但没有定论的问题。
- 目标:做第一个大规模、跨平台的研究,给出可泛化于"一类"软体机器人的 ML 本体感知最佳实践指南。

## 方法
围绕四个核心维度(对应论文 Fig.1)开展受控实验:
- **传感器与驱动信号选择**:对比不同强度/故障传感器组合,并测试是否加入驱动(执行器)信号。
- **模型输入/输出处理**:相对 vs 绝对输入、滤波与否、用 keypoints 表示朝向 vs 传统表示。
- **时序与分布漂移**:从录制不同位置取测试集(末端漂移最严重)、用不同长度+重叠率的序列采样应对不等长录制。
- **网络架构**:MLP / RNN(LSTM)/ CNN / GRU 对比,并加入"全局已逝时间"作为输入尝试捕获长期漂移。
- 实验载体:两个公开数据集——电气驱动的 HSA 机器人平台(内置压力传感器)+ 气动软躯干(外部压阻应变传感器),共训练 363 个模型。

## 主要结果
- **驱动信号是最大增益**:把驱动(伺服)位置加入输入显著提升精度;在 Platform 数据集上,仅用 4 个伺服位置作输入的误差低于任何纯传感器组合——说明此时网络可学到无扰动前向运动学,但在有外力/材料退化时仍需传感器。
- **时序架构最优**:LSTM 与 GRU 在两个数据集上均最低误差;GRU 在 Platform 上显著优于 LSTM,值得作为 LSTM 的替代首选;MLP 因无历史信息而最差。加入全局已逝时间并不能改善(无法捕获短时动力学)。
- **数据采样**:较短序列 + 重叠率采样应对不等长录制最佳;数据量收益递减(Platform 用 1/4 数据性能基本不变,1/16 才显著下降;Trunk 在 1/4 即明显下降,GRU 对数据量最敏感、收益最大)。
- **综合最佳配置**达到:Platform 位置误差 1.93 ± 0.09 mm、角度误差 0.94 ± 0.06°;Trunk RMSE 1.32 ± 0.03 mm——不仅优于 baseline,也是全部 363 个模型中最低(据摘要+结果节)。
- **朝向表示**:用 keypoints 跟踪作为朝向的替代表示值得考虑。

## 与本项目的关系
- **关联主题**: data-driven-self-modeling, soft-robot-proprioception, temporal-network, hysteresis-modeling, whole-body-shape
- **可借鉴 / 差异**:
  - 这是本项目"数据驱动软体机器人本体感知/自建模"管线最直接的方法学背景与背书:它系统论证了数据驱动端到端学习是软体机器人本体感知的成熟范式,且(1)必须把驱动信号作为输入、(2)时序网络(GRU/LSTM)对捕获历史依赖/粘弹迟滞必不可少——与我们 transition 模型用 action 历史 + GRU/MultiScaleEMA 的设计选择高度一致。
  - 关键差异:该工作把"本体感知"的输出表示为末端位姿、降阶运动学参数或 keypoints(离散/低维表示),**并非全身连续形态(shape)的密集估计**;其管线是传感器/驱动→状态的回归,不做神经场体渲染、不做免标定 2D 图像自建模。因此它定位为"方法学背景",而非与我们形态建模正面对标的方法。
  - 该论文明确指出软材料存在应变率依赖、应力松弛、蠕变等粘弹性时变效应正是解析建模失效、需数据驱动的根因——直接为本项目 A6/A7 的论述提供权威引证。
- **支撑哪句论述**:
  - **A7**(数据驱动端到端联合训练避免先验依赖、能隐式捕获粘弹性迟滞):该论文以 363 个模型的系统实验确立"数据驱动 + 时序网络"为软体机器人本体感知的标准范式,并显式论证粘弹性时变效应是数据驱动优于解析建模的根因,是 A7 的核心方法学背书。
  - **A5**(联合 vs 两阶段):该论文倡导端到端从原始信号直接回归状态的管线设计,印证联合训练优于分阶段,可作 A5 的旁证。
  - **A6**(传统建模需先验物理参数、损伤/变形后失效):其引言对软材料连续变形 + 粘弹性 + 老化/疲劳使解析建模失效的论述,直接支撑 A6。
