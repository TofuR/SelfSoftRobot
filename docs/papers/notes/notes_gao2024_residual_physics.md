# 阅读笔记：Sim-to-Real of Soft Robots With Learned Residual Physics

> Junpeng Gao*, Mike Y. Michelis*, Andrew Spielberg, Robert K. Katzschmann — IEEE Robotics and Automation Letters (RA-L), 2024
> 链接: https://arxiv.org/abs/2402.01086
> arXiv: 2402.01086

## 一句话概括
在可微分有限元(FEM)解析仿真之上, 学习一个施加于整个网格的"残差体力"(residual body force), 用稀疏运动标记(motion markers)的真实数据训练, 把高自由度软体机器人的仿真与实物差距(sim-to-real gap)缩小, 在硅胶梁与气动纤维增强臂上比传统系统辨识(SysID)误差降低最多 60%。

## 核心问题 / 动机
- 软体机器人仿真既昂贵又不准: 几何/材料近似粗、制造缺陷、粘弹性与塑性、迟滞效应等导致显著的 sim-to-real gap。
- 传统系统辨识只能微调有限参数(密度/刚度/压缩性/摩擦/阻尼), 当误差来自材料模型选错、时空离散过粗、FEM locking 等非参数失配时, 仿真器的表达能力不够。
- 想要一种"系统无关"(system agnostic)、可推广到高自由度连续体的通用方法, 不必为每种软体机器人逐一精细建模。

## 方法
- **混合公式**: 可微分 FEM 仿真提供定性先验(弯曲方向、近似变形幅度), 神经网络学习残差项来修正仿真与真实差距。
- **残差是体力**: 残差项表现为施加在整个仿真网格上的力(force on whole mesh), 直接最小化 sim-to-real 状态预测误差。
- **稀疏观测**: 真实位置数据仅来自稀疏运动标记(continuum 结构无法全传感化, 本质部分可观测), 用稀疏标记约束全程网格残差。
- **物理先验作为起点**: 解析仿真提供先验, 残差网络在其基础上微调, 比从零(tabula rasa)学物理更具信息量。
- 验证平台: (1) 硅胶弹性梁; (2) 带各向异性纤维增强、难以建模的气动软臂。

## 主要结果
- 在硅胶梁和气动纤维增强软臂上, 残差物理方法**优于传统系统辨识最高达 60%**。
- 证明残差物理**不限于低自由度系统**, 能有效弥合高维连续体系统的 sim-to-real gap。

## 与本项目的关系
- **关联主题**: sim-to-real gap、残差物理学习、混合(解析+数据驱动)建模、迟滞、高自由度全身形状、稀疏观测
- **可借鉴 / 差异**:
  - **思路同源(解析先验 + 学习残差)**: 本文用 FEM 解析仿真做物理先验、神经网络学残差; 与本项目神经场(NeRF 式)自建模 + 迟滞状态转移 + 免标定 2D 管线在哲学上一致 — 都主张"物理先验 + 数据驱动修正"优于纯白盒或纯黑盒。可作为引言中"hybrid / residual modeling"路线的代表引用。
  - **关键差异(我们更彻底地端到端 + 免标定)**: 本文仍依赖一个可微分 FEM 仿真器作为强先验, 且真实数据需要稀疏运动标记(需标记/传感); 我们的项目走更彻底的端到端数据驱动自建模, 不依赖精确 FEM/CAD 先验, 且用单目图像骨架做免标定监督, 适配损伤/变形后预设模型失效(A6)的场景。本文的"残差"是加在已有仿真上的修正项, 我们的"自建模"是直接从观测学整条状态转移。
  - **迟滞**: 摘要明确把迟滞列为 sim-to-real gap 成因之一, 但本文残差是"力"而非显式迟滞状态; 我们的迟滞状态转移(open_loop rollout)更直接建模加载-卸载回线。
- **支撑哪句论述**: **A5**(两阶段串联误差累积 — 本文是"解析仿真 + 残差修正"的串联式 hybrid, 残差网络只补差, 不重学, 可作 A5 反衬: 即便 hybrid 仍依赖先验仿真器, 端到端可避免累积); **A6**(传统建模需精确物理参数/CAD, 损伤变形后失效 — 本文恰恰指出 SysID 参数微调在材料模型/离散化失配时不够, 必须靠残差学习补); **A7**(数据驱动联合训练避免先验依赖 + 隐式捕获粘弹性迟滞 — 本文残差网络从真实数据学到的修正项隐式吸收了粘弹性/迟滞, 印证 A7 的"隐式捕获"论点)。
