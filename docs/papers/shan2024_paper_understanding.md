# SoftNeRF: A Self-Modeling Soft Robot Plugin for Various Tasks — 论文理解

> 论文：Shan et al., "SoftNeRF: A self-modeling soft robot plugin for various tasks," 2024
> 核心思想：将条件化 NeRF 应用于软体机器人自建模，通过驱动状态条件化的多尺度哈希编码 + SDF 体渲染，实现形状重建、运动规划和损伤检测。
> 软体机器人平台：硅胶软体机器人，4 根驱动缆绳，单视角智能手机相机

---

## 1. 问题定义

给定一个连续变形的软体机器人：

- **输入**：驱动状态 A = (a₁, a₂, a₃, a₄)（4 根缆绳的拉力/位移）
- **输出**：机器人完整 3D 形状（NeRF + SDF 表示）
- **目标**：仅通过单视角相机观察，学习驱动状态到 3D 形状的映射

核心挑战：
1. 软体机器人**无限自由度**，无法用有限关节角度参数化
2. **大范围非线性变形**，传统运动学模型失效
3. **单视角观测**，存在严重深度歧义

---

## 2. 方法概述

### 2.1 整体架构

```
输入: (X: 3D查询点, A: 驱动状态)
                        ┌─────────────────────┐
   X ──→ Hash Encoding ──→│ Geometry Feature    │──→ F_g(X)
                        │ F_g (多尺度)        │          │
                        └─────────────────────┘          │ 拼接
                        ┌─────────────────────┐          │
   A ──→ MLP Encoder ──→│ Kinematic Feature   │──→ F_k(A)
                        │ F_k (驱动状态编码)   │          │
                        └─────────────────────┘          │
                                                         ↓
                        ┌─────────────────────┐    ┌──────────┐
                        │ SDF Decoder D_s     │←───│ concat   │──→ s (SDF值)
                        └─────────────────────┘    └──────────┘
                        ┌─────────────────────┐         │
                        │ Color Decoder D_c   │←────────┘──→ c (颜色)
                        └─────────────────────┘
```

### 2.2 多尺度哈希编码 (Multi-Scale Hash Encoding)

Geometry Feature F_g 使用 Instant-NGP 风格的多分辨率哈希编码：

```
F_g(X) = concat(h₁(X), h₂(X), ..., h_L(X))
```

其中每个 h_l 是一个分辨率级别上的哈希查找表：
- L = 16 个分辨率级别
- 每级特征维度 = 2
- 分辨率从粗到细：N_min = 16 到 N_max = 4096
- 总参数量：L × T × 2（T 为哈希表大小，默认 2^19）

**优势**：比频率编码（positional encoding）更高效，能自适应地分配容量到需要的空间区域。

### 2.3 运动学特征编码 (Kinematic Feature)

驱动状态 A 通过小型 MLP 编码为运动学特征 F_k(A)：

```
F_k(A) = MLP_k(A)  →  维度与 F_g 匹配
```

### 2.4 SDF 解码与体渲染

**SDF 解码器** D_s：将拼接特征映射为符号距离值 s：

```
s = D_s(concat(F_g(X), F_k(A)))
```

**SDF 到不透明度转换**：

```
α_i = max(0, (Φ_s(s_i) - Φ_s(s_{i+1})) / Φ_s(s_i))
```

其中 Φ_s 是 Sigmoid 函数（或拉普拉斯 CDF），将 SDF 值转换为概率。

**体渲染**：

```
C(r) = Σ_i T_i · α_i · c_i
T_i = Π_{j<i} (1 - α_j)
```

### 2.5 误差引导的自适应采样 (Error-Guided Adaptive Sampling)

SoftNeRF 提出一种基于误差的自适应采样策略：

1. **粗采样**：均匀采样 N_c 个点
2. **误差估计**：计算每个区间的渲染误差
3. **细采样**：在误差大的区间密集重采样 N_f 个点
4. **合并渲染**：用全部 N_c + N_f 个点进行最终渲染

相比 NeRF 的基于权重的重采样（sample_pdf），SoftNeRF 直接利用误差信号指导采样，对软体机器人大变形区域分配更多采样点。

## 3. 数据采集流程

### 3.1 软体机器人平台

- **机器人**：硅胶材质软体机器人
- **驱动**：4 根缆绳（tendon-driven），分别控制不同方向的弯曲
- **传感器**：单部智能手机相机（RGB only）
- **标记点**：机器人表面可能有视觉标记辅助评估

### 3.2 数据采集

1. 设置固定的单视角相机
2. 依次驱动 4 根缆绳到不同位移
3. 每个驱动状态拍摄一张 RGB 图像
4. 记录对应的驱动状态 A = (a₁, a₂, a₃, a₄)
5. 数据量相对有限（受限于软体机器人的物理驱动速度）

### 3.3 与本项目的对比

| 特性 | SoftNeRF | 本项目 |
|------|----------|--------|
| 机器人类型 | 硅胶软体 | 气动软体 |
| 驱动方式 | 缆绳 | 气压 |
| 自由度 | 4 (缆绳位移) | 连续骨架 |
| 相机 | 单视角智能手机 | 单视角 |
| 3D 监督 | 无 (纯 2D) | 无 (纯 2D) |
| 深度信息 | 无 | 无 |

## 4. 训练流程

### 4.1 损失函数

```
L = λ_color · L_color + λ_reg · L_reg + λ_mask · L_mask
```

其中：
- **L_color**：渲染图像与真实图像的 MSE 损失
- **L_reg**：SDF 正则化损失（Eikonal 约束 ||∇s|| = 1）
- **L_mask**：轮廓/掩码一致性损失（渲染掩码 vs 真实前景掩码）
- λ_color, λ_reg, λ_mask：各项损失的权重系数

### 4.2 训练策略

- 从粗到细训练（coarse-to-fine）：先训练粗分辨率哈希，逐步激活细分辨率
- 误差引导采样随训练进程动态调整
- 支持增量学习：新数据到来时快速微调

## 5. 3D 形状重建

### 5.1 Marching Cubes 提取

与 Chen 2022 类似，通过 Marching Cubes 从 SDF 场提取等值面：

```
给定驱动状态 A：
1. 在 3D 空间均匀网格查询 SDF 值
2. Marching Cubes 提取 s = 0 等值面
3. 输出三角网格表示机器人形状
```

### 5.2 单视角深度歧义

由于只有单视角监督，SoftNeRF 面临严重的深度歧义：
- 相机光线方向上的位置不确定
- 背面结构主要靠 SDF 先验和正则化约束推断
- 这与本项目的 exp2 实验发现一致（2D/3D MNE 差距 4.96x）

## 6. 运动规划与损伤检测

### 6.1 基于梯度的运动规划

利用 SDF 的可微性：

```
给定：目标形状/姿态
求解：驱动状态 A*

方法：
1. 定义形状目标函数（目标 SDF 值分布）
2. 通过 SDF 最小化形状差异
3. 梯度 ∂SDF/∂A → 更新驱动状态
```

### 6.2 损伤检测与恢复

**检测**：
```
1. 给定驱动状态 A
2. 模型预测 3D 形状
3. 相机观测实际形状
4. 2D 渲染误差或 3D SDF 异常 → 检测损伤
```

**恢复**：
```
1. 收集损伤后的少量新数据
2. 在原模型基础上微调 ~5000 迭代
3. 模型重新适应变形后的形状
```

### 6.3 与 Chen 2022 损伤恢复对比

| 特性 | Chen 2022 | SoftNeRF |
|------|-----------|----------|
| 检测方式 | SDF 与点云距离 | 2D/3D 预测误差 |
| 恢复数据量 | ~50 样本 | ~5000 迭代 |
| 恢复时间 | ~8.13 分钟 | 未明确 |
| 适用对象 | 刚性机器人 | 软体机器人 |

## 7. 与本项目的代码对应关系

SoftNeRF 无公开代码，但其核心模块与本项目 MS-SCNF 的对应关系：

| SoftNeRF 概念 | 本项目对应 | 说明 |
|---------------|-----------|------|
| 多尺度哈希编码 F_g | MultiScaleEMA | 本项目用多尺度特征 + EMA 时序编码 |
| 运动学特征 F_k(A) | SkeletonHead | 本项目用骨架坐标替代驱动状态 |
| SDF 解码器 D_s | SkeletonConditionedDensity | 本项目输出密度而非 SDF |
| 误差引导采样 | 无 | 可引入的改进点 |
| 体渲染 | renderer.py | 相同的体渲染管线 |
| SDF 正则化 | 骨架约束损失 | 本项目用骨架而非 Eikonal |

## 8. 关键洞察与对本项目的评估

### 8.1 SoftNeRF 的贡献

1. **首个软体机器人 NeRF 自建模**：将 NeRF 范式从刚性机器人扩展到软体机器人
2. **多尺度哈希编码**：比传统频率编码更适合大变形场景
3. **误差引导采样**：自适应地将采样点分配到变形剧烈区域
4. **实用损伤检测**：单视角下即可检测形状异常

### 8.2 SoftNeRF 的局限性

1. **单视角深度歧义未解决**：与本项目相同的问题，Z 轴误差严重
2. **缺乏多视角验证**：没有多相机实验对比
3. **定量评估有限**：缺少与 3D GT 的精度对比
4. **泛化性未知**：只在一个特定软体机器人上验证

### 8.3 对本项目的启示

1. **多尺度哈希编码值得尝试**：SoftNeRF 的 F_g 比 MS-SCNF 的 MultiScaleEMA 在高分辨率细节上可能更好
2. **SDF 输出优于密度输出**：SDF 天然支持碰撞检测和梯度优化，而密度场需要额外阈值处理
3. **单视角不够**：SoftNeRF 和我们的实验都证实，单视角无法解决深度歧义，需要多相机方案
4. **误差引导采样可以集成**：本项目可以在体渲染管线中加入误差引导的精细采样
5. **软体机器人自建模仍需创新**：
   - SoftNeRF 验证了 NeRF + SDF 在软体机器人上的可行性
   - 但深度歧义、精度评估、多视角融合仍是开放问题
   - 本项目的骨架条件化设计是一个有价值的差异化方向
