# SoftNeRF: A Self-Modeling Soft Robot Plugin for Various Tasks — 论文理解

> 论文：Shan et al., "SoftNeRF: A self-modeling soft robot plugin for various tasks," 2024
> 核心思想：将条件化 NeRF 应用于软体机器人自建模，通过驱动状态条件化的多尺度哈希编码 + SDF 体渲染，实现形状重建、运动规划和损伤检测。
> 软体机器人平台：硅胶软体机器人，4 根驱动缆绳，多视角 RGB 相机（仿真 65 视角 / 真实环绕视频）

---

## 1. 问题定义

给定一个连续变形的软体机器人：

- **输入**：驱动状态 A = (a₁, a₂, a₃, a₄)（4 根缆绳的拉力/位移）
- **输出**：机器人完整 3D 形状（NeRF + SDF 表示）
- **目标**：通过多视角 RGB 相机观察，学习驱动状态到 3D 形状的映射

核心挑战：
1. 软体机器人**无限自由度**，无法用有限关节角度参数化
2. **大范围非线性变形**，传统运动学模型失效
3. **多视角 2D 监督到 3D 的推理**，需通过体渲染隐式恢复三维结构

---

## 2. 方法概述

### 2.1 整体架构（Kinematic-Aware SDF Hash Grids）

```
输入: (X: 3D查询点, A: 驱动状态)
                        ┌─────────────────────┐
   X ──→ Hash Encoding ──→│ Geometry Feature    │──→ F_g(X)
                        │ F_g (多尺度哈希)     │          │
                        └─────────────────────┘          │ 拼接
                        ┌─────────────────────┐          │
   A ──→ MLP Encoder ──→│ Kinematic Feature   │──→ F_k(A)
                        │ F_k (驱动状态编码)   │          │
                        └─────────────────────┘          │
                                                         ↓
                        ┌─────────────────────┐    ┌──────────┐
                        │ SDF Decoder D_s     │←───│ concat   │──→ s (SDF值)
                        │ (4层MLP, 128通道)    │    └──────────┘
                        └─────────────────────┘         │
                        ┌─────────────────────┐         │ h (中间特征)
                        │ Color Decoder D_c   │←────────┘──→ c (颜色)
                        │ (2层MLP, 64通道)     │
                        └─────────────────────┘
                                      │
                                      ↓
                                体渲染 → 2D 图像
```

**四个模块**：
1. **Spatial Geometry Encoder (F_g)**：多分辨率哈希编码，将 3D 坐标映射为几何特征
2. **Kinematic Encoder (F_k)**：4 层 MLP（128 通道），将驱动状态编码为运动学特征
3. **SDF Decoder (D_s)**：4 层 MLP（128 通道），将拼接特征解码为符号距离值
4. **Color Decoder (D_c)**：2 层 MLP（64 通道），将中间特征解码为颜色值

### 2.2 多尺度哈希编码 (Multi-Scale Hash Encoding)

Geometry Feature F_g 使用 Instant-NGP 风格的多分辨率哈希编码：

```
F_g(X) = concat(h₁(X), h₂(X), ..., h_L(X))
```

其中每个 h_l 是一个分辨率级别上的哈希查找表：
- L = 16 个分辨率级别
- 每级特征维度 = 8
- 分辨率从粗到细：N_min = 2⁵ = 32 到 N_max = 2¹¹ = 2048
- 总输出维度：L × 8 = 128

**优势**：比频率编码（positional encoding）更高效，能自适应地分配容量到需要的空间区域。不同分辨率的哈希表对应不同尺度特征：低分辨率捕捉全局形状（整体弯曲），高分辨率捕捉局部细节（表面皱褶）。

### 2.3 运动学特征编码 (Kinematic Feature)

驱动状态 A 通过 4 层 MLP（128 通道）编码为运动学特征 F_k(A)：

```
F_k(A) = MLP_k(A)  →  维度与 F_g 匹配
```

### 2.4 SDF 解码与体渲染

**SDF 解码器** D_s：将拼接特征映射为符号距离值 s：

```
s = D_s(concat(F_g(X), F_k(A)))
```

**SDF 到不透明度转换**：

```
α_i = max(0, (Φ_s(s_i) - Φ_s(s_{i+1})) / Φ_s(s_i))
```

其中 Φ_s 是 Sigmoid 函数（或拉普拉斯 CDF），将 SDF 值转换为概率。

**体渲染**：

```
C(r) = Σ_i T_i · α_i · c_i
T_i = Π_{j<i} (1 - α_j)
```

### 2.5 颜色解码器 (Color Decoder)

Color Decoder D_c 接收 SDF 解码器的中间特征 h（不是最终 SDF 值 s），输出颜色 c：

```
c = D_c(h)
```

**为什么需要 Color Decoder**：
1. **RGB 监督比二值掩码信息更丰富**：RGB 图像的 3 通道比 binary mask 提供了更密集的监督信号
2. **视角相关外观约束**：不同视角下同一物体颜色可能不同，这为多视角一致性提供了额外约束
3. **特征向量 h 作为桥梁**：h 连接几何信息与外观信息，使 SDF 解码器专注于几何，颜色解码器专注于外观
4. **提升渲染质量**：RGB 渲染 loss 比 mask loss 更强，推动模型学习更精确的表面位置

### 2.6 误差引导的自适应采样 (Error-Guided Adaptive Sampling)

SoftNeRF 提出一种基于误差的自适应**像素采样**策略（注意：这是训练时在图像平面上的像素采样，不是射线上的 3D 点采样）。

**阶段 1 — 粗训练（前 10,000 迭代）**：
- 使用全部像素训练
- 目的：让模型先学到整体结构

**阶段 2 — 误差引导精训练（10,000 迭代后）**：
1. 将渲染图像下采样 N=20 倍，得到低分辨率误差图
2. 在低分辨率图上计算逐像素渲染误差（预测 vs GT）
3. 根据误差分布构建 PDF，高误差像素被选中概率更高
4. 每个 epoch 选取 64 个 PDF 像素（基于误差）+ 192 个随机像素 = 256 像素
5. 仅在这 256 个像素上计算 loss

**与 NeRF 的 sample_pdf 对比**：
- NeRF 的 sample_pdf：在射线上根据密度重采样 3D 点（coarse → fine）
- SoftNeRF 的误差引导：在图像平面上根据渲染误差重采样像素
- 两者正交互补，理论上可以组合使用

## 3. 数据采集流程

### 3.1 软体机器人平台

- **机器人**：硅胶材质软体机器人
- **驱动**：4 根缆绳（tendon-driven），分别控制不同方向的弯曲
- **仿真环境**：SofaGym Trunk 环境
- **真实机器人**：硅胶软体机器人 + HONOR 30 Pro 智能手机

### 3.2 仿真数据采集

1. 使用 SofaGym Trunk 仿真环境
2. 生成 123 个不同的驱动信号
3. 每个驱动信号对应 **65 张多视角 RGB 图像**（1300×1300 分辨率）
4. 划分：102 个用于训练，21 个用于测试
5. 总计：102 × 65 = 6,630 张训练图像

### 3.3 真实世界数据采集

1. 使用真实硅胶软体机器人，4 根缆绳驱动
2. 使用 HONOR 30 Pro 智能手机**录制环绕视频**
3. 手持手机围绕机器人移动，拍摄不同视角的图像
4. 共 21 组驱动信号，每组对应多视角图像
5. 从视频中提取帧作为训练数据

## 4. 训练流程

### 4.1 损失函数

```
L = λ_color · L_color + λ_reg · L_reg + λ_mask · L_mask
```

其中：
- **L_color**：渲染图像与真实图像的 MSE 损失（RGB 三通道）
- **L_reg**：SDF 正则化损失（Eikonal 约束 ||∇s|| = 1）
- **L_mask**：轮廓/掩码一致性损失（渲染掩码 vs 真实前景掩码）
- λ_color = 1, λ_reg = 0.1, λ_mask = 0.1

### 4.2 训练策略

- **总迭代次数**：100,000 次迭代
- **硬件**：RTX 6000 GPU
- **粗训练阶段**（前 10,000 迭代）：使用全部像素，模型学习整体结构
- **精训练阶段**（10,000 迭代后）：误差引导像素采样，聚焦高误差区域
- 支持增量学习：新数据到来时快速微调（损伤恢复场景）

### 4.3 与本项目训练设置对比

| 特性 | SoftNeRF | 本项目 |
|------|----------|--------|
| 损失函数 | MSE(RGB) + Eikonal + Mask | MSE(render) + 骨架 3D loss |
| 深度监督 | 无（多视角 2D） | 有（仿真器 3D GT） |
| 正则化 | Eikonal (||∇s||=1) | 骨架约束 |
| 训练数据量 | ~6,630 张多视角图 | ~5,000 数据点 |
| 训练迭代 | 100,000 | ~200 epochs |
| 硬件 | RTX 6000 | 单 GPU |

## 5. 3D 形状重建

### 5.1 Marching Cubes 提取

通过 Marching Cubes 从 SDF 场提取等值面：

```
给定驱动状态 A：
1. 在 3D 空间均匀网格查询 SDF 值
2. Marching Cubes 提取 s = 0 等值面
3. 输出三角网格表示机器人形状
```

### 5.2 多视角与深度歧义

SoftNeRF 使用多视角图像缓解了单视角的深度歧义，但仍面临一定限制：
- 多视角通过体渲染的多视角一致性隐式约束 3D 结构
- 但 2D 渲染监督相比直接 3D 监督（如 Chen 2022 的 RGB-D 点云）精度有限
- 背面结构主要靠 SDF 先验和正则化约束推断

## 7. 运动规划与损伤检测

### 7.1 基于梯度的运动规划

利用 SDF 的可微性：

```
给定：目标形状/姿态
求解：驱动状态 A*

方法：
1. 定义形状目标函数（目标 SDF 值分布）
2. 通过 SDF 最小化形状差异
3. 梯度 ∂SDF/∂A → 更新驱动状态
```

### 7.2 损伤检测与恢复

**检测**：
```
1. 给定驱动状态 A
2. 模型预测 3D 形状
3. 相机观测实际形状
4. 2D 渲染误差或 3D SDF 异常 → 检测损伤
```

**恢复**：
```
1. 收集损伤后的少量新数据
2. 在原模型基础上微调 ~5000 迭代
3. 模型重新适应变形后的形状
```

### 7.3 与 Chen 2022 损伤恢复对比

| 特性 | Chen 2022 | SoftNeRF |
|------|-----------|----------|
| 检测方式 | SDF 与点云距离 | 2D/3D 预测误差 |
| 恢复数据量 | ~50 样本 | ~5000 迭代 |
| 恢复时间 | ~8.13 分钟 | 未明确 |
| 适用对象 | 刚性机器人 | 软体机器人 |

## 9. 关键洞察与对本项目的评估

### 9.1 SoftNeRF 的贡献

1. **首个软体机器人 NeRF 自建模**：将 NeRF 范式从刚性机器人扩展到软体机器人
2. **多尺度哈希编码**：比传统频率编码更适合大变形场景
3. **误差引导像素采样**：自适应地将训练资源分配到高误差区域
4. **实用的损伤检测**：多视角下可检测形状异常
5. **多视角采集方案**：验证了多视角 2D 图像通过体渲染恢复 3D 形状的可行性

### 9.2 SoftNeRF 的局限性

1. **多视角 2D 监督精度有限**：虽然使用多视角，但仅通过 2D 渲染 loss 监督，不如 Chen 2022 的直接 3D 点云监督精确
2. **缺乏多视角与单视角的对比实验**：没有消融实验证明多视角 vs 单视角的精度提升
3. **泛化性未知**：只在一个特定软体机器人上验证
4. **无时序建模**：使用当前驱动状态而非动作历史，忽略了软体机器人的粘弹性迟滞

### 9.3 对本项目的启示

1. **多尺度哈希编码值得尝试**：SoftNeRF 的 F_g 比 MS-SCNF 的 MultiScaleEMA 在高分辨率细节上可能更好
2. **SDF 输出优于密度输出**：SDF 天然支持碰撞检测和梯度优化，而密度场需要额外阈值处理
3. **多视角 2D 监督有效但有限**：SoftNeRF 的多视角方案验证了多视角的价值，但仍不如直接 3D 监督；我们用单视角面临更严重的深度歧义
4. **误差引导采样可以集成**：本项目可以在体渲染管线中加入误差引导的像素采样策略
5. **Color Decoder 的启示**：使用 RGB 监督比灰度/mask 提供更丰富的训练信号，值得在真实数据采集中考虑
6. **软体机器人自建模仍需创新**：
   - SoftNeRF 验证了 NeRF + SDF 在软体机器人上的可行性
   - 但精度、泛化性、时序建模仍是开放问题
   - 本项目的骨架条件化设计和时序编码是差异化方向

## 10. 深入讨论笔记

> 以下为阅读论文过程中的深入分析与讨论记录。

### 10.1 Color Decoder 的设计动机

**问题**：既然最终目标是 3D 形状重建，为什么还需要颜色输出？

**分析**：
1. **RGB 监督信号更丰富**：二值掩码每个像素只提供 1 bit 信息（前景/背景），而 RGB 图像每个像素提供 3×8=24 bit 信息。更密集的监督信号 → 更好的梯度 → 更快的收敛
2. **视角相关外观提供额外约束**：不同视角下同一 3D 点的颜色可能不同（高光、阴影），这些差异提供了关于表面法线和材质的额外约束，有助于多视角一致性
3. **特征向量 h 作为几何-外观桥梁**：SDF 解码器输出中间特征 h，h 同时编码了几何信息和外观信息。SDF head 从 h 提取几何（符号距离），Color head 从 h 提取外观（颜色）。这种设计使两个任务共享底层特征，互相促进
4. **实用价值**：重建的 3D 模型带有颜色信息，可用于可视化、检测表面损伤等

### 10.2 多视角方案的对比：SoftNeRF vs Chen 2022

**关键区别**：

| 维度 | SoftNeRF (多视角 2D) | Chen 2022 (多视角 3D) |
|------|---------------------|----------------------|
| 传感器 | RGB 相机 | RGB-D 相机 |
| 原始数据 | 多视角 RGB 图像 | 多视角 RGB-D 图像 |
| 3D 获取方式 | 体渲染隐式恢复 | 深度图 → 显式点云融合 |
| 监督类型 | 2D 渲染 loss (MSE) | 3D Chamfer-L1 loss |
| 精度 | 中等（Acc=0.241cm） | 高 |
| 硬件要求 | 普通 RGB 相机 | RGB-D 相机 |
| 对深度歧义 | 部分缓解（多视角一致性） | 完全消除（直接 3D 测量） |

**启示**：SoftNeRF 的方案更轻量（只需 RGB），但精度上限低于 Chen 2022（需要 RGB-D）。本项目可以从 SoftNeRF 的多视角 RGB 方案起步，降低硬件门槛。

### 10.3 误差引导采样的实现细节

**完整的采样流程**：

```
训练流程:
1. [前 10,000 迭代] 粗训练阶段
   - 使用图像的全部像素计算 loss
   - 目的：建立整体结构认知

2. [10,000 迭代后] 精训练阶段
   Step 1: 将当前渲染结果下采样 N=20 倍
           (如 1300×1300 → 65×65)
   Step 2: 在低分辨率图上计算逐像素误差图
           error_map = |rendered - GT|
   Step 3: 将误差图转为概率分布 (PDF)
           pdf = error_map / sum(error_map)
   Step 4: 从 PDF 中采样 64 个高误差像素
   Step 5: 随机采样 192 个像素（保证覆盖）
   Step 6: 仅在这 256 个像素上计算 loss
```

**与 NeRF 原始分层采样的关系**：
- NeRF 的 coarse→fine 是在**射线上**的 3D 点重采样
- SoftNeRF 的误差引导是在**图像平面上**的像素重采样
- 两者是正交的，理论上可以组合使用

### 10.4 输入条件化的设计选择

SoftNeRF 直接使用驱动状态 A = (a₁, a₂, a₃, a₄) 作为条件输入，而非动作历史。

**与我们项目的对比**：
- SoftNeRF：当前帧驱动状态 → F_k(A) → 与空间特征融合
- 本项目：过去 20 帧动作窗口 → EMA → SkeletonHead → 骨架 → 密度场

**SoftNeRF 忽略时序的合理性**：
- 缆绳驱动的硅胶机器人，响应较快，迟滞效应可能较弱
- 多视角监督提供了足够强的约束，不需要额外的时序信息
