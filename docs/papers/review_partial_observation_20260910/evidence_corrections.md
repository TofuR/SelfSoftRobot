# 本轮原文核对的重要修正

这些修正用于新论文准备；旧单篇笔记保留以便追溯，不据此继承旧初稿叙事。原文与章节见[核心卡片](core_papers.md)和[来源清单](source_manifest.json)。

| 项目 | 容易误用的说法 | 核对后的使用方式 |
|---|---|---|
| AFT | 只是一篇感知论文；单相机遮挡全身闭环尚无人涉及 | AFT有单RGB-D、数字遮挡重建试验和实际全身控制；两种试验分节，不能擅自合并为联合物理遮挡闭环。它是直接相关工作 |
| AFT消融 | 每个模块都改善每项精度 | Table II无多尺度的形状误差2.73%略低于完整2.85%，tip则更差；分别报告指标 |
| Chen 2025 | 仿真训练，或RNN/TCN是其核心方法 | III-B是真实MoCap准静态采集；核心为气压+方向特征。`notes_hysteresis_aware_nn_2025.md`指向相同2504.13582，但旧题名/描述不准确，作为重复别名 |
| Krauss | 仅静态/无历史；七项实机消融；50 Hz实时优化 | 有递归潜动力学与实机开环；七项重训练消融主要用优化MAE/预测MSE代理；50 Hz是模型离散化与执行设置 |
| Yu | 单视角任意3D形状控制 | 多视角二维曲线实现几何感知控制；单目视图不等于单视角系统；严重遮挡仍是其讨论的限制 |
| Wang | 本项目首先结合RGB与动作历史推断全身形状 | 已有LSTM肌腱历史+RGB特征融合及受载形状估计；本项目需证明同局部观测下的后续预测和实际控制收益 |
| Zheng | 从图像边界恢复动态状态，理论可直接移用 | boundary是杆基部/末端物理测量边界；其PDE观察器假设不同 |
| Herrmann | 物理模型必然慢；5 ms没有原文依据 | 本轮在4.3核到8段观察器5 ms采样，4.2的0.38 s/10 s仿真是另一指标。物理传感预算与RGB控制不同，不能跨系统排名 |
| Schäfke | RNN-NMPC运行1 kHz | IV-C中NMPC为5 Hz；PI基线1 kHz，传感总线1 ms；分别引用 |
| Almanzor | 手绘全身目标是本项目首创；1 Hz控制 | 已支持静态全身视觉/手绘目标；1 Hz为采集条件，平均约10 s收敛是另一指标 |
| Hu两篇 | Teaching robots…和Part-Based NeRF…是一篇 | DOI分别为10.1038/s42256-025-01006-w和10.1002/smb2.70005，分别建记录 |
| Tang两条 | 已核Science Advances论文等同旧whole-body-shape笔记 | 本地已核为通用软臂控制/结构与可塑突触论文，DOI10.1126/sciadv.aea3712；旧条目身份继续待核 |
| 当前项目 | 自建模仍指NeRF；实时达到严格10 Hz；证明稳定 | 当前是历史状态到平面中心线模型；虚拟实际发令间隔P95约116 ms；期限丢弃与停止策略不构成物理稳定性证明 |
