## 跨论文的写作规律

1. **好的引言不是只从“大背景”走到“我们提出”。** 中间必须出现明确的失败机制、信息假设或控制约束；例如误差累积、短时域状态初始化、标记遮挡后的对应歧义。
2. **分类应服务于一个问题。** Yu按形状表示，AFT按模型与优化，Zheng按动态/传感/状态；我们按“怎样获得控制相关状态”分类更合适。
3. **实验要和中心句成对。** 宣称减少传感→减少/改变观测；宣称历史有用→配对历史与强RNN；宣称及时→端到端分布；宣称控制有效→真实执行，不只预测loss。
4. **作者的形容词不能替代数值。** AFT称real-time但这里约2.5 Hz；Schäfke的NMPC为5 Hz；Krauss的50 Hz是动力学/执行网格。频率比较必须注明测量边界。
5. **避开不必要的宏大动机。** 本文无需从具身智能或生物认知起笔；遮挡中全身形状任务已经足够形成具体问题。
