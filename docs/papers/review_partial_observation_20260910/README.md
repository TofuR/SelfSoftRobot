## 最接近关系与公平差异

| 工作 | 已有能力与本项目重叠 | 本项目值得检验的区别 | 不能怎样比较 |
|---|---|---|---|
| AFT | 单RGB-D、遮挡形状估计、全身形状闭环；约2.5 Hz形状跟踪 | 单RGB部分边缘直接修正历史状态并传递到动作；联合遮挡闭环验证 | 对方遮挡与控制分节评价，不能自动合并；削去深度/纹理后失败不代表原算法失败 |
| Krauss | 视觉潜动力学、历史递推、真实软臂开环控制 | 接受局部新观测的状态校正及真实动作修订 | 不能说对方没有历史；50 Hz不是在线求解频率 |
| Yu / Almanzor | 全身形状视觉控制、可解释表示/手绘目标 | 形状不完整时怎样保留控制相关历史 | 不能把全身控制、手绘目标或可解释几何当首次 |
| Chen / Park | 方向迟滞或时间历史建模与补偿 | 同当前输入/方向仍不同的历史效应；部分图像下的校正能力 | 不把方向网络误写成无迟滞，也不只选静态弱基线 |
| Wang | RGB和驱动历史融合、受载全身形状估计 | 可信局部证据、未来预测与实际遮挡闭环控制 | 不把“历史+视觉融合”本身称新颖 |
| Schäfke | RNN隐藏状态及真实NMPC | 在同部分观测与计算预算下比较结构状态与一般递归观察器 | 不拿开环GRU代替强反馈GRU |
| Zheng / Herrmann | 稀疏物理传感的动态状态观察器；有理论或高速实现 | RGB边缘观测下的学习状态与失效边界 | 不说物理方法都慢，也不移植其稳定性/可观测性证明 |

## 建议阅读顺序

1. 先读AFT、Yu、Almanzor，明确哪些形状/视觉控制能力已经存在。
2. 再读Chen、Krauss、Schäfke、Wang，确定历史与反馈基线。
3. 读Zheng、Herrmann，明确欠定状态与观察器论证的严谨边界。
4. 用逐段图谱学习“任务→失败机制→现有路线→具体缺口→方法→验证”的展开，再按本项目问题重写。
5. 最后按实验需要读取约束、鲁棒性、不确定性和主动探索材料；未核条目先查原文身份。

## 维护规则

优先以DOI/arXiv合并文献身份，保留旧笔记别名。`primary_checked`只表示清单写明的章节已核，不表示逐字审阅全篇或独立复现实验。`note_only`不代表论文不存在；`identity_pending`也不代表伪造，只表示不能可靠引用。正式BibTeX应从出版页导出并核对版本，不从暂定题名批量生成。
