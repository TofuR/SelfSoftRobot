## AFT: Appearance-Based Feature Tracking for Markerless and Training-Free Shape Reconstruction of Soft Robots

**aft2025 · G3 · 单RGB-D / 遮挡 / 形状重建 / 全身闭环** · [原文](https://arxiv.org/abs/2511.18215)

核对范围：I；IV-C–G；Table II。写作位置：引言第3段；RW3；重建反馈对照。

| 维度 | 核对后的提要 |
|---|---|
| 问题 | 如何利用自然外观纹理，在免专门训练/无标记条件下恢复软臂形状并用于控制？ |
| 方法/观测 | RGB-D 自然纹理特征、分层匹配和运动学拟合；使用现成视觉模型与初始几何对齐。训练免费指无需为该机器人重新训练，不是不用学习组件。 |
| 实验证据链 | IV-C/D先测跟踪精度、速度与组件消融；IV-E再改变数字遮挡的位置/宽度；IV-G最后分别完成全身形状和末端闭环任务。 |
| 具体结果或可用结论 | IV-C约2.5 Hz；Table II完整方法0.4 s/frame。IV-G全身8点任务：OptiTrack与AFT反馈的平均误差分别1.636±0.972、1.638±1.034 cm；这是对方平台指标。 |
| 边界与公平比较 | 遮挡重建与闭环控制在不同实验节，不能自动合并成物理遮挡闭环验证。RGB-D/自然纹理预算与本项目不同。Table II移除多尺度后形状误差2.73%略低于完整2.85%，不能说所有模块改善所有指标。 |
| 可借鉴的论证 | 把重建、遮挡敏感性、实际控制逐层验证；必须列为直接相关工作，不能声称单相机遮挡形状控制无人研究。 |

核对范围：I；III；IV。写作位置：引言第2/4段；RW1/2；预测与控制指标设计。

| 维度 | 核对后的提要 |
|---|---|
| 问题 | 视觉学习的潜动力学如何支持可靠的软连续体开环控制及目标指定？ |
| 方法/观测 | 视觉潜表示/VON与Koopman或MLP动力学，ABCD等设计；递推状态包含历史效应。 |
| 实验证据链 | 表示与多步预测→真实开环控制→III-C七个重训练消融，用压力优化MAE和图像预测MSE评价；III-D长时静态/外推等为模拟分析。 |

| 可借鉴的论证 | 同时检验表示、预测与控制，而不是从前向精度推断控制成功；自身主张要落在不完整反馈如何改变状态和动作。 |

## Shape-Interpretable Visual Self-Modeling Enables Geometry-Aware Continuum Robot Control

核对范围：I；IV-B–F；V。写作位置：引言第2/3段；RW1；全身任务设计。

| 维度 | 核对后的提要 |
|---|---|
| 问题 | 怎样兼顾形状可解释性、视觉自建模与几何感知控制？ |
| 方法/观测 | 多视角二维Bézier表示与Neural ODE、自模型Jacobian；通过各视角形状实现三维几何控制，不依赖显式三维重建。 |
| 实验证据链 | IV-B–E从调节、轨迹跟踪到避障和自运动；IV-F用12个参考目标比较DVIK；V讨论分割与严重遮挡。 |
