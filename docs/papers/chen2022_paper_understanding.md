# Fully Body Visual Self-Modeling of Robot Morphologies — 论文与代码理解

> 论文：Chen et al., "Full body visual self-modeling of robot morphologies," Science Robotics, Vol. 7, 2022
> 核心思想：通过多视角 RGB-D 相机采集点云，用 SDF（符号距离函数）学习机器人的连续 3D 形状表示，条件化于关节角度，实现自建模、运动规划和损伤检测。
> 项目主页：creativemachineslab.com

---

## 1. 问题定义

给定一个已知运动学结构（关节类型和连接关系）但未知外观几何的机器人：

- **输入**：关节角度 A = (a₁, a₂, ..., aₙ)
- **输出**：机器人完整的 3D 形状（以 SDF 表示）
- **目标**：仅通过视觉观察（多视角点云融合）学习一个条件化的隐式 3D 自模型

核心假设：已知运动学结构（DH 参数），但不知道连杆的实际几何形状。

---

## 2. 方法概述：Dual-Encoder SDF Network

### 2.1 核心公式

模型学习一个条件化的 SDF（Signed Distance Function）：

```
F(C(X), K(A)) = d
```

其中：
- X ∈ R³：3D 查询点
- A：关节角度向量
- C(X)：Coordinate Network 编码的 3D 坐标特征
- K(A)：Kinematic Network 编码的运动学特征
- d：符号距离值（负值 = 机器人表面内部）

### 2.2 双编码器架构

```
                    ┌──────────────────┐
     X (3D坐标) ──→ │ Coordinate Net   │ ──→ C(X) ─┐
                    │ (SIREN MLP)      │           │  拼接
                    └──────────────────┘           ├────→ SDF Head ──→ d (符号距离)
                    ┌──────────────────┐           │
     A (关节角度) ──→│ Kinematic Net    │ ──→ K(A) ─┘
                    │ (SIREN MLP)      │
                    └──────────────────┘
```

**关键设计**：

1. **SIREN 激活函数**：使用 sin(ω₀ · Wx + b) 替代 ReLU，ω₀ = 30
   - 优势：天然适合表示连续几何，梯度始终非零，适合 SDF 的梯度计算
   - 对比：ReLU 网络在零点处不可导，不利于 SDF 梯度优化
2. **双编码器分离**：空间特征 C(X) 和运动学特征 K(A) 分别编码后再融合
   - Coordinate Network 学习与姿态无关的空间几何先验
   - Kinematic Network 学习关节空间到特征空间的映射
3. **SDF 输出**：单一标量值 d，表示到最近表面的距离和内外判断

### 2.3 与本项目的架构对比

| 特性 | Chen 2022 | 本项目 MS-SCNF |
|------|-----------|----------------|
| 3D 表示 | SDF（符号距离） | 密度场 + 骨架 |
| 条件输入 | 关节角度 | 骨架坐标 |
| 相机设置 | 5× RGB-D | 1× RGB |
| 激活函数 | SIREN (sin) | ReLU + EMA |
| 输出 | 距离值 | 密度 + 颜色 |
| 深度监督 | 有（RGB-D 点云） | 无（仅 2D 渲染） |

## 3. 数据采集流程

### 3.1 硬件平台

- **机器人**：WidowX 200 Robot Arm（4-DOF 刚性机械臂）
- **相机**：5 × Intel RealSense D435i RGB-D 相机
  - 环绕机器人布置，覆盖正面、两侧、顶部等多个视角
  - 每个相机同时提供 RGB 图像和深度图
- **计算**：单块 Nvidia 2080 Ti

### 3.2 数据规模

| 数据类型 | 数量 | 说明 |
|---------|------|------|
| 仿真数据 | ~10,000 点 | PyBullet 仿真，精确 3D GT |
| 真实数据 | 7,888 帧 | 5 相机 × 多姿态，含深度 |
| 总训练时间 | 数小时 | 单 2080 Ti |

### 3.3 点云融合

1. 5 个 RGB-D 相机分别获取深度图
2. 利用相机内参和外参，将深度图反投影为 3D 点云
3. 将所有相机点云融合到统一世界坐标系
4. 对融合点云进行去噪和下采样
5. 融合后的点云作为 SDF 的训练目标

### 3.4 对本项目的启示

Chen 2022 使用 5 个 RGB-D 相机解决了深度歧义问题。对于我们的软体机器人：
- **最少需要 2 个相机**：从不同轴向观察即可消除单视角深度歧义
- **exp3 实验验证**：多视角约束下 X 轴误差占 41.1%，说明不同视角对误差约束的贡献不同
- **RGB-D 的价值**：深度图直接提供 3D 监督信号，比纯 2D 渲染损失高效得多

## 4. 训练流程

### 4.1 损失函数

SDF 训练使用 Chamfer-L1 距离：

```
L = Chamfer-L1(P_pred, P_gt)
```

其中：
- P_pred：从 SDF 提取的等值面点云（通过 Marching Cubes）
- P_gt：多视角融合的真实点云

Chamfer-L1 距离计算：
```
Chamfer(P₁, P₂) = (1/|P₁|) Σ_{x∈P₁} min_{y∈P₂} ||x-y||₁
                 + (1/|P₂|) Σ_{y∈P₂} min_{x∈P₁} ||x-y||₁
```

### 4.2 SDF 正则化

为确保 SDF 质量：
- **Eikonal 约束**：||∇F(x)|| = 1，保证 SDF 梯度为单位向量
- 这使得 SDF 可以用于梯度优化（运动规划中的逆运动学）

### 4.3 训练策略

| 参数 | 值 |
|------|-----|
| 模型大小 | 1.1 MB |
| 训练硬件 | Nvidia 2080 Ti |
| SIREN ω₀ | 30 |
| 训练数据 | 10K sim + 7888 real |

### 4.4 对比：本项目训练设置

| 特性 | Chen 2022 | 本项目 |
|------|-----------|--------|
| 损失函数 | Chamfer-L1 (3D) | MSE + 渲染损失 (2D) |
| 深度监督 | 直接 3D 点云 | 无 |
| 正则化 | Eikonal | 骨架约束 |

## 5. 3D 提取与表示

### 5.1 Marching Cubes 提取网格

给定关节角度 A，提取机器人 3D 形状：

```
1. 在 3D 空间均匀采样查询点网格
2. 对每个点计算 F(C(X), K(A)) 得到 SDF 值
3. 使用 Marching Cubes 算法提取等值面 (d = 0)
4. 输出三角网格 (mesh)
```

### 5.2 SDF 的优势

1. **连续表示**：无限分辨率，可查询任意点的距离
2. **可微**：支持梯度优化，直接用于逆运动学
3. **紧凑**：1.1MB 模型参数即表示所有姿态的完整形状
4. **内外判断**：SDF 正负直接区分机器人内外

### 5.3 仿真与真实精度差距

- **仿真**：SDF 重建与 GT 非常接近（精确 3D 监督）
- **真实**：存在精度差距，主要来源：
  - RGB-D 深度图噪声（RealSense D435i）
  - 多相机标定误差
  - 环境光照影响深度估计

## 6. 运动规划

### 6.1 梯度优化逆运动学

利用 SDF 的可微性，通过梯度下降求解逆运动学：

```
给定：目标端点位置 p_target
求解：关节角度 A*

优化过程：
1. 初始化 A₀
2. 前向计算：得到 SDF 表面 → 提取端点位置 p(A)
3. 计算损失：L = ||p(A) - p_target||²
4. 反向传播：∂L/∂A → 更新 A
5. 重复直到收敛
```

**关键**：SDF 的梯度 ∂F/∂X 天然指向表面法线方向，可以用于形状分析和碰撞检测。

### 6.2 RRT* 路径规划

```
1. 在关节空间中随机采样
2. 用学到的自模型进行碰撞检测（查询 SDF 值）
3. 构建快速随机树 (RRT*)
4. 使用 shortcut 进行路径平滑
```

实验结果：
- 100 个规划任务
- 平均规划时间 2.92 秒
- 成功率 > 95%

### 6.3 运动学网络泛化

Kinematic Network 的泛化能力优于直接坐标预测：
- 在未见的关节角度组合上仍能准确预测形状
- 表明 K(A) 捕获了关节空间的连续结构

## 7. 损伤检测与恢复

### 7.1 损伤检测

通过比较预测和观测的差异来检测损伤：

```
1. 给定当前关节角度 A
2. 用模型预测机器人形状 SDF_pred
3. 通过相机获取实际点云 P_observed
4. 计算误差 gap = dist(SDF_pred, P_observed)
5. 若 gap > 阈值 → 检测到损伤/形态变化
```

### 7.2 损伤定位

```
1. 检测到损伤后，推断"哪个关节/连杆受损"
2. 方法：比较各关节角度的推断值与实际值
3. 关节角度不匹配 → 定位到具体关节
```

### 7.3 损伤恢复

```
1. 收集少量损伤后的数据 (~50 个样本)
2. 在原模型基础上微调 100 epochs
3. 恢复时间：~8.13 分钟
4. 恢复后的模型重新准确预测变形后的形状
```

**意义**：模型可以快速适应形态变化，这对于长期运行的机器人至关重要。

## 8. 关键洞察总结

1. **多视角 RGB-D 是 3D 精度的关键**：5 个 RGB-D 相机提供直接 3D 监督，避免了 2D→3D 的歧义。本项目的 exp2 和 exp3 实验也证实了这一点（2D/3D MNE 比值 4.96x）

2. **SDF 是理想的机器人自建模表示**：连续、可微、紧凑（1.1MB）、天然支持内外判断和碰撞检测。对比本项目的密度场表示，SDF 更适合运动规划和碰撞检测

3. **SIREN 激活函数对几何建模至关重要**：sin 激活保证梯度始终非零，比 ReLU 更适合表示平滑的 3D 表面。本项目可以考虑引入 SIREN 替代当前的 ReLU 激活

4. **双编码器设计值得借鉴**：空间特征和运动学特征分离编码，降低了学习难度。本项目已有类似的 SkeletonConditionedDensity 设计，但可以进一步强化运动学分支

5. **快速损伤恢复的实用性**：50 个样本 + 8 分钟微调即可恢复模型精度，这对于实际部署的软体机器人非常重要（软体机器人容易变形和损伤）

6. **已知运动学 vs 未知运动学**：Chen 2022 假设已知运动学结构（DH 参数），这对于软体机器人不适用。我们的方法需要同时学习运动学和几何——这是一个更大的挑战

7. **对本项目的直接启示**：
   - **多相机方案**：Chen 2022 的 5 相机方案验证了多视角的可行性，我们可以从双相机起步
   - **RGB-D 价值**：深度监督信号比纯 2D 渲染损失高效得多（exp2: 4.96x 精度差距）
   - **SDF 替代密度场**：考虑将当前的密度场输出替换为 SDF，以支持碰撞检测和梯度优化
   - **SIREN 激活**：可以尝试引入 SIREN 激活函数提升几何建模质量
