# 稀疏观测下 OpenLoop 软臂自建模：论文实验方案

> 状态：实验设计基线，供后续训练、实机采集和论文组织统一使用
> 主线模型：`OpenLoopTransitionModel`
> 核心场景：观测一次软臂形态，随后在遮挡或低观测频率下，仅根据动作序列开环预测一段时间
> 关联实现：`scripts/evaluation/eval_horizon.py`、`scripts/control/inverse_plan.py`、`scripts/evaluation/viz_control.py`
> 实机落地：[`real_robot_validation_workbench_todo.md`](real_robot_validation_workbench_todo.md)

---

## 1. 论文要回答的核心问题

本项目不以“把单步预测误差继续压低”为最终目标，而要验证以下完整因果链：

1. **机制层**：软体机器人的路径依赖是否要求模型保留足够长的动作历史；OpenLoop 训练和迟滞状态是否能把这种历史转化为稳定的多步形态预测。
2. **任务层**：预测模型是否足够准确、可微且稳定，能够从 IK / 逆规划得到满足压力与速率约束的可执行动作序列。
3. **应用层**：多个基础任务组合后，机器人能否在稀疏观测、局部遮挡和受限空间中完成真实操作流程。

论文的中心主张应限定为：

> 给定一个形态观测作为绝对状态锚点，history-aware OpenLoop 状态转移模型能够在有限时间内预测软体机器人的后续全身形态，并支撑路径依赖的动作规划与稀疏观测操作。

这里的“OpenLoop”表示窗口内部不再读取真实形态；窗口开始允许一次观测。它不是无限时间、完全无初始状态的预测。

### 1.1 三个层级的准确含义

- **机制层**不是“模型组件逐个拆掉”，而是发现由材料与观测条件决定的规律：形态如何保留加载历史、需要多少历史才能消除预测和 IK 歧义、视觉中断多长时间后状态不再可靠。
- **任务层**不是任意选一个控制指标，而是机制成立后才获得的单项能力：在相同目标但不同加载历史下求出正确动作；在一段不可见时间内预测整条软臂轨迹；在稀疏检查点之间连续传播并重新锚定状态。
- **应用层**不是把多个曲线画在一起，而是在外部视觉天然不可用的真实场景中，把这些单项能力按顺序组合为完整操作流程。

### 1.2 从科学问题到新增能力

| 原有障碍 | 为什么已有方法做不到 | 本项目解决的关键 | 解锁的任务 | 对应应用条件 |
|---|---|---|---|---|
| 粘弹性迟滞 | 当前压力到形态不是单值映射；准静态 IK 忽略加载路径 | 估计有效历史并建立 history-conditioned 状态转移 | 路径依赖形态 IK | 循环、变速、连续动作而非每步等待稳态 |
| 视觉遮挡/低频观测 | 视觉伺服失去状态反馈后无法继续；纯动作查表会漂移 | 一次状态锚定后进行有限窗口 OpenLoop 预测 | 不可见区间的状态传播与动作规划 | 外部相机无法看到机器人全身 |
| 连续体全身可能碰撞 | 末端到达不代表中段安全 | 预测每个时刻的全身骨架/形态 | 不可见区间的全身约束轨迹规划 | 管腔、挡板后方、设备内部等受限空间 |
| 长流程超过单窗口视野 | 无界 OpenLoop 累计误差不可控 | 在稀疏检查点重新观测和重锚定 | 多窗口计划—执行—重锚定 | 只有少数观察口或检查点 |

因此，论文应用必须同时需要“历史依赖、视觉中断和全身约束”中的至少两项，最好三项都具备。若一个场景能被普通视觉伺服、静态压力查表或末端 IK 轻易完成，它只能作为调试任务，不能作为本工作的代表应用。

## 2. 实验变量：不要混淆 H 与 K

### 2.1 动作历史长度 H

`H` 是每次状态转移可访问的显式动作历史长度：

```text
a[t-H+1 : t] + predicted state + latent z -> predicted next state
```

它回答：**为了表达材料记忆和路径依赖，需要保留多长的动作历史？**

`H=1` 只移除了显式动作窗口，并不等价于整个模型完全无记忆，因为状态 `s` 和潜变量 `z` 仍在窗口内递推。因此 H 消融必须与 `z` 消融结合解释，不能简单把 `H=1` 称为“无记忆模型”。

### 2.2 开环长度 K

`K` 是两次真实形态观测之间连续使用模型自身预测的步数：

```text
observe s0 -> predict s1 -> ... -> predict sK -> observe again
```

它回答：**在给定误差容限下，机器人多久观察一次仍然可用？**

### 2.3 训练长度 K_train 与测试长度 K_eval

需要进一步区分：

- `K_train`：训练时反向传播展开的 OpenLoop episode 长度；
- `K_eval`：测试或部署时实际自由运行的长度。

主结果使用与部署一致的 `K_train`；视野实验可以让同一模型在多个 `K_eval` 下截断运行。超过 `K_train` 的结果属于时域外推，应单独标明，不能与训练范围内结果混合。

## 3. 总体实验结构

| 层级 | 核心问题 | 最终证据 |
|---|---|---|
| 机制层 | 历史、状态锚点和观测间隔何时足以确定后续形态与逆解 | 物理记忆时间、IK 临界历史、H–K 可行域、迟滞回线与误差传播 |
| 任务层 | 能否在视觉中断期间求出并执行路径依赖、全身安全的动作轨迹 | IK 可行率、不可见轨迹误差、约束满足率、预测—执行差距 |
| 应用层 | 能否靠少数观察口完成受限空间中的多阶段操作 | 完整流程成功率、观测预算、碰撞/越界、完成时间和重复稳定性 |

三层必须顺序推进。机制精度不达标时，任务失败无法归因；任务层尚未实机闭环时，不应直接宣称应用成功。

## 4. 机制层实验

### M0. 数据划分与评估协议

#### 目的

确保结果测量的是未见轨迹上的预测能力，而不是同一连续序列相邻帧之间的信息泄漏。

#### 要求

- 按完整采集序列划分 train / validation / test，不按帧随机划分；
- 测试序列在确定模型和超参数前锁定；
- 归一化参数只由训练集计算；
- 至少覆盖 loading、unloading、hold、动作反转和不同压力变化速率；
- 多腔道阶段额外留出未见过的腔道组合；
- 所有方法使用相同数据、训练预算、模型容量和随机种子集合；
- 统计以“轨迹/窗口”为独立样本，不把连续帧当作独立重复试验。

当前单条 1-DOF 序列适合开发与预实验，但论文主结论需要多条独立动作序列和独立实机重复。

#### 主指标

- 全身平均节点误差与 p90；
- 每段末端 NDI 误差与 p90；
- 相对臂长误差；
- open-loop error-by-k 与误差曲线面积 `AUC_K`；
- 给定容限下的 `K_safe`；
- `z` 范数和数值发散率。

像素误差用于免标定 2D 状态，毫米误差用于 NDI 末端验证。若论文声称 3D 全身预测，需要额外的多相机三角化真值，不能用末端 NDI 代替整条中心线真值。

### M1. 物理记忆时间与模型历史长度：历史长度响应曲线

#### 科学问题

软体机器人对过去动作的依赖有多长？增加历史长度何时不再带来显著增益？

#### H 的选择原则

不预设 `H=40` 是正确值。首先通过阶跃—保持—释放和三角波实验估计物理响应时间 `T_phys`：

- 阶跃后形态变化衰减到峰值的 5% 以内；或
- 释放后回弹进入稳态带；或
- 动作—形态滞后相关下降到预设阈值。

然后把时间换算为采样步数，选取近似对数尺度：

```text
HΔt ∈ {Δt, 0.125T_phys, 0.25T_phys, 0.5T_phys, T_phys, 2T_phys}
```

其中 `H=1` 作为最短历史端点。若预实验尚无法稳定估计 `T_phys`，首轮可使用：

```text
H ∈ {1, 5, 10, 20, 40, 80}
```

但最终论文应换算成秒，并解释其相对于材料响应时间的意义。

#### 控制变量

- 全部模型使用 OpenLoop 训练；
- 固定 `K_train`、`K_eval`、网络宽度、`z_dim`、损失和训练预算；
- 每个 H 使用相同的数据划分和随机种子。

#### 不只看精度：历史利用指标

在相同当前压力附近配对 loading / unloading 样本，计算：

```text
R_path = predicted loading-unloading shape gap
         / ground-truth loading-unloading shape gap
```

- `R_path ≈ 0`：模型把不同历史压成同一个状态；
- `R_path ≈ 1`：模型恢复了真实路径差异；
- `R_path > 1`：模型夸大迟滞。

同时比较预测和真实的压力—末端位移迟滞回线面积、方向和相位差。

#### 结论形式

绘制误差、`R_path` 和迟滞回线误差随 H 的变化，定义模型的最小充分历史长度：

```text
H_model* = 达到最优性能 95%，且继续增加 H 收益不显著的最短历史
```

`H_model*` 是模型和数据条件下的操作量，不能自动等同于材料内禀记忆时间。只有当它与独立测得的 `T_phys/Δt` 一致，并且随动作速率、材料或结构变化呈合理缩放时，才可以进一步讨论物理临界记忆 `T*`。单一机器人上的结果应诚实表述为“有效历史需求”，而不是普适材料常数。

### M2. 稀疏观测能力：K 与可用预测视野

#### 科学问题

给定一个真实形态锚点，模型可以在不再观察的情况下可靠预测多久？

#### 实验

使用 M1 得到的 `H_model*`，对同一 OpenLoop 模型评估：

```text
K_eval ∈ {1, 5, 10, 20, 40, 80, ...}
```

K 的上限应覆盖从“几乎持续观察”到“明显超过可用视野”的范围，以便观察完整失效边界。所有步数同时换算为秒。

主实验使用一个面向目标部署区间训练的 `K_train`，在 `k≤K_train` 内得到连续误差曲线；另选短、中、长三个 `K_train` 做训练视野消融，判断更长展开是否真正延长 `K_safe`。

#### 结果

- `error(k)` 与置信带；
- `K_safe(ε)`，其中 ε 由任务容差确定；
- 观测频率—误差 Pareto 曲线；
- `z_norm(k)` 与发散率；
- 每段、每节点的误差传播位置。

核心结论不是“某个 K 的误差是多少”，而是：

> 为保持给定任务精度，最少需要多高的观测频率。

#### H–K 可行域

H 和 K 最终不是两个互不相关的超参数：历史不足会让局部转移本身欠定，K 过长会让小误差持续反馈。完成单变量扫描后，应在 `H_model*` 附近选择 3–4 个 H，并与多个 K 组合，绘制：

```text
feasible(H, K; ε_task) =
    1, 若窗口内全身误差和任务约束始终小于阈值
    0, 否则
```

这张相图给出可操作区域：在某种材料、动作速率和任务容限下，至少保留多少历史、最多允许多久不观察。它比独立报告若干精度数字更接近论文的科学结论。

#### 非周期遮挡

固定 K 对应周期性观察，但真实遮挡往往是长度不一的连续缺失段。最终模型还应在相同总观测预算下比较：

- 周期性稀疏观测；
- 随机单帧缺失；
- 连续 burst occlusion；
- 只在少数物理检查点观察。

主指标按“距最近一次有效观测的时间”聚合，以验证结论依赖的是不可见持续时间，而不是恰好采用固定窗口切分。

### M3. OpenLoop 训练是否解决暴露偏差

#### 科学问题

模型在部署时接收自身预测状态，针对这种输入分布训练是否必要？

#### 对比

使用完全相同的网络、初始化数据和损失：

1. `tf=1`：窗口内始终输入真实状态；
2. `tf=0`：首帧是真实种子，之后输入自身预测，即主方法；
3. 仅当 `tf=0` 训练不稳定时，再加入有明确理由的退火版本，不把所有 schedule 都变成实验。

三个模型都使用相同的纯 OpenLoop rollout 测试。

#### GT-state 诊断

对已经完成 OpenLoop 训练的同一个 checkpoint，额外运行“每一步输入真实前一状态”的诊断。它不代表部署，也不作为主结果，只用于分解：

```text
OpenLoop 总误差 = 局部状态转移误差 + 误差反馈后的累计效应
```

若 GT-state 单步误差低而 OpenLoop 快速漂移，问题在稳定性；若两者都高，问题在局部动力学建模。

### M4. 迟滞潜变量 z 的必要性

#### 科学问题

显式动作历史和可见形态之外，是否还需要一个随路径演化的潜在材料状态？

#### 最小充分消融

- 完整模型；
- 去掉 `z` 或将 `z` 每步重置，使其不能跨步携带信息。

保持 H、K 和其他参数不变。主测试使用：

- 相同压力的 loading / unloading 配对；
- 动作反转；
- 不同速率到达同一压力；
- 相似可见初始形态、不同前序历史的窗口。

如果完整模型只改善平均误差，却不能改善路径区分和迟滞回线重现，则不能声称 `z` 学到了迟滞机制。

### M5. 分数阶记忆的主张门槛

只有当论文把“分数阶长记忆”作为方法贡献时才执行本实验。

选择一个理论匹配的对照即可：

- 分数阶幂律记忆：长尾衰减；
- 多尺度 EMA：指数衰减。

两者匹配参数量、H、K 和训练预算。比较 `H_model*`、迟滞回线重现和长程 `K_safe`，而不是罗列所有 GRU/TCN/Transformer。若分数阶模型没有稳定、可解释的增益，则论文应把编码器降为实现选择，不作为核心贡献。

---

### M6. 最小基线集合

论文主文只保留能回答科学问题的基线：

| 基线 | 回答的问题 |
|---|---|
| Copy / hold-last-state | 模型是否优于“不发生变化”的平凡预测 |
| 最短显式历史 H=1 | 历史窗口是否必要；注意它仍保留递推状态与 z |
| GT-trained 同结构模型 | OpenLoop 训练是否必要 |
| 无 z 模型 | 潜在迟滞状态是否必要 |
| EMA（条件性） | 仅在声称分数阶记忆时验证幂律记忆价值 |

早期 MSTNF、C-MSTNF、MS-SCNF 属于项目发展过程，不进入当前论文主比较。SAM/raw、节点数、`tip_fix` 和清洗规则固定为数据管线，不作为模型消融；除非论文另行声称感知鲁棒性。

## 5. 任务层实验：科学机制解锁了什么控制原语

单目标到达、形态匹配可以用于调通优化器，但它们本身并不证明本项目不可替代。任务层主实验必须在没有历史或持续视觉时无法被同样完成。

### T0. 所有规划任务的三道关口

每个任务必须依次通过：

1. **模型内可行**：优化收敛，整段预测轨迹满足目标，动作满足压力和变化速率约束；
2. **实机可执行**：动作序列能完整下发，无通信失败和安全截断；
3. **物理上成功**：实机 NDI/隐藏真值达到目标，且中间轨迹也满足约束。

必须报告 prediction-to-execution gap：

```text
模型预测的形态轨迹 - 实机执行后的形态轨迹
```

只比较规划末态不足以证明“可行运动轨迹”，因为优化器可能在中途穿过物理障碍、产生不可实现的快速压力变化，或利用模型误差获得虚假解。

### T1. 路径依赖形态 IK：同一目标为何需要不同动作

#### 这是哪项新增能力

传统静态 IK 把逆映射写成 `target_shape -> action`。迟滞下正确问题应是：

```text
current shape + recent loading history + target shape
    -> feasible future action sequence
```

#### 实验构造

- 让机器人从 loading、unloading、循环加载和不同速率历史到达相近初始形态；
- 对每组历史指定相同目标末端或相同目标全身形态；
- history-aware planner 与 H 不足、无 z 或准静态 planner 分别求解；
- 将每条动作序列在对应的真实初始历史上执行，并交换到错误历史上交叉执行。

#### 决定性证据

- 正确动作序列是否随历史系统变化；
- 同一动作在错误历史上是否失败；
- 随已知历史长度增加，IK 歧义集和失败率是否下降；
- 消除歧义所需的 `T_IK*` 是否与 M1 的 `H_model*`、独立 `T_phys` 同量级。

这里的核心不是“planner 比 do-nothing 更近”，而是证明路径历史是逆解成立所必需的条件。

### T2. 不可见区间的全身约束轨迹规划

#### 这是哪项新增能力

视觉伺服只能在能观察时纠正状态；末端 IK 只约束终点。OpenLoop 全身模型应允许在 K 步不可见区间内，同时预测和约束每个中间形态。

#### 任务

在窗口开始观察一次软臂，随后关闭视觉输入。规划动作序列，使机器人：

- 末端到达目标区域；
- 整条中心线不进入障碍/禁区；
- 每段末端或指定节点通过给定门区；
- 全程满足压力和压力变化速率限制。

#### 对比

- history-aware OpenLoop 全身规划；
- endpoint-only 规划：检验“末端到达但身体碰撞”；
- H 不足/准静态规划：检验迟滞导致的轨迹偏离；
- 高频视觉反馈作为信息充分上界，而不是最终部署方法。

#### 指标

- 实机目标到达率；
- 不可见区间全身无碰撞率；
- 最小安全间距；
- 轨迹最大误差而非只有末态误差；
- 动作和速率约束违反；
- 不同遮挡长度 K 下的任务成功率。

### T3. 稀疏检查点之间的重锚定与长流程推进

#### 这是哪项新增能力

单个 OpenLoop 窗口只能覆盖有限时间。要完成超过 `K_safe` 的操作，必须把多个“观察—预测—执行”窗口连接起来，而不能假设一次预测到终点。

#### 任务

给定少数允许观察的检查点：

```text
observe/re-anchor
  -> plan and execute through invisible interval
  -> reacquire at checkpoint
  -> correct accumulated state error
  -> plan next interval
```

比较固定间隔检查点、根据环境设置的非均匀检查点和仅初始观察。评价长流程成功率、每次重锚定消除的误差、观察次数以及失败发生在哪个窗口。

T3 是机制层 K 视野与应用层长距离操作之间的桥梁。

### T4. 调试性基元的定位

以下实验仍然需要，但只作为任务链路的单元测试或成功阈值标定：

- 单目标末端到达：验证逆规划和 NDI 评价链路；
- 全身目标形态匹配：验证模型不只是末端回归器；
- do-nothing / GT-action replay：分别作为平凡下界和已记录目标的可达上界。

它们不应独立承担论文应用贡献。

## 6. 应用层实验：选择只有本科学问题解决后才可完成的场景

### A0. 应用选择准则

代表应用应同时满足：

1. 外部视觉在操作过程中天然中断，而不是为了实验人为挡住一台本可继续使用的相机；
2. 连续动作和循环加载使准静态 action-to-shape / IK 不再可靠；
3. 中段碰撞或形态约束重要，不能只控制末端；
4. 操作时间超过一个 OpenLoop 窗口，需要稀疏重观测；
5. 当前平台能够诚实实现，不依赖尚未具备的抓取、接触力控制或组织安全模型。

按照这些条件，当前最合适的主应用不是泛化的“抓取”，而是：

> **双段软臂在不透明弯曲通道/设备盲区中的稀疏观测巡检。**

### A1. 主应用：不透明弯曲通道中的稀疏观测巡检

#### 为什么以前无法实现

- 进入不透明通道后，外部相机无法持续看到全身，视觉伺服中断；
- 通道转弯需要连续加压、卸压和动作反转，准静态压力查表不能预测真实形态；
- 即使末端到达下一个检查点，中段仍可能撞壁；
- 一次无界 OpenLoop 无法可靠覆盖整个通道。

#### 场景设计

建立包含两个或多个弯段、挡板和少数观察口的通道。双段六腔道软臂携带简单视觉标记或探测头，不要求抓取器。实验分两套环境：

- **透明数字孪生通道**：外部相机和 NDI 全程记录真值，但算法只接收指定检查点观测；
- **不透明验证通道**：复现真实视觉条件，算法行为与透明试验一致，NDI/内部记录仅作独立评价。

透明环境不是让模型持续看，而是让研究者获得遮挡期间的隐藏真值。

#### 完整操作链

```text
入口观察并恢复当前形态/历史状态
  -> history-conditioned IK 规划第一弯段
  -> 在不可见区间执行全身约束轨迹
  -> 在观察口重锚定
  -> 根据新状态规划第二弯段
  -> 到达巡检点并保持探测姿态
  -> 按新的加载历史规划回撤
  -> 返回入口
```

这不是多个普通到达的拼接：每一段的逆解依赖上一段留下的材料状态，回撤动作也不等于进场动作的简单反向。

#### 决定性对比

- proposed：history-aware OpenLoop + 稀疏重锚定 + 全身约束；
- 无历史/历史不足：检验路径依赖失败；
- endpoint-only：检验中段碰撞；
- 仅初始观察：检验无界累计误差；
- 高频观察：信息充分性能上界。

#### 评价

- 完成“进入—巡检—回撤”全流程的成功率；
- 到达每个检查点和最终巡检点的误差；
- 遮挡期间轨迹误差、最小壁面间距和碰撞次数；
- 总观测次数、重规划次数和完成时间；
- 压力/速率安全违反；
- 不同加载历史下的重复稳定性；
- 相对于高频观察，观测减少比例与成功率损失。

### A2. 可迁移场景与诚实边界

同一能力链可迁移到设备挡板后的探测、航空发动机/管路检查、灾害缝隙探索和腔内连续体机器人导航。但当前无接触力、组织安全和复杂环境交互模型，因此这些只能作为潜在领域，不应直接声称已经解决。

论文主实验聚焦一个做扎实的不透明通道场景即可。只有在硬件和数据充分时，再增加“设备挡板后的目标探测”作为第二应用，而不是堆叠多个相似演示。

### A3. 应用层的核心结果：观测预算—成功率边界

改变可用观察口数量和位置：

```text
高频观察 -> 多检查点 -> 少检查点 -> 仅初始观察
```

绘制完整任务成功率、碰撞率和完成时间随观测预算的变化，并与机制层 H–K 可行域对应。最终应用结论应是：

> 在满足给定全身安全和任务成功率的前提下，history-aware OpenLoop 自建模把持续视觉需求降低到多少个离散观察点。

## 7. 多腔道与双段验证

六腔道不是简单把 `action_dim` 从 1 改为 6；它引入同段腔道竞争和跨段耦合。实验数据至少覆盖：

- 单腔道激励，用于识别基本作用方向；
- 同段双腔道和三腔道组合；
- 第一段单独动作、第二段单独动作；
- 两段协同动作；
- 动作反转和循环加载；
- 未见过的跨段动作组合。

测试集应专门保留部分动作组合，验证组合泛化。随机帧划分无法检验这种能力。

任务层先在单段/低维动作上证明规划闭环，再进入双段六腔道。应用层应以六腔道为最终平台，因为受限空间中的全身形态控制需要两段协同。

## 8. 推荐执行顺序与通过条件

### Phase I：机制成立

1. 补充独立序列和测试 session；
2. 完成 H 响应曲线并确定 `H_model*`，与 `T_phys` 对照；
3. 完成 K 视野曲线并确定任务相关 `K_safe`；
4. 完成 OpenLoop-vs-GT-trained 和有无 z 消融；
5. 只有声称分数阶贡献时再比较 EMA。

通过条件：主模型在目标 K 内稳定优于 Copy 和 H=1，并能重现 loading/unloading 路径差异。

### Phase II：任务可行

1. 用末端到达和全身形态匹配调通规划—执行链路；
2. 完成不同初始历史下的路径依赖形态 IK；
3. 完成不可见区间的全身约束轨迹规划；
4. 完成多个稀疏检查点之间的重锚定；
5. 所有规划轨迹进行实机 replay，报告完整 prediction-to-execution gap。

通过条件：history-aware 方法在对应真实初始历史上生成可执行轨迹；历史不足方法出现可重复的路径依赖失败；主方法在不可见区间达到预设成功率并满足全身安全限制。

### Phase III：应用闭环

1. 建立透明真值通道和同构不透明验证通道；
2. 完成“进入—多弯段推进—巡检保持—回撤”流程；
3. 扫描观察口数量、位置和最长不可见区间；
4. 多次独立重复并记录历史依赖、碰撞、漂移和重锚定失败。

通过条件：在显著减少观测的条件下，全流程成功率接近高频观测上界；机制层 H–K 可行域能够预测应用中的成功/失败边界。
