## 二、逐实验分析

### 2.1 exp2: 3D GT vs 纯 2D — 最关键的对比

**数据**:

| 指标 | Model A (3D GT) | Model B (2D only) | 比值 |
|------|-----------------|-------------------|------|
| MNE | 0.0611 m | 0.3028 m | **4.96x** |
| Tip Error | 0.1582 m | 0.5534 m | **3.5x** |
| X 误差 | 0.0421 m | 0.1001 m | 2.4x |
| Y 误差 | 0.0315 m | 0.0813 m | 2.6x |
| Z 误差 | 0.0200 m | 0.2452 m | **12.3x** |

**图表分析** (`comparison.png`, `axis_errors.png`):

- **comparison.png**: 训练曲线显示 Model A 的 loss 在 40 epochs 内稳定下降；Model B 的 loss 下降更慢且震荡更大。指标柱状图清晰显示 Model B 在所有指标上都差，尤其是 MNE 和 Tip Error。逐轴误差柱状图中 Z 轴的差异最为悬殊。

- **axis_errors.png**: 三个直方图分别展示 X/Y/Z 的误差分布。
  - X 轴: Model B 的误差分布明显更宽，均值偏离 0 更远
  - Y 轴: 类似 X，Model B 更分散
  - **Z 轴: Model B 的误差分布极其宽阔，从 -0.6 到 +0.4m，而 Model A 集中在 ±0.05m 以内**

**结论与推理**:

1. Z 轴误差从 0.020m 暴涨到 0.245m（**12.3x**），占总误差的比重从 33% 跃升到 **81%**
2. 原因：相机从 X 轴方向（1.5, 0, 0.5）拍摄，Z 轴是**与相机视线几乎平行的方向**
3. 体渲染沿射线积分时，沿 Z 方向的偏移只轻微改变遮挡关系 → 渲染 loss 对 Z 方向位移的梯度极弱
4. **结论：单视角 2D 渲染 loss 对深度方向的约束力严重不足，差距在 10 倍以上**

### 2.2 exp5: 迟滞分析 — HA-EMA 有效性验证

**仿真器迟滞验证** (`sim_hysteresis_loops.png`):

三角波驱动实验结果：在三个频率（0.5/1.0/2.0 Hz）下，扭矩-tip_x 曲线形成了**可观测但非常窄的迟滞环**。

- 迟滞环确实存在，说明 PyElastica 的阻尼系数产生了一定程度的粘弹性
- 但环非常窄，意味着加载和卸载路径的差异很小
- 频率越高环越宽，符合粘弹性材料的频率依赖特性

**HA-EMA vs StandardEMA 对比**:

| 指标 | StandardEMA | HA-EMA | 差异 |
|------|-------------|--------|------|
| MNE | **0.0226 m** | 0.0234 m | +3.3% (略差) |
| Tip Error | **0.0568 m** | 0.0581 m | +2.3% (略差) |
| Smoothness | 0.00513 | **0.00439** | -14.4% (更光滑) |

**图表分析** (`ema_comparison.png`, `learned_parameters.png`):

- **ema_comparison.png**: 训练曲线几乎重合，两者的 train loss 和 test loss 走势一致。柱状图指标对比中，MNE 和 Tip Error 的差异极小（柱子高度几乎相同），Smoothness HA-EMA 略优。
- **learned_parameters.png**: 显示了学习到的 decay rates。HA-EMA 有 loading/unloading 两组不同的 decay rate，但数值非常接近，说明网络学到的方向区分很小。

**结论与推理**:

1. **HA-EMA 没有显著优于 StandardEMA**（MNE 差 3.3%，在误差范围内）
2. HA-EMA 的 Smoothness 略好（-14.4%），说明方向门控确实在起作用，产生了更光滑的骨架
3. 但总体差异不大的**根本原因是仿真器的迟滞效应本身太弱**
4. 从 `sim_hysteresis_loops.png` 可以看出，迟滞环面积非常小 → 加载/卸载路径差异不大 → 标准 EMA 已经足够处理这种微弱差异
5. **如果仿真器的迟滞更显著（如真实世界材料），HA-EMA 的优势可能会体现出来**

**决策影响**：
- 方向 B（迟滞建模）的核心假设——"迟滞是软体机器人的重要特性"——在当前仿真器中**未得到充分验证**
- 需要要么：(a) 增大仿真器的阻尼/粘弹性参数，(b) 在真实机器人上验证

### 2.3 exp1: 纯 2D 骨架学习

**数据**: MNE=0.3129m, Tip=0.5884m

**图表分析** (`skeleton_comparison.png`):

骨架对比图中，6 个样本的 GT（蓝色）和 Pred（红色）骨架对比清晰显示：
- 预测骨架的形状大致正确（弯曲方向基本一致）

### 2.4 exp3: 多视角分析

**数据**: X误差41.1%, Y误差32.2%, Z误差26.7%

即使是**有 3D GT 训练的模型**，深度方向的误差仍然最大（41.1%），说明：
- 深度歧义不仅是训练信号的问题，也是渲染本身的固有局限
- 多视角约束对**所有模型**（无论训练方式）都有价值

---

### 2.5 exp4: 域随机化

**结果有 bug**: 所有噪声水平的 MNE 完全相同。

原因已在方向 D 分析中指出：MNE 是 3D 骨架误差，不受图像噪声影响。需要用渲染 PSNR 评估（exp4b）。

### 2.6 nb06 & nb07: 早期探索

| 实验 | 基线 MSE | 实验 MSE | 基线抖动 | 实验抖动 | 结论 |
|------|---------|---------|---------|---------|------|
| nb06 线性变形 | 0.0192 | 0.0241 (+26%) | 0.0073 | 0.0021 (**-71%**) | MLP非线性必要, 但线性更光滑 |
| nb07 课程频率 | 0.0190 | 0.0208 (+10%) | 0.0062 | 0.0107 (+73%) | C2F训练不充分, 反而更差 |

**nb06 推理**: 线性变形虽然精度不够，但时序连续性好得多。MS-SCNF 的骨架先验方案正是在保留 MLP 表达力的同时通过显式骨架约束获得光滑性——这验证了 MS-SCNF 的设计动机。

**nb07 推理**: 课程频率的思路被吸收到 MS-SCNF 的多尺度骨架训练中（coarse→fine），但独立使用时因为训练不充分而失败。

## 三、综合评估

### 3.1 什么已经证实

| 结论 | 证据 | 置信度 |
|------|------|--------|
| 3D GT 监督对骨架精度至关重要 | exp2: 4.96x 差距, Z轴12.3x | **高** |
| 单视角深度方向约束严重不足 | exp1+exp2: Z误差占81%+; exp3: 深度误差41% | **高** |
| MLP非线性对变形场必要 | nb06: 线性精度差26% | **高** |
| MS-SCNF骨架先验设计合理 | nb06+nb07: 隐式变形场失败, 显式骨架成功 | **高** |
| 当前仿真器迟滞效应很弱 | exp5: 迟滞环极窄, HA-EMA无显著优势 | **中** |
| 高频位置编码分量不可省略 | nb07: 频率消融每级贡献2-7% | **高** |

### 3.2 什么尚未证实

| 问题 | 状态 | 需要什么 |
|------|------|---------|
| 物理先验+渐进训练能否改善纯2D | 未验证 (exp1b 未运行) | 运行 exp1b |
| 多视角能否消除深度歧义 | 仅分析了误差分布, 未训练 | 双视角训练实验 |
| DR对渲染鲁棒性的提升 | 评估有bug, 未正确验证 | 运行 exp4b |
| HA-EMA在强迟滞条件下是否有效 | 当前仿真器迟滞太弱 | 增大阻尼参数或用真实数据 |
| 真实世界数据能否迁移 | 未开始 | 真实机器人+相机 |

### 3.3 当前最大的瓶颈

**瓶颈 1: 单视角深度歧义 (最严重)**

exp1+exp2+exp3 一致证实：单视角的 Z 轴误差是核心问题。
- exp2: Z 误差从 0.020m → 0.245m (12.3x)
- exp1: Z 误差占 85%
- 即使有 3D GT 训练, exp3 也显示深度方向误差最大(41%)

**解决路径**: 多视角训练是最直接的方案。理论上两个正交相机可以完全消除深度歧义。

**瓶颈 2: 仿真器迟滞太弱 (影响创新点)**

exp5 显示 HA-EMA 与 StandardEMA 差异仅 3.3%，且迟滞环极窄。
- 如果论文以迟滞建模为核心创新, 必须在有明显迟滞的场景中验证
- 选项: (a) 增大 PyElastica 阻尼, (b) 使用粘弹性材料模型, (c) 直接在真实机器人上验证

**瓶颈 3: 纯2D训练不收敛 (影响自建模定位)**

exp1 和 exp2 的 2D-only 模型 MNE 都在 0.3m 量级, 与 3D GT 的 0.06m 差距巨大。
- 需要验证 exp1b 的渐进式策略能否改善
- 如果仍不行, 则论文应承认需要多视角或弱 3D 先验

这是验证"纯2D能否工作"的关键实验。如果 exp1b 的 MNE 降到 0.15m 以下，说明物理先验+渐进训练可以部分替代 3D GT。

确认 DR 对渲染质量的鲁棒性提升, 为 sim-to-real 做准备。

基于 exp3 的分析, 实现双视角渲染 loss, 验证多视角能否消除深度歧义。
