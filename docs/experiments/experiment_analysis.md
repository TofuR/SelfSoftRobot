### 1.2 核心发现

**发现 1: 3D GT 监督至关重要**

MS-SCNF (3D GT) 的 MNE 为 0.059m，而纯 2D 渲染 loss (exp1) 为 0.313m。
差距 **5.3 倍**，说明单视角 2D 渲染 loss 无法提供足够的 3D 约束。

**发现 2: 深度方向是主要误差来源**

exp3 多相机分析:
- X 轴 (正面相机深度方向): 占总误差 **41.1%**
- Y 轴 (侧面深度方向): **32.2%**
- Z 轴 (垂直方向): **26.7%**

相机视线方向的误差最大 → 深度歧义是核心问题。

**发现 3: 线性变形更平滑但精度不足**

nb06 结果:
- 线性变形的时序抖动比 MLP 低 **71%** (0.0021 vs 0.0073)
- 但空间精度差 **25.7%**
- 结论: MLP 非线性是必要的，但需要约束

**发现 4: 课程频率训练不充分**

nb07 结果:
- C2F 只跑到 epoch 20，频率只激活到 3/6
- 频率消融实验显示每个额外频率贡献 2-7% 的 MSE 改善
- 高频分量 (5,6) 贡献最大 (7%)，不可省略
- C2F 的时序抖动反而比固定频率差 73%

**发现 5: 域随机化噪声评估有 bug**

exp4 所有噪声水平的 MNE 完全相同 (精确到小数点后 6 位)，
说明噪声增强在评估时未正确应用。

## 2. 问题根因分析

### 2.1 为什么纯 2D 渲染 loss 训练不好

渲染 loss 的梯度路径:
```
rendering loss → OM_rendering → density MLP → distance to skeleton → skeleton positions → temporal encoder
```

这是一条 **5 层以上的间接梯度路径**:
1. density MLP 的 softplus + exp 非线性造成梯度消失/爆炸
2. distance-to-skeleton 在远距离梯度接近零
3. 10000 个像素 × 32 samples = 320000 个点，但只有 ~200 个点在杆附近有非零梯度
4. 单视角的深度维度几乎无约束

### 2.2 为什么课程频率效果不好

- 训练只跑了 20 epochs（设计是 40+ epochs）
- 低频率阶段还没收敛就进入下一阶段
- 频率切换时损失函数突变，破坏已学习的表示

### 2.3 域随机化评估 bug

`evaluate()` 函数中 `augment_fn` 只应用于 GT 图像，但骨架评估不受图像噪声影响。
MNE 是基于 GT 3D 位置的，与图像无关 → 噪声不影响结果。
